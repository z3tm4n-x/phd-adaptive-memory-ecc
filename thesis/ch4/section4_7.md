## 4.7. Выводы по главе 4

Предложен порядок выбора контроля долгоживущих данных по требованию к вероятности неисправимой ошибки за срок службы. Из системного допуска выделяются доли на прямое поражение одного слова и накопление ошибок от разных частиц. Пройдёт ли режим проверку по накоплению, зависит от временно́го профиля инверсий, их распределения между полными словами и момента, когда исправление станет известно контроллеру. Поэтому режимы сравниваются по затратам после проверки надёжности, при одинаковых условиях памяти, наблюдений и обслуживания.

Ужесточение допуска увеличивает число обязательных проходов постоянного режима. Лестница может сохранять редкий обход, пока это разрешают полные нулевые отчёты. На трёх проектных картах с разносом половин на полпрохода при четырёх допусках это даёт преимущество лестнице в пяти из двенадцати случаев, постоянному режиму — в двух. В двух случаях интервалы затрат допустимых режимов пересекаются, в двух доказана допустимость только постоянного режима, в одном исключены оба. При 64 КиБ и допуске $10^{-3}$ преимущество по ожидаемой занятости подтверждено при **любой** карте пар — не менее 8,5619 раза для расчётного класса ГСО. На 128 КиБ общая гарантия для лестницы также сохраняется, а для дополнительного требования оставить три четверти допуска после оценки непрерывного обхода достаточно установить охват не менее 21 007 полных пар.

На 256 КиБ уже сам вывод о допустимости зависит от размещения. Для проектных пар $(w,w+65\,536)$ учёт двух фаз чтения и завершённой записи дал $Q_{\rm нак}(T)\le6{,}78\cdot10^{-4}$ за десять лет при допуске $10^{-3}$. При штатном регистровом управлении и отсутствии дополнительных потерь истории любой допустимый постоянный период требует в ожидании не менее 28,156 млн с защитного порта, а для лестницы получен верх 1,974 млн с. Отношение исходных границ — не менее 14,26 раза. При той же карте и выборе одного постоянного периода только для принятых реконструкций гарантированное отношение составляет не менее 3,249 раза. Если до выбора известна конкретная история GOES, на проверенных реконструкциях для 64 КиБ меньшей занятости уже достигает постоянный режим.

Для проектной карты 256 КиБ на ПЛИС реализованы постоянный период 86,429 мс и восемь ступеней управления по ERR. В цифровой модели подтверждены чтение обеих половин всех 65 536 слов, исправляющая запись, полнота отчёта и следующий фактический старт прохода. При одинаковой защите трёх копий и конфигурационной памяти лестнице дополнительно требуются 558 логических таблиц и 186 регистров. Полезное чтение в отдельном слоте получает правильные данные с той же задержкой. Таким образом, подтверждённый выигрыш относится к ожидаемому времени внешнего порта. Для оценки энергии и затрат восстановления необходимы данные о фактической активности и отказах.

Применение к изделию требует подтвердить пространственный закон поражений либо достаточную для данного обслуживания нижнюю частоту обнаруживаемых частиц при сохранении верха частоты касаний каждого слова. Требуются также оценка прямых поражений полного слова, наблюдаемость ошибок скрытых позиций и результат записи при новом попадании. Для проекта 256 КиБ дополнительно устанавливается карта пар. У ПЛИС общий пропуск выборки ERR способен лишить все три копии сведений об одной ошибке. Поэтому сроковую долю $6\cdot10^{-6}$ для исключений исполнения проверяют по физическим частотам и совместности повреждений, их последствиям и времени восстановления каждого из сравниваемых контроллеров.
