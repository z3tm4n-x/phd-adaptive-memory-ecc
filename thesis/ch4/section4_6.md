## 4.6. Проверка на реконструированных профилях

При выборе постоянного периода важно, какие сведения о будущей обстановке доступны проектировщику. Период можно назначить для всего класса профилей ГСО, для более узкого множества принятых архивных реконструкций либо для одного заранее предъявленного профиля. Лестница во всех трёх случаях изменяет период только по отчётам, полученным во время работы.

Сначала сравним две постановки, в которых требуется один постоянный период для целого множества профилей. На одной и той же карте 256 КиБ при разносе половин на полпрохода гарантированное сокращение ожидаемой занятости составляет не менее 14,26 раза для класса ГСО и не менее 3,249 раза для множества реконструкций. Сужение множества позволяет постоянному контроллеру реже посещать память. Оба отношения получены по нижней границе затрат любого допустимого постоянного периода и верхней границе лестницы при штатном управлении ($I=X=0$). [Численные границы для двух множеств профилей](appendix_chapter4.md#archive).

**Что наблюдается на одной истории.** Сравним конкретные допустимые постоянные периоды и лестницу на солнечных протонных рядах. Обе половины каждого слова читались с разносом на полпрохода у обоих контроллеров. Для каждого из объёмов 64 и 256 КиБ построены 128 реализаций частиц на каждый профиль с основной смесью одиночных и соседних двухсловных поражений. В паре сопоставляемых реализаций контроллеры получают одни и те же частицы, но каждый наблюдает ERR только при собственных чтениях. Использованы номинальные часы и штатные отчёты. В занятость вошли пуск и всё последующее обслуживание до конца срока, включая запись, после которой может сохраниться новая ошибка.

Одна история представляет собой непрерывный пятиминутный ряд SEPEM с 16 декабря 1996 г. 07:20 по 16 декабря 2006 г. 19:20 UTC. Восемь реконструкций GOES включают два направления пятиминутного ряда и по два направления минутных рядов GOES-16, 18 и 19. Их горизонт длится с 1 января 2017 г. 00:00 по 1 января 2027 г. 12:00 UTC. Измерения учтены до 9 ноября 2026 г., пропуски и хвост до конца горизонта заполнены по принятому правилу. [Построение рядов](appendix_chapter4.md#temporal).

**Сколько раз менялся период.** На 256 КиБ в десятилетии SEPEM зарегистрировано в среднем по выборке 11 590,53 возврата с редкой ступени на $L$. Все переходы отдельно не записывали. Каждому возврату предшествовало от одного до семи повышений. После последнего возврата возможны ещё до семи. Поэтому при $R$ возвратах число смен периода $S$ удовлетворяет $2R\le S\le8R+7$. Для среднего по 128 реализациям это даёт границы 23 181–92 732 с округлением наружу. Установка периода при пуске учтена отдельно.

**Когда доступен весь профиль.** Для 64 КиБ на заранее предъявленной истории SEPEM проверен постоянный период около 2,20 с. В парном опыте средняя занятость такого контроллера составила около 471 тыс. с, лестницы — около 240 тыс. с. На восьми отдельных реконструкциях GOES знак сравнения меняется. Для каждой из них найден свой допустимый постоянный период от 84 до 1 803 с с округлением до целых секунд. Даже наибольший из верхов ожидаемой занятости этих постоянных кандидатов меньше 13,6 тыс. с, тогда как для лестницы требуется не менее 174 тыс. с. Здесь преимущество постоянного режима следует уже из границ на каждой предъявленной истории. При проектировании для будущего воздействия такое решение применимо лишь при сопоставимом объёме предварительных сведений.
