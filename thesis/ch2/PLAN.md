## 0. Место главы

- **Решает задачи паспорта 1 и 2**, обеспечивает **положение 1**. Формулировки паспорта в главе не пересказываются.
- **Сквозной сюжет.** Сбои возникают случайно с меняющейся интенсивностью → неисправимая ошибка возникает двумя путями: одна частица сразу или накопление между проверками → вклад накопления при принятых условиях ограничен величиной, пропорциональной интегралу квадрата интенсивности и времени без проверки, поэтому решают редкие сильные события → для расчёта нужны обстановка, частота сбоев памяти, устройство её слов и то, как память сообщает об ошибках.

### 2.1. Радиационная обстановка и расчётные условия (6 с.)

**2.1.1. Источники частиц и изменчивость интенсивности (1,5 с.)**
- Галактические космические лучи — фон, медленно меняющийся с циклом солнечной активности; солнечные протонные события — редкие сильные эпизоды. [ЛИТ: ГОСТ Р 25645.165-2025; ОСТ 134-1044-2007; COSRAD; Подзолко 2017 — сверить].
- Масштаб изменчивости для сквозного примера: при защите 3 г/см² отношение пика к фону в условном конверте около N2.1-ratio раз. [НАШ, T141; условный конверт, не физическая квантиль].
- Рисунки и таблицы: Т2.1.

**2.1.2. Расчётные условия по ГОСТ и ОСТ (1,5 с.)**
- Смысл расчётных потоков, не превышаемых с вероятностью 0,9: это отдельные уровни отдельных характеристик (пик, флюенс), а не совместная квантиль траектории отклика памяти. [ЛИТ: ГОСТ — сверить обозначения и редакцию по первоисточнику].
- Произведение раздельных уровней не является совместной квантилью; совместный уровень ∫λ²dt при вероятности превышения 0,1 для сквозного примера не установлен. [НАШ, T127; ОГР, T141: physical_q90 = null].
- Условное и безусловное требования: если среда лежит в расчётной области с вероятностью не меньше 1 − δ_ср, а условная вероятность превышения не больше Q_усл, то достаточно δ_ср + Q_усл ≤ Q_доп. Уровень превышения расчётного спектра и доверительный уровень сечения не становятся такими слагаемыми по совпадению чисел. [НАШ, T52 §1 п. 7].
- Исторический ряд не гарантирует будущее и не равен сигналу, доступному на борту. [ОГР].
- Рисунки и таблицы: Т2.1.

**2.1.3. Допустимая обстановка через предельные величины (1,5 с.)**
- Модель: λ(t) = λ_ф(t) + λ_с(t); 0 ≤ λ_ф(t) ≤ λ̄_ф; λ(t) ≤ λ_пик; ∫λ_с dt ≤ N_соб — **(2.1)**. Ограничение роста H_ℓ(λ(t)) − H_ℓ(λ(u)) ≤ ρ(t − u) с порогом ℓ: ниже порога ограничен абсолютный рост, выше — относительный; падение не ограничено, начальный пик допустим, повторный подъём подчиняется тому же ρ — **(2.2)**. [ОПР; НАШ как класс: T45 §1, T52 §1 (1), T114 A1].
- Следствие: F ≤ min(λ_пик T, λ̄_ф T + N_соб), S₂ ≤ min{λ_пик² T, λ_пик F, λ̄_ф² T + (λ_пик + λ̄_ф) N_соб} — **(2.3)**; при свободном начале граница точна (пик первые L секунд, затем фон), поэтому одно ограничение роста глобальный S₂ не уменьшает. [НАШ, T52 §2 (2); [?] — вопрос П3].
- Инженерный смысл: обстановка задаётся пятью числами; среднее значение интенсивности S₂ не определяет.
- Пример (две раздельные строки): прежний условный класс — N2.1-old1…old5; новый конверт — N2.1-b30, -p30, -F30, -S30. Не смешивать.
- Рисунки и таблицы: Т2.2.

**2.1.4. Временная структура вспышек по GOES и SEPEM (1,5 с.)**
- Коэффициент формы события κ = S₂,с/(λ_пик N_соб) ≤ 1; κ = 1 — прямоугольная форма, верх при заданных пике и экспозиции. Распределение κ по эпизодам SEPEM. Модельная форма при тех же b, p, F снижает S₂ на N2.1-sh2 % — это модель с допущением переноса формы, не физический уровень. [НАШ, T141 METHOD, T150; область — параметрическая].
- Многособытийность: N2.1-ev1 событий за 10 лет по выборке эпизодов против N2.1-ev2 по модели ГОСТ на том же интервале; расхождение не объясняется одной заменой цикла. [НАШ, T127; [ЛИТ] SEPEM RDS v2.00 (ESA, 2016)].
- Нарастание по минутным данным GOES: исторические максимумы скорости в шкале H_ℓ (N2.1-g2…g4); пример случая 19.01.2026 со временем роста в e раз около N2.1-g1 с. Это не граница класса. [НАШ, T113 — инженерное дополнение без полной научной рецензии, подаётся как данные; ЛИТ: данные GOES SGPS, NOAA].
- Отклик в этих рядах — data32/протоны/10 мм Al, не полный вход сквозного примера. [ОГР].
- Рисунки: Р2.1 (вспышка по GOES с допустимыми рамками), Р2.2 (распределение κ), Р2.3 (чувствительность к числу событий).
- Итог раздела.

### 2.2. От потоков частиц к частоте сбоев (6 с.)

**2.2.1. Свёртка спектра с сечением (1,5 с.)**
- R(t) = Σ_a ∫∫ φ_a(E, Ω, t) σ_a(E, Ω) dE dΩ — **(2.4)**; нормировка результата (на бит, слово, прибор) наследуется от сечения; для всенаправленного потока множитель 4π повторно не вводится. [ЛИТ: стандартный метод — источник подобрать и сверить; НАШ: проверка нормировок, T141].
- Геометрический коэффициент протонного отклика a_H (1/2 или 1) — параметр: переход 1/2 → 1 при 3 г/см² даёт N2.2-d05 → N2.2-d06 с⁻¹. [НАШ, T141; ОГР: физически не разрешён].
- Рисунок: Р2.4 (цепочка расчёта).

**2.2.2. Перенос через защиту (1 с.)**
- Разные операторы переноса (готовый COSRAD после Al и CSDA по ГОСТ на той же сетке) дают разные пики при одном сечении. [НАШ, T141 spectra-transfer; числа добавить в таблицу при написании].

**2.2.3. Механизмы сбоев (1,5 с.)**
- Тяжёлые ионы (сечение от ЛПЭ), протоны высоких энергий (ядерные реакции), прямая ионизация протонами низких энергий. [ЛИТ: Coronetti и др. 2020, 2021; Боруздина и др. 2014; Красников и др. 2018 — сверить применимость].
- Для CY62167: максимум прямой ионизации при 0,8–1 МэВ перед верхними слоями металлизации, около N2.2-x1 см²/бит против N2.2-x2 для протонов высоких энергий (N2.2-xr раз). Энергия указана до слоёв металлизации, а не в чувствительном объёме; угловые измерения отсутствуют. [ЛИТ: Coronetti 2021].
- Нельзя переносить сечение между образцами без основания. [ОГР].
- Рисунок: Р2.5 (сечение от энергии) — данные не в репозитории, см. GAPS В9.

**2.2.4. Результат для сквозного примера (1 с.)**
- Последовательная замена одного компонента на общих входах при 3 г/см²: N2.2-d00 → d01 → d02 → d03 → d04 → d06 с⁻¹ (Т2.3, Р2.6). [НАШ, T141; порядок замен не даёт единственной физической атрибуции].
- **Утверждённая формулировка:** при тех же входах учёт протонов низких энергий увеличивает ∫λ²dt примерно в 6 раз (N2.2-ratio) и делает достаточную оценку непроходной: часть выражения без D уже не меньше N2.2-Q30 > Q_доп. Это не нижняя граница Q(T) и не невозможность. [НАШ, T127].

**2.2.5. Сбой, затронутые разряды, касание слова, исправление (1 с.)**
- Различаются: родительское событие (λ — на весь массив), метка (множество изменённых позиций), касание слова, прямое событие (не менее t_код + 1 позиций одного слова), зарегистрированная группа в испытаниях, исправление. Число сигналов исправления зависит от проверки и исправления и не является ещё одной нормировкой того же интеграла. [ОПР; НАШ: T36 §1 п. 2, T89 §1].
- Пересчёт data32 → полное слово множителем 38/32 — допущение равной чувствительности проверочных разрядов. [ОГР].
- Таблица: Т2.4. Итог раздела.

### 2.3. Организация памяти и корректирующая способность кода (5 с.)

**2.3.1. Кодовое слово и событие отказа (1 с.)**
- Слово из n разрядов, из них n_и информационных; корректирующая способность t_код. SEC- и SEC-DED-коды. [ЛИТ: Hsiao 1970].
- Событие A_T: хотя бы раз хотя бы в одном слове число ошибочных разрядов больше t_код; Q(T) = P(A_T) — **(2.5)**. Определение вводится здесь, свойства — в 2.6.1. [ОПР; паспорт].
- Варианты слова: внутреннее 32+6 у CY62167 с сигналом исправления по документации изготовителя; внешнее SEC-DED (39, 32) — в примере большой памяти; только 32 информационных разряда — модели главы 3. Области результатов не переносятся между вариантами. [ЛИТ: документация CY62167 Rev F, AN88889]. Таблица Т2.5.

**2.3.2. Отображение адресов на ячейки (1,5 с.)**
- По открытым данным испытаний CY62167 (Zenodo 10.5281/zenodo.8314389) восстановлено аффинное отображение физических координат во внешние адреса ×8: ранг N2.3-a2, проверка без расхождений на N2.3-a1 записях. [НАШ, RE-CY62167-ADDRESS-MAPPING-01; MAP «CY62167: проверенный задел»; ЛИТ: метод восстановления по статистике адресов — источники подобрать, GAPS, вопрос П10].
- Группировка во внутренние слова и проверочные разряды не восстановлена. [ОГР].
- Условие пары x16-адресов: при известной паре проход охватывает 2¹⁹ слов; без неё консервативный обход 2²⁰ адресов удваивает число операций; запас N2.3-al % от Q_доп этого не покрывает. Это утрата достаточного расчёта, а не доказанное нарушение. [НАШ/решение автора 12.10.2026; протокол опыта — 2.7].
- Рисунок: Р2.7.

**2.3.3. Многократные сбои от одной частицы (1,5 с.) — учебный пример**
- Несколько затронутых ячеек от одной частицы; несколько ошибок в одном слове; перемежение. [ЛИТ: Maiz 2003; Gasiot 2007; Giot 2008; Baeg 2009; Reviriego 2010 — сверить]. Рисунок Р2.8 — схема двух случаев.
- **Учебный пример (решение автора 1а).** Четыре слова, t_код = 1, каждое событие задевает ровно два слова по одному новому разряду. Одинаковые вероятности воздействия на каждое слово не определяют Q(T): q = 2(a² + c² + e²) ∈ [1/6, 1/2]; S(q, m) = e^{−m}(1 + m + q m²/2), Q = 1 − S^k — **(2.6)**; точное множество [Q(q = 1/2), Q(q = 1/6)], обе границы достигаются. Таблица решений (Т2.6, N2.3-r…) и Р2.9 из data/res001_exact.csv. Моделирование подтвердило значения в пределах заданной полуширины N2.3-mc. [НАШ, RES-001 при всех 14 условиях].
- Инженерный смысл: нужная полнота данных зависит от решения; при ε = 0,55 различие множества выбор не меняет.
- Оговорка: в примере очистка мгновенная и синхронная; последовательный обход — в 2.5. [ОГР].

**2.3.4. Корректирующая способность t_код ≥ 1 (1 с.)**
- Избыточность и цена декодирования растут с t_код; сравнение силы кода, периода проверки и долгоживущих данных известно. [ЛИТ: Hansen и др. 2025; Reviriego и Maestro 2009 — сверить].
- Таблица Т2.7 «доказано для общего t_код / посчитано условно / не исследовано»: общее — только определения (2.5); условных расчётов для t_код ≥ 2 нет; оценки для t_код ≥ 2 не исследованы (план исследования 3.4, 05–10.11). Внутренний код CY62167 не перенастраивается. [ОГР].

### 2.4. Профиль использования и время хранения данных (3,5 с.)

**2.4.1. Долгоживущие и часто перезаписываемые данные (1 с.)**
- Код, ядро, таблицы хранятся долго и редко переписываются; редкое чтение приложением не обосновывает редкий контроль. [ЛИТ: Hansen 2025; ОПР].

**2.4.2. Перезапись: восстановление слова и потеря сведений (1 с.)**
- Чтение с исправленной выдачей, запись исправленного образа и логическая запись новых данных — разные операции; последняя меняет правильный образ. [ОПР].
- Ненаблюдаемая запись может стереть единственную ошибку без сигнала; поэтому в модели с записями приложения перед записью читается одно из парных слов с полным сигналом исправления; цена — N2.5-wr. [НАШ, T114 §3; условный договор].

**2.4.3. Защищаемые данные и событие отказа (0,75 с.)**
- Q(T) относится к объявленному множеству защищаемых данных; смена множества меняет событие. [ОПР].

**2.4.4. Проверка только нужных областей — ограничение (0,75 с.)**
- Нужны правила включения и исключения областей, инициализации, остаточных ошибок и счётчика; простая замена W меньшим числом гарантию не переносит. [ОГР; план исследования 3.5, 11–17.11].
- Пример: профиль сквозного примера без записей приложения в защищаемой области и вариант с наблюдаемыми записями — раздельно. Таблица Т2.8. Итог раздела.

### 2.5. Последовательный контроль и регистрация исправлений (6 с.) — пилотный раздел

**2.5.1. Как идёт обход (1 с.)**
- Период P, длительность прохода T_пр ≤ P, известные фазы чтения r_w и окончания исправления v_w ≥ r_w каждого слова; одно чтение за проход. [НАШ как договор модели: T36 §1 п. 5, T45 §1 п. 3].
- Пример календаря: кадры по 8 слов, наименьший период в семействе P_мин ≤ N2.5-P с; чтение без исправления ≤ N2.5-R нс, с исправлением ≤ N2.5-E нс. [НАШ, T110, T114 §2, T127; проектные верхние границы, не измерения]. Таблица Т2.9; временная диаграмма — Р2.10.

**2.5.2. Когда ошибка становится видна (1 с.)**
- Ошибка видна только при чтении своего слова; задержка обнаружения — до следующего чтения этого слова. [ОПР].
- Ошибки, пришедшие в уже прочитанные слова, остаются после конца прохода: завершённый проход не даёт чистого начала. [НАШ, T36 §§1, 3].
- Разбиение наблюдаемого числа на старый остаток, поступления до прохода и в ещё не прочитанные слова, и новый остаток — **(2.7)**. [НАШ, T36 §2; RES-003 вывод].
- Рисунок: Р2.11.

**2.5.3. Свойства сигнала исправления (1,5 с.)**
- Число выявленных ошибок зависит от ранее выбранного периода — через остаток и поступления до прохода. [НАШ, T36; [?] — вопрос П7].
- Повторные сигналы: повторное чтение неисправленного слова и второй адрес той же пары — не новое событие; после исправления новое раскрытие остатка не обязательно новая частица; одно событие может дать сигналы в нескольких словах. [НАШ, T114 §2, A3].
- Три варианта обслуживания: безусловная запись; запись после исправимой ошибки; запись по сигналу исправления. При записи по сигналу к концу операции удалены старые ошибки, но новые попадания во время операции остаются — отдельный член X. [НАШ, T52 §§1–3; T110 §1 п. 4, §3]. Таблица Т2.10.
- Двойная ошибка показана на Р2.10 (обход — ошибка — чтение — исправление — двойная ошибка).

**2.5.4. Что можно и нельзя заключить об обстановке (1,5 с.)**
- Счёт исправлений не равен счёту поступлений; вспомогательная система с метками совпадает с реальной до первого разрыва сопряжения, и A_T ⊆ {τ_разр ≤ T} — **(2.8)**. [НАШ, T36 §2].
- Нулевой счёт не удостоверяет малую текущую интенсивность. [НАШ, T45].
- Вывод о спокойной обстановке по отсутствию сигналов требует нижнего канала наблюдения (доля непрямых событий не меньше a, многословных не больше ζ); он не следует из верхнего сечения. [НАШ, T114 A3; T89].
- Счёт по словам не определяет Q(T) — ссылка на учебный пример 2.3.3. [НАШ, RES-001].
- **Проверка (шаблон 4.4, п. 7):** численные условия календаря и времени независимо проверены рецензией T110 (123 условия) — это проверка расчёта, не физическое измерение. Проверку модели наблюдения на малой памяти можно добавить в задачу оркестратора (GAPS В1).
- **Условия применимости:** нет непредусмотренных записей; известные фазы; атомарное исправление; защищённый кодек; полный сигнал исправления — условие, физически не подтверждённое (T110 §1 п. 4).
- Пример — только вариант с записью по сигналу. Итог раздела.

### 2.6. Оценки вероятности превышения корректирующей способности (7 с.) — пишется последним

**2.6.1. Свойства показателя Q(T) (0,75 с.)**
- Первое превышение за срок; состоявшееся событие не отменяется исправлением; не равно отказу системы, обнаруженной двойной ошибке или состоянию в конце срока. Среднее время до отказа Q(T) не заменяет. [ОПР; ЛИТ: марковская модель у Hansen 2025 — для сопоставления].
- Аддитивная форма −ln(1 − Q) не используется без отдельного доказательства. [ОГР, MAP «Магистерская и статья»].

**2.6.2. Две составляющие (1 с.)**
- Вне оплаченных квот первое превышение имеет одного из трёх свидетелей: прямую метку, касание изначально грязного слова, пару новых событий; объединение событий даёт сумму. Замена суммы на 1 − e^{−U} без нового основания запрещена. [ЛИТ: раздельный учёт накопленных и кластерных ошибок — Lee, Baeg, Reviriego 2011; НАШ: включение для последовательного обхода с конечным исправлением, T52 §3, T110 §3].

**2.6.3. Квадратичная зависимость (1,5 с.)**
- Известно: при постоянной интенсивности вероятность пары растёт как квадрат числа поступлений за интервал. [ЛИТ: Saleh и др. 1990; Tausch 2009].
- Для меняющейся интенсивности и интервалов каждого слова: ½ Σ η_w M_J² ≤ ½ χ P S₂ — **(2.9)**; при равномерных одиночных попаданиях χ = (n − 1)/(nW). [НАШ, T52 §2 (3); [?] — вопрос П2].
- Область применимости: независимые метки разных событий; для формулы χ — одиночные равномерные попадания; иначе χ = Σ q_w². [ОПР].
- Рисунок: Р2.12.

**2.6.4. Достаточная верхняя оценка при постоянном периоде (1,5 с.)**
- U(P) = δ_нач + δ_исп + 1 − e^{−dF} + k₀ min(F, λ_пик P) + ½ χ P S₂ + X + S_обсл — **(2.10)**; X для записи по сигналу — **(2.11)**. Допустимые периоды находятся объединением не более 42 интервалов. [НАШ, T52 (7) и §5; T110 (3)]. Условия применимости — Т2.11: условие → основание → проверка → последствие нарушения.

**2.6.5. Необходимая нижняя оценка (1 с.)**
- p⁻(h) = C(n, 2) λ_р² h² e^{−n λ_р h} — **(2.12)**; Q(T) ≥ 1 − exp(−Σ p⁻) по непересекающимся ячейкам без обслуживания — **(2.13)**. Исключает постоянный класс только в своей области; для адаптивных расписаний нужно отдельное доказательство. [НАШ, T45 §2; [?] — вопрос П5].
- Между оценками — «по имеющимся данным не установлено». [ОГР].

**2.6.6. Проверка точным расчётом и моделированием (1 с.)**
- Ждёт задачи оркестратора (GAPS В1). Сейчас точный расчёт и моделирование есть только для учебной модели 2.3.3 (другая модель обслуживания). Рисунок Р2.13.

**2.6.7. Сквозной пример и пример большой памяти (1 с.)**
- CY62167, ГСО, 10 лет, 3 г/см², постоянный период P_мин, запись по сигналу; прежние условные входы: U ≤ N2.6-Qu ≤ Q_доп; составляющие — пары N2.6-pr (N2.6-sh %), D = N2.1-D, начало N2.6-in, незавершённое исправление N2.6-ap, квоты N2.6-qt; наибольшее допустимое D — N2.6-Dm. [НАШ, T127 service.json].
- Отдельная строка — входы с прямой ионизацией: часть без D ≥ N2.2-Q30 > Q_доп; достаточная оценка не проходит; вывод «не установлено», не невозможность. [НАШ, T127].
- Отдельный пример — большая память с внешним кодом (39, 32), диагностический класс: достаточный период N2.6-L1 с при загрузке ≤ N2.6-L3 %; для W = 1 935 832 нижняя оценка ≥ N2.6-L2 > 0,01 исключает только объявленный постоянный класс с безусловной записью. [НАШ, T58].
- Рисунок Р2.14, таблицы Т2.12–Т2.13. Итог раздела.

### 2.7. Требования к исходным данным и проверка модели наблюдения (4 с.)

**2.7.1. Состав испытаний и характеристик (1,5 с.)**
- Организация слова с проверочными разрядами и группировкой адресов; многократные события по словам; прямая ионизация протонами низких энергий; испытание с включённой коррекцией и регистрацией сигнала; наклонное падение. Для каждого — какое решение поддерживает (Т2.14). [НАШ, T89, T81; ЛИТ: практика испытаний — подобрать].
- Требование к прямым событиям: E N_D ≤ R + Σ_j C_j σ_j и закон нулевого счёта P{N_j = 0} ≤ e^{−E_j σ_j} — **(2.14)**; добавочный флюенс — **(2.15)**. D₀ = N2.7-D0 — заданная точка автора, не измерение. [ЛИТ: предел при нулевом счёте; НАШ: композиция T89 §§1–4; [?] — вопрос П9].
- Для внутреннего слова CY62167 полное D неизвестно: нулевые наблюдения относятся к 32 информационным разрядам. [НАШ, T81].

**2.7.2. Как недостающие сведения меняют решение (1 с.)**
- Таблица Т2.15: неизвестная группировка адресов → удвоение прохода; допущение 38/32; пропуск прямой ионизации → достаточность теряется; только сведения по словам → множество значений Q(T); нет нижнего канала → нулевой счёт ничего не удостоверяет; неизвестные полнота регистрации и нормировка → требование к флюенсу неизвестно; рост экспозиции не восстанавливает группировку. [НАШ: RES-001, T89, T127, T114].
- Короткий опыт по сигналу исправления для проверки пары адресов — требование, опыт не выполнен. [ОГР, решение автора 12.10.2026].

**2.7.3. Сверка с полётными счётчиками — план и ограничение (1 с.)**
- Сравнивается прогноз наблюдаемого счёта, а не поток частиц с числом исправлений; сначала совпадают устройство, код, охват, расписание, смысл счётчика, насыщение и сброс, пропуски, интервалы регистрации. Кандидаты — Solar Orbiter (SWA-HIS) и Venus Express по [Sánchez-Cano и др., 2023]. Сверка не выполнена (план 3.9: 26.10–06.11); если к моменту написания будет готова — включается в своей области. [ЛИТ; ОГР]. Таблица Т2.16. Итог раздела.
