### 2.1. Радиационная обстановка и расчётные условия (6 с.)

**2.1.1. Источники частиц и изменчивость интенсивности.** ГКЛ — фон; солнечные протонные события — редкие сильные эпизоды [ЛИТ: ОСТ 134-1044-2007, 5.1, 6.4–6.6, прил. Б, Г — по копии; ГОСТ Р 25645.165-2025 — сверить; COSRAD; Подзолко 2017 — сверить]. Масштаб изменчивости в условном конверте сквозного примера при 3 г/см²: отношение пика к фону около N2.1-ratio раз [НАШ, T141; не физическая квантиль]. Т2.1.

**2.1.2. Расчётные условия по ГОСТ и ОСТ.** Расчётные уровни — отдельные уровни отдельных характеристик: характеристики СКЛ задаются при вероятности 0,1 их превышения за срок активного существования; для сбоеустойчивости — спектры максимальных (для СКЛ — пиковых) плотностей потоков и показатель «допустимая частота сбоев»; временного профиля и совместного уровня траектории норма не задаёт; по РД 134-0139-2005 показатель сбоеустойчивости — частота сбоев ν ≤ ν_сб.доп при максимальных потоках, раздельно для «обычного» (ГКЛ, ЕРПЗ) и «экстремального» (СКЛ) режимов, а вероятность за срок вычисляется только для отказов по средним потокам [ЛИТ: ОСТ 134-1044-2007, 6.2, 6.6, 7.3.1, прил. Б; РД 134-0139-2005, 4.8, 5.1–5.2, 5.6 — по копиям; ГОСТ — сверить]; произведение раздельных уровней не является совместной квантилью; совместный уровень S₂ при вероятности превышения 0,1 не установлен [НАШ, T127; ОГР, T141]. Условное и безусловное требования: δ_ср + Q_усл ≤ Q_доп при обоснованном покрытии среды [НАШ, T52 §1 п. 7]. Исторический ряд не гарантирует будущее и не равен бортовому сигналу [ОГР]. Т2.1.

**2.1.3. Допустимая обстановка через предельные величины.** λ(t) = λ_ф(t) + λ_с(t), 0 ≤ λ_ф(t) ≤ λ̄_ф, λ(t) ≤ λ_пик, ∫λ_с dt ≤ N_соб — **(2.1)**; H_ℓ(λ(t)) − H_ℓ(λ(u)) ≤ ρ(t − u) — **(2.2)** [ОПР; НАШ как класс: T45 §1, T52 §1 (1), T114 A1]. Здесь λ — интенсивность родительских событий; для моделей с внутренним кодом та же форма задаётся для интенсивности касаний слов ν, а в радиационной цепочке — для частоты битовых инверсий λ_инв; эти интенсивности не отождествляются без закона кратности. Вычислимые верхи F̄ = min(λ_пик T, λ̄_ф T + N_соб) и S̄₂ = min{λ_пик² T, λ_пик F̄, λ̄_ф² T + (λ_пик + λ̄_ф) N_соб}, причём F ≤ F̄, S₂ ≤ S̄₂ — **(2.3)**; при свободном начале граница достижима [НАШ, T52 §2 (2); [?] П3]. Пример — две раздельные строки: прежний условный класс (N2.1-old1…old5) и конверт цепочки с прямой ионизацией (N2.1-b30, -p30, -F30, -S30). Т2.2.

**2.1.4. Временная структура вспышек.** Коэффициент формы κ = S₂,с/(λ_пик N_соб) ≤ 1 [НАШ, T141 METHOD]; модельная форма при тех же входах снижает S₂ на N2.1-sh2 % — модель с допущением переноса формы [НАШ, T150]. Многособытийность: N2.1-ev1 (выборка) против N2.1-ev2 (модель ГОСТ) событий за 10 лет [НАШ, T127; ЛИТ: SEPEM RDS v2.00]; для среднего цикла (табл. Г.1 ОСТ) — N2.1-mu1 по ГОСТ Р 25645.165-2025 и N2.1-mu2 по формуле (Б.2) ОСТ; разные нормативные формулы, GAPS Б14–Б15. Нарастание по минутным GOES: максимумы N2.1-g2…g4, время роста в e раз N2.1-g1 с — исторические данные, не граница класса [T113 — инженерное дополнение, подаётся как данные]. Р2.1, Р2.2.

### 2.2. От потоков частиц к частоте сбоев (6 с.)

**2.2.1. Свёртка спектра с сечением.** При сечении на бит λ_бит(t) = Σ_a ∫∫ φ_a(E, Ω, t) σ_a,бит(E, Ω) dE dΩ — частота инверсий одного бита; частота инверсий массива λ_инв(t) = N_бит λ_бит(t), где N_бит — число битов, к которым относится сечение (для полного слова при равной чувствительности проверочных разрядов N_бит = nW); при сечении на прибор множителя числа битов нет; в общем случае — сумма по элементам с их нормировками — **(2.4)**; повторный 4π не вводится [ЛИТ: РД 134-0139-2005, 5.1, (5.1) — форма свёртки; 5.5, (5.4) — верхняя оценка по сечениям насыщения; НАШ: проверка нормировок, T141]. Частота сбоев ν_РЭА по РД сопоставляется с λ_инв только при совпадении события (битовая инверсия) и нормировки. Геометрическое соглашение в РД не задано — параметр a_H (GAPS Б4). Р2.3.

**2.2.2. Перенос через защиту.** Разные операторы переноса дают разные пики при одном сечении [НАШ, T141 spectra-transfer; числа добавить при написании].

**2.2.3. Механизмы сбоев.** Тяжёлые ионы, протоны высоких энергий, прямая ионизация протонами низких энергий [ЛИТ: Coronetti 2020, 2021; Боруздина 2014; Красников 2018 — сверить]. Нормативная методика испытаний протонами рассчитана на энергии порядка 20–1000 МэВ и область прямой ионизации не охватывает; подтверждение протонами 200–1000 МэВ — лишь до ЛПЭ 14 МэВ·см²/мг [ЛИТ: РД 134-0139-2005, 4.9, В.4.1]. Для CY62167 сечение прямой ионизации около N2.2-x1 см²/бит против N2.2-x2 (N2.2-xr раз), энергия — перед слоями металлизации [ЛИТ: Coronetti 2021]. Р2.4 — резерв: решение при работе над 2.2 по принятым численным источникам; при их недостаточности назвать конкретный недостающий массив.

**2.2.4. Результат для сквозного примера.** Замена одного компонента на общих входах при 3 г/см²: N2.2-d00 → d01 → d02 → d03 → d04 → d06 с⁻¹ (Т2.3). Формулировка: при тех же входах учёт протонов низких энергий увеличивает ∫λ²dt примерно в 6 раз (N2.2-ratio) и делает достаточную оценку непроходной: часть выражения без D не меньше N2.2-Q30 > Q_доп; это не нижняя граница Q(T) и не невозможность [НАШ, T141, T127].

**2.2.5. Сбой, затронутые разряды, касание слова, исправление.** Родительское событие, метка, касание слова, прямое событие (больше t_код разрядов одного слова), зарегистрированная группа, исправление [ОПР; НАШ: T36 §1 п. 2, T89 §1]. Пересчёт 38/32 — допущение равной чувствительности проверочных разрядов [ОГР]. Т2.4.

### 2.6. Оценки вероятности превышения корректирующей способности (7 с.) — пишется после #166

**2.6.1. Свойства Q(T).** Первое превышение за срок; не отказ системы; среднее время до отказа Q(T) не заменяет; аддитивная форма −ln(1 − Q) без доказательства не используется [ОПР; ОГР].

**2.6.2. Две составляющие.** Вне оплаченных квот первое превышение имеет одного из трёх свидетелей: прямую метку, касание изначально ошибочного слова, пару новых событий; объединение событий даёт сумму; замена на 1 − e^{−U} без основания запрещена [ЛИТ: Lee, Baeg, Reviriego 2011; НАШ: T52 §3, T110 §3].

**2.6.3. Квадратичная зависимость.** [ЛИТ: Saleh 1990; Tausch 2009 — постоянная интенсивность]. Для меняющейся интенсивности и интервалов каждого слова: ½ Σ_w Σ_k η_w M²_{J_wk} ≤ ½ χ P S̄₂, χ = Σ_w η_w — **(2.9)**. η_w — верх вероятности того, что метки двух разных событий образуют в слове w опасную пару: достаточно η_w = q_w²; при независимых равномерных одиночных попаданиях допустимо усиление η_w = (n − 1)/(nW²). При q_w = 1/W: χ = 1/W (β₀ = χ/2 = 1/(2W), так в T127) либо χ = (n − 1)/(nW) (β = (n − 1)/(2nW), так в T110). Равенство β = χ/2 используется только при тех же λ, метках и нормировке [НАШ, T52 §2 (3); [?] П2]. Р2.10.

**2.6.4. Достаточные верхние оценки при постоянном периоде — два связанных набора.**
- **(2.10)** — договор T52 для безусловной записи и записи после исправимой ошибки на внешнем слове: U(P) = δ_нач + δ_исп + 1 − e^{−dF̄} + k₀ min(F̄, λ_пик P) + ½ χ P S̄₂ + X + S_обсл, где k₀ = min(1, q K₀), q = max_w q_w; X = 0 при безусловной записи и X = X_C из T52 (4) при записи после исправимой ошибки; S_обсл — вклад попаданий в окна, не обеспеченные обслуживанием (0, если корректность чтения–записи доказана и при попаданиях в окно). Свойство «не более 42 интервалов» относится к вычислению периода в T52 [НАШ, T52 §§1–5].
- **(2.11)** — связанный набор T110 для записи по сигналу: U_Q = e_M + D* + K₀ B P_s⁺/W + β𝓘 + X_E вместе с его условиями (полный сигнал, запись при сигнале, остаток после операции, квоты); член X_E не подставляется в (2.10) и наоборот [НАШ, T110 §§1, 3].
- Т2.10 — условия применимости (условие → основание → проверка → последствие нарушения).

**2.6.5. Необходимая нижняя оценка.** При допустимом законе независимых одиночных попаданий с интенсивностью λ_р на разряд, на непересекающихся ячейках без обслуживания и для заданного класса календарей: p⁻(h) = C(n, 2) λ_р² h² e^{−n λ_р h} — **(2.12)**; Q(T) ≥ 1 − exp(−Σ p⁻) — **(2.13)**. Нижняя оценка постоянного класса не переносится на адаптивные правила; для них нужно отдельное доказательство [НАШ, T45 §2; [?] П5]. Между оценками — «по имеющимся данным не установлено» [ОГР].

**2.6.6. Проверка точным расчётом и моделированием.** Численные входы для 2.6 и раздела «Достоверность» **приняты — для обслуживания с безусловной записью** (#166, PR171; проверенная версия `6597dfb108f884a3b5a34f6fa03300d417162d16`, слияние `88e70108b0e9bfebbe10220436464e6568750b54`; таблица, машинные значения и рисунок — `experiments/sequential-small-validation-20261014/outputs/` в main; приёмка — MAP 15.10). Восемь синтетических точек: W = 4 и 8, внешнее слово (39, 32), t_код = 1. В изложении различаются три величины: точность вычисления Q(T) (ширина сертифицированного интервала эталона), ширина между верхней и нижней оценками ((U − L)/Q) и статистическая погрешность моделирования (поточечные 95%-интервалы; совместное покрытие не заявлено).
