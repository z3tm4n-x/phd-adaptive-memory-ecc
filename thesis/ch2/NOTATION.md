## 3. Термины

| Во внутренних материалах | В тексте главы |
|---|---|
| риск, риск за срок | вероятность неисправимой ошибки за время работы Q(T) |
| ε, допуск | допустимая вероятность Q_доп |
| U / C / E | обслуживание с безусловной записью / с записью после исправимой ошибки / с записью по сигналу исправления |
| ERR | сигнал исправления в тракте коррекции; у CY62167 — вывод по документации, полнота по слову — условие |
| full38 | полное 38-разрядное слово |
| SEU / MBU, MCU / SMU | одиночный сбой / несколько затронутых разрядов или ячеек от одной частицы / несколько ошибок в одном слове |
| direct-событие | прямое событие |
| вспомогательная система, разрыв сопряжения, нижний канал (a, ζ) | в главе 2 не используются; глава 3 или приложение |
| R0-A / R0-B | сквозной пример на CY62167 / пример памяти большого объёма |
| налог, occupancy | загрузка интерфейса контролем (с указанием состава) |
| сертификат | проверяемое достаточное условие |
| класс Λ | множество допустимых изменений интенсивности сбоев |
