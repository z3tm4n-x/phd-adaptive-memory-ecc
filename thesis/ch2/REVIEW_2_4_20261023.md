# Отзыв оркестратора на §2.4 — 23.10.2026

**Решение: адресная доработка; раздел пока не принят.** Линия изложения содержательна: необходимость двух оценок → пути первого превышения → проверка малых моделей. Хорошо объяснены поглощающее состояние и различие трёх видов погрешности. Таблица и рисунок согласованы с принятыми расчётами; §§2.2–2.3 сохранены. Однако в объяснении главной оценки есть смысловая ошибка, а несколько переходов остаются слишком сжатыми.

1. **Исправить вывод (2.10).** Наличие пары попаданий в разные разряды не всегда вызывает превышение: последовательность инверсий $a,a,b$ даёт состояния $\{a\},\varnothing,\{b\}$. Для верхней оценки нужна обратная связь: каждому первому превышению сопутствует учтённая пара; не всякая учтённая пара вызывает превышение. До формулы определить интервалы по заранее заданному календарю: для безусловной записи — окончания записей, для записи после исправимой ошибки — снимки, с границами 0 и $T$. Не называть их все промежутками между фактическими восстановлениями: при условной записи такие промежутки случайны и могут быть длиннее $P$. Затем объяснить дополнительный учёт пар, разделённых снимком.

2. **Сделать оценки однозначными для подстановки.** В общей предпосылке о начальном состоянии одной фразой сохранить условие источника: сведения о нём не меняют заданного закона будущих попаданий. Для $X_z$, $X_{\text{С}}$ и $S_{\text{обсл}}$ ясно назвать используемые вычислимые верхние границы. Перед (2.12) напомнить содержательное отличие записи по сигналу: гарантируется устранение старых ошибок, а устранение возникших во время операции не гарантируется. Одного упоминания отсутствия записи после чистого снимка недостаточно: это свойство есть и у предыдущего варианта.

3. **Уточнить описание численной проверки, не пересчитывая её.** При вычислении нижней оценки ячейки дополнительно разделены в точках изменения интенсивности и обрезаны границами срока; это необходимо для применения (2.13). Рациональная арифметика и гарантированный интервал относятся к основному расчёту по словам; контрольный перебор всех состояний выполнен отдельно с плавающей точкой. Сейчас соседство фраз создаёт впечатление, что оба расчёта рациональные.

4. **Убрать язык протокола.** Заменить «нарушения предпосылок оплачиваются», «эта составляющая оплачивает», «восстановление … не обещается» обычными научными формулировками. Удалить «совместное покрытие … не заявляется»: поточечный характер интервалов уже указан. Завершение сократить до результата проверки и краткой границы применимости, без повторного перечня оговорок и пересказа вводного абзаца. Не сокращать необходимые объяснения ради объёма.

Нужен один исправленный раздел и точечная синхронизация обозначений/карты источников. Числа и состав проверки сохранить; новых расчётов, источников или задач исследователям этот отзыв не требует. §§2.2–2.3 и руководство не менять. После правки снова прочитать §2.4 целиком; самопроверка не заменяет решение о приёмке.
