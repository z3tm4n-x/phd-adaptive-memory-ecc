## 3.6. Выводы по главе 3

Доказано достаточное условие гарантии за весь срок для контроллера, который выбирает период обхода по своим часам, командам и полученным отчётам. Скрытое первое повреждение может сохраниться между посещениями слова и даже пережить начатую исправляющую запись. В теореме 3.1 для решения на каждом шаге учитываются вероятность повторного касания слова с таким остатком и запас на всё последующее обслуживание. При сложении пошаговых неравенств получается единая граница до конца срока, включая последний неполный интервал.

Если окна повышенной частоты известны заранее, для обоснования расписания требуется учесть пары с одним попаданием до границы окна и другим после неё. В рассмотренном примере для 4 МиБ эта добавка укладывается в запас выбранных периодов. При управлении по результатам обхода нулевой счёт за один цикл сам по себе не оправдывает немедленный выбор самого длинного периода. Для двух настроек проверенной реализации метода Красникова и соавторов на 512 КиБ с кодом $(39,32)$ построен допустимый профиль с $Q(T)\ge1{,}0287\cdot10^{-3}>10^{-3}$.

Для серии своевременных отчётов без исправлений установлена связь с частицами, одиночные повреждения от которых обязательно проявились бы к решению. Пусть $\mu_{jr}$ — ожидаемое число таких частиц в гарантированной части истории для заранее выбранных момента $t_j$ и ступени $r$. Тогда вероятность разрешить эту ступень или более длинный период до остановки доказательства не превышает $e^{-\mu_{jr}}$. Такое разрешение необходимо, чтобы при удвоении периода могли накопиться ошибки по разные стороны пропущенной проверки. По этому свойству обоснована лестница, требующая всё более длинной подтверждённой истории при каждом удвоении периода.

Для 64 КиБ с кодом 32+6 лестница обеспечивает $Q_{\rm нак}(T)\le0{,}000552583<10^{-3}$ за десять лет при каждом профиле расчётного класса геостационарной орбиты (ГСО) и на любой карте 16 384–32 768 полных слов. Оценка относится к первоначально исправным словам, обе половины которых защищены от записей приложения. Приняты однословные поражения или поражения двух соседних слов одной частицей, достоверное обнаружение изолированной ошибки в любой позиции и обязательная запись исправленных данных. Общая вероятность исключений исполнения ограничена величиной $6\cdot10^{-6}$ за срок. В расчётной смеси нет прямого поражения нескольких разрядов слова одной частицей. При переносе результата на модель с прямыми метками требуется обосновать совпадение процессов до первой такой метки и выделить долю допуска на её появление.

Для той же смеси при отсутствии дополнительных потерь истории и обращений управления ($I=X=0$) лестница сокращает ожидаемую десятилетнюю занятость порта по сравнению с любым допустимым постоянным периодом на той же карте 64 КиБ. Для полного расчётного класса ГСО гарантировано сокращение минимум в 8,56 раза. Когда один постоянный период можно заранее подобрать для всего множества реконструкций SEPEM и GOES, гарантированная граница сокращения составляет 1,115 раза. [Сопоставимые границы в таблице 3.4](section3_5.md#port-comparison).

Для более крупных областей ограничением может стать время самого частого обхода. На проверенных картах 0,5–4 МиБ с одним портом и разносом половин слова на полпрохода найдены допустимые профили, на которых $Q_{\rm нак}(T)>10^{-3}$ для лестницы и для любого реализуемого постоянного периода. При 4 МиБ общий порт обслуживает два кристалла, одна частица поражает один из них. [Условия по объёмам](appendix_section3_5.md#volumes).
