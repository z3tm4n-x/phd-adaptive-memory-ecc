## 3.6. Выводы по главе 3

Доказано достаточное условие гарантии за весь срок для контроллера, который выбирает период обхода по своим часам, командам и полученным отчётам. Скрытое первое повреждение может сохраниться между посещениями слова и даже пережить начатую исправляющую запись. В теореме 3.1 для решения на каждом шаге учитываются вероятность повторного касания слова с таким остатком и запас на всё последующее обслуживание. При сложении пошаговых неравенств получается единая граница до конца срока, включая последний неполный интервал.

Для памяти с внешним кодом $(39,32)$ установлено, что при проверке расписания по заранее известным окнам нужно учитывать перенос неисправленной ошибки через границу окна. Следующее попадание в другой разряд того же слова может вызвать превышение уже в новом режиме. Для управления по наблюдениям проверены две настройки реализации метода Красникова и соавторов, выбирающей самый длинный период после нулевого счёта за один цикл. При обеих настройках такой переход может нарушить допуск. Для 512 КиБ построен допустимый профиль с $Q(T)\ge1{,}0287\cdot10^{-3}>10^{-3}$.

Для памяти со встроенным кодом $(38,32)$ установлена связь между серией своевременных отчётов без исправлений и числом частиц, которые обязательно вызвали бы зарегистрированное исправление к моменту решения. Пусть $\mu_{jr}$ — ожидаемое число таких частиц в гарантированной части истории для заранее выбранных момента $t_j$ и ступени $r$. Тогда вероятность разрешить эту ступень или более длинный период до остановки доказательства не превышает $e^{-\mu_{jr}}$. Такое разрешение необходимо, чтобы при удвоении периода могли накопиться ошибки по разные стороны пропущенной проверки. По этому свойству обоснована лестница, требующая всё более длинной подтверждённой истории при каждом удвоении периода.

Для 64 КиБ такой памяти принята модель поражения одного или двух соседних кодовых слов одной частицей. Лестница обеспечивает $Q_{\rm нак}(T)\le0{,}000552583<10^{-3}$ за десять лет при каждом профиле расчётного класса геостационарной орбиты (ГСО) и на любой карте 16 384–32 768 полных слов. Оценка относится к первоначально исправным словам, обе половины которых защищены от записей приложения. Предполагаются достоверное обнаружение изолированной ошибки в любой позиции и обязательная запись исправленных данных. Общая вероятность исключений исполнения ограничена величиной $6\cdot10^{-6}$ за срок. В этой модели в каждом затронутом слове одна частица изменяет только одну позицию. При переносе результата на модель с прямыми метками требуется обосновать совпадение процессов до первой такой метки и выделить долю допуска на её появление.

Для той же модели поражения одного или двух слов при отсутствии дополнительных потерь истории и обращений управления ($I=X=0$) лестница сокращает ожидаемую десятилетнюю занятость порта по сравнению с любым допустимым постоянным периодом на той же карте 64 КиБ. Для полного расчётного класса ГСО гарантировано сокращение минимум в 8,56 раза. Когда один постоянный период можно заранее подобрать для всего множества реконструкций SEPEM и GOES, гарантированная граница сокращения составляет 1,115 раза. [Сопоставимые границы в таблице 3.4](section3_5.md#port-comparison).

Для более крупных областей ограничением может стать время самого частого обхода. На проверенных картах 0,5–4 МиБ с одним портом и разносом половин слова на полпрохода найдены допустимые профили, на которых $Q_{\rm нак}(T)>10^{-3}$ для лестницы и для любого реализуемого постоянного периода. При 4 МиБ общий порт обслуживает два кристалла, одна частица поражает один из них. [Объёмы и размещения, §4.3](../ch4/section4_3.md#larger-volumes).
