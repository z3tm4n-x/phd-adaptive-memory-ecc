## 3.6. Выводы по главе 3

Теорема 3.1 даёт достаточное условие, при котором правило выбора периода по доступным контроллеру отчётам, часам и ранее выданным командам удовлетворяет допуску на вероятность накопления за весь срок. Проверка учитывает скрытый от контроллера остаток ошибки, в том числе инверсию, возникшую во время чтения с исправляющей записью конечной длительности, и последний незавершённый интервал.

Для расписания с заранее известными окнами вклад одиночной ошибки, сохранившейся на границе окна, входит в верхнюю оценку отдельным слагаемым. На двух настройках проверенной реализации метода Красникова и соавторов показано, что нулевого счёта за один цикл недостаточно для немедленного перехода к самому длинному периоду. В конфигурации 512 КиБ с кодом $(39,32)$ один допустимый профиль даёт $Q(T)\ge1{,}0287\cdot10^{-3}>10^{-3}$ при обеих проверенных настройках.

Для фиксированных момента решения $t_j$ и ступени $r$ установлено вероятностное свойство наблюдений. Если контроллер разрешил период не короче периода этой ступени и к моменту решения доказательство ещё не остановилось, в проверяемой части истории отсутствовали частицы, от которых до решения обязательно был бы зарегистрирован сигнал исправления ERR. По (3.9) вероятность этого совместного события не превосходит $e^{-\mu_{jr}}$, где $\mu_{jr}$ — ожидаемое число таких частиц. На этом основании построена лестница периодов для 64 КиБ с кодом 32+6. При принятой смеси поражений одного слова или двух соседних слов и для любого профиля расчётного класса геостационарной орбиты (ГСО) получено $Q_{\rm нак}(T)\le0{,}000552583<10^{-3}$ за десять лет. Граница действует для любой карты пар адресов, охватывающей от 16 384 до 32 768 внутренних слов. [Свойство наблюдений (3.9)](section3_3.md) · [Десятилетняя граница (3.14)](section3_4.md#eq-3-14).

Для тех же 64 КиБ при отсутствии дополнительных потерь истории и обращений управления ($I=X=0$) сравнивалась ожидаемая занятость защитного порта за десять лет. Для расчётного класса профилей ГСО лестница занимает не более 472 647 с, любой допустимый постоянный режим — не менее 3 452 586 с. При выборе одного постоянного периода для всех принятых реконструкций SEPEM и GOES соответствующие границы равны 429 799 и 412 236 с. Абсолютные границы получены по всем картам. Отношение границ для двух режимов на одной и той же карте даёт сокращение занятости не менее чем в 8,5619 раза для расчётного класса профилей ГСО и в 1,1151 раза для реконструкций. [Таблица 3.4](section3_5.md#port-comparison).

С увеличением объёма длительность самого быстрого обхода на последовательном порту возрастает. Для 256 КиБ в проектном примере главы 4 использовано известное размещение, при котором две половины каждого слова читаются с разносом на полпрохода. Та же схема размещения проверена для 0,5, 1, 2 и 4 МиБ при одном последовательном порте. Для каждого из этих объёмов найден допустимый профиль, на котором нижняя граница вероятности накопления превышает $10^{-3}$ для любого реализуемого постоянного периода и для принятой лестницы. При 4 МиБ два кристалла используют общий порт, одна частица поражает один кристалл. [Условия сравнения по объёмам](appendix_section3_5.md#volumes).

Оценка вероятности накопления предполагает, что в начале срока в охваченных словах нет ошибок. На протяжении срока приложение не записывает ни в одну из их половин, включая партнёрскую половину за границей области. Для изолированной ошибки в любой позиции слова требуются достоверный ERR и обязательная запись исправленных данных. При распознанной потере отчёта набор нулевой серии начинается заново. Ложное подтверждение нуля и пропущенная запись входят в общую границу вероятности исключений исполнения $6\cdot10^{-6}$ за десять лет. Полную вероятность неисправимой ошибки памяти ограничивает сумма верхних оценок для накопления и для прямого поражения одной частицей двух или более разрядов одного слова. Для конкретной микросхемы требуется отдельно обосновать верхнюю границу вероятности прямого поражения.
