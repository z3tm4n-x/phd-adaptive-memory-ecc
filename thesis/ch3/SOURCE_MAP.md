### Контроль области §3.1

В §3.1 не переносится численная иллюстрация на 0,125 МиБ из конца краткой формы: у неё отдельный закон меток. Объёмы 64 и 128 КиБ, два постоянных соперника и условие 21 007 полных пар относятся к §3.5. Непрохождение выбранной верхней оценки означает «гарантия этим тестом не установлена», а не доказанное нарушение требования.

## §3.5. Сравнение постоянного периода и лестницы по ERR на ГСО

Главная точка — 0,0625 МиБ долгоживущих данных на CY62167GE30-45, 32 768 адресов ×16 при любой карте пар, внешний обход по ERR, десять лет. На накопление выделено $10^{-3}$, включая $6\cdot10^{-6}$ на исключения исполнения. Характеристики СКЛ приняты с вероятностью превышения 0,1 за срок. Границы скорости роста и суммы подъёмов заданы дополнительно. Для каждого сравнения постоянный соперник выбирает лучший период, допустимый для всего указанного множества обстановок, включая периоды между ступенями лестницы. Цены — границы ожидаемых секунд защитного порта за десять лет, включая продолжение работы после доказательной остановки. $I$ ограничивает ожидаемое число дополнительных общих интервалов со сбросом истории до этой остановки, $X$ — прочую занятость защитного порта за срок в секундах. Эксплуатационная граница для $I$ остаётся открытой. [Доли требования и условия на оборудование](../GEO_NATIVE_DESIGN_CASE.md#direct-budget).

**Главная точка.** На всём классе ГСО при $I=X=0$ верх ожидаемой занятости для лестницы — 472 647 с за десять лет, нижняя граница экономии — 8,56 раза. На множестве принятых реконструкций постоянный соперник заново выбирает период. Для лестницы в этом сравнении верх — 429 799 с, экономия — не менее 1,115 раза. Каждое отношение ограничено на одной карте у обоих соперников. При попадании одна частица поражает одно слово с вероятностью 4/5 либо два соседних слова с вероятностью 1/5. Учтены полные своевременные ERR и оговорённый исход записи. На заранее выбранной карте из 16 384 полных слов оценка средней цены за SEPEM 1996–2006 равна 240 270 с у лестницы и 470 674 с у допустимого постоянного периода 2,197 с, подобранного для этой истории (1,959 раза). Стандартная ошибка среднего у лестницы — 91 с. [Архивный опыт и цены на GOES](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/blob/1485cff03aa4c149efbc8367717f29060cfec8d3/experiments/t186-volume-archive/README.md). [Таблица затрат, границы при сбросах](../../experiments/t186-pair-service-table/README.md) · [Обоснование объёма](../GEO_NATIVE_DESIGN_CASE.md#selected-volume).

### Отдельные сравнения для 0,125 МиБ

**Весь расчётный класс ГСО.** На замкнутой карте из 32 768 слов адреса половин равны $(w,w+32\,768)$. В основной смеси 4/5 частиц задевают одно слово, остальные — два соседних на кольце, по одному разряду в каждом. При $I=X=0$ лестнице достаточно 782 799 с защитного порта, а любой допустимый постоянный период занимает не менее 11 527 603 с. Экономия составляет не менее 14,72 раза. Для двукратного преимущества достаточно $34{,}016758 I+X\le4\,981\,003{,}088$ с. Для другого закона, когда частица задевает два равномерно выбранных разных слова, принято сравнение на каждой карте диапазона $32\,768\le W\le44\,529$. Его нижняя цена постоянного режима — 7 825 256,934 с, верх лестницы при $I=X=0$ — 1 061 779,678 с. При $X=0$ для двукратного преимущества там достаточно $I\le83\,807$. [Карта и проверка основной смеси](../../experiments/t186-native-cost-map/README.md) · [Исходный двухсловный закон](../../theory/t196-native-err-20261110.md).

**Затем — все принятые реконструкции SEPEM и GOES.** Постоянный период заново выбирается только для этого множества. На той же замкнутой карте с той же смесью лестнице при $I=X=0$ достаточно 717 260 с, постоянному режиму нужно не менее 1 585 505 с. Это не менее 2,21 раза. При дополнительных сбросах **не менее чем двукратная** экономия гарантирована при $34{,}016758 I+X\le75\,493{,}124$ с. При $X=0$ достаточно $I\le2\,219$.
