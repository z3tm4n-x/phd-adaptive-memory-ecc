## §3.5. Сравнение постоянного периода и лестницы по ERR на ГСО

Главная точка — 0,125 МиБ долгоживущих данных на CY62167GE30-45, внешний обход по ERR, десять лет. На накопление выделено $10^{-3}$, включая $6\cdot10^{-6}$ на исключения исполнения. Характеристики СКЛ приняты с вероятностью превышения 0,1 за срок. Границы скорости роста и суммы подъёмов заданы дополнительно. Для каждого сравнения постоянный соперник выбирает лучший период, допустимый для всего указанного множества обстановок, включая периоды между ступенями лестницы. Цены — границы ожидаемых секунд защитного порта за десять лет, включая продолжение работы после доказательной остановки. $I$ ограничивает ожидаемое число дополнительных общих интервалов со сбросом истории до этой остановки, $X$ — прочую занятость защитного порта за срок в секундах. Эксплуатационная граница для $I$ остаётся открытой. [Доли требования и условия на оборудование](../GEO_NATIVE_DESIGN_CASE.md#direct-budget).

**Сначала — весь расчётный класс ГСО.** На замкнутой карте из 32 768 слов адреса половин равны $(w,w+32\,768)$. В смеси 4/5 частиц задевают одно слово, остальные — два соседних на кольце, по одному разряду в каждом. При $I=X=0$ лестнице достаточно 782 799 с защитного порта, лучшему допустимому постоянному периоду требуется не менее 10 654 383 с. Доказанная экономия — не менее 13,61 раза. Для сохранения двукратного преимущества достаточно $34{,}016758 I+X\le4\,544\,393{,}022$ с. Для исходного закона двух **равномерно** выбранных разных слов принят отдельный результат на каждой карте диапазона $32\,768\le W\le44\,529$. Нижняя цена постоянного режима — 7 825 256,934 с, верх лестницы при $I=X=0$ — 1 061 779,678 с, для экономии не менее чем вдвое при $X=0$ достаточно $I\le83\,807$. [Смесь на замкнутой карте](../../theory/t196-cluster-main-20261112.md) · [Исходный двухсловный закон](../../theory/t196-native-err-20261110.md).

**Затем — все принятые реконструкции SEPEM и GOES.** Постоянный период заново выбирается только для этого множества. На той же замкнутой карте с той же смесью лестнице при $I=X=0$ достаточно 717 260 с, постоянному режиму нужно не менее 1 585 505 с. Это не менее 2,21 раза. При дополнительных сбросах **не менее чем двукратная** экономия гарантирована при $34{,}016758 I+X\le75\,493{,}124$ с. При $X=0$ достаточно $I\le2\,219$. Для двух равномерно выбранных слов на частицу при $X=0$ достаточно $I\le7\,656$ на этой замкнутой карте. Исходная оценка для того же закона, общая для диапазона $32\,768\le W\le44\,529$, даёт $I\le1\,692$. Ниже указаны абсолютные цены этой оценки на двух концах диапазона.
