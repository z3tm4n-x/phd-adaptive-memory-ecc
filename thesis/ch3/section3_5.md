## 3.5. Сравнение затрат постоянного и адаптивного контроля

Какую часть времени порта памяти можно освободить, если контроллер выбирает период обхода по отчётам об исправлениях? Для сравнения требуется постоянный режим, который обеспечивает тот же допуск на вероятность накопления ошибок за десять лет. Затраты режима характеризует наибольшее по заданному множеству профилей математическое ожидание времени, в течение которого порт занят защитными обращениями. За десять лет ($T=315\,576\,000$ с) складываются длительности всех фактически выполненных защитных чтений и исправляющих записей. В этот счёт входят пуск, часть последней операции в пределах срока и работа контроллера после остановки доказательства. Слоты приложения у обоих режимов одинаковы. Время процессора и энергия имеют собственные меры затрат.

Рассмотрим два множества профилей воздействия. В первом сравнении постоянный период должен обеспечивать допуск для расчётного класса профилей воздействия на геостационарной орбите (ГСО), заданного ограничениями (3.10). Во втором заранее известны все принятые реконструкции SEPEM и GOES. Здесь можно заново выбрать один период, который выдержит каждую из них. В обоих случаях период выбирается для данной карты адресов до начала срока, может принимать любое физически выполнимое значение и остаётся постоянным независимо от поступивших ERR. Лестница §3.4 получает в ходе работы только собственные отчёты, часы и текущий режим. Меняется множество возможных профилей, по которым проверяют допуск и оценивают наибольшую ожидаемую занятость порта.

В главном примере за проход длительностью $L=11{,}4688$ мс по календарю читаются $A=32\,768$ адресов по 16 разрядов, то есть 64 КиБ. При любой карте адресных пар он охватывает от 16 384 до 32 768 внутренних слов 32+6. Каждое охваченное слово исходно исправно. До конца срока приложение не записывает ни в одну из его половин, в том числе в партнёрскую половину за границей области. Частица затрагивает одно равномерно выбранное слово с вероятностью $4/5$, с вероятностью $1/5$ — также следующее слово на кольце. В каждом из затронутых слов инвертируется одна равновероятная позиция из 38. При полном своевременном отчёте зарегистрированный ERR вызывает запись исправленных данных. Новая инверсия во время операции может сохраниться. На накопление отведено $\varepsilon_{\rm нак}=10^{-3}$, включая сроковую долю исполнительских исключений $\delta=6\cdot10^{-6}$. Для применения к изделию отдельно проверяют вероятность прямого поражения нескольких разрядов одного слова одной частицей.

**Какие чтения неизбежны при постоянном периоде.** Слишком длинный промежуток между проходами оставляет время для двух частиц, способных поразить разные разряды одного слова до его очередной проверки. Чтобы исключить период, достаточно предъявить один допустимый профиль и допустимые часы, при которых вероятность накопления строго больше $10^{-3}$. Для полного класса таким профилем служит разрешённое начальное плато высокой частоты с последующим фоном. Для множества реконструкций используется входящее в него десятилетие SEPEM с 16 декабря 1996 г. по 16 декабря 2006 г.

Обозначим через $M$ число охваченных слов. Для каждого диапазона $l\le M\le u$ определён порог $K$ в слово·с. При физических периодах $P\ge K/M$ промежуток между началами проходов делят на равные участки длиной $h$, где $K/M\le h<2K/M$. В начале каждого участка отбрасывают полосу, достаточную для всех возможных фаз чтения и записи обеих половин слова. В оставшееся время обслуживание исключено. Если туда пришли ровно две частицы и у них есть общее поражённое слово, вероятность превысить способность кода зависит от числа общих слов и от позиций инверсий. Расчёт учитывает как совпадение позиций, так и возможность двух общих слов у одной пары частиц. Для каждого участка находят верх условной вероятности пережить его без превышения, если прежде превышения ещё не было. Эти верхи перемножают. Из единицы вычитают полученный верх вероятности пройти все участки без превышения и один раз вычитают $\delta$ на возможное исключение исполнения. С учётом обоих краёв срока получается строгая нижняя оценка вероятности накопления сразу для **всех** $P\ge K/M$. [Приложение к §3.5, формулы (П3.5.1)–(П3.5.2)](appendix_section3_5.md#fixed-period).

Допустимый период при максимальном масштабе часов и нулевом смещении границ обязан быть короче $K/M$. При остальных разрешённых часах расстояние между началами не превышает $K/M+2J$, где $J$ ограничивает сдвиг одного начала. Отбросим два краевых прохода и учтём только обязательные чтения. За один проход их $A$, каждое занимает не менее $c_R^-=100\,\xi_-\,\text{нс}-2J=98{,}999$ нс. Вероятность исполнения без исключения за десятилетие не меньше $1-\delta$. Поэтому нижняя граница ожидаемой занятости любого допустимого постоянного режима для всей полосы $l\le M\le u$ равна

<a id="eq-3-15"></a>

$$
 F^-_{l,u}=(1-\delta)A c_R^-
          \left(\frac{T l}{K+2J u}-2\right).
 \tag{3.15}
$$

Например, при $16\,384\le M\le20\,480$ для класса профилей (3.10) достаточно $K=4\,858$ слово·с. Для исключаемых периодов нижняя оценка $Q_{\rm нак}(T)\ge0{,}001000009860$ уже выше допуска. Выражение в скобках в (3.15) даёт более $1{,}0643\cdot10^9$ полных проходов. При $A=32\,768$ и $J=0{,}5$ нс отсюда следует занятость не менее **3 452 586,199 с**. На реконструкциях в той же полосе $K=40\,687$ слово·с, нижняя оценка вероятности равна $0{,}001000006487$ и необходимая занятость составляет не менее **412 236,428 с**. Допустимые постоянные периоды существуют на любой карте 64 КиБ. В частности, период 93,4444 мс удовлетворяет допуску в обоих сравнениях. [Приложение к §3.5, таблица П3.5.1](appendix_section3_5.md#period-thresholds).

**От периодов лестницы к занятости порта.** Быстрые ступени добавляют чтения, пока контроллер собирает требуемое число $N_r$ полных нулевых интервалов перед очередным удвоением. Для периода $\tau_r=2^rL$ физическое расстояние между началами проходов не меньше $h_r^-=\xi_-\tau_r-2J$. При старшем периоде за срок требуется не более $2+T/h_9^-$ начатых проходов с учётом краёв. За каждую секунду, проведённую ниже уровня $r$, к частоте проходов добавляется разность $\Delta_r=1/h_{r-1}^- -1/h_r^-$. Если действует ступень $k$, прибавки от $r=k+1$ до $9$ доводят исходную частоту старшего режима до $1/h_k^-$. При пуске и после каждого сброса на повторный допуск уровня $r$ отводится до $(N_r+1)A_*^+$, где $A_*^+=\xi_+A_*+2J$ — наибольшая длительность общего интервала. Единица сверх $N_r$ учитывает интервал, в котором пришлось прервать серию.

Умножив верх числа проходов на $A$ и на верх времени одного чтения $c_R=101{,}001$ нс, получаем верх затрат на чтения. Здесь $C_0$ — верх времени чтений при старшем расписании с краями срока и начальным проходом, а $D$ — верх дополнительных секунд чтения при полном наборе нулевой истории по всем девяти порогам. Для указанных календаря и порогов

<a id="eq-3-16"></a>

$$
 C_0=A c_R\left[2+\frac{T}{h_9^-}
            +(\xi_+L+J)\sum_{r=1}^9\Delta_r\right],
 \qquad
 D=A c_R A_*^+\sum_{r=1}^9(N_r+1)\Delta_r .
 \tag{3.16}
$$

Первый набор истории приходится на пуск. Последующие наборы зависят от числа общих интервалов, в которых обнаружено исправление. Пусть $S_1$ ограничивает интеграл частоты инверсий эталона за срок, а $c$ переводит эту частоту в частоту касаний одного слова. Тогда до остановки доказательства верх ожидаемого числа исправляющих записей равен $H=(u+1)cS_1$. Дополнительная единица покрывает повторный ERR от инверсии в слове, которое в момент попадания уже обслуживалось. Для восстановления истории нужен другой счёт. Если частица пришла вне полосы обязательного прохода, её исправления могут прервать один общий интервал. При попадании в эту полосу два слова могут проверяться по разные стороны момента попадания и дать отчёты в двух соседних интервалах. Пусть $E_d$ ограничивает экспозицию во всех таких полосах. Тогда число интервалов с исправлениями в ожидании не превышает $H_{\rm яч}=\min\{H,uc(S_1+E_d)/\mu_{\mathcal C}\}$, где $\mu_{\mathcal C}=6/5$ — среднее число поражённых слов на частицу. Зависимость между двумя отчётами от одной частицы сохраняется в этой оценке. [Приложение к §3.5, формулы (П3.5.3)–(П3.5.4)](appendix_section3_5.md#history-resets).

До остановки время чтений в ожидании ограничено суммой $C_0+D(1+H_{\rm яч})$, а время записей — величиной $c_WH$, где $c_W=101{,}001$ нс на одну запись. После остановки работа контроллера продолжается также на траекториях, где способность кода ещё не превышена. При условиях обслуживания и законе меток §3.4 для каждого $M\in[l,u]$ имеем $Q_{\rm нак}(T)\le\Pr\{\tau_{\rm stop}\le T\}\le\widehat q_{l,u}$. Для расчётного класса профилей ГСО и для множества реконструкций берутся свои границы $\widehat q_{l,u}$ по [формуле (3.14)](section3_4.md#eq-3-14).

Обозначим через $C_{\rm после}$ время защитных обращений от остановки до конца срока. Если остановки не было, это время равно нулю. При наступившей остановке число оставшихся слотов не может превысить календарную границу за весь срок $N_h=901\,654\,730\,833\,032$. На один слот достаточно учесть одно чтение и одну запись. На каждой траектории и затем в среднем получаем

<a id="eq-3-17"></a>

$$
 C_{\rm после}\le(c_R+c_W)N_h\,\mathbf1_{\{\tau_{\rm stop}\le T\}},
 \qquad
 \mathsf E C_{\rm после}\le(c_R+c_W)N_h\,\widehat q_{l,u}.
 \tag{3.17}
$$

В (3.17) взято ожидание потраекторного неравенства, поэтому момент остановки и последующие обращения могут быть зависимыми. Физическая вероятность $Q_{\rm нак}(T)$ учитывает лишь траектории с превышением и сама по себе не ограничивает ожидаемую длительность всех обращений после остановки. Сложив границы для чтений до остановки, исправляющих записей и продолжения обслуживания по (3.17), получим верхнюю границу ожидаемой занятости лестницы для каждой карты указанного диапазона при отсутствии дополнительных потерь истории и обращений управления

<a id="eq-3-18"></a>

$$
 V^+_{l,u}= C_0+D(1+H_{\rm яч})+c_WH
              +(c_R+c_W)N_h\widehat q_{l,u}.
 \tag{3.18}
$$

Для тех же 16 384–20 480 слов на расчётном множестве (3.10) старшее расписание с краями даёт в этой оценке около 177,9 тыс. с, первый набор истории и возвраты — 124,7 тыс. с. На штатные записи приходится менее 1 мс, на возможную работу после остановки — около 100,6 тыс. с. По неокруглённым слагаемым $V^+_{l,u}\le403\,248{,}773$ с. На реконструкциях для той же полосы получено $V^+_{l,u}\le369\,662{,}117$ с. Это верхние границы математического ожидания за весь срок. [Приложение к §3.5, таблица П3.5.2](appendix_section3_5.md#port-bounds).

**Сравнение на одной карте.** Для карты $\pi$ из диапазона $l\le M\le u$ обозначим полученные границы через $C_{\rm пост}^-(\pi)=F^-_{l,u}$ и $C_{\rm лест}^+(\pi)=V^+_{l,u}$. Поскольку постоянный режим может выбирать на этой карте любой допустимый период, нижняя граница относится и к лучшему выбору. Гарантированный коэффициент сокращения занятости вычисляется из отношения (3.15) и (3.18) для одной карты с последующим минимумом по картам

<a id="eq-3-19"></a>

$$
G^-=\min_{\pi}
\frac{C_{\rm пост}^{-}(\pi)}{C_{\rm лест}^{+}(\pi)}.
\tag{3.19}
$$

В [таблице 3.4](#port-comparison) $I=0$ означает отсутствие дополнительных интервалов со сбросом истории, а $X=0$ — отсутствие прочих защитных обращений управления. Два столбца абсолютного времени дают границы для всех карт. Для постоянного режима выбран наименьший из четырёх нижних пределов, для лестницы — наибольший из четырёх верхних.

Если требуется готовность к любому профилю расчётного класса (3.10), постоянный период должен быть достаточно коротким для высокого начального плато и сохраняется таким же при слабом воздействии. Лестница может удлинять период по мере поступления нулевых отчётов. При выборе постоянного режима по реконструкциям множество рассматриваемых профилей сужается. В разобранном диапазоне слов исключение по архивному свидетелю начинается при $40\,687/M$ с, по начальному плато — при $4\,858/M$ с. Поэтому нижняя граница занятости постоянного режима уменьшается значительно сильнее, чем верхняя граница занятости лестницы. Отсюда различие между гарантированными коэффициентами 8,5619 и 1,1151. Выбор одного периода сразу для всех реконструкций сохраняет смысл гарантии на множестве. Выбор по заранее предъявленному отдельному профилю и выборочные средние занятости на 128 моделируемых реализациях потока для заданного профиля рассмотрены в [§4.6](../ch4/section4_6.md).

Если $I$ ограничивает ожидаемое число дополнительных общих интервалов с потерей истории до остановки, каждый из них добавляет к верху не более $D\le20{,}397479$ с на повторные чтения. С учётом остальных дополнительных секунд порта $X$ получается

<a id="eq-3-20"></a>

$$
C_{\rm лест}^{+}(\pi;I,X)
\le C_{\rm лест}^{+}(\pi;0,0)+20{,}397479I+X .
\tag{3.20}
$$

Для двукратного сокращения занятости порта на расчётном классе профилей ГСО достаточно $20{,}397479I+X\le1\,323\,044{,}327$ с. Для реконструкций двукратное сокращение занятости этими границами не установлено уже при $I=X=0$.

**Как объём и размещение меняют сравнение.** При выборе основного объёма заранее потребован запас при непрерывном обходе. Верх $Q_{\rm нак}^+(L)$ должен занимать не более четверти допуска при любом профиле расчётного класса (3.10). Для 64 КиБ при любой карте этот верх составляет не более 0,095780 доли допуска. При увеличении до 128 КиБ проход удлиняется вдвое. Если обе половины слова входят в область, интервал между их чтениями зависит от размещения адресов. При неизвестном размещении каждому слову гарантировано хотя бы одно посещение за проход. На любой карте 128 КиБ для лестницы при расчётном классе профилей ГСО получен верх $Q_{\rm нак}(T)\le0{,}000715390<10^{-3}$. При $I=X=0$ занятость порта по сравнению с допустимым постоянным режимом на той же карте сокращается не менее чем в 13,4014 раза для класса (3.10) и в 2,0983 раза для реконструкций. Для реконструкций общий верх лестницы равен 1 024 307 с. Двукратное сокращение занятости сохраняется при $34{,}016758I+X\le37\,474{,}420$ с.

Отдельное условие возникает именно для четверти допуска в непрерывном режиме 128 КиБ. Если $N_{\rm пар}$ пар целиком входят в область, то $M=65\,536-N_{\rm пар}$. При неизвестном размещении возможны от 32 768 до 65 536 слов, и верх по всем картам составляет 0,365108 доли допуска. При $N_{\rm пар}\ge21\,007$ имеем $M\le44\,529$, а верх уменьшается до 0,249999 доли допуска. Число адресных чтений сохраняется, но уменьшается число различных полных слов, в которых может накопиться вторая ошибка. Для выбора 128 КиБ по критерию четверти достаточно подтвердить охват указанного числа партнёров. Для сравнения занятости 2,0983 на реконструкциях такого дополнительного сведения не требуется.

На 256 КиБ известное размещение позволяет использовать два посещения каждого слова за проход. На карте $(w,w+65\,536)$ обе половины входят в область и разнесены на половину прохода. Для этой конфигурации при любом профиле расчётного класса ГСО получено $Q_{\rm нак}(T)\le0{,}000678$. При $I=X=0$ занятость лестницы не превышает 1 973 781,020 с, любому допустимому постоянному режиму требуется не менее 28 156 816,664 с. Нижняя граница отношения занятостей составляет 14,265420. Для произвольной замкнутой карты отдельная граница вероятности дана в [§2.5](../ch2/chapter2.md#25-требования-к-исходным-данным). В главе 4 карта с разносом на полпрохода служит проектным примером, на котором сравниваются аппаратное исполнение обеих схем, обслуживание приложения и затраты на защиту самого контроллера. [Занятость порта в §4.4](../ch4/section4_4.md) · [§4.5. Исполнение и защита контроллера](../ch4/section4_5.md).

Увеличение объёма на том же последовательном порту удлиняет даже самый быстрый проход. На проверенных картах 0,5, 1, 2 и 4 МиБ обе половины каждого слова также разнесены на полпрохода. Уже при 0,5 МиБ свободные промежутки частого расписания на одном допустимом профиле дают $Q_{\rm нак}(T)\ge0{,}00107403$ для любого постоянного периода и для лестницы. У лестницы эти промежутки сохраняются при любом разрешённом пропуске посещений. Для 1, 2 и 4 МиБ нижние границы также превышают $10^{-3}$, поэтому для этих объёмов оба режима исключены по надёжности до сравнения секунд порта. При 4 МиБ два кристалла используют один порт, а каждая частица по условию затрагивает один кристалл. [Область применимости сравнений по объёмам в приложении к §3.5](appendix_section3_5.md#volumes).
