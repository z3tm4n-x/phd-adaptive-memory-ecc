# Обозначения и термины диссертации

Редакция для глав 2–3, база `a9378e5a1d307783f6b86c9bd2c28ab2d898560e`. Обозначения источников сохраняются в цитатах и карте происхождения. Совпадающие буквы разных моделей не означают совпадения физических величин.

## Память, событие и обслуживание

| Обозначение / термин | Смысл и единицы | Граница использования |
|---|---|---|
| \(W\) | Число защищаемых полных слов | Не число внешних x16-адресов и не число бит |
| \(n\) | Число позиций полного слова | Внутреннее 32+6: 38; внешнее SEC-DED(39,32): 39; data-only модели: 32 |
| \(t_c\) | Число исправляемых ошибочных позиций | Основные принятые оценки управления: \(t_c=1\); обобщение определения события не обобщает теоремы |
| \(E_w(s)\) | Ошибочные позиции слова относительно правильного образа | При записи новых данных правильный образ меняется по договору |
| \(A_T\), \(E_{\rm cap}\) | Хотя бы одно превышение \(t_c\) хотя бы в одном слове до \(T\) | Событие первого достижения; не автоматически DED, SDC, неправильный DQ или системный отказ |
| \(Q_\pi(T;\theta)\) | Вероятность \(A_T\) для политики и модели | В RES-001…004 соответствует \(F_A\); в RES-002 исходное \(Q\) обозначает сертификат и в главе переименовано в \(U_{\rm ext}\) |
| \(U_\pi,L_\pi\) | Достаточный верх и необходимый низ вероятности | \(U>\varepsilon\) не означает \(Q>\varepsilon\) |
| \(T,H\) | Полный горизонт, с | \(H\) в RES-003/004 — 3600 с; не переносится на десятилетний пример |
| \(a,\tau\) | Действие / период контроля, с | Семантика привязана к расписанию конкретного метода |
| \(P\), \(P_s,P_l\) | Календарный проход / короткий и длинный периоды каждого слова, с | Отличаются от плотной занятости \(Wc\) |
| \(c\) | Длительность или резерв сервисного блока | Секунды либо явно названные такты; нижняя цена не выводится из одного верхнего WCET |
| latch / fence / release | Снимок слова / завершение исправления / освобождение операции | Их совпадение не предполагается |
| U / C / E | Безусловный write-back / условная запись внешнего кода / запись по полному ERR | Разные договоры состояния, апертуры и цены |
| \(K_0,\rho_0\) | Верх начальных грязных слов и вероятность плохого начала | Чистое начало не восстанавливается после переключения |
| \(p(a)\) | Парный x16-адрес того же внутреннего слова | Проверяемая инволюция; A0-пара CY62167 физически не установлена |

## Среда, родители и наблюдение

| Обозначение / термин | Смысл и единицы | Граница использования |
|---|---|---|
| Родитель | Одно физическое событие с полной меткой позиций | Не автоматически восстановленный кластер и не отдельный ERR |
| \(\lambda(t)\) | Интенсивность родителей на массив, с\(^{-1}\) | В T36/T45/T52; закон меток нужен для перехода к инверсиям |
| \(\nu(t)\) | Верх непрямой словесной нагрузки, с\(^{-1}\) | В T73/T80/T110/T114/T119; не закон ERR |
| \(x_j,b_Z(t)\) | Полная интенсивность одиночных битовых инверсий массива в data-only моделях | Равномерность и нормировка заданы отдельно |
| \(r(t)\) | Интенсивность инверсий одной позиции, с\(^{-1}\) на позицию | \(\lambda=nWr\) только в соответствующем одиночном законе |
| \(b,s,\bar b,B\) | Фон, избыток, потолок фона и общий потолок | Интенсивности в одной нормировке; \(B\) не интеграл \(B_h\) |
| \(F_S,F\) | Верх вспышечной и полной экспозиции за срок | Интегралы интенсивностей, не реализованный счёт событий |
| \(S_2\) | Верх \(\int_0^T\lambda^2dt\) либо \(\int_0^T\nu^2dt\), с\(^{-1}\) | При \(b+s\) включает \(b^2+2bs+s^2\); битовый \(S_2\) имеет иную нормировку |
| \(H_\ell,\rho\) | Преобразование интенсивности и скорость его роста, с\(^{-1}\) | Не вероятностная квота \(\rho_0\) |
| \(g\) | В RES-002 — безразмерное межбиновое изменение; в T36 — абсолютный рост, с\(^{-2}\) | В календарях поздних работ буква также обозначает интервал тактов; области не смешивать |
| \(q_w,q,\chi\) | Верх касания слова, его максимум и сумма квадратов/разрешённых парных коэффициентов | Усиление для разных позиций требует собственного закона меток |
| \(D_*\) | Верх \(\mathbb E N_D\) прямых внутрисловных многобитовых родителей за срок | Не нижний вклад в вероятность и не протонная PDI |
| \(d\) | В T36/T52 — вероятность опасной метки родителя; в T119 — длительность E-операции | Размерность и локальное определение обязательны |
| ERR / новый ERR | Доступное сообщение об исправимой ошибке / новая эпоха коррекции полного слова | Повторные чтения и alias дедуплицируются; один MCU может дать несколько наблюдений |
| \(C,C^{\rm aux}\) | Реальный счёт исправлений и виртуальный счёт меток | Их совпадение доказывается до разрыва сопряжения |
| \(K\), \(\tau_{\rm br}\) | Остаток виртуальных поступлений и первый разрыв сопряжения | Не наблюдаются контроллером; после прохода \(K\) не обнуляется автоматически |
| LOW / FAST | Ограниченное по сроку разрешение пропуска / короткий режим | LOW не является истинной меткой спокойной среды |

## Управление, неопределённость и цена

| Обозначение / термин | Смысл | Граница использования |
|---|---|---|
| \(\theta,\Theta,\Lambda\) | Модель, допустимые модели и класс сред | Робастная гарантия равномерна по классу; его физическое покрытие — отдельный вопрос |
| \(q(z,k)\) | Распределение вспомогательного режима и остатка | Не физический posterior и не скаляр \(q\) непересечения пар RES-001 |
| \(K_a[y],P_a\) | Совместное ядро наблюдения/перехода и его сумма по наблюдениям | Зависят от выполненного действия |
| \(D\) | Постоянное среднее время пребывания CTMC, с | В RES-004 неизвестно, но не меняется за 3600 с |
| \(D(x)\) | Допустимая длина объявленного интервала в T57, с | Другая функция, не параметр CTMC |
| \(V_R,s\) | Ожидаемая цена продолжения в единицах вероятности и свободный запас RES-003 | \(s\) в модели среды означает интенсивность избытка; контекст различается |
| \(E_i,\mathfrak b_i,\gamma\) | Остаток робастного бюджета, его списание и исходный бюджет | Выдаются на весь срок |
| \(\varepsilon\) | Предельная вероятность за объявленный горизонт | Не вероятность на отдельный проход и не точность численного расчёта |
| \(\alpha,\delta\) | Явно назначенные статистические/модельные/исполнительные квоты | Значение определяется конкретным доказательством; квоты не обновляются с эпохой |
| \(U_{\rm ext}\) | Достаточный сертификат внешней информации | Переименование исходного \(Q\) RES-002 для единства обозначений |
| \(C_{\rm ctl,T},C_{\rm ctl,Q}\) | Средняя за срок / спокойная цена защиты и управления | Безусловный учёт до конца срока, включая плохие истории |
| \(C_{\rm bus,T}\) | Полная средняя занятость интерфейса | Включает полезное приложение; не равна защитной цене |
| \(C_{\mathcal F}^{\rm LB}\) | Доказанный низ цены всего объявленного постоянного класса | Не цена одного выбранного соперника |
| \(G\) | В сравнении — коэффициент lower/upper; в RES-004 — transfer-множитель 1,064 | Разные локально определённые величины |
| Условные проходы | \(\mathbb E[N_{\rm complete}\mid A_T^c]\) | Историческая метрика RES-003/004; не полная цена интерфейса |
| STA / WCET / максимум трасс | Статический временной анализ / наихудшее время исполнения / наблюдённый максимум | Один объект не подменяет остальные |
| Запас вероятности / операции / STA | \(\varepsilon-U\) / резерв длительности / запас setup или hold | Три разных вида запаса |

Термин «периодический контроль памяти» включает проверку, исправление и запись в объёме выбранного сервиса. «Восстановление» и scrubbing в источниках читаются именно в их временном договоре, без предположения об одновременном очищении массива.
