# RTL / FPGA

SystemVerilog, testbenches, constraints и scripts для iVerilog/Vivado.

Будущая структура:

- `src/` — synthesizable RTL;
- `tb/` — testbenches;
- `constraints/` — XDC;
- `scripts/` — reproducible Vivado/TCL flow.

Generated Vivado directories и waveforms исключены через `.gitignore`.
