# COSRAD integration

Этот каталог предназначен для scripts, preprocessing и provenance радиационных сценариев COSRAD.

Большие или лицензионно ограниченные исходные файлы не коммитятся. Вместо них для каждого использованного набора данных фиксируются:

- `Dataset ID`;
- версия COSRAD;
- параметры сценария;
- дата генерации;
- исходное имя файла;
- SHA-256, если файл хранится локально;
- путь/место внешнего хранения;
- preprocessing steps;
- связанные `EXP-ID`.
