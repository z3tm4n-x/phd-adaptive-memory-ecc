# Analytical / Mathematical Models

Здесь будут храниться аналитические и символические модели исследования.

Каждая модель должна иметь:

- описание assumptions;
- связь с источниками или собственными выводами;
- диапазон применимости;
- тесты/численную проверку, если применимо;
- ссылку на соответствующие `RQ/HYP/RES`.
