# Zotero exports

Zotero является master-библиотекой литературы.

В этот каталог допускаются только **экспорты для воспроизводимости и сборки текстов** (`.bib`, `.ris`, при необходимости CSV), но не основная PDF-библиотека и не база `zotero.sqlite`.

Рекомендуемое имя BibTeX-экспорта: `references.bib`.
