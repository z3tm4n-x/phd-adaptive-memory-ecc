## Замысел и цель статьи

**Практический вопрос:** какую интенсивность сбоев использовать при выборе периода последовательного контроля памяти, когда интенсивность меняется на порядки из-за солнечных событий?

**Цель:** обосновать выбор периода из требования Q(T)≤ε за весь срок при заданных ограничениях событийного воздействия и обслуживания памяти; показать, когда расчёт по средней интенсивности разрешает недопустимый период, а расчёт по пиковой интенсивности на весь срок приводит к излишне частому, иногда ресурсно невыполнимому контролю.

**Научный вопрос:** какие верхние и нижние оценки по фону, пику, длительности и суммарному воздействию события позволяют проверить период при последовательном обходе, переносе остатка ошибок и принятом правиле записи?

**Главная линия:** среднее → недостаточная защита в доказанных случаях; пик на весь срок → избыточная частота, вплоть до нарушения ресурсного ограничения; событийные сведения → предъявленный допустимый и выполнимый период там, где соответствующая область непуста. Наличие всех трёх исходов в каждой точке не предполагается. Невыполнимость пикового предписания не исключает защиту другими периодами; наибольший период достаточного теста не объявляется оптимальным.

**Практический выход:** исходные параметры события и памяти → оценки Q(T) → интервал достаточных периодов с ресурсным ограничением либо строгий нижний свидетель нарушения, либо ответ «по имеющимся оценкам не установлено». Вероятностный и ресурсный исходы показываются раздельно.

## Вклад и литературное отличие

Собственный вклад статьи — проверяемые верхние и нижние оценки последовательного обслуживания в своих объявленных областях и их применение к выбору периода на масштабе многолетней работы. В расчётном примере нижняя оценка доказывает недопустимость конкретного периода по среднему, а достаточный тест позволяет предъявить допустимый период при ограничении загрузки шины. Принятое сравнение показывает, что предписание по пику за весь срок в той же точке не помещается в ресурс.

Формулировки строятся как **отличие → эффект** относительно проверенных моделей:
- Явные моменты чтения и завершения записи, остаток после разных правил обслуживания → достаточный тест для соответствующего последовательного процесса.
- Ограничения переменной интенсивности через событийные параметры → проверка за весь срок без замены квадрата интенсивности квадратом её среднего.
- Нижняя оценка первого превышения из исправимого входа → строгое исключение конкретного периода, которое невозможно получить одним непрохождением верхнего теста.

[Адресная литературная основа PR329](PRIOR_ART.md) сохраняется: полные Saleh 1990, Tausch 2009, Lee 2011 и разборы Cardarilli. Квадратичный эффект неравномерности, парный коэффициент и произведения выживания известны. Не заявляются новизна самого эффекта профиля, мировой приоритет «миссионного» доказательства или превосходство по точности без согласованного сравнения. Формула Saleh не объявляется ошибочной: исследуется инженерная подстановка среднего вне нужной области гарантий.

Конечная длительность записи — результат **о границах применимости упрощения**. По принятому T340 её влияние на выбранный достаточный период мало при связанном неперекрывающемся обслуживании и существовании обоих периодов. Малость добавки не разрешает удалить её у границы ε без запаса. Дополнительные ошибки обслуживания и задержки вне блока этим результатом не ограничены.

## Объект, известные сведения и общий расчёт

Пример — **условная обстановка ГСО с параметрами события**, без отдельного расчёта конкретного изделия. CY62167 служит иллюстрацией модели обслуживания главы 2. Физическая квалификация миссии, назначение орбитальной α и выбор главной точки диссертации сюда не входят.

Сохраняются входы [T340](../../experiments/t340-article-significance-20261030/inputs.json): (39,32) в 48-разрядной упаковке; T=315576000 с; ε=10⁻³; 512 КиБ / 1 / 2 / 4 МиБ; прежняя нормировка на бит; три правила записи Б/И/С; полный резерв c=200 нс и принятый отдельный срез 1 мкс; Δ=0,c/2,c; ресурсная доля ρ=1. Срезы по r=пик/фон и длительности события не расширяются. Чистое начало, независимые одиночные инверсии, отсутствие записей приложения и правильный локальный сервис — общие допущения расчётной модели.

В формулах сравнения λ относится ко всему массиву. b — фон, B=rb — пик, E — заданная верхняя надфоновая экспозиция соответствующего класса. Для прямоугольного среза E=(B−b)d; событийный верх b²T+(B+b)E равен его S₂. Он не требует знания положения события. Прямоугольник с центром T/2 остаётся допустимым свидетелем для нижней оценки.

**Информационное условие:** E конкретного среза и общий потолок F_s исходной семьи различаются. Если известен только больший F_s, достаточный тест использует его; фактическую экспозицию будущей реализации под видом известных сведений не подставляем. Обоснование масштаба параметров не означает, что реальное солнечное событие прямоугольно.

Для честного сравнения три корня выводятся из одного достаточного аппарата T340 §4:
- S_mean=T·λ_mean²;
- S_event — применимый событийный верх S₂;
- S_peak=T·B².
При β=(n−1)/(2nW) функция корня H(S)=ε/(βS) для Б или Δ=0; для И/С при Δ>0 — H(S)=[ε/(βS)−Δ]/(1+1/W). Основные кривые — P_avg, P_event, P_peak, полученные одной H. Средний вариант при реальном переменном профиле является проверяемым кандидатом, а не гарантией.

Ресурс: P≥P_min=Wc/ρ и Δ≤c. Требуемая доля шины Wc/P выводится явно: она позволяет применить меньший доступный бюджет без новой сетки по ρ. Пиковая постоянная интенсивность может выходить за событийную квоту; здесь она — консервативная расчётная огибающая, не нижний свидетель внутри класса событий.

**Сохранение принятого результата:** P_ref из точного источникового теста T340 остаётся отдельным контрольным значением. Для 4 МиБ / r=100 / суток при P_ref≈61,033235455 с принято Q(T)≥0,003536579593960845268447>0,001; для И/С достаточен P_corr≈17,218210229 с. Прежний результат сохранён без изменения.

**Новое сравнение принято:** при правиле С и c=Δ=200 нс точный P_avg=8585359837056063/140737488355328 с исключён новым нижним Q(T)≥0,003534811406408480683096>0,001. Событийный период ≈17,218210 с требует ≈1,217985% шины; пиковый ≈0,00643524 с ниже P_min=0,2097152 с. Если известен только широкий F_s, тот же тест даёт ≈0,27949814 с и ≈75,0328% шины. [Таблица и исходные данные](../../experiments/article-intensity-comparison-20261030/README.md) сохраняют все 34 строки и контрасты r=10/1000.
