# Publications

Материалы статей создаются здесь только когда соответствующий научный результат достаточно зрелый.

Рекомендуемая структура при старте статьи:

`ART-001-short-title/`

В каталоге статьи должны быть зафиксированы связанные `RES`, используемые figures/tables и bibliography export. Статья не должна становиться единственным местом хранения результатов.
