## Общие правила

Использовать термины автора: память / контролируемая область памяти; частота сбоев (один раз — интенсивность пуассоновского потока); неисправимая ошибка; периодический контроль памяти (скраббинг) при первом упоминании. В утверждённых названиях используется «скраббинг». Реализуемость относится к ресурсу интерфейса, допустимость — к Q(T), гарантированный период подтверждён верхней оценкой. E означает границу ожидаемого числа дополнительных сбоев, не флюенс частиц и не реализованный счёт.

Главный результат определяет композицию. Общие допущения задаются один раз; технические уточнения занимают место соразмерно их значимости. Журнальная точность чисел не меняет выданных расчётных величин. В рукописях нет PR, хешей и внутреннего языка проекта; основания сохраняются в частном сопровождении и исследовательских файлах.

Одновременно не более трёх исследовательских задач вместе с рецензиями; писатель вне лимита. Рецензии назначаются на итоговые утверждения и примеры. Теорема, численная гарантия, фактическая экономия, физическая квалификация и реализованная аппаратура остаются отдельными результатами. Новые расчёты — только под конкретное утверждение из [программы исследований](../thesis/RESEARCH_PLAN.md).
