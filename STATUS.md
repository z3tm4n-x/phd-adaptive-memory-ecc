# Состояние проекта — 09.11.2026

**Центр.** Автономное переключение периода контроля памяти по собственным исправлениям при редких непредсказуемых всплесках, прежде всего солнечных протонных событиях. Ц0 принят автором с четырьмя поправками. [Центральное утверждение](thesis/CENTRAL_CLAIM_20261026.md) · [Каркас](thesis/ASSEMBLY_PLAN.md) · [План](thesis/RESEARCH_PLAN.md). Горизонт — весна 2028 года, дату защиты подтверждает Иван.

**Главная точка.** Для ГСО за десять лет объём пока открыт. Сначала Ц1 и Ц2 задают общий класс обстановки, затем Ц1 передаёт Ивану шесть строк по 0,125 / 0,25 / 0,5 МиБ. Для выбора при $10^{-3}$ нужен допустимый период длиннее непрерывного обхода и заметная добавочная загрузка шины, ориентир 5%. Допуск $10^{-4}$ показывает пределы. Для LEO сохраняется выбранный Иваном объём. [Условия и критерий выбора](thesis/ORBIT_SELECTION_20261028.md).

**Приёмка 09.11.** [Первые таблицы Ц1](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/pull/419#issuecomment-6740021398) и [расширение Ц2](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/pull/420#issuecomment-6740024369) на независимой рецензии. T141 без ограничения роста сохраняется отдельной строкой «предел постановки». Высокий уровень при запуске совместим и с конечной скоростью роста. Условия начала срока и покрытия архивов входят в описание общего класса.

**Условия решений.** При обоснованном $k_{\rm класс}<3$ остановиться и сообщить автору как классовый потолок, так и типичные $R(w)$, в том числе большие. Если для реального размещения не обоснован параметр меток, гарантия остаётся условной и выносится Ивану. В Ц3 к экономии за срок добавить пиковую загрузку в частом режиме и его суммарную длительность. Строгая оптимальность постоянного режима требует достижения нижней границы.
