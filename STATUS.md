# Состояние проекта — 23.10.2026, принят пересчёт новой постановки

**Цель:** заметно снизить затраты на защиту адаптивным управлением при Q(T)≤ε. Итог — **08.12**. Основной сценарий — долгоживущие данные и фиксированный код, сравнение с лучшим постоянным режимом того же кода. Выбор кода — отдельный многокритериальный сценарий с полной ценой. Приложение показывается отдельно; физика GEO/LEO не меняется.

**Новая приёмка:** [PR250](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/pull/250) принят после независимых численной и теоретической рецензий и слит; [область и проверка](experiments/fixed-code-long-lived-20261023/REVIEW_20261023.md). Для условного долгоживущего банка 0,5 МиБ с фиксированным (39,32), f=1, найден k53: Q≤0,000738060, проверки/исправления ≤0,766405% шины. Отношение нижней цены постоянного класса к верхней адаптивной ≥1,2950289 для проверок/исправлений. Класс имеет один общий период для всех слов. Дополнительные расходы управления, CPU и энергия не обнулены; физический пример не подтверждён.

**Новая поставка:** [PR252](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/pull/252) — отбор RTG4 SECDED (24,18) и XQRKU060 SECDED (72,64); независимая приёмка впереди. Новый физический Q или выигрыш не рассчитан. [Приёмка PR246/247](docs/reviews/ORCHESTRATOR_FIFTH_20261023.md) сохраняется в прежней области.
