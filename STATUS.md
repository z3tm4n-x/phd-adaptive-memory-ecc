# Состояние проекта — 26.10.2026, осмысление центрального утверждения

**Цель:** метод адаптивного управления с учётом зависимости наблюдений от действий и остатка ошибок при Q(T)≤ε за весь срок. Научный итог — **08.12**. Основное сравнение — фиксированный код и долгоживущие данные; выбор кода и приложение учитываются отдельно.

**Решение Ивана26.10:** до **29.10** — короткое осмысление без научных вычислений: одна таблица в общих полях и два варианта центрального утверждения. **А:** расписание известной части обстановки + обратная связь для непредсказуемых событий; два сравнения — с лучшим постоянным режимом и с расписанием без обратной связи. **Б:** собственная обратная связь; многократная экономия — только как требование к внешним сведениям. RES-003 и правила для класса — два варианта общего метода; текущий RES-003 не назначается центром.

[Записка дополнена по пяти вопросам Ивана](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/blob/606a757b7ce7d0ada95a106fdbea10273ff50f83/thesis/CENTRAL_CLAIM_20261026.md), [PR264 — предложение к выбору29.10](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/pull/264), не принятый новый результат. Иван предварительно склоняется к А; окончательного выбора нет. **Новые расчёты — только после его выбора**, не автоматически по дате. Механизм экономии, ограниченный объём нового доказательства, сильное расписание и полная цена должны обосновывать рекомендацию А; иначе рекомендовать полноценный Б. Одинаковая кратность двух сравнений не требуется.

На исправном канале оконное правило равно расписанию; добавочная польза обратной связи не установлена. Q≤0,000962972 при допуске0,001, запас около3,7%; физическое покрытие и аппаратные цены неизвестны.

**Шаг назад26.10:** общий научный центр шире RES-003. Гарантию по известному закону и равномерную гарантию для класса сохраняем раздельно. Гибрид ещё не получен объединением принятых строк. Коэффициенты1,295 и1,766 относятся к разным затратам и конфигурациям.

**Область примера:** решение24.10 о расчётной модели и отдельной архитектурной иллюстрации XQRKU060 сохраняется. [PR263 принят Иваном](docs/literature_mapping/saa-windows-20261026/REVIEW_20261026.md) как практика планирования RXTE; физические параметры прежних окон и добавочная польза счётчика не установлены. Достаточно обозначить класс применения, отдельного исследования распространённости23° нет. Физическая квалификация, новая аппаратура и переработка §§2.2–2.4 в выбор А/Б не входят.
