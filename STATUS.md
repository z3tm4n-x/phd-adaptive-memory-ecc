# Состояние проекта — 13.11.2026

**Главный пример.** ГСО, десять лет, 0,125 МиБ долгоживущих данных CY62167GE30-45, встроенный код 32+6, внешний обход по ERR. На накопление выделено $10^{-3}$, включая $6\cdot10^{-6}$ на исключения исполнения. При двух равномерно выбранных словах на частицу и не менее 21 007 полных пар адресов непрерывный обход занимает не более четверти этой доли. Постоянный период 93,4444 мс и лестница до 5,8721 с проходят достаточное условие. [Исходные условия и сервис](thesis/GEO_NATIVE_DESIGN_CASE.md#design-table) · [Цены и запасы при сбросах](thesis/ch3/SOURCE_MAP.md#native-comparison).

**Множественные сбои.** Приняты задачи 1.2–1.4. На замкнутой расчётной карте из 32 768 слов частица поражает одно слово с вероятностью 4/5 и два соседних с вероятностью 1/5. При полном своевременном счёте и регистровом управлении лестнице нужно в ожидании до 782 799 с защитного порта на всём классе ГСО, лучшему допустимому постоянному периоду — не менее 10 654 383 с. Для постоянного периода, выбранного только по всем реконструкциям SEPEM и GOES, соответствующие границы — 717 260 и 1 585 505 с. Доказанная экономия составляет соответственно не менее 13,61 и 2,21 раза. Для четырёх, пяти и восьми соседних слов достаточный верх лестницы превышает допуск. [Видимость и доказательство](theory/t196-visible-parents-20261112.md) · [Сравнение по законам](thesis/GEO_NATIVE_DESIGN_CASE.md#cluster-laws).

**Прямая составляющая.** В 28 сериях проверены 173 802 зарегистрированных кластера при отключённой коррекции. Для смеси из главного примера иллюстративная доля $10^{-4}$ требует не более одного опасного попадания на 97 637 500 частиц, вызвавших инверсию. Открыты их группировка по частицам, карта всех 38 разрядов и полнота регистрации. [Размещение и требуемая статистика](thesis/GEO_NATIVE_DESIGN_CASE.md#direct-budget).

**Контроллер.** На восьмиадресной цифровой модели подтверждены сечение отчёта, установка команды, девять сценариев инъекции для каждого из двух вариантов и оба синтеза. Для проверки квоты на изделии нужна частота опасных исходов. [Проверенная версия и измерения](experiments/native-example-20261111/README.md) · [Три условия для микросхемы](thesis/GEO_NATIVE_DESIGN_CASE.md#chip-tests).

**Ближайшие работы.** Приняты [ионные данные 1.5](experiments/t186-heavy-ion-transfer-1-5/README.md) и [сверка трёх свойств микросхемы](experiments/t96-ge30-physical-conditions/README.md). В архиве измерены размеры записанных кластеров при отключённой коррекции. Для гарантии на изделии остаются открытыми адресация, отклик ERR на ошибку проверочного разряда, исход попадания при записи и своевременная видимость на каждом интервале решения. [Двухкомпонентное условие №479](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/pull/479) передано на научную рецензию. Для [карты выбора режима, 3.1–3.2](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/issues/186#issuecomment-6845792805) принятые законы позволяют уже сравнивать три объёма и четыре допуска. Письмо изготовителю с вопросом о расстоянии между всеми 38 ячейками слова находится у автора.

**Контрастные примеры.** Для внешнего (39,32) при 0,25 МиБ приняты [сравнение затрат при локальном счёте](experiments/t186-advisor-ge30-20261110/GUARANTEE.md), [условия при потерях отчётов и четыре допуска](theory/t358-marked-regime-selection-20261110.md#geo-epsilon). Для наземного хранения принят [вариант без периодического контроля](experiments/t446-terrestrial-retention/README.md).
