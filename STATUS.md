# Состояние проекта — 24.10.2026, принято сравнение Cardarilli

**Цель:** заметно снизить затраты на защиту адаптивным управлением при Q(T)≤ε. Итог — **08.12**. Основной сценарий — долгоживущие данные и фиксированный код, сравнение с лучшим постоянным режимом того же кода. Выбор кода — отдельный многокритериальный сценарий с полной ценой. Приложение показывается отдельно; физика GEO/LEO не меняется.

**Принятый расчёт:** [PR250 и две рецензии](experiments/fixed-code-long-lived-20261023/REVIEW_20261023.md): условный долгоживущий банк 0,5 МиБ, фиксированный (39,32), f=1; k53 даёт Q≤0,000738060 и проверки/исправления ≤0,766405% шины. Отношение нижней цены постоянного класса к верхней адаптивной ≥1,2950289. Класс имеет один общий период для всех слов. CPU, энергия и дополнительное управление не обнулены; физический пример не подтверждён.

**Новая приёмка:** [PR258, сравнение Cardarilli #257](docs/literature_mapping/space-memory-codes-20261023/REVIEW_RS_20261024.md) принято для §1.4 вслед за обзором PR256. Отличие нашего механизма управления уточнено по оригиналам; положения сохранены. [PR252](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/pull/252), отбор RTG4/XQRKU060, ожидает приёмки; физический Q не установлен.

**Шаг назад 24.10:** Cardarilli уже рассматривает реконфигурацию RS и накопление вероятности за весь срок. Отличие RES-003 — связка собственного наблюдения, остатка после прохода и рекурсивного ограничения для будущих решений; паспорт уже её содержит. Основное адаптивное доказательство остаётся для t=1, для t=2 — отдельные оценки постоянных проверок. RS GR712RC — кандидат при необходимости; новая кампания не назначена. Приоритет — PR252, карта и согласованный основной пример.

cFE обосновывает архитектуру таблиц, не универсальную долю памяти. При f<1 нужны объём, календарь и общий бюджет Q между областями; аппаратная цена — параметр. Физика, смысл Q, положения и сроки сохранены.
