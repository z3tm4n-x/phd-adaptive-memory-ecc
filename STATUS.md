# Состояние проекта — 24.10.2026, первый срез карты принят

**Цель:** заметно снизить затраты на защиту адаптивным управлением при Q(T)≤ε. Итог — **08.12**. Основной сценарий — долгоживущие данные и фиксированный код, сравнение с лучшим постоянным режимом того же кода. Выбор кода — отдельный многокритериальный сценарий с полной ценой. Приложение показывается отдельно; физика GEO/LEO не меняется.

**Принятый расчёт:** [PR250 и две рецензии](experiments/fixed-code-long-lived-20261023/REVIEW_20261023.md): условный долгоживущий банк 0,5 МиБ, фиксированный (39,32), f=1; k53 даёт Q≤0,000738060 и проверки/исправления ≤0,766405% шины. Отношение нижней цены постоянного класса к верхней адаптивной ≥1,2950289. Класс имеет один общий период для всех слов. CPU, энергия и дополнительное управление не обнулены; физический пример не подтверждён.

**Новая приёмка:** [PR259, четыре объёма](experiments/regime-map-methodology-20261019/volume-slice-20261024/REVIEW_20261024.md). Для 512 КиБ достаточный остаток управления u<0,226111 п.п. шины. Для 256 КиБ выбранная строка преимущества не доказывает; для 128/64 КиБ его не докажет данная пара оценок при любом k. Это граница оценок, не доказательство проигрыша метода. Новые интегралы воспроизведены. PR252/256/258 приняты в прежних областях.
