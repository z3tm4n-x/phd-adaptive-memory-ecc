# Состояние проекта — 10.11.2026

**Основная расчётная точка.** ГСО, 0,25 МиБ долгоживущих данных, код (39,32), десять лет, допустимая вероятность неисправимой ошибки $10^{-3}$. В классе $\mathcal A_U$ с квотой суммарного подъёма $U=28{,}855$ с⁻¹ постоянный период $4L=51{,}380224$ мс даёт $Q^+\le0{,}000853862$ при известных затратах до 6,211111% шины. [Класс и постоянный соперник](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/pull/426#issuecomment-6748103827).

**Поиск двукратной экономии завершён для интерфейса, допускающего полную недоступность отчётов.** Существует допустимое исполнение, при котором память исправляет ошибки, а контроллер весь срок получает одинаковые сведения при любом положении всплеска. Любому причинному правилу, выполняющему требование, нужно более 16 129 798,07 с защитных чтений, или более 5,1112% шины. Половина верхней оценки затрат допустимого постоянного режима равна 3,10556%. Это выполняет критерий остановки автора. [Итоговая рецензия №432](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/pull/432#issuecomment-6758352656).

**Что даёт доступный счёт.** Для зарегистрированного правила $L/32L$ при видимости исправлений $\gamma\ge1/2$, нулевом прямом вкладе, $\delta=6\cdot10^{-6}$ и своевременном исполнении принят верх $Q(T)\le0{,}000852522$. Двукратную экономию по известным затратам шины обеспечивает дополнительное условие $X+72{,}03006I\le1\,984\,875{,}853$ с. $I$ ограничивает ожидаемое число ячеек с перезапуском до остановки, $X$ — прочую защитную работу шины за срок. Для реального исполнения остаётся подтвердить видимость, доступность счёта, сроки и затраты. [Гарантия №431](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/pull/431#issuecomment-6758466659) · [Цена №430](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/pull/430#issuecomment-6758472656).
