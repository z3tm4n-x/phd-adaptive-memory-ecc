# Состояние проекта — 25.10.2026, основание оконного среза принято

**Цель:** заметно снизить затраты на защиту адаптивным управлением при Q(T)≤ε. Итог — **08.12**. Основной сценарий — долгоживущие данные и фиксированный код, сравнение с лучшим постоянным режимом того же кода. Выбор кода — отдельный многокритериальный сценарий с полной ценой. Приложение показывается отдельно; физика GEO/LEO не меняется.

**Новая приёмка:** [PR260, предсказуемые интервалы](experiments/comparison-foundations-20261018/predictable-windows-20261025/REVIEW_20261025.md). Для 512 КиБ, (39,32), k_H=20/k_L=1780 получено Q≤0,000962972. В объявленной модели сравнение с лучшим постоянным периодом даёт не менее 5× при дополнительной загрузке управления u≤0,00288866 п.п. шины — около 28,9 мкс/с. Неизвестная цена не обнулена; CPU, энергия и аппаратная точка не подтверждены.

**Область:** опасные окна и их неточность заданы заранее; покрытие среды и квоты канала — допущения расчёта. На исправном канале правило совпадает с готовым расписанием: преимущество обратной связи над ним не установлено. PR250/259 сохраняют прежние результаты ERR-правила; его перебор ради 5× остановлен. PR252/256/258 приняты в своих областях.
