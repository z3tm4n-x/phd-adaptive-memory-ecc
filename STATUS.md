# Состояние проекта — 10.11.2026

**Вариант А, ГСО.** Принят расчётный календарь CY62167GE30-45 для внутреннего слова 32+6. Полный обход всех адресов ×16 занимает 22,9376 мс для 0,125 МиБ и 45,8752 мс для 0,25 МиБ. Чтение занимает 100 нс порта, запись при ERR добавляет 100 нс. Группировка половин в изделии остаётся неизвестной. [Паспорт обслуживания №456](experiments/t186-native-ge30-x16/README.md).

**Кандидат главного примера.** При допуске $10^{-3}$ автор заранее потребовал $Q^+_{\rm непр}/Q_{\rm доп}\le1/4$. Для 0,125 МиБ подстановка даёт достаточную границу в 44 529 внутренних слов, то есть не менее 21 007 целых пар среди 65 536 адресов области. Расчёт лестницы и её полной цены на том же обходе ожидает итоговой независимой рецензии. Физическое выполнение условия на пары не установлено. Цель проверки контроллера на уменьшенной области — локальный счёт и границы $I,X$. [Численная поставка №457](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/pull/457) · [Критерий, установленный до расчёта](thesis/RESEARCH_PLAN.md#native-err).

**Принятый пример с внешним (39,32).** При 0,25 МиБ на общем порту GE30-45 проход занимает $L=45{,}8752$ мс. Правило $L/32L$ после 205 полных интервалов без исправлений даёт $Q(T)\le0{,}000880198$ при $\gamma\ge1/2$, $d=0$, $\delta=6\cdot10^{-6}$ и достоверном локальном счёте. [Итоговая рецензия №448–449](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/pull/448#issuecomment-6764956149).

**Цена внешнего (39,32).** В расчётном законе частица выбирает два различных слова равномерно и по одному равномерному разряду в каждом. Нижняя граница ожидаемых затрат всего допустимого постоянного класса составляет 79 058 943,463 с защитной шины. У $L/32L$ при $I=0$ верх ожидаемых затрат на чтения и ремонты за весь срок равен 8 446 152,412 с. Для двукратной экономии достаточно $X+100{,}864632\,I\le31\,083\,319{,}320$ с. Здесь $I$ ограничивает ожидаемое число дополнительных перезапусков до первой доказательной остановки, $X$ — всю остальную занятость защитного порта. Для изделия остаётся обосновать видимость ошибок после встроенной коррекции, согласованность трёх чтений, подтверждение полного нуля в срок и фактические затраты при пропусках отчётов. [Ведомость цены](experiments/t186-advisor-ge30-20261110/GUARANTEE.md) · [Календарь порта](experiments/t186-advisor-ge30-20261110/SERVICE.md).

**Границы результата.** На этом порту верхи для $L/64L$ и лестницы до $512L$ превышают допуск, их фактическая допустимость открыта. На исходном сервисе с проходом 12,845056 мс полная потеря отчётов исключает двукратную экономию по прежней мере затрат. Там же Ц4 дала сравнения на реконструкциях SEPEM и GOES. [Два календаря](theory/t196-dyadic-local-count-20261110.md) · [Предел №432](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/pull/432#issuecomment-6758352656) · [Архивная иллюстрация №440](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/pull/440#issuecomment-6761382665).

**Ц5. Наземное хранение.** При зарегистрированном одиночном законе OFF после общего пуска даёт $Q(T)\le0{,}000017533768$ за десять лет. Верх ожидаемой известной занятости порта — 15,8 мс. Для изделия нужны границы совместных попаданий и частоты по внутренним словам. [Расчёт №446](experiments/t446-terrestrial-retention/README.md) · [Проверенные режимы](theory/t358-marked-regime-selection-20261110.md#tested-selections). **Ц5. Допуск за срок на ГСО.** При $10^{-1}$ допустимый постоянный режим дешевле $L/32L$ по известным операциям. При $10^{-2}$ двукратная экономия остаётся открытой, при $10^{-3}$ она подтверждена в указанном бюджете управления. При $10^{-4}$ все постоянные периоды исключены, допустимость $L/32L$ остаётся открытой. [Четыре допуска](theory/t358-marked-regime-selection-20261110.md#geo-epsilon).

**Требование к интерфейсу внешнего (39,32).** Распознанный пропуск сохраняет сроковую гарантию при исполнении назначенных чтений и записей. После оплаты всего резерва управления для 2× достаточно $100{,}864632\,I+Z\le21\,841\,268{,}163488$ с, где $Z$ — работа порта вне учтённых операций и резерва. При потере всех отчётов от пуска правило выполняет постоянный $L$. Для изделия нужны собственные верхние границы $I,Z$. [Три условия на одном порту](theory/t358-marked-regime-selection-20261110.md#geo-report-quality) · [План Ц5](thesis/RESEARCH_PLAN.md#c5-selection).
