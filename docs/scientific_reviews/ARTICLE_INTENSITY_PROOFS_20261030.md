## 3. Содержательная проверка приложения

### 3.1. Общие условия и событийные сведения

В §§1–2 сначала заданы чистое начало, независимые singleton XOR-инверсии, локальность сервиса, фиксированный календарь и правильность операции при попаданиях. Событие (П1) — первое превышение в любом полном слове за весь T, включая время операции. Последующее восстановление не отменяет событие. n=39 отделено от размещения в 48 разрядах; девять неиспользуемых разрядов не включены в вероятность.

Массивная λ, словесная λ/W и побитовая λ/(nW) согласованы с η и β в (П7). При изменении W сохраняется темп на бит. Для основной точки множитель относительно 38·524288 справочных битов равен 39/19, к S₂ применяется его квадрат. Равенство числа родителей и инверсий ограничено одиночными метками.

(П5) следует из трёх поточечных неравенств и одного интегрального ограничения на весь срок. При E=(B−b)d прямоугольник достигает событийного верха, не требуя знания его положения для верхней гарантии. Класс инженера b≤λ≤B уже класса 0≤λ≤B приложения; это не мешает применимости верха. Подстановка E вместо большего F_s явно меняет класс гарантии, а не незаметно улучшает старую гарантию. Постоянный B на весь T используется как верхняя огибающая, даже если нарушает квоту E; нижним допустимым свидетелем его не называют.

**Вывод: ПРИНЯТЬ** информационную постановку и нормировку. Расчётный выбор b,B,E остаётся условным, без дополнительной вероятности физического покрытия.

### 3.2. Поздние ошибки и верх за весь срок

В (П8)–(П12) разбиение Б проходит по окончаниям записи, И/С — по снимкам. Для И/С снимок не объявлен очисткой. При первом превышении выбираются последние рождения двух сохранившихся ошибок в разных разрядах. Если их разделяет снимок e, более ранняя ошибка принадлежит J_e, более поздняя — H_e: предыдущая операция уже должна была удалить более старую сохранившуюся ошибку, а операция e удаляет её к e+Δ. Здесь используется строгое Δ<P.

Это включение сохраняет остаток после чистого чтения, условную запись и попадания в ожидающее исправление. Выбор последних рождений корректно обрабатывает повторные инверсии. Вероятность ограничивается ожидаемым числом пар на детерминированных интервалах; пуассоновость числа пар и независимость событий превышения не предполагаются. Условливания потока на выживание или ERR нет.

Переход к S₂ использует разбиение каждого слова, затем неперекрытие J_e внутри слова и глобальное неперекрытие H_e по ресурсному договору. Именно это даёт суммы ≤WS и ≤S, а не фиктивную атомарную очистку. Начало, последний неполный промежуток и обрезанные H_e учтены. Искусственная граница T не создаёт исправления.

Указанный отдельно член чувствительности обслуживания S_обсл не приравнен к нулю на основании малого Δ/P. Три корня получены при общей предпосылке правильного сервиса; при другой гарантии исполнения необходимо вернуться к исходному неравенству, возможно с 1/P. Объединение всех вероятностных слагаемых относится к одному T.

**Вывод: ПРИНЯТЬ** перенос верхней оценки в приложение и её применение к трём предписаниям в данной области.

### 3.3. Нижнее исключение конкретного календаря

В (П13) ровно два прихода имеют вероятность μ²e^−μ/2. При чистом входе требуются разные позиции; при одной ошибке достаточно первого попадания в другую позицию. Множитель (n−1)/n поэтому работает из любого исправимого входа. Второе попадание может погасить ошибку, но не историческое превышение.

Для последовательных свободных ячеек применяется условная граница выживания из произвольного исправимого состояния, затем произведение по независимым словесным потокам с локальным сервисом. Это не объявление независимости соседних превышений. Потенциальное окно Δ исключено независимо от фактической записи; остаток не обнулён. Пропуск начальных, обрезанных и пересекающих границу профиля ячеек ослабляет нижнюю оценку в правильную сторону.

(П15) считает именно полностью помещающиеся свободные ячейки. Разные среды не суммируются. Q⁻>ε исключает проверенный календарь при выбранном допустимом прямоугольнике, а значит его равномерную гарантию для класса; все периоды и все профили этим не исключаются. Применимость к новому P_avg проверена отдельно в §4 настоящей рецензии.

**Вывод: ПРИНЯТЬ** изложение нижнего аппарата и новый способ его применения; старое число при P_ref не переносилось заменой подписи.

### 3.4. Корни, ресурс и операционное упрощение

В (П16) одна и та же аффинная ветвь решается для S_mean, S_event и S_peak. Средний вариант при переменном профиле остаётся кандидатом. Порядок положительных корней и совпадение при r=1 следуют из порядка S, но не доказывают допустимости среднего. Наибольший корень данного достаточного теста не назван оптимальным физическим периодом.

Округление вниз сохраняет вероятностный тест, но отдельно перепроверяются нижний ресурсный предел и Δ<P. Неположительный корень, положительный корень ниже ресурса и отсутствие доказанного нарушения различены. S=0 рассмотрено отдельно, деления на ноль нет.

Условие (П19) — точный остаток именно достаточного теста: ε−aP≥a(Δ+P/W). Малость сокращения периода (П18) не разрешает удалить положительный член при P=P₀. Полоса (П21) правильно описывает пересечение нижнего ресурсного предела. На её правой границе дополнительное Δ<P проверяется отдельно: при W=1, ρ_ш=1, Δ=c=P_min равенство исключено. Уточнение устраняет прежнюю слишком широкую фразу о допустимости на границе; на зарегистрированные W≥131072 не влияет. Ненулевой предел грубой ветви при Δ→0 отделён от точного поперечного момента. Альтернативная граница (П22) стремится к нулю. Для Б конечное окончание уже входит в собственное разбиение; равенство верхов не превращается в равенство физических процессов.

### Короткая независимая проверка нового нижнего числа

Следующий фрагмент использует только стандартную библиотеку и формулу уже принятого нижнего теста. Знак остатка ряда Тейлора даёт для x≥0: A_odd(x)≤e^−x≤A_even(x). Это арифметическая проверка, не новая лемма физической модели.

```python
from fractions import Fraction as F

W, n, T, d = 1048576, 39, F(315576000), F(86400)
P, delta = F(8585359837056063, 140737488355328), F(1, 5000000)
nu = F(39, 38*524288) * F('0.0001586')

def poly(x, k):
    term = total = F(1)
    for j in range(1, k+1):
        term *= -x/j
        total += term
    return total

def snapshots(x, inclusive):
    if x < P:
        return 0
    cycles = x // P
    phase = W*(x/P-cycles)
    last = phase.numerator // phase.denominator
    return (cycles-1)*W + (last+1 if inclusive else
                           -((-phase.numerator)//phase.denominator))

hlo = hhi = F(0)
counts = []
for a, b, factor in [(F(0), (T-d)/2, 1),
                     ((T-d)/2, (T+d)/2, 100),
                     ((T+d)/2, T, 1)]:
    count = max(0, snapshots(b, True)-snapshots(a+P-delta, False))
    counts.append(count)
    mu = nu*factor*(P-delta)
    coefficient = count*F(n-1, 2*n)*mu**2
    hlo += coefficient*poly(mu, 9)
    hhi += coefficient*poly(mu, 8)
lo, hi = 1-poly(hlo, 36), 1-poly(hhi, 37)
assert counts == [2711478036552, 1484083060, 2711478036551]
assert F('0.003534811406408480683096') <= lo <= hi
assert hi <= F('0.003534811406408480683097')
assert lo > F(1, 1000)
print('PASS')
```
