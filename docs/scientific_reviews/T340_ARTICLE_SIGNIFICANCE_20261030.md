**1. Малость операционной поправки — ПРИНЯТЬ.** В (3) использована первая
ветвь принятого поперечного верха: `X=a(Δ+P/W)`, а не длительность обхода.
Для Б окончания задают разбиение с длинами ≤P: последний первый fence
происходит в `(W−1)P/W+Δ≤P`. Начало 0 и обрезанный хвост сохранены.
Для И/С нужны виртуальные снимки и поперечные пары до окончания операции;
слабая обязанность С не заменена полным очищением.

Из `P₀=(1+1/W)PΔ+Δ` и осуществимости `Δ≤ρPΔ/W` непосредственно следует
`PΔ/P₀≥W/(W+1+ρ)≥W/(W+2)`. Поэтому предел сокращения **200/(W+2)%**
верен во всей заявленной области при существовании обоих периодов.
Нулевое Δ даёт X=0; ненулевой предел грубой ветви при Δ→0 не выдан за
скачок физического риска. Полоса потери осуществимости и (5) верны;
пустому множеству допустимых периодов процент не присваивается.
Предел не распространяется на pending вне блока, нарушения обслуживания
или дополнительный `S_svc`, потенциально имеющий порядок 1/P.

**2. Соперник и непрерывные пороги — ПРИНЯТЬ.** Формулы Saleh (4.12)/(4.13)
сверены по изображению печатной с.118: интенсивность на бит, полное слово,
число слов и число циклов сопоставлены верно. SHA256 PDF:
`514a3857f40c30f49233d658da2dd04afa35f3640c3ae6d7e7ecfef4fa635015`.
В идеальном сервисе событие «затронуты хотя бы два различных бита» содержит
первое превышение XOR-модели; формула источника здесь даёт верх, а не точное Q.
Расширение на NHPP и заданные фазы допустимо через независимые приращения.
При конечном И/С фиктивный сброс на снимке не имеет этой гарантии, что
правильно отмечено в SMALL16. Усреднение профиля — отдельное инженерное
упрощение при общих T, ε, нормировке, начале и ресурсном резерве.

Формулы CV², монотонность по r, производная по f и решение (7) верны.
При заданном f категории определяются условиями `CV²≤1/9`,
`1/9<CV²≤1/4`, `CV²>1/4`, с пересечением квот и ресурса.
Это аналитическое описание непрерывной области, а не интерполяция 34 строк.
При конечном И/С отношение профильных корней с вычитанием Δ отделено
от отношения мгновенных корней. Для полного сдвига требуется произведение
`γ·g/(1+CV²)`. Универсальные полосы с γ и g обоснованы; внутри них
категория устанавливается интервальным расчётом, при касании границы
сохраняется интервальный ответ. Однозначная категория каждой точки

**3. Наибольший период исходного теста — ПРИНЯТЬ.** В (9) положительный
множитель коэффициента равен `(n−1)(1−a^(j−1))`; убывание модулей при μ≤1
обосновывает q_l/q_u. Логарифмические границы (10) сохраняют направление.
Число полных интервалов и степенные суммы учитывают все W фаз заданного
календаря, начальные/конечные части и случай окончания ровно на T.

В (11)–(12) `f′(0)=0`, `m≤f″≤M`; разложение производной на
`k_w[f′(νP)−f′(νr_w)] + a_w[f′(νa_wP)−f′(νr_w)]` даёт указанный низ.
При `P≤min(T/6,1/ν)` он положителен, а в сменах целой части H непрерывна.
Весь оставшийся хвост, включая P>T, исключён начальными интервалами
половины слов. Монотонность на хвост без доказательства не предположена.
Из суммы квадратов длин и общей локализации G следует (13).
Независимая проверка дала `γ>0,9994972412674987`; нижние логарифмы

**4. Строгий нижний свидетель — ПРИНЯТЬ.** Из календаря удалены все
потенциальные окна, независимо от ERR. Полная свободная ячейка оканчивается
на `jh` и начинается на `jh−P+Δ`, причём j≥W. Подсчёт (14) не добавляет
начальные, обрезанные или пересекающие смену профиля ячейки.
Из чистого входа достаточно ровно двух попаданий в разные биты; из входа
с одной ошибкой — ровно двух попаданий, первое из которых в другой бит.
Второе попадание может погасить ошибку, но уже состоявшееся первое
превышение не отменяется. Обе вероятности равны `b_n μ² exp(−μ)`.
Внутри слова используется условная граница на каждом прошлом без
превышения; будущий NHPP не условливается на выживание. Межсловное
произведение разрешено независимыми потоками и локальностью сервиса.
Незавершённое восстановление не превращено в мгновенное очищение.

<summary>Независимая проверка основных чисел: стандартная библиотека Python</summary>

Код запускается из отдельного checkout **проверенного SHA PR342**.
Он читает сохранённый JSON, не импортирует авторские функции и не добавляет
новые точки. Вычисления `Fraction` точные; `Decimal` используется для
радикалов и вывода. Знаки у порогов дополнительно проверяются рационально.

```python
from fractions import Fraction as F
from decimal import Decimal as D, getcontext
from math import comb
from pathlib import Path
import json

getcontext().prec = 90
s = json.loads(Path('experiments/t340-article-significance-20261030/outputs/results.json').read_text(encoding='utf-8'))
def dec(x):
    x = F(x)
    return D(x.numerator)/D(x.denominator)
def eb(x):
    assert 0 <= x <= 1
    term = total = F(1)
    for j in range(1,13):
        term *= -x/j
        total += term
    return total-term*x/13, total  # odd/even Taylor bounds for exp(-x)

n, T, eps = 39, F(315576000), F(1,1000)
volumes = [131072,262144,524288,1048576]
b, peak, c = F('0.0001586'), F('0.9814'), F('0.0000002')
z, bn = b/(38*524288), F(38,78)
nu0, Fs = n*z, 115776*(peak-b)
for W in volumes:
    bound = F(200,W+2)
    old = s['whole_region_operation_bound_percent'][str(W)]
    assert F(old['lower']) <= bound <= F(old['upper'])
    print('operation %', W, dec(bound))
hl = sum((eps**j/j for j in range(1,21)), F(0))
hu = hl+eps**21/(21*(1-eps))
G = 2*eps/(volumes[0]*comb(n,2)*z*z*T)
numax = n*(b+Fs/T)/(38*524288)
gamma = eps/hu*(1-G/(2*T))*eb(numax*G)[0]
assert gamma > F('0.9994972412674987')
for row in s['thresholds']:
    d, p = F(row['d_s']), F(row['percent'],100)
    f, v = d/T, p/(1-p)
    radical = dec(v).sqrt()
    r = 1+radical/((dec(f)*(1-dec(f))).sqrt()-dec(f)*radical)
    lo, hi = F(row['r']['lower']), F(row['r']['upper'])
    cv = lambda x: (x-1)**2*f*(1-f)/(1+(x-1)*f)**2
    assert lo <= F(r) <= hi and cv(lo) <= v < cv(hi)
    safe = gamma*F(volumes[0],volumes[0]+2)/(1-p)-1
    assert cv(F(row['total_shift_transition_uniform_bracket']['lower'])) <= safe
    assert b*hi <= peak and b*(hi-1)*d <= Fs
    for W in volumes:
        a = W*comb(n,2)*z*z*(T+(hi*hi-1)*d)
        assert (eps/a-c)/(1+F(1,W)) >= W*c
    print('threshold', d, row['percent'], r)

row = next(x for x in s['sensitivity'] if x['label']=='main' and x['rule']=='C' and x['peak_ratio']=='100')
P = F(17179328528260875,281474976710656)
assert P == F(row['reference_passing_endpoint_rational'])
W, d, r = 1048576, F(86400), F(100)
parts = [(F(0),(T-d)/2,nu0),((T-d)/2,(T+d)/2,nu0*r),((T+d)/2,T,nu0)]
counts, hazard = [], F(0)
for a, end, rate in parts:
    l, u = (a+P-c)/P, end/P
    ln, ld, un, ud = l.numerator*W,l.denominator,u.numerator*W,u.denominator
    count = sum(max(0,(un-w*ud)//(ud*W)-max(1,-(-(ln-w*ld)//(ld*W)))+1) for w in range(W))
    counts.append(count)
    mu = rate*(P-c)
    hazard += count*bn*mu*mu*eb(mu)[0]
assert counts == row['free_cell_counts_at_reference']
L = 1-eb(hazard)[1]
assert L > F('0.0035365795') > eps

# Independently certify the same reference endpoint: full cells plus
# an upper bound on edge logs, enumerated word by word.
nu = nu0*(1+(r-1)*d/T)
unit, cycle = W*P.denominator, W*P.numerator
full = squares = 0
for w in range(W):
    first = w*P.numerator
    k, tail = divmod(int(T)*unit-first,cycle)
    full += k
    squares += first*first+tail*tail
mass = nu*P
ea, ex = eb(F(n-1,n)*mass), eb(mass)
qhi = 1-n*ea[0]+(n-1)*ex[1]
H = full*(qhi+qhi*qhi/(2*(1-qhi)))+bn*nu*nu*F(squares,unit*unit)/(1-bn*mass*mass)
assert H < hl
C_upper = 1-eb(H)[0]
assert C_upper < eps
a = W*comb(n,2)*z*z*(T+(r*r-1)*d)
pc = (eps/a-c)/(1+F(1,W))
assert pc == F(row['corrected_root_rational']) and pc >= W*c
assert a*((1+F(1,W))*pc+c) == eps
print('cells', counts)
print('C upper', dec(C_upper), 'L lower', dec(L), 'P corrected', dec(pc))
```

Для независимого верхнего H в конце кода использованы только
`−ln(1−q)≤q+q²/[2(1−q)]` для полных ячеек и
`−ln(1−q)≤q/(1−q_max)` для краёв, где `q≤b_n μ²≤q_max`.
Это проверка того же рационального P_ref, без нового поиска периода.
