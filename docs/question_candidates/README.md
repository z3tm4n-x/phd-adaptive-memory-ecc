# Research Question Candidates

Этот каталог хранит exact candidate cards, представленные PI для
`ACCEPT / REVISE / REJECT` до permanent registration.

Candidate card:

- не резервирует и не присваивает permanent `RQ-xxx`;
- не входит в canonical registry `docs/questions/`;
- не является ответом, decision, hypothesis, experiment, result или novelty
  claim;
- после PI `ACCEPT` должна быть перенесена в `docs/questions/` с обновлением
  зависимостей и canonical registry;
- после `REVISE` сохраняет candidate status до отдельного acceptance.
