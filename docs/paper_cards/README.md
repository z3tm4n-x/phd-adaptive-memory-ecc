# Paper Cards

Этот каталог содержит принятые analytical cards внешних публикаций. Bibliographic master, metadata and PDFs remain in Zotero; GitHub stores only the traceable analysis.

## Acceptance rule

A permanent `PAPER-xxx` identifier means that the card has passed Orchestrator review for completeness, source/inference discipline, provenance and relevance. It does not mean that the paper's assumptions or conclusions are adopted as project facts.

## Candidate claims

Candidate claims inside a Paper Card remain unaccepted until the Orchestrator explicitly selects them and Evidence Auditor checks them. A Paper Card acceptance never creates a `CLM-xxx` automatically.
