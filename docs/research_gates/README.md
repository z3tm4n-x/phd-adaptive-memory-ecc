# Research Gates

Этот каталог хранит directional gate artefacts, которые задают проверяемый
переход между уже принятым состоянием исследования и следующим возможным
этапом работы.

Research gate:

- не является `RQ`, `HYP`, `DEC`, `EXP`, `RES` или novelty claim;
- не разрешает эксперимент сам по себе;
- должен явно задавать научный вопрос, входы, ограничения, проверяемые выходы,
  критерий завершения и требуемое prior-art closure;
- после PI approval может использоваться как основание для отдельной
  регистрации `RQ`/`HYP`/`EXP`, если такая сущность действительно нужна.
