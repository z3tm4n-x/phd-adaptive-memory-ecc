## Предварительный результат

Уже проверенные устройства показывают, почему одного числа исправляемых битов
недостаточно. В GR712RC короткий двоичный BCH и два чередуемых RS-кода дают
разные множества исправляемых сочетаний. Коррекция прочитанных данных не означает
изменения сохранённого слова. В демонстраторе SITAEL код страницы NAND работает
совместно с трансляцией адресов, стиранием и управлением износом; этот сервис
отличается от восстановления слова SRAM.

SOURCE — прямо проверено по первоисточнику; INFERENCE — вывод сопоставления;
UNKNOWN — сведения в проверенном материале не установлены.
Лётное применение, документированное изделие/IP, демонстратор и исследовательское
предложение различаются. Указание семейства не подтверждает конкретный декодер.

## Границы собственного метода

Согласно актуальной MAP, основные адаптивные результаты относятся к t=1.
Для (44,32) по BCH приняты кодек и отдельные оценки постоянных проверок;
обобщение адаптивной гарантии на t=2 не принято. DAEC и RS потребуют проверки
множества исправляемых сочетаний, наблюдений и действия восстановления.
Отсутствие ошибки на выходе, DUE, ошибочная коррекция и первое превышение
корректирующей способности за срок — разные события.

Рекомендация следующих примеров будет сформулирована после проверки остальных
семейств; численные кампании и аппаратные работы не запускаются.
