# ALTEA-Survey. Один проход Южно-Атлантической аномалии

**01.08.2011, МКС, американский лабораторный модуль, позиция P4 (LAB1S6).**
В открытом архиве NASA RadLab для одного прохода есть минутные координаты,
поток зарегистрированных частиц и дозовые величины. **Первое недостающее
измерение для протонного вклада** — поток протонов по энергии и направлениям
за эти же минуты, хотя бы в одном калиброванном интервале вблизи 40 МэВ
с указанной экспозицией. Вычислить частоту сбоев CY62167 в с⁻¹ по этому
продукту нельзя. [Ответ архива](radlab-pass.json) · [Описание продукта](https://visualization.osdr.nasa.gov/radlab/gui/knowledgebase/Release_history).

### Что измерено

За 1 августа RadLab вернул 1 348 различных минутных отметок из возможных 1 440.
По [плану](PLAN.md) выбрана первая непрерывная серия с наблюдениями с обеих сторон
границы. Для принадлежности Южно-Атлантической аномалии требуются одновременно
модуль магнитного поля $B<27\,000$ нТл и параметр Мак-Илвейна $L<2{,}4$.
Пропуск разрывает серию. Между 02:11 и 02:30 UTC включительно имеются все
20 отметок, а в 02:10 и 02:31 поле равно 28 284,4 и 27 842,1 нТл соответственно.
Сетка с шагом 60 с локализует проход. Точная секунда пересечения и время,
в течение которого детектор действительно регистрировал частицы, в этих строках
не указаны. [Narici et al., 2017, §4](https://doi.org/10.1051/swsc/2017016) · [Суточный запрос RadLab](https://visualization.osdr.nasa.gov/radlab/api/?spacecraft=ISS&instrument_id=ALTEA-Survey&timestamp%3E=2011-08-01T00%3A00&timestamp%3C2011-08-02T00%3A00&absorbed_dose_rate&dose_equivalent_rate&flux&latitude&longitude&altitude&B&L&format=json).

### Каналы, защита и опубликованные спектры

В P4 шесть кремниевых телескопов стояли попарно вдоль трёх осей МКС.
Толщина алюминиевого корпуса одного телескопа — 1,3 мм, его двусторонний
геометрический фактор — около 230 см²·ср. Телескоп регистрирует линейную
передачу энергии (ЛПЭ) в кремнии, с порогом 2,9 кэВ/мкм и насыщением
около 690 кэВ/мкм. Протоны проходят отбор прибора примерно при 25–45 МэВ,
ядра гелия — при 25–250 МэВ на нуклон. Для каждой такой полосы в минутном
ответе нет отдельного числа частиц. Геометрический фактор и календарная
длительность не определяют экспозицию канала в см²·ср·с без живого времени,
направления и эффективности регистрации. [Конфигурация и пороги ALTEA](https://visualization.osdr.nasa.gov/radlab/gui/knowledgebase/ALTEA) · [Периоды установки](https://visualization.osdr.nasa.gov/radlab/gui/knowledgebase/ALTEA-Survey).

Поле в P4 уже измерено внутри станции. По оси X на него влияют соседние
модули, по оси Z в этой позиции — ферма МКС. Для выбранного направления
и интервала не установлены суммарные поверхностные плотности и состав
материалов на пути к телескопу и к предполагаемому кристаллу памяти.
Поэтому 1,3 мм корпуса нельзя принять за весь экран перед памятью.
[Narici et al., 2015, табл. 1, рис. 3 и §4.1](https://doi.org/10.1051/swsc/2015037).

В работе 2015 года рис. 4 показывает отбор по аномалии на интегральном потоке.
Спектры ЛПЭ на рис. 9–11 накоплены на высоких широтах, на рис. 12 из низких
широт исключена аномалия. На рис. 13 дана накопленная за сутки доза в аномалии
вдоль оси Z. В работе 2017 года проходы аномалии исключены из рис. 7–9.
В опубликованном сравнении 2019 года спектры ALTEA также отобраны на высоких
широтах. Авторы описывают индивидуальные треки и указывают сервер SWERTO и
подборку iSWA как места хранения данных ALTEA. Публичной выгрузки треков
или спектра за выбранные минуты из этих ссылок получить не удалось.
[Narici et al., 2015, §§3.1–3.4](https://doi.org/10.1051/swsc/2015037) · [Narici et al., 2017, §4](https://doi.org/10.1051/swsc/2017016) · [Zeitlin et al., 2019, §§2.3.1–2.3.2, рис. 5–6 и Acknowledgments](https://doi.org/10.1029/2018SW002103).

### Сопоставление с памятью и результат для карты

Для CY62167GE30-45ZXI в принятой таблице при 40 МэВ есть точка
$\sigma_{p,\mathrm{bit}}\simeq 1{,}0\times10^{-13}$ см²/бит, оцифрованная
по экспериментальному маркеру KVI на рис. 3 Coronetti et al. Это сечение
сбоя бита данных для протонов при нормальном падении. Совпадает энергия
внутри полосы чувствительности ALTEA. Отклик на всём интервале 25–45 МэВ и
его угловая зависимость этой точкой не заданы. Для 29 МэВ в принятой таблице
проверенного значения нет. [Coronetti et al., 2021, §§II–IV и рис. 3](https://doi.org/10.1109/TNS.2021.3061209) · [Таблица сечений](../../../../experiments/RE-CY62167-PROTON-01/sigma_bit_experimental.csv) · [Паспорт применимости CY62167, §§1–2](../../../../experiments/t127-cy62167-pdi/DATA_PASSPORT.md).

Минимальный пригодный вход — число идентифицированных протонов по энергии
и направлению одного телескопа за этот проход с границами каналов и их
эффективной экспозицией, либо уже нормированный дифференциальный поток
в см⁻²·ср⁻¹·с⁻¹·МэВ⁻¹ с теми же метаданными.
Для свёртки потребовались бы поток на той границе, где определена энергия
в протонном испытании, и отклик в том же энергетическом и угловом интервале.
Даже результат в с⁻¹ на бит потребовал бы отдельных данных о размещении
проверочных битов и кратности сбоев от одной частицы для перехода к внешнему
слову (39,32). Испытания с отключённой внутренней коррекцией этих данных
не дают. [Паспорт отклика, §§1–2](../../../../experiments/t127-cy62167-pdi/DATA_PASSPORT.md).

Карта получает датированный пример положения МКС и интегрального поля в P4.
Вклад этой компоненты в частоту сбоев остаётся неизвестным. Основания
назначить физическую долю непредсказуемой надфоновой экспозиции $\alpha$
или вероятность неисправимой ошибки $Q(T)$ за срок из этого прохода нет.
На названном недостающем измерении проверка ALTEA завершена.

### Повтор

Команды запускаются из этой папки с Python 3.10 или новее.

```sh
python verify.py
python verify.py --archive
```

Первая команда без сети проверяет [суточный ответ](radlab-day.json.gz) и
ответ за проход, включая выбор первой непрерывной серии. Вторая повторяет оба запроса
по HTTPS, проверяет исходные байты по SHA-256 и совпадение общих полей
прохода в двух ответах. Для суточного JSON, полученного заранее, доступен
`python verify.py --day-file /путь/к/day.json`. Оба исходных запроса 07.11.2026
вернули HTTP 200. При последующем сетевом повторе из рабочего окружения
соединение прервалось. Автономный повтор по двум сохранённым ответам выполнен.
SHA-256 ответа за проход — `296e5a241e3cf410e8b1412cdb60d8ca303c8fa919ad59e876d4523c0b7f0ed1`,
за сутки — `1d5724819cf97957262ca2a3891b10050d16445bf18197d9d10740c5c4658100`.
