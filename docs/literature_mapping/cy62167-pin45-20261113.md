# Какой бит адреса Zenodo 8314389 соответствует выводу 45 CY62167GE30

13.11.2026 · Литературная проверка для задачи 3.4.

**Вывод — неизвестно.** У CY62167GE30-45ZXI в режиме ×8 вывод 45 служит адресным входом A20. В 15 из 28 файлов наземных облучений опубликовано числовое поле, согласующееся с внешним байтовым адресом. Ни для одного из этих файлов проверенные источники не связывают бит поля с уровнем на выводе 45. Для остальных 13 файлов опубликованы только координаты ячеек. [Паспорт, с. 6, рис. 5 и прим. 11](https://www.infineon.com/assets/row/public/documents/10/49/infineon-cy62167g30-cy62167ge30-16-mbit-1m-words-x-16-bit-2m-words-x-8-bit-static-ram-with-error-correcting-code-ecc-datasheet-en.pdf#page=6) · [Zenodo 8314389, версия 1](https://zenodo.org/records/8314389).

Например, строка 10 в `clust_C720MeV.txt` — `756 755 1`. Проектная проверка интерпретирует первое число обычной строки как адрес байта, два последних — как координаты. ## Что нужно подтвердить у авторов

Обозначим через `a` число в первом поле обычной трёхчисловой строки, через `A` — уровни на адресных выводах микросхемы. Обе проверяемые трактовки совместимы с диапазоном в 2²¹ байт. При прямой нумерации `A20 = a[20]` и `A[19:0] = a[19:0]`. При линейном байтовом адресе с младшим битом выбора байта `A20 = a[0]` и `A[19:0] = a[20:1]`. Даже точное восстановление `a` по координатам ячейки не измеряет уровни на выводах. Также остаётся возможным преобразование адреса при публикации. [Принятые уравнения для числового поля](../../experiments/RE-CY62167-ADDRESS-MAPPING-01/address_mapping_equations.md).

Вопрос авторам — какой бит опубликованного поля `a` соответствует выводу 45 в режиме ×8, как остальные биты соответствуют A19…A0 и для каких серий действует указанное правило с учётом преобразований при выгрузке? Ответ с указанием серий позволит выбрать трактовку без публикации внутренней карты памяти. Документальная проверка возможна также по схеме платы, назначению битов в прошивке и формированию поля в экспортёре для той же серии.
