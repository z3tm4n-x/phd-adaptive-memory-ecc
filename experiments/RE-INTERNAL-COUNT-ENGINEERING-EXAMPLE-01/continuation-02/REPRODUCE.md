# Reproduction and falsification

Run from a checkout containing this package and the preserved accepted RES-003 package. No RADAR, GPU, h5py, network input download or hardware board is required for simulation. The original ZIP is needed only to independently reconstruct the published derived templates; its 32,996,570 bytes and hashes are fixed in inputs/manifest.json. Use the user-supplied file or DOI source under EUPL-1.2, not an unversioned replacement.

Python 3.12.14; numpy 2.3.5; scipy 1.18.1; numba 0.67.0; llvmlite 0.49.0; matplotlib 3.11.2; psutil 7.2.2. The extraction alone additionally uses openpyxl (read-only). Development used the bundled Python for workbook extraction and the project's goes16-venv for numerical work; neither path is embedded as a dependency in the scripts. Install the pinned numerical dependencies in an isolated environment. NumPy/Numba RNG and floating differences on another platform should be reported, not overwritten into the reviewed trial archives.

The archive argument may be replaced with any local path to the same bytes. Original files/workbooks are not modified. Extraction rebuilds only this package's derivatives. `reference.py` reparametrizes unchanged accepted code with `cache=False`; it does not modify the accepted experiment. Timing fields in certificates are intentionally non-reproducible wall-clock observations. Scientific table arrays, config and input counts are the comparison targets.

Complete experiment, with the preregistered plan and selected policies already archived:

```powershell
python "$pkg/run_experiment.py" tune --workers 6 --batch-size 10
python "$pkg/run_experiment.py" test --workers 6 --batch-size 20
python "$pkg/analyze.py"
python "$pkg/check_results.py"
```

For an audit of the published test without repeating tuning, skip `tune`: selected_policies.json is the frozen selection. Do not accidentally replace the selection using a changed tuning seed/config. To check statistical conclusions only, run analyze.py then check_results.py against the published `test_*.npz` trial records; no simulator or ZIP is needed by check_results.py. Regeneration overwrites outputs in this new package, so use a separate audit checkout.

On this Windows sandbox the first multiprocessing attempt failed before any trials with WinError5 (named pipes). It ran after normal host execution authorization; there was no algorithm change or silent fallback. Six local worker processes are computation parallelism, not delegated agents. Paths must support long names; compileall uses adjacent `-b` files to avoid long `__pycache__` paths. Generated bytecode is ignored.

## Trial record schema and independence

Each test NPZ: rows[trial,policy,field], event_sha256[trial], stream_counts[trial,2] and policies[policy,7]. Policy order Proposed, Count-disabled, Fixed, Precomputed, PA-DOM. Fields: E_cap flag; stop time; completed passes; final partial reserved-pass-equivalent; completed interface reads; acknowledged conditional writes; actual read/write bus seconds (including partial in-flight transaction); reserved service seconds; controller updates; maximum own interval count; minimum update likelihood; computational-failure flag. Stream counts: all modeled parent epochs including empty/cropped groups, then protected word masks (not total bits for merged masks). Event hash includes complete generated parent identity/translation before cropping. Trial IDs/seeds are deterministic and batch-size independent.

Independent paths: source raw connected components vs authors' group logs; explicit scheduled set-of-bits oracle vs lazy numeric executor; block moment ODE vs scalar moment formula; fsum full potential expression vs affine action chooser; binomial-tail inversion/scalar paired sums vs beta-quantile/vector analysis. Shared: accepted controller tables/functions, underlying NumPy/SciPy/Numba, source masks and chosen model assumptions. Tests do not establish the real particle-parent process.

Tuning trial archives are larger development caches, ignored by Git; compact candidate scores and hashes are published. Their exact relative cache names and SHA256 are in tune_manifest.json and can be regenerated with the fixed 2000 trials. Confirmatory trial records are in Git, not an inaccessible Windows-only archive.

Execution times, sample memory use, validation outcomes and final hashes are recorded in REPORT/HANDOFF/provenance. Host update timing is not WCET. Falsification priorities: perturb group mapping while preserving first moment; ignore parity; alter commit/latch tie ordering; replace group rate by bit rate; independently rederive paired sample membership from trial rows. Any resulting mismatch invalidates the corresponding claimed path, not automatically the accepted RES-003 theorem.
