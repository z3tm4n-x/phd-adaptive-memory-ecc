# Ц1. Выбор объёма постоянной защиты на ГСО

**Ивану предлагается 0,5 МиБ для сравнения в Ц3 при ε=10⁻³.** Расчёт охватывает 315 576 000 с. Непрерывный обход имеет номинальный период 25,690112 мс и верх Q≤0,000706896. Необходимые дополнительные обращения любой допустимой постоянной защиты занимают не менее 16,846% шины (53,16 млн с). Проверенный кандидат занимает не более 24,766% (78,16 млн с). Зазор между необходимой ценой и ценой кандидата открыт. Для ε=10⁻⁴ уже этот объём требует не менее 6,60 доступных максимумов числа чтений. Среди восьми строк нет объёма с допустимой постоянной защитой при обоих допусках. Выбор объёма остаётся за автором до Ц3. Для контраста LEO используется тот же объём. ## Условия вывода

Это результат для объявленной огибающей ГСО и условного класса меток. Из T141 взяты Al 3 г/см², ГСО 36000 км, средний цикл, `aH=r_check=q_LET=1`, согласованные отклик H и исключительный LET-компонент, общий космический фон `b≈0,0001585981032/с`. Референс имеет `D=38·524288` разрядов. Максимум полной частоты `B≈0,98130085/с`, общий `S₁≤163642,48033` инверсий, `S₂≤111494,591264/с`. Строки рассчитаны с десятичных компонент, заданных в `components.csv`, а не по округлённым значениям этого текста. Положительные солнечные компоненты `s_i` имеют пик `p_i` и экспозицию ≤`p_i·115776 с`. Из этого следует конверт `b²T+2b τΣp_i+τ(Σp_i)²`. Одновременное плато всех компонент в середине срока достигает конверта и служит свидетелем внутри этого класса. От его даты выбор периода не зависит. Более узкий класс с иной формой потребует нового свидетеля. Уровень П=0,1 и перенос отклика по углам, проверочным позициям и хвосту спектра не устанавливают равномерного физического покрытия с заданными ε. [T141 и паспорта](../t141-radiation-chain/DATA_PASSPORT.md) · [компоненты](../t141-radiation-chain/outputs/components.csv).

В каждой строке внешнее (39,32), 48 выделенных позиций, частота на активную позицию `u(t)=ν_ref(t)/D`, чистое начало, read-only приложение, полный корректный сервис E и его прежняя квота `δ₀=6·10⁻⁶`. Каждая непустая метка относится к одной экзогенной частице, разные родители пуассоновские при фиксированном профиле. Сценарные верхние ограничения `d` на число опасных родителей за банк за T равны 0, 10⁻⁵, 10⁻⁴. Для прямого события платим `d` один раз. При `d=0` число слов одной частицы всё ещё может превышать единицу. На остаточных метках разрядные частоты не превосходят `u`. При разных родителях это даёт прежнюю парную мажоранту. Для необходимой границы класс допускает **полный** исходный одиночный закон при тех же сервисе, фазах и профиле. Для физического семейства с обязательной ненулевой кратностью принадлежность этого свидетеля требуется проверить отдельно. [Д1](../../theory/t413-parent-marks-d1-20261109.md) · [Д2 и недостающие физические сведения](../t413-cy62167-placement-d2/README.md).

## Ресурс и верх Q

Календарь обслуживает слово `3j mod W` в слоте `1568⌊j/8⌋+164(j mod 8)` тактов. При непрерывной проверке период равен `196W` номинальных наносекунд. Физические интервалы `P₁⁻…P₁⁺` в миллисекундах составляют 25,689854598…25,690369402, 51,379709697…51,380738303, 102,759419895…102,761476105 и 205,518840291…205,522951709 для четырёх объёмов. Используются `ξ⁻=0,99999`, `ξ⁺=1,00001`, `J=0,5 нс`, `d_E=124ξ⁺+3J` нс. Первоначальный проход, правый край последней операции и перенос остатка входят в гарантию.

По (11) THEORY с физическими моментами новой ГСО для `P_k⁺=196kWξ⁺·10⁻⁹+J` (J в секундах) получаем достаточный верх

$$U_k=\min\{1,\delta_0+d+K_W[(P_k^++d_E)S_2+2B d_E S_1]\},\qquad K_W=\frac{39\cdot38W}{2D^2}.$$

Для 0,5 МиБ при k=1 члены парного накопления, перекрёстной апертуры и исполнения равны примерно `0,0007008859855`, `9,862735·10⁻⁹`, `0,000006`. При ε=10⁻³ на прямую добавку и прочие ещё не оплаченные вероятностные слагаемые остаётся `0,00029310415179`. Обе ненулевые сценарные опоры Д2 помещаются отдельно. Доля опасных частиц, общий отклик проверочных разрядов и полнота покрытия реальной среды остаются неизвестными. Если общую мажоранту всех разрядов умножить на `η`, оба парных члена умножаются на `η²`. При d=0 верх этой строки проходит до `η≈1,19088`, точный критерий — неравенство выше. Это чувствительность, не измеренная допустимая поправка. [Постоянный тест, (11)–(15)](../regime-map-methodology-20261019/predictability-volume-20261028/THEORY.md).

## Необходимая цена класса и семь исключений

Выбираем допустимое полное плато, одинаковые исправные часы `ξ⁺` с нулевым джиттером и одиночные метки. Делим плато на `ceil(τ/120)` равных частей длины L. Для любого физического периода `P≥P₀` и любой фазы число возможных апертур слова на части не больше `M=L/P₀+2`. Их удаление даёт сумму квадратов свободных длин не меньше `[L−M d_E]₊²/(M+1)`. При `v=39B/D` опасность пары из разных битов на одной части снизу ограничена `W·(38/78)(1−vL)v²[L−M d_E]₊²/(M+1)`. Условливание идёт от любого исправимого состояния. Между частями память не очищается. Если Z — сумма этих оценок, то (13) даёт `Q⁻ ≥ Z/(1+Z)−δ₀`. Формула консервативна за счёт `e^(−vL)≥1−vL` и `1−e^(−Z)≥Z/(1+Z)`.

В JSON для каждой строки сохранён направленный правый конец порога `P₀` с `Q⁻(P₀)>ε`. Весь хвост `P≥P₀`, включая OFF, исключён для равномерной гарантии. Следовательно, на всём оставшемся допустимом классе необходимы как минимум `(1−δ₀) W [T/(P₀+J)−2]₊` чтений. Сравнение с абсолютным числом слотов `N_max` охватывает также периоды вне целочисленного меню кандидатов. Для ε=10⁻³ отношение необходимого числа чтений к максимуму равно приблизительно 0,695 / 2,782 / 11,13 / 44,52 по объёмам. Для ε=10⁻⁴ оно равно 6,61 / 26,43 / 105,72 / 422,77. Отсюда семь исключений при указанном входе. Для оставшейся строки `P₀≈0,036956881 с`. Цена любого допустимого постоянного режима по serial ≥23,939% (75,55 млн с), верх конкретного кандидата ≤34,971% (110,36 млн с). Для реальной ГСО, в которой не обоснованы класс и размещение, физическая допустимость открыта.

## Работа, пики и историческая строка

Защитная шина оплачивает 48 тактов чтения, serial — 68 с декодированием. Дополнительная запись/разворот стоят до 56 тактов с допусками. Число начатых чтений сверху ограничено `min(N_max, W(T/P⁻+2)+δ₀N_max)`. Ремонты ограничены этим числом и `2F_b+U_k N_max`, где `F_b=39WS₁/D` считает активные инверсии. Начатая крайняя операция и работа после первого отказа оплачены. Принятые app-чтения, ответ до 2533,01712 нс при сроке 3000 нс и `3W` начальных записей показаны отдельно в JSON. Управление, CPU, энергия, действительная ёмкость и WCET сохраняют свои коэффициенты. Верх кандидата в таблице относится к известным защитным операциям. Полная цена получается прибавлением соответствующих затрат управления.

В любом 1 мс совместный консервативный пик чистой шины ≤57,934624%, последовательного обслуживания ≤67,936577% при пределе 80%. Учтены оба зарезервированных потока приложения и полное заполнение слота управления. Остаток ≥12,063423 п.п. действует вместе с прежними слотами, сроками и условием атомарности шага управления. Среднюю долю нельзя использовать как разрешение занять занятый слот.
