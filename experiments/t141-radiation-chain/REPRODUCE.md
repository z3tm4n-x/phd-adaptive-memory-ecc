# T141 — повтор без сети

Проверенная среда: Python 3.12.14, NumPy 2.3.5, SciPy 1.18.1,
pandas 3.0.1, Windows. Версии библиотек закреплены в `requirements.txt`.
`config.json` — паспорт фиксированного сценария этой поставки; произвольный
пользовательский конфиг не является интерфейсом программы. Изменение сценария
требует согласованного изменения функций, проверок и нового паспорта.
Исследованные вариации явно заданы аргументами функций и строками таблиц
чувствительности, а не подразумеваются из изменения одного поля JSON.
Пример установки в отдельную среду: `python -m pip install -r
experiments/t141-radiation-chain/requirements.txt`.

Из корня checkout, полный новый расчёт:

```sh
python experiments/t141-radiation-chain/reproduce.py --raw "/path/to/SEPEM_H_reference.txt" --cache "/path/outside/git/t141-cache" --verify-again
```

Нужен ранее полученный **SEPEM Reference Data Set version 2.00, European
Space Agency (2016)**; H-reference SHA проверяется до чтения. Загрузок нет.
Все остальные численные входы закреплены в Git. Полные производные H-ряды
пишутся только в указанный кеш **вне checkout**. При повторе добавить
`--reuse-cache`: проверяются fingerprint и SHA каждого массива. Без совпадения
повтор отклоняется; новый расчёт выполняется без этого флага.

`--verify-again` повторяет компактные расчёты/статистику и независимую
проверку в отдельном временном каталоге под новым пакетом `.cache/`, сверяет
SHA результатов. Полная свёртка raw второй раз не запускается. Тесты
выполняются один раз, протокол записывается в `outputs/validation.json`.
Выходные каталоги старых задач и raw не изменяются.

Если внешний RDS недоступен, ограниченная проверка закреплённых спектров:

```sh
python experiments/t141-radiation-chain/calculate.py
python experiments/t141-radiation-chain/checker.py
python -m unittest discover -s experiments/t141-radiation-chain -p "test_*.py" -v
```

Она не считается повтором профильного расчёта по raw; checker использует
сохранённые компактные `profile-events.csv`. Протокол полного повтора
можно читать, но нельзя приписывать его новому ограниченному запуску.

Основные файлы:

- `chain.py` — проверяемые интерфейсы, свёртка, запреты двойного счёта,
  конверт второго момента и общая временная сетка;
- `calculate.py` — четырёхточечный COSRAD-конверт, последовательные замены,
  спектр/перенос, параметры и новый машинный договор;
- `profiles.py` — новая свёртка двух H-диапазонов для четырёх защит,
  общий профиль/фон, популяция и чувствительности;
- `checker.py` — отдельный скалярный интерполянт/адаптивная квадратура,
  исходные контрольные суммы и проверка полного квадрата;
- `conditions.json` — обязательства и последствия нарушения, а не
  автоматически подтверждённые свойства прибора.

Внешние PDF нужны для повторного источниковедческого чтения, но не для
воспроизведения арифметики; версии и локаторы — в паспорте. Тесты,
численная воспроизводимость и независимая научная рецензия различаются.
