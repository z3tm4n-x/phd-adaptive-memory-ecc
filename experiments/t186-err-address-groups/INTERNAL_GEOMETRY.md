# Внутреннее слово CY62167GE30-45: что известно о размещении 38 ячеек

**Вывод по п. 7д.** Ноль совпадений в 28 сериях получен для отдельной регулярной группировки №489 по 32 информационные ячейки на одном Y с шагом 16 по X. При H_pin эта группа фиксирует $x_{11}$, а целая половина ×16 включает оба значения $x_{11}$. При H_low два байта одной половины уже различаются по $y_4$ и находятся на разных Y. Поэтому использовать ноль этой группировки как основание для геометрии полного внутреннего слова в №493 нельзя. Для переноса на ГСО нужны сведения о второй половине и шести проверочных ячейках, а также верх прямого поражения слова одной частицей. Расчёты п. 3.4 на явно заданных парах адресов сохраняют свою область. **Инженерный вывод.** На одной локальной паре разрядных шин один обычный однобитовый усилитель за одну выборку не различит два независимых бита из разных строк. Разные локальные усилители, иерархические шины или две внутренние выборки с запоминанием первой совместимы с внешними сроками, если выборки и декодирование в них укладываются. Длительности внутренних фаз чтения и обновления неизвестны. Отдельные подмассивы могут граничить друг с другом. Схемы не задают минимального расстояния между половинами. [Схема GE30][ds2] · [Обзор][brief]

**OWN RESULT.** Воспроизведены 14 протонных и 14 ионных серий №489. Для одной строки с шагом 16 по X получено **0/140 106** и **0/33 696** совпадений. Максимальные размахи по X — 7 и 13 шагов соответственно. В двух строках через 16 по Y совпали 0 и 4 записи, в четырёх — 1 и 4. Архив не связывает удалённые инверсии с одной частицей. В независимых нейтронных опытах с включённой ECC Clemente и соавт. объясняют неисправленные чтения накоплением. Причина каждой пары в табл. IV не установлена. [Повтор и координаты](README.md) · [Архив](https://zenodo.org/records/8314389) · [Clemente и др., §IV.C](https://doi.org/10.1109/TNS.2018.2800905)

**Физический масштаб.** Для Cypress 65 нм опубликованы площадь ячейки 0,5–0,7 мкм² и эффективная глубина 0,372 мкм, подобранная по протонным сечениям. Для CY62167GE30-45ZXI с отключённой ECC в более ранней модели четыре вложенных объёма имеют глубину 0,360 мкм и стороны 0,360 / 0,984 / 1,612 / 3,160 мкм. Коэффициент сбора внешнего объёма равен 0,007. Измеренный шаг по X и верх радиуса сбора тяжёлых ионов в проверенных источниках отсутствуют. [Şerban и др., табл. I и рис. 7(f)](https://doi.org/10.1109/TNS.2024.3520506) · [Coronetti и др., §II и табл. III](https://doi.org/10.1109/TNS.2021.3061209)

**Что остаётся неизвестным (UNKNOWN).** Для однострочного размещения нужен минимальный зазор по X между центрами **всех 38** позиций. Если $d$ ограничивает глубину слоя, $\theta$ — угол к нормали, $\varphi$ — азимут от строки, а $r_X$ ограничивает боковое смещение до инверсии с учётом вторичных частиц, то достаточно зазора строго больше $d|\tan\theta\cos\varphi|+2r_X$. Для оставшихся направлений нужен верх частоты совместных поражений слова. При 0°, 45° и 60° опубликованы интегральные сечения инверсий без координат пар. Для квадратной ячейки, $d=0{,}372$ мкм и полного пересечения слоя по подстановке №493 расстояние в 16 шагов составляет 11,31–13,39 мкм. Порог проекции превышают 0,039–0,054% входящих треков изотропного потока. Доля прямых поражений среди частиц, вызвавших хотя бы одну инверсию, остаётся неизвестной.
