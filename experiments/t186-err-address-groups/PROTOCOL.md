# 7д. Признак общей группы до проверки файлов и подстановки координат

На базе `48d63ebb49cd1873a796f2a57c39c105eab92137` проверяем, присутствуют ли в опубликованных данных наблюдения для следующего различающего опыта. При подтверждённой коррекции в ×8 один устойчивый изолированный дефект должен воспроизводимо поднимать ERR при чтении всех четырёх байтов одного внутреннего слова. Полное правильное значение DQ совместимо с ERR=1. На двух полных проходах в разном порядке до первой записи нужен тот же набор адресов. Одна адресная запись правильного байта должна погасить сигнал во всей этой группе, контрольные группы с независимыми дефектами должны сохраниться. Записываются порядок, валидность, DQ, ERR и все записи. Охват за пределами исследованного диапазона указывается отдельно. [Задание автора](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/issues/186#issuecomment-6848671967) · [Исходная публикация, §IV.C](https://doi.org/10.1109/TNS.2018.2800905).

Из локального экземпляра публичного ZIP GENEPI сверим поля, разрядность анализа и наличие чтений без расхождения DQ. Литературный исполнитель устанавливает полноту поиска по всей записи UCM. При отсутствии полного журнала укажем минимальный различающий набор полей и запасной протокол с отдельным питанием SRAM, штатным ×8 и восстановлением номинала до чтения. Внутренняя нескорректированная шина может быть недоступна; отдельно обозначим, для какого вывода достаточно внешних DQ/ERR.

На принятой карте v21 у одного адреса ×8 восемь прообразов. Сверим прямое и обратное преобразования на уровне **32 информационных координат** четырёх адресов. Для демонстрации различимости заранее задаём три искусственных регулярных разбиения по свободным разрядам координат опубликованной сетки. У каждого байта меняются $x_4,x_5,x_6$. У слова дополнительно меняются $(x_7,x_8)$ в одной строке, $(x_7,y_4)$ в двух строках, $(y_4,y_5)$ в четырёх строках. Указанные разбиения покрывают ровно по 32 информационные позиции. Проверим пересечения этих полных слов с каждой исходной записью 28 серий по фильтру 1.4. Отдельно воспроизведём прежние осевые счётчики при шаге 16. Найденные адресные группы сравниваются с такими раскладками лишь после привязки разрядов тестера к опубликованному адресу и проверки абсолютных координат на независимых группах. Координаты шести проверочных позиций остаются отдельным входом.
