# Вывод для статьи 1

**OWN RESULT; условная модель, до независимой приёмки.** При одном обслуживании
сведения о событии позволяют получить достаточный допустимый период там,
где средний кандидат нарушает epsilon, а пиковое предписание не помещается
в ресурс. Главный пример — 4 МиБ, суточное событие r=100, правило С,
c=Delta=200 нс. Это вывод о трёх способах расчёта по принятому тесту,
не о глобальной оптимальности P_event и не о невозможности иной защиты.

## Что требуется знать о событии

**ASSUMPTION входа:** для каждого показанного подкласса заранее известны b,B,E;
`b<=lambda(t)<=B`, `int(lambda-b)<=E`. В массивной нормировке
`S_event=b²T+(B+b)E`; для выбранного прямоугольного свидетеля это точное S2.
В расчёте не нужна известная дата события. Центр T/2 выбран только для L.
Форма прямоугольника не объявляется реалистичным полётным журналом.

В главной точке на reference-масштабе E=1356,60096, а общий
F_s=113604,2043264: E/F_s≈0,01194147. После умножения на nW/19922944:
S_mean≈35,28269883/с, S_event≈125,00359237/с, S_peak≈334450,88169/с.
Из одного общего F_s период 17,218210 с **не следует**. Более широкий класс
даёт корень около 0,27949814 с и резерв 75,0328%. При r=1000 аналогичный
корень уже около 0,02831148 с и вне ресурса. Отдельная диагностика этого
ограничения есть во всех строках JSON; научное семейство не расширялось.
Нужные физические данные — основания b,B и применимой именно к классу
известной квоты E, полный закон меток по 39 битам и условия принятого сервиса.

Пиковый расчёт использует верх lambda<=B на всём сроке. Постоянный пик
может нарушать квоту E, поэтому он не используется как допустимый нижний
свидетель. Средний расчёт подставляет среднее прямоугольника в тот же тест;
его успешный формальный корень не является гарантией переменного профиля.

## Операция, полный горизонт и предел переноса

**SOURCE:** T340 §4 доказывает сокращение не более `200/(W+2)%` при существовании
обоих периодов в связанном ресурсе. Для 4 МиБ это менее 0,000190735%;
в главной точке фактическое сокращение корня ≈0,0000965289%.
При Delta=0 и правиле Б используется отдельная ветвь U=beta*S*P.
При И/С, Delta>0 — U=beta*S*((1+1/W)P+Delta). Малый сдвиг не позволяет
отбросить положительный член у границы epsilon. Неисчезающий при Delta→0
запас этой грубой ветви не считается физическим скачком Q.

При c=1 мкс, r=1000 уже нулевой событийный корень≈0,23419945 с меньше
Wc=1,048576 с. Процент между допустимыми конечным и нулевым режимами здесь
не определён. Это ресурсный провал данного достаточного теста.

**OWN RESULT учёта:** в главной точке событийный календарь резервирует
3 843 668,016251 с за весь T, средний кандидат — 1 084 888,6603782 с,
но последний исключён нижней оценкой. Для r=1000 событийный резерв
≈282 584 801,639367 с. Учтены начало при t=0, последняя частичная операция,
окончание по Delta и продолжение календаря после ошибки; никакой остановки
физического исполнения по моменту доказательного отказа нет.

**UNKNOWN:** размещение 6 МиБ сырой памяти, аппаратный верх c, корректность
сервиса при попаданиях, CPU/энергия, реальные требования приложения и ненулевые
прочие квоты не установлены этим расчётом. Они не приняты равными нулю:
числа занятости относятся только к объявленным полным резервам c при rho=1.
Для меньшего бюджета требуется rho_available>=Wc/P плюс согласованный
временной договор; один средний процент не доказывает ответ приложения.
Принятые нулевые прочие вероятностные слагаемые остаются явными допущениями.
