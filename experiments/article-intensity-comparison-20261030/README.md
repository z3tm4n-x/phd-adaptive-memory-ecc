## Повтор

Python 3.12.14, matplotlib 3.11.2, numpy 2.3.5. После установки
`python -m pip install -r experiments/article-intensity-comparison-20261030/requirements.txt`
из корня репозитория достаточно одной команды:

```text
python experiments/article-intensity-comparison-20261030/reproduce.py --check
```

Она проверяет хеши оснований, запускает направленные проверки, вычисляет все
34 строки и три рисунка в памяти, сверяет с поставкой. Без `--check` файлы
поставки воспроизводятся на диске; `--pilot` выводит одну строку без записи.
Ни принятые 16 малых случаев, ни корни P_ref повторно не вычисляются.
PDF/PNG сверяются побайтово, текстовые JSON/Markdown/SVG — после CRLF→LF;
те же правила действуют для хешей в manifest.json. Проверка экспорта относится
к указанным версиям окружения.
Время фактического запуска — [run_metadata.json](outputs/run_metadata.json),
отделено от детерминированных результатов; это не WCET контроллера.

План зафиксирован до новых подстановок коммитом
`e9adc21b2b57cc985f54cf6810713b32a4e1fb3a`: [PLAN.md](PLAN.md).
Научная база `610811084f4f8b8adcc9d04f4294aaf97832c82f`, старт ветки от
`07e431f18d63db5d5657dde0be71d11b97227cee`.
[inputs.json](inputs.json) закрепляет восемь оснований по SHA-256 LF;
[manifest.json](outputs/manifest.json) — код, данные и все экспорты.
Общий тест и нижний аппарат — [T340 §§4,7](../../theory/t340-article-significance-20261030.md),
перенос допускает [принятая рецензия](../../docs/scientific_reviews/T340_ARTICLE_SIGNIFICANCE_20261030.md).

## Рисунки, данные и подписи

Во всех рисунках: код (39,32), W=1048576 (4 МиБ полезных, 6 МиБ размещения),
T=315576000 с, epsilon=0,001, rho=1, правило С. Фон на reference-масштабе
0,0001586/с; нормировка массива nW/19922944. Три линии используют один
сервис и один достаточный тест. Параметры c и Delta — принятые условные
резервы/задержки, а не измеренный WCET. Для удобства экспорта сами изображения
не содержат внутренних номеров задач или PR. Размеры: 9,4×6,2 и 11,2×5,8 дюйма;
PNG 200 dpi, SVG/PDF векторные, линии различимы без цвета.

**Рисунок 1. Выбор интенсивности при суточном событии.**
Три положительных корня от r=B/b при c=Delta=200 нс. Серое поле под

## Состав и точность

[calculation.py](calculation.py) — рациональные корни, безопасный binary64,
ресурс, вызов принятой нижней функции и календарный учёт до T.
[checks.py](checks.py) — проверки нормировки, ветвей, границ и независимая
Decimal-проверка новых L с точностью 110 знаков.
[figures.py](figures.py) — таблицы визуализации и три изображения;
[reproduce.py](reproduce.py) — единый вход и сверка поставки.

Корень H и выбранный период не смешаны: `exact_root_s` — рациональный корень,
`selected_P_s` — наибольший binary64 не выше него. Это представимость вычисления,
не аппаратный такт. 24 десятичных знака границ нужны для проверки направления,
не означают физическую точность входов. В читаемой таблице периоды округлены
вниз до семи значащих цифр; верх операционного сокращения округлён вверх.
Статусы вне ресурса и непройденный достаточный тест не доказывают невозможности
защиты. Полная цена CPU, энергии, приложения и подтверждённый WCET остаются UNKNOWN.
