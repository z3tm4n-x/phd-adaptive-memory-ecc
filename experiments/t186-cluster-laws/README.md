# Четыре закона поражения. Выбор посылки о видимости для §1.2

**Предложение автору.** В доказательстве задавать вероятность того, что хотя бы одно слово родителя окажется среди слов, исправление которых контроллер успевает зарегистрировать к решению. Эта вероятность зависит от карты, фазы прохода и доступной истории. Средняя кратность нужна для пересчёта инверсий в частоту частиц. На шестисекундном стрессе лестница дала первое превышение в **4,35%** траекторий при двух равномерных словах и в **2,29%** при пяти соседних. У последнего закона она получила меньше сбросов и заняла меньше порта. На десятилетних входах различие в риске самой лестницы находится ниже разрешения опыта.

## Парное сравнение

Банк содержит 16 полных слов 32+6, 32 адреса ×16, 64 байта данных. Один проход длится 11,2 мкс, старшая ступень лестницы — 2,8672 мс. Пары половин — (0,16)…(15,31). Экспериментальный исход — хотя бы одно появление двух ошибочных позиций в одном слове за срок. На каждый из четырёх законов и трёх профилей пришлись 131 072 независимые траектории. На каждой одни времена, слова и биты использованы всеми режимами, а каждый контроллер получает ERR на своих чтениях. Законы, профили, периоды, правило, размер выборки и анализ были [опубликованы до прогонов](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/blob/c6a54e0d02233a21015d8429efd329ed7a4ce444/experiments/t186-cluster-laws/PROTOCOL.md).

## Два соперника §3.5

- **Постоянный режим для всего расчётного класса ГСО.** На его высоком плато ожидается 5,72095 инверсии на малый банк за десять лет. У пяти соседей экспериментальная граница сдвигается к более длинному периоду. При одних и тех же 375,810 с одиночный закон и смесь 0,8/0,2 дали низ выше допуска, пять соседей — верх ниже допуска, двум равномерным словам данных для классификации на этой точке недостаточно. Лестница на плато занимает около 352 205 с. Один профиль позволяет проверить этого свидетеля, а выбор лучшего соперника для всего класса требует границы на остальных допустимых профилях. [Свидетель №457](../../theory/t196-native-err-20261110.md)
- **Постоянный режим для всех принятых реконструкций.** На архивном свидетеле SEPEM 1996–2006 ожидается 5,01143 инверсии. При пяти соседях 3006,477 с имеет верх ниже допуска, у трёх других законов этот период остаётся неразрешённым. При 6012,954 с все три уже имеют низ выше допуска, пять соседей — интервал через допуск. Разброс отдельных классификаций для одного и двух равномерных слов не устанавливает их строгого порядка. Здесь проверено одно принятое десятилетие. Общая допустимость по всем реконструкциям и новый нижний свидетель цены постоянного класса остаются задачей доказательства. [Архивный свидетель №462](../../theory/t196-archive-same-map-20261110.md)

На этих двух входах уменьшенная лестница почти всегда идёт с шагом 256L и занимает около 0,111607% порта. Даже самый дорогой из отобранных на данных постоянных режимов занимает 10,74846 с за десять лет. При уменьшении банка сократилась длительность старшей ступени, а при сохранении нормировки сократилось число инверсий. Абсолютные периоды и цены в таблице относятся к 16 словам. Прежние доказанные сравнения для 0,125 МиБ со своим законом и календарём сохраняют их исходную область.

## Что передать теоретику

Пусть к решению проверяются четыре последовательных слова из 16. Для четырёх законов вероятность пересечения этой четвёрки одной меткой равна соответственно **1/4, 9/20, 21/80 и 1/2**. В пересчёте на одну ожидаемую инверсию банка интенсивность таких родителей пропорциональна **1/4, 9/40, 7/32 и 1/10**. Родитель с пятью словами чаще пересекает четвёрку при своём появлении, однако сами родители приходят в пять раз реже одиночных. Число исправлений, число положительных отчётов и число понижений ступени различаются. Например, для пяти соседей на стрессе в среднем получено 6,330 завершённых записей, 1,295 сброса и 0,955 перехода с более редкой ступени на L за 6 с.

Контроль с **одинаковым средним 2** получается перечислением, без пятого прогона. Для двух соседних слов вероятность задеть ту же четвёрку равна 5/16 (пять из 16 стартов), для двух равномерных — 9/20 (54 из 120 пар). В §1.2 предлагаем проверять условную вероятность пересечения множества слов, доступных к данному сечению, затем отдельно обосновывать сохранение дефекта, выборку ERR и регистрацию полного прохода. Геометрическое пересечение само по себе не обеспечивает сброс. Для постоянного соперника потребуется также вероятность совместного попадания в конкретные слова. Для пары соседей она равна 1/4 при пяти последовательных словах и 1/120 при двух равномерных. Четыре основных закона одновременно меняют кратность и размещение. Из наблюдаемых частот нельзя выделить действие одной лишь кратности.

**Цена и условия исполнения.** Для образца памяти предполагается общий чистый старт. Защита занимает порт на чтениях и обратных записях, включая работу после первого двухбитового состояния до T. Модель №460 возвращает в контроллер ERR при ненулевой маске и после превышения способности к исправлению. Эта ветвь определяет воспроизводимую цену продолжения на стенде. Отчёты целы и поступают после последнего release к сечению, I=0. При принятом регистровом управлении таймер, счётчик, смена ступени и доставка отчёта занимают 0 дополнительных секунд **порта SRAM**, X=0. Процессорная работа, энергия, ошибочные отчёты и поведение реального декодера после двух инверсий требуют самостоятельных характеристик. Доверительные интервалы характеризуют разброс выборки при зафиксированном законе.

## Воспроизведение

Команды выполняются из корня рабочей копии. Проверенная среда — Python 3.13.5, NumPy 2.2.4, SciPy 1.15.2, Numba 0.61.2.

```sh
python experiments/t186-cluster-laws/verify.py
python experiments/t186-cluster-laws/run.py --cache /path/to/t141-cache --check
python experiments/t186-cluster-laws/verify.py --results
```

Без `--check` вторая команда записывает results.json. Нужен исходный массив T141 с опубликованной контрольной суммой. Кэш можно восстановить из SEPEM RDS v2. [SHA-256](../t141-radiation-chain/outputs/profile-provenance.json) · [Порядок повтора T141](../t141-radiation-chain/REPRODUCE.md)
