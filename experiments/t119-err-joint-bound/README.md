# T119: адресный совместный фазовый расчёт

Issue #119, draft PR #121. База `3dc57116db443a8e963126eb18791b242e2dc7c0`;
принятая T114 `a8f57dc33f919ccca8e6474141615f55f88cb938` импортируется только
для чтения. Научный текст: `theory/t119-err-joint-bound.md` и приложение.
Это промежуточная условная поставка; 10×/спокойный1% пока не подтверждены.

## Одна команда повтора, без перезаписи

Из корня репозитория, Python3 стандартной библиотеки:

```sh
python3 -B experiments/t119-err-joint-bound/verify.py
```

Команда сначала полностью повторяет штатную T114 **без** `--write`, затем
новые тесты и конечные расчёты; сверяет новый report.json побайтно.
В неё входят прежние цепочки T110/T104/А/T95 через T114.
Несовпадение — ошибка; не исправлять старый отчёт пересохранением.
Отдельный `--write` предназначен только для осознанной генерации **нового**
T119/report.json после изменения собственного расчёта. Он не пишет T114.

## Что в пакете

- `PLAN.md`: план, опубликованный **до** подбора на `2e56f19b…`, и журнал
  нового инструмента; исходная сетка T114 не изменена.
- `config.json`: точные SHA, основная область, конечная семья таймеров,
  десять направленных подстановок и ненулевая область приложения.
- `joint.py`: совместный нулевой участок всех пропущенных границ,
  фактические фазы, конечные ограждения времени/интенсивности.
- `balance.py`: доказанная проверка заданной функции запаса на целых
  прямоугольниках, в том числе при отрицательном генераторе. Не оптимизатор.
- `balance_preview.py`: float-предложение коэффициентов, **не допуск**.
- `history_checks.py`: явные допустимые подъём–плато–спад, начальный пик,
  повторный подъём; W524288 и реальные фазы, полные/частичные записи на
  границах freeze. Это диагностика, не симуляционная замена гарантии.
- `test_joint.py`, `verify.py`, `report.json`: регрессии и точные результаты;
  все отказы, чувствительности и неизвестные поля сохранены.
- `HANDOFF.md`: параметры, ресурс, область приложения и остаток доказательства.

## Арифметика и воспроизводимость

Допуск использует Fraction и принятые Decimal48 интервалы DOWN/UP с
ограждёнными exp/log. M=8 целых фазовых интервалов; начальные192 q-клетки,
пять конечных уточнений активных клеток, u-множители1/2/4/16. Доказательство
между узлами — монотонность K и дроби мажоранты, не плотность сетки.
Временной пилот: M4, q96, Z48; 4560 проверенных прямоугольников.
В его config: alpha имеет единицы с⁻¹, q0 — с⁻¹, A — с;
Z и вероятностный интеграл безразмерны. Все календарные времена — секунды,
ticks — целые такты core; проценты выводятся из безразмерных долей.
Новый полином-момент и экспоненциально взвешенный конус сверены с Decimal100.
Для барьера **самой релаксации**, не физического риска, вычисляется нижний
конец K; верхний конец не выдаётся за нижнюю вероятность события.

У явных историй интегралы имеют закрытые полиномиальные/экспоненциальные
первообразные с направленным округлением; report даёт оба конца и ширину.
Все144 адресных вероятностных выражения ограждены с шириной <1e-35.
Их флюенсы <F_S, рост точно .048 на подъёмах и только разрешённые падения;
после1600 с фон до T. Это одни среды, а не отдельные худшие прошлые.

Float-семейство таймеров и245 коэффициентов запаса сохраняется в report
полностью, с `admission_authority=false`. Его минимум не научный сертификат
и не глобальный оптимум. Только названные directed_cases проходят допуск.
Направленный фазовый расчёт имеет объём порядка M*k_a²*N_q; для основной
поставки максимальный полный k_a=7. k_a=33 проверяется адресно в одном q для
барьера, а не объявляется допустимым после float-прогона.

## Порядок фактической работы

Штатный T114 (19 тестов,439 проверок, byte-identical report) повторён до
нового подбора; план сохранён в отдельном опубликованном коммите.
Сначала выведено совместное событие, затем проведён численный пилот и
конечный отбор. Полные явные истории добавлены при последующей проверке
доказательства, после первого численного пилота; они не использовались
для подбора. Это фактический порядок, а не утверждение, что все проверки
из первоначального плана были выполнены до первого числа.

Результат — меньшее достаточное Q(T) и новые условные строки при прежних
входах. Улучшение до целевых10×/1% пока не получено. Нет новой физической
кампании, монитора, RTL, изменения принятого научного текста или общего
оптимизатора. Внешняя SEC-DED(39,32) этой проверкой не квалифицируется.
