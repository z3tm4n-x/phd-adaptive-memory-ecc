# Повторение проверок поставки A

Из каталога задания, Python 3.11+ с NumPy и SciPy:

```sh
python -B src/verify_package.py
python -B src/prepare_inputs.py --archive /absolute/path/to/results.zip
python -B -m unittest discover -s tests -v
```

Архив должен иметь SHA-256 `84b578195499782bb70570dc1dd6d492711a3f6e7f167528912295bf6a2e7beb` и размер 69464 байта. Он не копируется в репозиторий. Без `--archive` можно повторно получить численные таблицы из сохранённых опор; уже проверенный manifest архива остаётся в поставке.

Для независимого повторения новой оцифровки: взять проверенный `coronetti2020(2).pdf` с хэшем из sources.json; извлечь растровую картинку рис.6 на PDF-странице 5 по bbox из digitization.json. В native-изображении 1050×618 использовать красную маску R>200,G<80,B<80, 4-связные компоненты >100 пикселей; выбрать изолированные центры при E≈0.6,0.7,2.0. Калибровка и исходные центры сохранены. Округлять только итоговую новую σ до трёх значащих цифр.

`contracts.py` — отдельный малый oracle, **не** production-код RES-003. Тесты не воспроизводят всю прежнюю кампанию, не оценивают новую вероятность ошибки и не дают новому контроллеру PASS. Скалярный angular-check использует два способа квадратуры, но их совпадение не объявляется строгим error budget.

`src/import_into_checkout.py` переносит этот каталог в доступный локальный checkout после проверки точной базы, ancestry, чистоты дерева, ветки и коллизий. По умолчанию только проверка; `--apply` копирует, `--commit` вместе с `--apply` создаёт локальный commit, `--push` дополнительно публикует только целевую ветку обычным push без force. Скрипт не запускался на реальном checkout в этой среде. Main/PR/merge/Issues не затрагиваются.

Проверку целостности выполнять до повторной генерации. На другой версии численных библиотек последние знаки квадратуры могут отличаться; это нужно сравнивать по численным допускам, а не незаметно обновлять manifest. Версии фактического исполнения — provenance/execution.json.

Пример безопасного переноса из распакованного каталога задания:

```sh
python -B src/import_into_checkout.py /path/to/local/repository
# Следующая команда только по намерению выполнить запись и публикацию:
python -B src/import_into_checkout.py /path/to/local/repository --apply --commit --push
```

Скрипт откажется перезаписать отличающиеся файлы существующей ветки. Совместимое содержательное продолжение в таком случае выполняется отдельным осознанным Git-действием, без reset/force.

Проверки безопасного импорта на автономном временном Git-репозитории (без сети и push):

```sh
python -B tests/check_importer_fixture.py
```

Они требуют неизменённого проверяемого пакета. Для других версий библиотек выполняйте их до регенерации численных файлов. Сохранённый результат — outputs/importer_fixture_checks.json.
