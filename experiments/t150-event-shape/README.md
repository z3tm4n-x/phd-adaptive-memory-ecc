принята к исполнению по прямому поручению автора 13.10.2026.

Принятый тракт T141 закреплён на `ea789fc4b4d69699696d66a41b2738099d4154bb`.

[комментарий](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/pull/145#issuecomment-6144558391).

## План до нового расчёта

1. Проверить SHA сохранённых компонентных рядов T141; повтор полной свёртки
   4,36 млн исходных спектров не нужен без обнаруженного расхождения.
2. Для каждой защиты 2.5/3/3.5/4 г/см² вычислить полные первые/вторые моменты
   по одной хронологии. Отделить фон, низкий H (<5 MeV перед BEOL), высокий H
   и условный исключительный LET-вклад; сохранить матрицу перекрёстных членов.
3. Сравнить коэффициенты формы события и перекрывающихся 10-летних окон
   с прежними 0.85/0.53. Новая номинальная история содержит время вне маски.
   Сопоставление прямоугольника и формы делать при одинаковых b, пике и F.
4. Изолировать влияние низких энергий множителями 0/0.5/1/2; условную историю
   LET при этом не пересчитывать из изменённого H. Отдельно проверить q_LET
   и геометрию, сегментацию, цикл, внутрибиновые пики и редкий хвост.
5. До MC определить все исходы: набор, не помещающийся в T, получает S₂=+∞
   и событие превышения, без отбрасывания/перевыборки. Дать аналитический
   верх вероятности overflow в объявленной эмпирической модели. Новая MC
   нужна только для совместного сравнения откликов и полноценного исхода.
6. Выдать две разные статистики: q90 абсолютной профильной модели и
   распределение r при фиксированных COSRAD b,p,F. Не перемножать квантили.
   Неопределённость MC отделить от неопределённости переноса/популяции.
7. Рассчитать G_ideal=T·S₂/F² для согласованных реализаций и потенциал
   относительно явно заданного постоянного режима. Прежние R0-A/T119/T135
   и full-U T146 показать отдельно. Для новой среды G_cert выпускать только
   при полном договоре родителей, D*, ERR/канала, сервиса и соперника;
   иначе дать численные достаточные требования и null сертификат.
8. Направленные проверки и независимая малая проверка новых тождеств;
   отчёт, условия применения, SHA и команда воспроизведения. Независимую
   научную рецензию нового вывода не подменять самопроверкой.

Первый выход к 16.10 — эффект формы и низких энергий. Развилка к 23.10:
совместная модель с проверяемым переносом (ещё 3–5 рабочих дней) либо
законченная параметрическая область с сохранением осторожного конверта.
Основной риск — отсутствие основания будущего совместного хвоста; число
MC его не устраняет. Три пути и оценка труда уже определены в Issue.

Принятые результаты, R0-A, А2 и main не изменяются. Новых физических
испытаний, сообщений другим исполнителям и запуска дополнительных слотов нет.
