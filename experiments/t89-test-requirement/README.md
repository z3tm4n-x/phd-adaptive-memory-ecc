# T89 — расчётное требование к испытанию полного слова CY62167

Задача [#89](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/issues/89),
R1/R3. Главный пример: внутренний SEC 32+6, R0-A, ГСО, 10 лет;
основная защита 3 г/см², 2,5 г/см² — отдельно.
Это проект проверяемого требования, **не заказ и не проведение испытаний**.

База: `578d45bb705814f37b6c7116259619e106cf60c9`.
Переиспользуется принятая T81 `106dcb50b836b47ae6ee7f549975c11d0dbb4982`:
`METHOD.md`, `request_for_author.md`, `allocation_fluence` и опубликованные
веса среды. Решение автора 03.10 и Issue заменяют прежнее ожидание
физической квалификации; PR #91 не требуется ждать.

## Зафиксированное требование

N_D считает родителей, изменивших ≥2 различные позиции хотя бы одного
**полного** слова: 32 data + 6 check. Один родитель учитывается один раз.
Цель — верх среднего E[N_D]≤D₀, сейчас D₀=5·10⁻⁵;
безопасные D_крит по вариантам поступят из #88 и пока не определены.

При новом нуле и допустимом переносе опыта на страт j:

\[
 F_{\mathrm{new},j}\ge
 \frac{[-\ln(\alpha_j)C_{\rho,j}/b_j-E_{\mathrm{old},j}]_+}
 {(1-\theta_{F,j})q_jg_j},\qquad
 \sum_j b_j\le D_0-R,\quad\sum_j\alpha_j\le\alpha_\Theta.
\]

q — обоснованная нижняя полнота регистрации исходного полного события,
g — согласованная нормировка; R — верх непокрытого вклада за срок.
Неизвестные q/g/R не заменяются 1/1/0. Data32/ECC-off не засчитывается
как full38/ECC-on: принятый зачёт старой экспозиции равен нулю по правилу
расчёта, а её физическая пригодность остаётся неизвестной.
Ноль ERR не равен нулю прямых родителей; ERR не объявляется DED-флагом.
