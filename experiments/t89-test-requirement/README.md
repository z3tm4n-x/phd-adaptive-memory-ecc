# T89 — расчётное требование к испытанию полного слова CY62167

Задача [#89](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/issues/89),
R1/R3. Главный пример: внутренний SEC 32+6, R0-A, ГСО, 10 лет;
основная защита 3 г/см², 2,5 г/см² — отдельно.
Это проект проверяемого требования, **не заказ и не проведение испытаний**.

База: `578d45bb705814f37b6c7116259619e106cf60c9`.
Переиспользуется принятая T81 `106dcb50b836b47ae6ee7f549975c11d0dbb4982`:
`METHOD.md`, `request_for_author.md`, `allocation_fluence` и опубликованные
веса среды. Решение автора 03.10 и Issue заменяют прежнее ожидание
физической квалификации; PR #91 не требуется ждать.

## Зафиксированное требование

N_D считает родителей, изменивших ≥2 различные позиции хотя бы одного
**полного** слова: 32 data + 6 check. Один родитель учитывается один раз.
Цель — верх среднего E[N_D]≤D₀. Сохранена исходная точка D₀=5·10⁻⁵;
добавлены четыре безопасных нижних конца для налога ≤1% из T88 / PR #93,
SHA `da4de9c6684efa20de155b422dd0b25f50930108`.
Это наибольшие найденные сертифицированные точки конечного семейства T88,
не точные глобальные пороги. Обе пустые области ERR-only сохранены.

При новом нуле и допустимом переносе опыта на страт j:

\[
 F_{\mathrm{new},j}\ge
 \frac{[-\ln(\alpha_j)C_{\rho,j}/b_j-E_{\mathrm{old},j}]_+}
 {(1-\theta_{F,j})q_jg_j},\qquad
 \sum_j b_j\le D_0-R,\quad\sum_j\alpha_j\le\alpha_\Theta.
\]

q — обоснованная нижняя полнота регистрации исходного полного события,
g — согласованная нормировка; R — верх непокрытого вклада за срок.
Неизвестные q/g/R не заменяются 1/1/0. Data32/ECC-off не засчитывается
как full38/ECC-on: принятый зачёт старой экспозиции равен нулю по правилу
расчёта, а её физическая пригодность остаётся неизвестной.
Ноль ERR не равен нулю прямых родителей; ERR не объявляется DED-флагом.

## Короткое требование разработчику

**Чтобы подтвердить E[N_D]≤D₀, измерить в заранее назначенном ECC-on опыте
с ЛПЭ≥57 МэВ·см²/мг на чувствительном слое число полных прямых родителей
либо охватывающий их тестовый флаг, используя независимый эталон и
обоснованную полноту; при нуле нужен флюенс по формуле выше.**
Для D₀=5·10⁻⁵ в условной скалярной области T81 при одном uniform cap,
α=0,05, θ_F=0,3, q=g=1, R=0 и без старого зачёта достаточны числа ниже.
Дополнительно должны быть обоснованы перенос по ЛПЭ/углам, регистрация
data+check/check+check и нижняя экспозиция. Пока не покрыты hidden6/группировка
или заменяющий их black-box договор, межточечные/внешние направления,
спектральные хвосты и регистрационные потери; общий физический флюенс неизвестен.

| 5·10⁻⁵ | **3** | **2 014 297,960** | Один cap: 95%; R=0 только в иллюстрации |

одном cap и без старого зачёта; физический флюенс каждой строки остаётся null:

Сохранены условия T88: `T73_published`, полный internal38, запас времени
10%, условный монитор a_M=A_M=10⁶, w=d=1 с, выдача w/2, LOW direct-fast;
реальный прибор, полнота ERR и joint WCET не квалифицированы. Точные
канальные, ресурсные, средовые и стоимостные условия —
[METHOD §6](METHOD.md#6-повтор-и-передача-88) и `inputs/t88-effective_inputs.json`.
Верх скобки (нижний +10⁻⁹) для требования не использован.

Границы ≤1% оставляют лишь ~7,29·10⁻¹⁰ / ~8,56·10⁻¹⁰ запаса риска.
Отдельно посчитаны D_сертиф **без** требования 1%, предложенные рабочие
точки T88 с запасом ≥5·10⁻⁵ и политики ≤1% при тех же рабочих D₀.
Например, при 3 г/см² рабочий combined D₀=0,0002802445 требует
359 382,247 см⁻²; налог ≤0,287444410%, запас риска ≥0,000051910293120190.
При 2,5 г/см² рабочий combined D₀=0,0000545365 требует 2 310 790,766 см⁻²:
политика с запасом ≥5·10⁻⁵ стоит ≤25,542583406%; другая политика при том же
D₀ стоит ≤0,998874081%, но её запас лишь ≥0,000004537355937069.
Эти варианты нельзя смешивать. Числа всех вариантов — в раздельных таблицах.

Верх среднего D*, статистические 95%, условный ε=10⁻³ за миссию и уровень
превышения расчётной вспышки 0,1 не отождествляются. Большой флюенс не
устраняет отсутствие наблюдаемости полного события. Флюенс округлён вверх.

## Поставка и повтор

Из корня репозитория, Python 3.12+, без сети и внешних зависимостей:

```bash
python -X utf8 -B experiments/t89-test-requirement/run.py
```

Произвольный положительный D₀: добавить `--D0 0.0001
--out experiments/t89-test-requirement/recheck`.
26 тестов: регрессия 16 опубликованных значений T81, 96 исходных и 54 новых
независимых Decimal-100 проверок достаточности/соседнего меньшего флюенса;
монотонность, единицы, 1/D, остаток, q=0, null. Перенос T88 проверяет
контекст, SHA/контрольные суммы, точные концы скобок, риск+запас=ε и цену;
это не новый поиск или независимая рецензия всего T88.

- [Таблица всех требований](outputs/table.md), CSV/JSON и протокол проверки — `outputs/`.
- [Формула, покрытие, масштабы и условия](METHOD.md).
- [Протокол полного ECC-on события и углов](PROTOCOL.md).
- `config.json`: закреплённые входы T81/T88, отдельные условные допущения,
  неизменённые физические null и шесть статусов для налога ≤1%.
- `inputs/t88-*.json`: точные опубликованные снимки четырёх файлов на SHA
  T88; контрольные суммы проверяются офлайн. `outputs/t88_transfer.json`
  сохраняет цели, точные дроби риска/цены и соответствующие политики раздельно.

**Расчётная поставка #89 завершена, включая handoff #88.** Исходная формула
и ECC-on протокол не изменены. Для ERR-only отсутствие порога ≤1% — результат
установленного семейства, не ожидание данных, не D₀=0 и не физическая невозможность.
Остаток применимости: полный канал наблюдения, q/g/нижний флюенс, оболочка
по углам/ЛПЭ и R по-прежнему не квалифицированы. Возможны условное применение
формулы либо её конкретизация после отдельного подтверждения контрактов;
получение этих данных не назначено и не требуется для завершения этой задачи.

и экспозиции» R1/R3; новый RES/физическая квалификация не заявлены.
Принятые файлы не изменены; новых источников, внешних запросов, облучений
