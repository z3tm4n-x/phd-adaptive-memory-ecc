# RE-INTERNAL-COUNT-CONTROL-01

Рабочая поставка Research Engineer по принятому заданию. Не Scientific Review,
не RES и не утверждение литературной новизны. Начинать с [REPORT.md](REPORT.md),
математическое основание — [derivation.md](derivation.md).

Base: `a44355e38a5434fa69d7c343e456ddd944315d46`.
Ветка: `research/internal-count-control-01`. Изменения только в этом каталоге.

## Воспроизведение

Из корня репозитория:

```sh
cd experiments/RE-INTERNAL-COUNT-CONTROL-01
python -m pip install -r requirements.txt
OPENBLAS_NUM_THREADS=1 python reproduce.py
OPENBLAS_NUM_THREADS=1 python reproduce.py --full
```

Первая команда проверяет детерминированную допустимость, ядра и бюджет,
малый точный эталон и независимые тесты. Вторая дополнительно повторяет
проверочное сравнение на 20000 реализаций для каждого D с замороженными
настройками аналога из `outputs/selected_analogue.json`.

Повторить также пилотную настройку:

```sh
OPENBLAS_NUM_THREADS=1 python reproduce.py --retune --full
```

Пилотные промежуточные массивы сохраняются в `cache/`; этот каталог не входит
в поставку. Полные трассы и массивы Монте-Карло генерируются командой,
в Git сохраняются основные таблицы и точные фрагменты трасс. Для чистой
пилотной проверки удалить только созданный этим пакетом каталог `cache/`
либо запускать из свежего checkout. Отсутствие cache не мешает воспроизведению.

## Состав

`core.py` — счётчиковое ядро, предел ошибки, 26-компонентный фильтр, общий
бюджет и резервное продолжение. `simulate.py` — отдельная физическая событийная
модель, компактная реализация контроллера, адаптация PA-DOM. `exact_oracle.py`
— поглощающая совместная CTMC малой памяти. `feasibility.py` — все 12 Fixed
и 144 Precomputed. `tests.py` — независимые оракулы и адресные проверки.
`tune.py`, `validate.py` — раздельные пилот и проверочная выборка.
`outputs/manifest.json` — версии среды и хэши исполняемых файлов/результатов.

Математическая гарантия условна на принятую физическую модель и явно описанный
численный контракт. Доверительный интервал Монте-Карло не заменяет гарантию.
Время обновления измерено на CPU этой среды, а не на бортовом процессоре.
