# #340 — значимость поправок

Из этой папки, Python 3.10+; сторонних зависимостей нет:

```text
python -B reproduce.py
```

Из корня репозитория:

```text
python -B experiments/t340-article-significance-20261030/reproduce.py
```

Команда проверяет 16 принятых случаев без повторения точного расчёта Q/MC,
вычисляет зарегистрированные срезы и аналитические границы, перезаписывает
только собственные `outputs/results.json`, `outputs/TABLE.md`, `outputs/SMALL16.md`.
Длительность — несколько секунд на рабочем окружении, время не является
инженерным WCET. Старые входы/результаты читаются из репозитория.

* [Записка с доказательствами](../../theory/t340-article-significance-20261030.md).
* [PLAN](PLAN.md), [inputs](inputs.json) зарегистрированы до расчёта:
  [fcf654e](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/commit/fcf654e59d35a9ba98acbeb4f94c51f3a277bbf1).
* [Основная таблица](outputs/TABLE.md), [малая проверка](outputs/SMALL16.md),
  [JSON](outputs/results.json) с наружными интервалами, рациональными корнями,
  ресурсом, разложением эффекта и хешами входов (нормализация CRLF→LF).

Десятичные цифры таблиц округлены для чтения; при выборе исполнимого периода
нужно округлять **внутрь** пересечения риск/ресурс и снова проверять тесты.
Пакет рассматривает физические секунды условного непрерывного календаря,
не квалифицирует часы и целочисленный таймер.

Основной `P_corr` — наибольший по явно выбранной первой ветви достаточного
верха, не по всем усилениям и не истинный оптимальный период. В пустых
множествах процента нет. `L>epsilon` исключает конкретный период при
объявленном законе; `U>epsilon` такого вывода не даёт.

Чувствительность — условный singleton/ГСО/правильный сервис. `n=39` и
`n=38` в старых проверках сохранены отдельно; физическая alpha не задаётся.
Малость операции доказана только при Delta<=c<=P*rho/W. При pending вне
блока, иной модели записи, MCU или условном отсутствии попаданий в aperture
нужны соответствующие дополнительные основания и члены бюджета.
