В 548 одноминутных файлах выборки T67 нет пригодной соседней пары, у которой оба отсчёта имеют строгие флаги. Прямой повтор прошёл по временам, маскам и сигнатурам приборов в сохранённых свёртках. Из пятиминутных файлов получены **378 пар G16 East и 409 G16 West**, всего 787. Наибольшая положительная разность средних — 0,036079863→0,041488018 с⁻¹ у G16 West 10.09.2017 22:10→22:15 UTC. Удвоение наблюдаемого наклона 0,0000180271820963 с⁻² с внешним округлением до 10⁻⁹ даёт **gₛ=0,000036055 с⁻²**. У G17, G18 и G19 в проверенных продуктах дополнительных строгих пар нет. За пределами согласованной выборки новые минутные пары не установлены. В RDS v2 отдельный эквивалентный флаг для каждого бина отсутствует. [Прямой пересчёт по приборам](strict.json).

**Проверка каждого окна.** Пусть a=gΔ, mⱼ — надфоновая средняя. Из точного бинового теста теоретика получается наименьший требуемый старт Lⱼ в пределах [0,R] обращением средней min(R,x+gt). Максимально возможный конец бина i равен Yᵢ=min(R,√(2amᵢ)) при mᵢ≤a/2 и min(R,mᵢ+a/2) в остальных случаях. Для i<j несовместимость установлена, когда Yᵢ+g(tⱼ−tᵢ−Δ)<Lⱼ. При свободном старте и допустимых собственных средних весь тест равносилен отсутствию таких пар внутри окна. Для каждого j достаточно самого позднего нарушающего i. Содержащие пару старты образуют замкнутый целочисленный диапазон от j−W+1 до i, обрезанный архивом; W здесь число бинов десятилетия. Объединение этих диапазонов даёт точную маску без сброса состояния на начале события. На полном архиве для gₛ найдено 256 таких конечных бинов, включая несоседние ограничения. Маска исключённых десятилетий совпала с маской по 174 соседним нарушениям. [Код](strict.py) · [Сверка с прямой рекурсией](checks.py).

**Совместная проверка J на строгом подмножестве.** Для двух целых отрезков, содержащих все 657 558 проходящих окон, построены отдельные профили. В каждом бине прямая идёт от zᵢ до 2mᵢ−zᵢ. Нижний предел lᵢ=max(0,2mᵢ−R,mᵢ−a/2) ограничивает пик и наклон, qᵢ=max(lᵢ,min(mᵢ₋₁,mᵢ)) и zᵢ=min(qᵢ,2mᵢ−qᵢ₊₁). В начале q₀ выбирается с m₋₁=m₀, в последнем бине z=q. Для каждого бина проверены целочисленно точное среднее, пик, рост и только нисходящие скачки между бинами. Полные отрезки имеют J≤24,024395 и J≤16,963099 с⁻¹. Для любого их подокна его начальный уровень не превосходит начального уровня всего отрезка плюс уже израсходованный положительный подъём. Поэтому J подокна не превышает J отрезка. Эти профили служат свидетелями для gₛ; при определении U используются ранее зафиксированные реконструкции PR423.
