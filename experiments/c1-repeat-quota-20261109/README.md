# Ц1–Ц3. Квота повторных подъёмов и итог на 0,25 МиБ

**На основном подклассе и в исходном (A) сохраняется постоянный кандидат 4L=51,380224 мс.** На 0,25 МиБ он даёт Q⁺≤0,000853861825 при ε=10⁻³. Для известных защитных операций необходимы ≥5,0916431% шины, кандидат занимает ≤6,2111105%, или ≥16 068 003 с и ≤19 600 775 с за десять лет. Для исследованного автономного меню {h,4h} при h≥2 есть допустимый профиль, на котором сама вероятность первого неисправимого слова превышает ε. Для h=1 достаточный тест не проходит, а физическая допустимость остаётся открытой. Даже при её подтверждении известные операции оставляют **не более 500 674 с, 0,158654 процентного пункта шины, или 2,55436% относительно цены лучшего допустимого постоянного режима**. Это предел возможной экономии данного меню. ### Вероятность и цена

Здесь h=1 требует Dₒ+Iₒ≤L=12,845056 мс, где Dₒ включает проход и drain, а Iₒ — установку команды. Плато и допустимое штатное исполнение без внеочередных E дают нижний свидетель самой Q по (E) PR424. При h=2,…,6 наихудший из этих пяти нижних свидетелей >0,001091314, при h≥7 имеем >0,001074542. При h=1 одиночный свидетель даёт лишь >0,000502197. Для статистической остановки допустимый путь пустых отчётов в начале плато имеет вероятность ≥0,9951487. Для версии без этой остановки низ мажоранты V*>0,001305143. Отдельный верх (6) PR420 для остановок при d=0, δ₀=0,000006 и Dₒ≤L даёт q≤0,002834346. Он включает остаток и краевые операции, действует на весь класс. Зазор относительно ε остаётся. Неизмеренное добавочное исключение или d увеличивает q на свой бюджет. [Физический свидетель и сертификат](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/blob/00efd0022164b2e8d6e45fc575ae4b4729a5cc16/theory/t196-c2-growth-start-20261109.md) · [Проверка диапазона h и цены](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/pull/424#issuecomment-6742263528).

При допустимости h=1 одни обязательные чтения требуют ≥19 100 100 с, ≥6,0524566% шины. Для верхней цены работы после остановки сохранён максимально возможный счёт аппаратных команд. При принятом временном контракте обозначим η=E N⊥ — ожидаемое за срок число перезапусков из-за недостоверного или позднего счёта и ложных сообщений до остановки. Из (10) PR420 при приведённом q и d=0:

* E T_fast ≤ min(T, 895 687,00 + 0,025690371·η) с. При η=0 верх доли срока составляет 0,283827%. Для общего η возможен быстрый режим весь срок.
* E N_switch ≤ min(24 568 143 603, 69 730 796 + 2η). В этом верхе учтены команды и после остановки. На номинальной истории своевременных нулевых отчётов с чистого старта одна смена режима, T_fast=Dₒ+2L≤0,038536 с. При постоянном штатном invalid смен нет и T_fast=T. Это конкретные истории, а не средние.
* На любом окне 1 мс внутри FAST занято ≤57,934624% шины и ≤67,936577% последовательного обслуживания при лимите 80%. Сервис включает слоты приложения и резерв управления. Запас последовательного обслуживания ≥12,063423 п.п. действует вместе с ограничениями слота и атомарности.
* При η=0 верх известных основных проверок и ремонтов за срок равен 19 946 704 с шины (≤6,320730%), serial ≤8,893523%. При неограниченном η соответствующий верх ≤78 348 361 с (≤24,827098%), serial ≤35,031384%. В обоих случаях сохраняется число команд после исключения, оплачивается работа после неисправимой ошибки. Дополнительные guard-операции, регистрация, дедупликация, обработка пачек и переключения оплачиваются отдельными неотрицательными C_guard, C_reg, C_switch. CPU и энергия остаются параметрами. При утрате аппаратного верхнего числа команд после исключения для полной ожидаемой цены нужен фактический верх оставшейся работы. Инициализация и приложение сохраняют учёт PR423.

### Покрытие и чувствительность

Квота 28,855 с⁻¹ закреплена [отдельным коммитом инженера](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/commit/d8eb9e4192cfaa7e37182ab87a4794dd2e2708cf) и [фиксацией теоретика](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/commit/5e3b40b46c7cbb2baebd6e2f3bfde32d92abfca0) до расчёта правила. На всех полных окнах покрыты биновые интегралы номинальной реконструкции. Для произвольной начальной фазы также проверена экспозиция. Максимум S₁=187 463,233269 <187 464. Для GOES измеренное, один возможный расход квоты и остаток для скрытой вариации указаны в [отчёте квоты](QUOTA.md).

Физического верха J на пропусках данные GOES не дают. В начальном неизмеренном промежутке при штатном g можно разместить 2 886 подъёмов высоты 0,01 с⁻¹ с разрешённым снижением после каждого. Они займут 6 571 с, добавят 32,855 надфоновые инверсии, сохранят прежние g, R, F и наблюдения, но израсходуют 28,86 с⁻¹ дополнительной вариации. Поэтому U — ограничение основного проектного подкласса.

Для строгой чувствительности gₛ=0,000036055 с⁻² плато разрешено, и обе строки Ц3 сохраняют те же границы. Из 3 313 873 полных окон SEPEM совместно проходят 657 558. Для этого подмножества медиана R(w)≈8 955,10. Полные GOES screened East/West нарушают gₛ; на редких строгих бинах G16 есть допустимые заполнения. [Строгая область и точные конструктивные свидетели](STRICT.md).

### Воспроизведение

Использованы Python 3.12 и NumPy 2.3.5. Нужны рабочие копии [PR419](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/tree/c944c91a2c20a207516824333e02711aaf34898f/experiments/c1-geo-fixed-20261109) и [PR423](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/tree/c0176b4837b5310378fb4218f2d549aeb4c991e9/experiments/c1-common-geo-20261109) с их проверенными внешними кэшами. Пути после `--common` и `--previous` указывают на корни соответствующих рабочих копий. Команды запуска из каталога опыта приведены ниже.

```text
python variation.py --common <pr423> --previous <pr419> --sepem-cache <t141> --goes-cache <goes5> --minutes <goes1> --check
python strict.py --common <pr423> --previous <pr419> --sepem-cache <t141> --goes-cache <goes5> --minutes <goes1> --check
python checks.py --common <pr423> --previous <pr419> --sepem-cache <t141> --windows <c1-sepem-windows.npz> --check
python comparison.py --common <pr423> --previous <pr419> --windows <c1-sepem-windows.npz> --check
```

Опция `variation.py --export-windows <путь.npz>` выдаёт для каждого старта наблюдаемый нижний показатель, J на границе, предел J слева и число начавшихся событий. Индекс 0 соответствует 01.07.1974 00:00 UTC, шаг — 300 с. Восстановленная таблица содержит 43 495 109 байт, SHA-256 `ce6ffeb345aaca5dbebe389a8ad8986d9eec9bbeea9334965dc3847ca9e2602f`. Строгая маска задана точными интервалами в JSON. Остаток для науки — физические квоты скрытых подъёмов, закон меток, исполнение и полная цена управления, независимая рецензия и действительная допустимость h=1.
