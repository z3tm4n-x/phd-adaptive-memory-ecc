Завершённая ограниченная разведка [#44](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/issues/44),
редакция 28.09.2026 с четырьмя уточнениями автора. База после PR #46:
`126b9b7e4238a6e90f85bbfa4a99447be95e78f3`. Вход для #45, не принятый RES.

## Суть для автора

Вечный пик действительно создаёт большой риск при плотном фиксированном контроле.
Произведение ячеечных оценок T36 подтверждает аргумент автора; фазы и зазор записи учтены.
Общий кандидат предела канала заметен сам по себе, а конструкция T36 добавляет свой пол.
Внешний канал сравнивается с обоими пределами отдельно; GOES-бин не считается точкой.
Относительный рост воспроизведён с прежними масками и заданными порогами, но не стал физической границей.
На сопоставимом пике G19 при 1 мм отклик выше; универсальная монотонность всех строк E/W не подтверждена.
ОСТ даёт среднее число событий и флюенс за срок; доступный первичный текст не закрыл закон счёта и CDF эпизода.
Физические K, запасы и совместное покрытие оставлены символами; уточнение COSRAD подготовлено, не отправлено.
