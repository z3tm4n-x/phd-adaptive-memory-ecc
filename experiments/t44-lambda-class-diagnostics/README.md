# T44: проверка класса Λ₀ и входов редкости

Задание [#44](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/issues/44),
актуальная редакция 28.09.2026 с четырьмя уточнениями автора.
База `126b9b7e4238a6e90f85bbfa4a99447be95e78f3`, после PR #46.
Ограниченная разведка R0/R1/R2/R5/R7, вход для #45.

Конфигурация зафиксирована до новых расчётов. Модель — независимые равномерные
одиночные пуассоновские инверсии и фиксированный плотный циклический контроль;
это диагностический свидетель, не новый физический закон R0.
Метрики: нижняя вероятность первого превышения, два разных пола верхней оценки
счётчикового канала, добавки задержки, выборочные логарифмические приращения.
Сравнения политик и метрики полной стоимости здесь нет.

Переиспользуются принятые T36 (Д4, В1–В2, тест 11) и T37: те же данные,
версии, направления и маски. Порог относительного роста задан до расчёта:
10⁻⁴/10⁻³/10⁻² соответствующего известного максимума T37.
GOES-пределы используются только как модельные входы диагностики.
Готовность: проверенные числа, условия и пробелы редкости, тесты и одна команда
повтора. Исход T44 передаётся автору/теоретику, но сам не разрешает сравнение R0.

Выполнение начато. Эта начальная фиксация ещё не является итогом задачи.
T36/T37, RES, паспорт и исходные данные не изменяются. T2, RTL, оптимизатор,
новый физический мост и внешняя отправка запроса COSRAD не запускаются.
