# Д3. Проверка запаса оконной точки c01

В методику Ц5 передаётся одна точка c01 на базе `840144d6858cb7d483a5499e0c34a606cf2cba67`. Банк 4 МиБ, 1 048 576 полных слов (39,32), α=0, 315 576 000 с, ε=0,001. Пары быстрых и редких периодов заданы в единицах штатного прохода. Проверяем M(26,208) с удержанием, L_cut(26,208) без удержания и N0(15,120) без удержания. [Поручение №413](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/issues/413#issuecomment-6761501057).

- Берём условные опоры Д2 по всей памяти и сроку. Для каждой частицы с двумя или более активными позициями хотя бы одного слова оплачиваем один прямой вклад. Для таблицы используем достаточный первомоментный верх d=0, 10⁻⁵, 10⁻⁴. Закон Д1 допускает зависимые слова. Нормировка задаётся для каждого активного разряда на том же профиле.
- Для остаточного потока проверяем перенос пар разных родителей одного слова на обязательные опоры каждого календаря. Индивидуальные фазы, апертура конечного обслуживания, остаток на границах, ветви потери и восстановления, первый проход, обрезание в T и прежние исключения входят в проверку. Точные рациональные суммы сверяем со всеми тремя принятыми исходными результатами при d=0.
- Выдаём одну таблицу девяти подстановок. Решение по знаку ε−Q⁺ принимаем до округления. При потере сертификата (26,208) проверяем уже назначенный N0(15,120). Для выбора указываем известную шину и последовательное обслуживание c01 при том же календаре, с работой после прямой метки или превышения до конца срока. Прочие затраты имеют свои коэффициенты.
- Проверяем включение одиночного нижнего свидетеля в класс верхних ограничений и условия для оценки (44,32). Принятые результаты остаются источниками для этой контекстной проверки. Для девяти подстановок достаточно точных операций над интегралами одного профиля.
