# Ц5. Качество отчётов внешнего декодера на GE30-45

База `82afe84c1c2385b380a214a9d73794df97b952a9`. Правило L/32L, 205 общих интервалов, точно двухсловный закон основной ГСО и допуск $10^{-3}$ закреплены в [№448](../t186-advisor-ge30-20261110/GUARANTEE.md) и [№453](../t186-ge30-epsilon/README.md). Источник наблюдения — внешний синдром полного (39,32) после трёх чтений ×16.

Сопоставляем полный своевременный отчёт, распознанный пропуск при сохранении обслуживания и непрерывный invalid от пуска. Для каждой строки проверяем вероятность первого превышения, занятость защитного порта до конца срока и сравнение с лучшим допустимым постоянным режимом. Для порога 216 540 учитываем кадры у краёв, допуски часов, резерв управления и работу вне него. При полной потере сверяем реально начатые проходы и чтения с постоянным L на том же календаре.
