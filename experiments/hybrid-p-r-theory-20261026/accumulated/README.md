это отказ этого сертификата, не нижняя оценка Q и не исключение семейства.
При **обоснованном** δ_C≤5·10⁻⁵ общий верх≤0.000942989284, запас≥0.000057010716
(5.701% допуска). Значение δ_C пока не установлено.

Накопленная сумма не объявляется Poisson: один α=10⁻⁴ оплачивает
экспоненциальный супермартингал, допускающий зависимые действия и повтор
родителя при weak E. Из C не вычитается p. Invalid поглощает всю группу;
FAST/restore не стирают остаток, фазу или риск. Базовый резерв считает
все близкие пары на полном T; квантиль K оплачивается только перед удлинением.

[PR272 применим условно](PR272_APPLICABILITY.md): закрытый C нужен через
source/processed/health и липкий invalid, не только bytes. Физические
границы использованы вместо nominal p. WCET и δ_C требуют подписи #186.
При этом договоре, в частном допустимом случае здорового канала без false,
ненулевая тихая среда r=b/10 даёт ΣC=0 с вероятностью>.6685.
Без связи префикса пустой wire не разрешает действие.

Сохранить JSON: та же команда с --write. Только stdlib; [результат](result.json)
содержит точные дроби, направленные округления и хеш checker. Проверены

остаток, весь бюджет и отказ по invalid/опозданию. Старой сетки и MC нет.

Цена продолжается до T на всех историях. Только в компоненте назначенных
проходов удачный запрос экономит 5999 проходов; guard-FAST, обработка и энергия
не бесплатны. Общая квота потерь позволяет сделать всю единственную группу
invalid, поэтому общего положительного низа вероятности успеха/средней
экономии пока нет. Следующий шаг — один условный пилот #186 по этим формулам
и полная цена; затем закон времени обучения и повторяемое удлинение.
