# Первый кандидат продолжения, до арифметики

Единственный вход среды/сервиса — согласованный inputs.json2cc9240.
Это параметры нового локального правила, не новая среда и не старая сетка.

- Основной блок PR268:25701088 nominal ticks, scan+drain.
- Обязательный первый startup scan+drain начинается в0 и занимает один
  блок; его C не используется. Затем базовый период2 блока и фиксированное
  обучение120000 полных действий. Первый проход не откладывается.
- Один запрос по накопленным C в конце обучения; η=1, α=10⁻⁴,
  порог остатка u=R/2. Кандидатная информативная история: суммарный C≤3,
  все используемые сообщения valid. Непригодный блок не повторяем.
- Проверяем консервативные физические границы:
  a_b^-≥0.051400с, a_b^+≤0.051404с,
  P_obs≤0.025702с; startup-end∈[0.025700,0.025702]с; h_b≤0.078с.
  Это допускаемые границы для проверки #186, не измерения.
- После положительного теста — один период12000 блоков,
  верх308.42с. После него — исходное базовое обслуживание доT.
- Остаток в момент удлинения: кандидат K=1,
  отдельная единственная ζ=10⁻⁴.
- Риск редкого интервала должен быть≤0.00055; весь срок:
  δ₀+δ_C+α+ζ+Q_base+0.00055≤0.001.
  δ_C не обнуляется; нужно обоснование её включения/предела.
- Без положительного теста: базовое обслуживание без расхода нового риска.
  Дополнительный FAST не отменяет/не сдвигает обязательные проходы.

Проверяем не только допуск редкого действия с u, но и непрохождение
того же локального достаточного допуска при U=R. Это объясняет роль
наблюдения внутри нового сертификата, не исключает другие постоянные правила.
