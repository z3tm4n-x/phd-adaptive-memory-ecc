## Повтор

Python 3.12; установка зависимостей: `python -m pip install -r experiments/t68-v21-inputs/requirements.txt`.
Из корня репозитория, одна команда расчёта и тестов (Linux/Windows):

```sh
python experiments/t68-v21-inputs/run.py
```

Первый запуск получает 28 raw-файлов Zenodo с проверкой существующих SHA-256.
Для работы без сети добавьте `--raw-archive "путь/New Folder.zip"`;
эта ветвь проверена на существующем пакете проекта. Экспорты COSRAD включены;
`source_inputs.json` связывает их с прежними архивами. Конфигурация заморожена
под v21, неизвестные входы — `null`. Результаты — `outputs/`, временные файлы —
исключённый из git `.cache/`. Пройдены 16 тестов чисел/единиц, SMU/merge,
XOR, ERR/U, адресных гипотез и ресурса.
