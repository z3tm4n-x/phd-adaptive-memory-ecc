# T152 — воспроизведение адресной проверки

Итог: [theory/t152-srem-channel.md](../../theory/t152-srem-channel.md).
Проверяется одно семейство SREM/IREM. Научные T146/T90 сохранены.
Результат — найденные численные массивы и два независимых пробела
совместного договора, а не физический коэффициент a/выигрыш.

## Повтор без перезаписи

Из корня полного checkout ветки `t152-srem-channel`, Python3.10+,
только стандартная библиотека:

```bash
python experiments/t152-srem-channel/check.py --cache /tmp/t152-psi-cache --fetch --check
```

Скачиваются только два публичных численных файла PSI. SHA-256 закреплён
в sources.json: другие байты отвергаются, принятые файлы не заменяются.
С готовым кешем повтор не требует сети:

```bash
python experiments/t152-srem-channel/check.py --cache /tmp/t152-psi-cache --check
```

`--check` сравнивает весь JSON побайтно и ничего в репозитории не пишет.
Один `--fetch` разрешает заполнить внешний кеш. Для первичного формирования
отчёта использован явный `--write`; принятые расчёты не перезаписываются.
Если источник недоступен или изменился, проверка завершается ошибкой,
не назначает a и не подставляет искусственную матрицу. Полные сторонние
PDF/HTML и рисунки в git не распространяются.

## Что выполнено

- Чтение действующих инструкций/Issue152/T146/T90; план закреплён до подбора
  чисел. Подбора параметров и новой физической/адаптивной кампании нет.
- Получены оригиналы двух IREM .drm и первичные документы; версии,
  источники и SHA-256 — sources.json. Herschel отмечен отдельно.
- Парсер проверяет обе матрицы целиком: хеш, порядок15 каналов,
  размеры/энергетические границы/стыки, положительные экспозиции,
  целочисленные счёты, нулевые строки. Четыре коротких примера — точные
  C/f и наружные десятичные интервалы, без физической интерпретации lower.
- Проверены неизменные входы/квоты, адресное временное противоречие и
  бюджет общей шины; все физически неизвестные поля остаются null.
- Шесть принятых файлов сверяются с git-blob SHA1 в pinned_inputs.json.
  Смена байта матрицы отвергается; направленное округление проверено.

Полные команды и хеш нового отчёта — reproduction.json. `all_audit_checks_pass`
означает успешный **аудит**, а не пригодность канала; поля
`joint_channel_contract_confirmed` и `physical_U100_qualified` равны false.
Независимая рецензия этой новой поставки не заявлена. Main/принятые
результаты/паспорт не менялись. Точные обязанности дальнейшей проверки
и собственная рекомендация теоретика находятся в основном дополнении.
