# T110 — согласованный сервис с записью по ERR

Рабочее научное дополнение к Issue #110; база инженерных входов —
`36f0dab3cfb1e051b9480d02c5aae303e943ecfe`, PR #109.
Ветка `t104-err-write-service-theory`, PR направлен в `t104-new-rtl-executor`.

Проверяемое утверждение: при явно заданных полноте ERR, семантике обслуживания,
календаре и области запросов приложения новое E-исполнение сохраняет
вероятность неисправимой ошибки Q(T) ≤ 10⁻³ за десять лет, ресурсный запас 10%,
пик контроля ≤ 80% в любом окне 1 мс и задержку приложения ≤ 3 мкс.
Сертификаты двух защит и сравнение с постоянным E будут приведены раздельно.
До появления доказательства и расчёта это цель работы, не заявленный результат.

Начальные входы воспроизведены без перезаписи: 28 новых проверок бюджета,
15 прежних временных, 49 А и 71 T95; 20 закреплённых blob и оба JSON совпали.
Это условный инженерный бюджет; физическая квалификация не заявляется.
Принятые T95/А и их области сохраняются. RTL и этапы В/Г не выполняются.
