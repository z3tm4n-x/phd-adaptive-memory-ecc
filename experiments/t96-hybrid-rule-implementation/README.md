## Повтор

Из корня репозитория, Python ≥3.10, без сторонних зависимостей (Windows/Linux):

```sh
python -B experiments/t96-hybrid-rule-implementation/run.py
```

Команда проверяет восемь исходных blob, направленные тесты и точное совпадение
`outputs/reproduction.json`; ничего не перезаписывает. `--write` обновляет
только собственный отчёт после осознанного изменения эталона.
Случайных прогонов нет; seed=103 объявлен только для будущего этапа Г.

## Итог и суть для автора

Эталон прямо реализует календарь T95, защищённые разрешения, LOW/hold,
потерю/возврат и неделимый pending-write. Проверены все 524288 адресов/фаз;
малый W=8 отдельно проверяет 256 масок, без переноса вероятности на R0-A.
CPU имеет приоритет в свободном интервале, но не вытесняет обязательный U.
Новые записи защищены функционально; основной вывод Q(T) по-прежнему read-only.
При потере остаются прежние календарь, окна и U_M; бюджет не начинается заново.
Шаг 4 нс точно представляет календарь через исходные 1-нс метки, но не
решает автоматически pin timing. Простое 48+48 нс не удовлетворяет joint-U.
Для принятия предлагается спецификация А, затем независимая рецензия;
аппаратная готовность и новые результаты в `results/` не заявлены.

| Величина, основной R0-A/3 г/см² | Значение и уровень |
|---|---|
| Вероятность неисправимой ошибки Q(T) | ≤0,000948089707 — принятый **условный** верх T95, не оценка по тестам |
| Запас по вероятности ε−U_Q(T) | ≈0,000051910293; D*=0,0002802445 не менялся |
| Пик загрузки интерфейса контролем с X | ≤71,45371408% в **любом** окне 1 мс — подстановка T80 (11) |
| Задержка приложения с запасом 10% | ≤1,545664457 мкс — при заданном FIFO/потоке/сервисе |
| Совместный U-WCET | Требуется ≤90,908181818 нс; физически не подтверждён |
| Наивное округление 45+45 к шагу 4 нс | 96 нс, не проходит; не принято как backend |
| Post-window путь при раннем 4-нс apply | Требуется ≤0,9999999999 с до запаса; исходный deadline не увеличен |

Полные условия, логические регистры и порядок событий — [CONTRACT.md](CONTRACT.md).
Таблица «предпосылка → обязанность → наблюдение → проверка», план формальных
свойств и один архивный SGPS-сценарий для Г — [PROPERTIES.md](PROPERTIES.md).
Код: `reference.py`, `test_reference.py`, `run.py`; параметры — `config.json`.
Это проверяемое достаточное условие при контракте T95, не его расширение.

## Инструменты и открытый остаток

А выполнен на Python 3.12.14, x86-64/KVM Intel Xeon Platinum 8573C.
GCC/G++ 13.3.0 доступны как кандидат host-измерений В, не выбран полётный CPU.
Без системной установки локально доступны pyslang 9.1.0 (импорт проверен),
YoWASP Yosys 0.69 (`-V` выполнен): кандидаты frontend/synthesis/SAT для Б.
RTL/формальные задачи на них в А **не запускались**. Vivado, плата,
отдельный HDL-симулятор и физические STA/CDC/WCET недоступны/не подтверждены.
AC701 не выбран; старые исполнители — только идеи тестов.

До Б нужны рецензия/принятие А и выбор backend/clock binding: либо обеспечить
исходные совместные сроки и полный образ, либо отдельно согласовать пересчёт
сервиса. Неизвестные D*, full38/ERR/clean-U, монитор и доступность не заменены
нулями; новых данных для их квалификации не ищем. Оценка А: 3–5 рабочих дней
работы и 1–2 дня рецензии; следующие этапы этой поставкой не запускаются.
