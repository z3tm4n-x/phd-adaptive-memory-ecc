# Воспроизведение

Из корня репозитория; CPython 3.12, проверенная версия 3.12.14, Windows 11.
Зависимости закреплены в `requirements.txt`. Обработка после их установки
полностью автономна: SEPEM не скачивается, NIST-таблицы включены, старые
σ/T67/T68 читаются из того же checkout, RADAR не запускается.

## Один полный запуск

```powershell
python -m venv ../sepem-venv
../sepem-venv/Scripts/python -m pip install -r experiments/tNN-sepem-profiles/requirements.txt
$env:PYTHONUTF8='1'
$env:SEPEM_RDS_V2='C:\Users\Иван\Downloads\Telegram Desktop\SEPEM_RDS_v2-00.zip'
$env:SEPEM_CACHE=Join-Path $env:TEMP 'sepem-profile-derived-cache'
../sepem-venv/Scripts/python -B experiments/tNN-sepem-profiles/reproduce.py
```

`SEPEM_RDS_V2` принимает и распакованный каталог. Для дополнительной сверки
его файлов с ZIP добавьте `--archive 'полный-путь-к-SEPEM_RDS_v2-00.zip'`.
Кэш обязан находиться вне Git-checkout; исходники остаются там, где их
поместил владелец. Скрипт перезаписывает только собственные производные
файлы в выбранном кэше и `outputs/`, не исходные данные.

На POSIX те же команды после `python -m venv ../sepem-venv`, с
`../sepem-venv/bin/python`, `export SEPEM_RDS_V2=/path/to/archive.zip` и
`export SEPEM_CACHE=/path/outside/checkout/cache`. Новые результаты могут
отличаться в последних знаках между версиями BLAS/платформами; побайтный
повтор заявляется только для сохранённой среды и одинакового входа.

Фактически использованный Python: `../tmp/goes16-venv/Scripts/python.exe`.
Первый полный повтор занял около 3 минут; исходная загрузка сети в это время
не входит. Основной статистический шаг занял около 20 с, измеренный пик
его рабочего набора — около 1.45 ГБ. Полная аппаратно-независимая оценка
памяти не заявляется. На диске нужен архив 192 МБ либо распакованные
источники, плюс около 600 МБ производного кэша. Точные время, зависимости,
команды и SHA — `outputs/reproduction_receipt.json`, `statistics_run.json`.

## Что проверяется

1. 62 детерминированных теста, включая неправильный 4π, переставленную
   матрицу, размер слова, сохранение частиц, остановленную массу, PDI,
   нули He, календарные границы и Poisson/квантиль.
2. Все reference-строки H/He; SHA архива, файлов и совпадение распаковки.
3. Воспроизведение старого 6940 из сохранённых компонент без изменения
   accepted-файлов; отдельно — LET/HEP/PDI состав исторического νS.
4. Удвоение квадратуры/сетки момента и порядка Bohr на пяти заранее
   выбранных спектрах. Критерий изменения λ: ≤0.1%; получено ≤5.01·10⁻⁶.
   Для реального ASTAR/LET He: три фиксированных спектра, порядок 12→24,
   изменение ≤2.59·10⁻¹⁰. Это диагностика сходимости, не интервальное
   доказательство полной физической ошибки. Граница только табличной
   интерполяции положительной дискретной суммы: H ≤1.82·10⁻⁵, He ≤1.16·10⁻⁵.
5. Полный H-ряд, условный He, события, все пятиминутные старты 10-летних
   окон, 200 000 миссий с фиксированным seed. Бино-границы не сжимаются.
6. T67: независимый порядок матричной свёртки и сравнение на общей области
   5–390 МэВ, 2.7 г/см², full38. Для трёх спектров новая CSDA/старое
   primary+secondary = 1.02685–1.04387. Это ограниченная согласованность
   порядка величины, не тождество физических моделей.
7. Формальная арифметика Q без нового сертификата; компиляция всех Python
   модулей пакета (`compileall -q -l`, без игнорируемых тестовых кэшей).

В `legacy_T67_reference_events.csv` оставлены три заранее выбранных события
2017-09-10, 2024-10-09, 2026-01-18; прежние data32-результаты пересчитаны
только множителем 38/32. Они **не** являются новым повтором сырых SGPS.
Перекрытия с RDS нет. Прямое межприборное подтверждение λ для одинаковых
событий не выполнено; здесь не заявляется выполненным этот более сильный
вариант критерия готовности. Сравнение с v21 — воспроизведение его
арифметики и состава, не подгонка новой свёртки к прежним числам.

## Независимость и исправления до поставки

Малые эталоны не просто вызывают production свёртку повторно: используются
аналитический постоянный отклик, отдельное изменение переменной с якобианом,
адаптивная скалярная интеграция узкого PDI и явный выходной спектр T67.
Общие зависимости — NumPy/SciPy, одни исходные таблицы, физические допущения.
Сверка 12→24 использует тот же алгоритм и потому независимым oracle не названа.
Скаляры ГОСТ вычисляются отдельно от векторного спектра, но параметры общие.
Алгоритмические проверки выполнены внутри инженерной поставки, не заменяют SR.

До фиксации исправлены: целочисленный буфер σ; разбор не-CSV заголовка RDS;
сортировка файлов Windows/ZIP; левая цензура e-fold у E0043/E0081/E0083;
чтение параметров машинной конфигурации и перекрытие имени локальной
переменной. Ошибки обрабатывались тестами, не изменением научных входов.
Исправление e-fold не изменило N, S₂, А или Б. Ранний `compileall` сообщил
о недоступных старых временных каталогах, хотя вернул 0; итоговый запуск
явно проверяет только модули пакета и не выдаёт этот ранний шаг за проверку.

Научные CSV и рисунки детерминированы при данной среде. JSON времени и
локальных путей естественно изменяется при повторе. Для сверки выходов
сохраните `reproduction_receipt.json` перед повтором: он перезаписывается.
SHA источников, кода, конфигурации и всех существенных outputs содержатся
в нём; полные сырые/производные временные ряды в Git не публикуются.
Локальный `.gitattributes` отключает автоматическую замену концов строк
для `inputs/` и `outputs/`, чтобы Git сохранял именно захешированные байты.
