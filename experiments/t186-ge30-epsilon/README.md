# ГСО. Четыре допуска на одном порту GE30-45

Основание — [назначение №186](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/issues/186#issuecomment-6766281075), база `f1296d5744edea239484ef2323951b27d00c8fdc`. Четыре значения ε заданы до расчёта. Объект, временной календарь, высокий старт для нижнего свидетеля и локальный счёт закреплены в [№448](../t186-advisor-ge30-20261110/GUARANTEE.md). Законом одной частицы заданы два различных равномерных слова и по одному равномерному разряду в каждом.

Для каждого допуска выбираем самый длинный целочисленный период, подтверждённый верхом №448. Для всего постоянного класса обращаем его двухсловный нижний тест при новом допуске и проверяем минимальный реализуемый период. Сравниваем цену L/32L после 205 пригодных нулевых ячеек с половиной необходимой цены всего класса. Цена отдельного достаточного кандидата ограничивает стоимость лучшего сверху. Работа защитного порта измеряется в секундах до конца срока, включая работу после первой остановки.
