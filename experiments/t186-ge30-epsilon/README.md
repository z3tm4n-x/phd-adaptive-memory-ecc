# ГСО. Четыре допуска на порту CY62167GE30-45

Двукратная экономия L/32L относительно лучшего допустимого постоянного режима подтверждается при $\varepsilon=10^{-3}$ в указанном ниже бюджете управления. При $10^{-1}$ даже обязательные чтения редкого режима дороже известных операций допустимого постоянного кандидата. При $10^{-2}$ исход сравнения остаётся открытым. При $10^{-4}$ постоянный класс пуст.

Вход зарегистрирован [в №186](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/issues/186#issuecomment-6766281075) на базе `f1296d5744edea239484ef2323951b27d00c8fdc`. ГСО, класс $\mathcal A_U$, 0,25 МиБ, 65 536 слов (39,32), $T=315\,576\,000$ с. Приход одной частицы инвертирует по одному равномерному разряду в двух различных равномерно выбранных словах. Сохранены $d=0$, $\gamma\ge1/2$, квота исполнительских исключений $\delta=6\cdot10^{-6}$, обязательный пуск, фазы и полный своевременный внешний счёт. На GE30-45 $L=45{,}8752$ мс, полное чтение занимает 240 нс, исправляющая запись добавляет 260 нс. После 205 полных пригодных нулевых ячеек подряд разрешён интервал $32L$. Непригодный отчёт возвращает частый режим. [Сервис](../t186-advisor-ge30-20261110/SERVICE.md) · [Принятые оценки №448–449](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/pull/448#issuecomment-6764956149).

В расчёте источником наблюдений служат собственные исправления внешнего декодера (39,32). Он собирает слово тремя чтениями x16. Внутренний декодер CY62167GE30 исправляет одиночную ошибку при чтении и сообщает об этом на выводе ERR. Когда на внешних линиях данных (DQ) передано верное слово, эта операция не увеличивает счётчик внешних исправлений. Поэтому двухсловный закон среза задаётся на DQ после внутренней коррекции. Экспериментальная частота и совместное распределение таких ошибок для ГСО пока неизвестны. [Привязка наблюдений](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/issues/186#issuecomment-6766467557) · [Cypress AN88889, §4.4](https://community.infineon.com/gfawx74859/attachments/gfawx74859/NonVolatileRAM/1914/1/Infineon-AN88889_Mitigating_Single-Event_Upsets_Using_Infineon_65-nm_Asynchronous_SRAM-ApplicationNotes-v04_00-EN%201.pdf#page=7).

$Q(T)$ — вероятность хотя бы одного превышения исправляющей способности за срок. Цена — защитная занятость шины за десять лет, в ожидании для худшего допустимого случая. В скобках указана доля всего срока. У неизменного L/32L верх $Q(T)$ равен **0,000880198**. Верх известных чтений и ремонтов при $I=0$ равен **8 446 152,412 с (2,676425 %)** и включает работу до $T$ после первой доказательной остановки. $I\ge0$ ограничивает ожидаемое число дополнительных сбросов истории до остановки. $X\ge0$ ограничивает остальные секунды защитного порта за весь срок, включая контроль полноты, команды, регистрацию и восстановление.

**Постоянный класс.** В столбце кандидата стоит самый длинный целочисленный период $kL$, прошедший достаточный тест `fixed(k)`. Его верх цены ограничивает известную цену лучшего допустимого режима сверху. Необходимую цену даёт отдельный двухсловный свидетель `lower(P, True)` на высоком стартовом плато. Нижний тест монотонно возрастает по $P$. Для каждого допуска решено строгое неравенство $Q^-(P)>\varepsilon$. Если $P_0$ — правый конец найденного интервала, то периоды $P\ge P_0$ исключены при любой фазе, включая OFF. Цена обязательных чтений на оставшихся периодах снизу ограничена $(1-\delta)W[T/(P_0+2J)-2]r_-$, где $r_-=(240\xi_- -2J_{\rm нс})$ нс. Сохранены обе краевые поправки. [Формулы №448](../t186-advisor-ge30-20261110/GUARANTEE.md) · [Точные подстановки и округления](result.json).

- При $10^{-1}$ предел принятого нижнего свидетеля при $P\to\infty$ равен приблизительно 0,052119686545. Эта оценка оставляет только универсальный низ обязательного пуска $(1-\delta)Wr_-$. Допустимость OFF отсюда не следует.
- При $10^{-2}$ исключён хвост от 0,750978210840 с. На целочисленном календаре периоды 14L–16L остаются между достаточным и исключающим тестами. При $10^{-3}$ хвост от 0,062520698070 с исключает уже 2L. В обоих случаях для сравнения использован низ всего класса с произвольной фазой.
- При $10^{-4}$ исключены все физические периоды от **0,006777158306 с**. Даже нижняя граница самого короткого интервала между посещениями слова, $L\xi_- -2J=0{,}045874740248$ с, больше. Подстановка этой короткой границы даёт $Q^-\ge0{,}000734523081$.

**Знак сравнения.** Верх полной цены L/32L равен верху известных затрат плюс $100{,}864632\,I+X$. Для 2× достаточно уложиться в половину необходимой цены постоянного класса. При $10^{-2}$ этот тест даёт отрицательный бюджет $-5\,155\,231{,}108$ с с округлением вниз. Для проверки обратного знака есть отдельный низ L/32L. На событии до $T$ без доказательной остановки, вероятность которого ≥ $1-0{,}000880198$, каждое слово читается как минимум раз за $32L\xi_++2J$ с учётом двух краёв срока. Поэтому ожидаемая цена одних обязательных чтений ≥ **3 364 052,058 с (1,066003 %)**. При $10^{-2}$ половина верха известной цены 13L достигает 4 758 535,964 с. Обе стороны сравнения перекрываются.

При $10^{-1}$ полный известный верх 132L уже ниже этого низа L/32L. Обозначим через $Y_{132}$ верх добавочных секунд защитного управления постоянного кандидата. Если $Y_{132}<5\,012\,218{,}936$ с, даже его полная цена меньше удвоенного низа L/32L, поэтому 2× против лучшего постоянного исключено и по полной цене. Проектный верх для $Y_{132}$ остаётся отдельным условием. Полезные чтения и общая начальная загрузка у вариантов одинаковы. CPU и энергия сохраняют свои единицы и неизвестные коэффициенты. Физический перенос требует видимости внешних ошибок после встроенной коррекции, согласованной сборки трёх x16 и соблюдения сроков обслуживания.
