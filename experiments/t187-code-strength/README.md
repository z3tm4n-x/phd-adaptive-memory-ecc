# T187 — воспроизведение и передача

Issue #187, [основная теорема](../../theory/t187-code-strength.md),
[приложения](../../theory/t187-code-strength-appendix.md).
Статус: собственный ограниченный условный результат, не принятое изменение
R0, не новый аппаратный декодер и не полное adaptive-t2 покрытие.

## Воспроизведение без перезаписи

Из корня репозитория, Python 3.10+; только стандартная библиотека:

~~~sh
python experiments/t187-code-strength/calculate.py --check
~~~

Скрипт воспроизводит report.json побайтно и проверяет Git-blob SHA пяти
используемых принятых файлов #166/#177. При несовпадении прерывается;
ничего не исправляет автоматически. Обычный вызов без ключей печатает
новый расчёт в stdout; только явный --write записывает собственный
outputs/report.json. Принятые outputs не открываются на запись.
Monte Carlo, исходные кампании и внешние пакеты не запускаются.

До расчёта inputs.json и PLAN.md закреплены на
d69a1f3655c42a5044240b2d7da9b8546c302150. Все20 проверенных строк сетки,
включая отказы, сохранены. Увеличения срока, подбора профиля/seed и смены
epsilon после первого расчёта нет. Малый mixed-E тест — адресная проверка
формулы для групп, а не новая физическая точка карты.

## Основной результат примера

Одна полезная ёмкость256 бит, W=8, внешние коды (39,32) и (44,32).
Общая per-bit среда задана двумя профилями прежнего #166. Для t=2
array-rate честно увеличен в44/39 раза. Полный горизонт3.4с,
epsilon=0.001, чистое начало, идеальный модельный U, без приложения.

| t | P | Условное c | Наихудший моментный upper | Полная цена U |
|---|---:|---:|---:|---:|
| 1 | 5 мс | 10 мкс | 0.000872051283 | 1.6% |
| 2 | 200 мс | 20 мкс | 0.000522892295 | 0.08% |

Числа upper в таблице округлены вверх. В JSON — точные рациональные
значения и интервалы Q по каждому профилю. У двух предъявленных
достаточных режимов отношение цен20; это не сравнение с нижней ценой
всего SEC-класса и не глобально оптимальный выбор силы кода.
При том же периоде t=2 цена выигрывает только при c2/c1<40.
Сценарии200/400/800мкс дают0.8/1.6/3.2% и показывают границу/проигрыш.
Новый FPGA-WCET из этих чисел не следует.

## Что проверено

- Ранги7/12; расстояния кодов обоснованы конструкцией, 40/991 синдромов
  корректируемых ошибок различны. GF-операции целые, не численная аппроксимация.
- Все8 U/#166 и8 E/#177 строк: неизменные n, W, профили и сервис;
  верхние оценки совпадают рационально, точные интервалы согласованы.
- 23 адресные проверки: составные свидетели, гипергеометрический переход
  против полных масок, XOR, начальные ошибки, E/pending, вырожденные
  случаи, коэффициенты, шаг ряда, ERR-насыщение и запрет наложения операций.
- Направленная рациональная арифметика; ширина интервалов <=10^-28.
  Это не независимая научная рецензия.

## Передача карте и реализации через оркестратора

| Поле | Что требуется | Сейчас |
|---|---|---|
| Код/полезная ёмкость | n,k,t,W, полная физическая карта и alias | Условные внешние39/44, k32, W8 |
| Воздействие | per-bit закон либо parent/MCU и распределение групп | Общий singleton per-bit; группы1/2 — символическая теорема |
| Риск | T, epsilon, D_t, начальные остатки, lifetime-квоты | T3.4, epsilon0.001; нули — модельные предпосылки |
| Моменты | S_(t+1) для singleton, квадратичные члены для группы2 | Вычислены для двух закреплённых профилей |
| Сервис | U/E, read/write/completion, незавершённые операции | U-пример; E-верх доказан, exact только для полного атомарного образа |
| Цена | c_R,c_wr,c_ctl, d_svc, ресурс после скрытого отказа | Символические; 10/20мкс — условная подстановка, WCET=null |
| Наблюдение | Что означает ERR, задержка, потери, совместное покрытие | Один ERR на корректируемое слово; новое adaptive-t2 покрытие=null |
| Приложение | Частота/всплеск, атомарность, наблюдаемые записи, deadline | В примере отсутствует; реальные входы=null |
| Ресурс | Peak(h), резерв, FIFO и совместные задержки | Формула достаточного пика; полного аппаратного подтверждения нет |

Рекомендация: использовать ограниченный результат для оси t карты только
после заполнения этих полей. Не переносить прежний D*, физический ERR,
времена внутреннего32+6 или необходимую цену SEC-класса на другую архитектуру.
Для нового адаптивного метода выбрать через автора один из трёх путей §5;
автоматически его не запускать. Main/принятые файлы/организационные документы
не менялись, другие исполнители не назначались.
