# T50 — входы R0-A и контракт наблюдений

Issue #50; база `81f0020c3b735e73716573bb8f1df5dd586f6baf`.
Завершённая ограниченная инженерная поставка; не новый принятый RES и не
разрешение запуска R0. Полный физический вход R0-A пока **не квалифицирован**.

## Суть для автора

1. Сохранён основной объект: GEO, 10 лет, ε=10⁻³, 2.5/3 г/см²,
   внешний 39/32, 2 MiB на трёх GE30. Испытанные data32 и внутренние 32+6
   не заменяют все внешние 39 позиций.
2. В прежнем COSRAD **найдены и проверены** суммарные орбитальные флюенсы
   SEP/GCR. Таблицы сохранены; закон числа вспышек для этого маршрута не нужен.
3. Решающий пробел — совместный контракт полного ECC-on отклика K_Θ и
   наблюдений. ERR есть, но ни он, ни внешний corrected пока не квалифицируют
   виртуальный счётчик T36/T45; неизвестные параметры оставлены null.
4. Для прежних суток/10 мм точно воспроизведены ∫r и ∫r²;
   I1(ν)=2609.655451 инверсий, I2(ν)=335.344917 инверсий²/с, J=4.254408.
   Это не 10-летний full39 R0-A и не выбор победителя по J.
5. Фоновые подмодели и SEP peak при 2.5/3 г/см² переданы отдельно;
   пик не умножается на срок, ψ=0.1 не становится δ_env или ε.
6. 45/9/1 воспроизведено; готовые границы показывают изменение **модельного**
   решения. Ноль наблюдений не принят за нулевую физическую upper.
7. Для #52 переданы пригодные входы и один точный запрос с альтернативами.
   Покрытие Θ отдельно: условные 0.001 плюс иллюстративные 0.05 дают upper
   0.051, не гарантию 0.001. Запрос никому не отправлен.

## Повторение

Из корня полного Git checkout, Python ≥3.9 + Git; сторонние зависимости не нужны:

```bash
python3 -B experiments/t50-lambda-inputs/reproduce.py
```

Команда ничего не записывает: проверяет 42 закреплённых Git-источника,
нормализованные спектры, пересчитывает summary и запускает 18 тестов.
`--emit` выводит заново полученный JSON. Необязательный `--archive /path/results.zip`
дополнительно сверяет нормализованные таблицы с оригинальным ZIP; в T50 эта
проверка выполнена. Основная команда не требует сети/ZIP/COSRAD/Vivado.
Проверено на Python 3.12.14, Linux. Все тесты прошли; принятые CSV не менялись.

Входы/модель/метрики/готовность зафиксированы до преобразований в config и
начальном коммите PR. Методы не сравнивались. Расчёты — только точная
арифметика готовых десятичных рядов и извлечение сохранённых таблиц.
