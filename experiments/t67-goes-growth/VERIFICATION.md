# Проверка поставки T67

01.10.2026. Это инженерная проверка исполнителем, **не независимая рецензия**
и не подтверждение физического класса Λ.

## Полный повтор

Выполнена команда из корня репозитория:

```bash
python -B experiments/t67-goes-growth/reproduce.py --cache ../t67-cache --out ../t67-results
```

При проверке использованы отдельный каталог результатов и существующий
кэш первоначально скачанных NOAA NetCDF. Все **1 097 исходных файлов**
повторно проверены по SHA-256; сетевое скачивание всего архива второй раз
не выполнялось. Команда завершилась с кодом 0 после тестов, обработки всех
47 окон, дополнительных проверок и создания графиков.

Среда: Linux, Python 3.12.14, NumPy 2.3.5, Matplotlib 3.10.8;
NetCDF C API из установленной VTK 9.3. Новые зависимости не устанавливались.
Это повтор в той же среде, **не кроссплатформная квалификация**.

Сравнены 27 выходных файлов первого и финального запусков: **26 побайтно
тождественны**, включая все численные таблицы и шесть PNG/SVG.
`source_manifest.json` отличается только порядком элементов `files`;
после сортировки по имени JSON-объекты равны целиком. При сравнении с
Git-объектами CSV дополнительно нормализуются окончания строк (Git хранит
LF). Значения, строки таблиц и контрольные суммы источников не различаются.
SVG разобраны как XML; PNG декодированы; целостность gzip проверена.

## Численные и регрессионные проверки

- **24 модульных теста** проходят. Включены нули/пороги H, масштабирование,
  разрывы/версии/плохие бины, повторные и цензурированные пересечения,
  единицы/fill/scaling, ориентация, противоположная семантика LUT,
  однократность калибровки, пропуски отклика, объединение окон и запись
  производных архивов/рисунков.
- Алгоритм первого e-fold сопоставлен с независимым полным перебором
  **всех 243** коротких немонотонных рядов из трёх уровней.
- Свёртка сжатого линейного ядра проверена прямым восстановлением спектра,
  полным матричным переносом и интегрированием на трёх фактических NetCDF:
  специальный сентябрь 2017 и оба разрешения G19 за 19.01.2026.
  Максимальное относительное расхождение **1,4994437854573757·10⁻¹⁵**.
  Типизированное чтение float и маршрут через double совпали точно;
  проверены эпоха и границы суточных временных рядов.
  Подробности: [integration_checks.json](outputs/integration_checks.json).
- Независимо сопоставлены нативные 5-min реконструкции с усреднением пяти
  1-min реконструкций при полной комплектации исходных секунд;
  [cadence_consistency.csv](outputs/cadence_consistency.csv). Это отдельная
  проверка согласованности, не подмена минутных измерений.
- Три содержательных графика визуально проверены: подписи, единицы,
  направления, временные оси и отделение измерений от модели.

## Что обнаружила проверка

При ранних повторах обнаружены усечённые производный NPZ и SVG; причина
усечения не установлена, SHA исходных NOAA файлов совпали. Добавлены
атомарная запись, проверка CRC/обратного чтения NPZ, разбор SVG/PNG и
контроль прочитанных байтов рисунка перед и после замены файла.
Финальный полный повтор с этими проверками прошёл.

Отдельно обнаружены шесть строк минутной сводки экспозиции, где маска
допускала NaN отклика. Исправлено исключение неконечных значений и добавлены
регрессионные тесты; таблица объединения окон пересчитана. Рост и переходы
уже исключали NaN, поэтому их экстремумы не изменились. Принятые результаты
других задач не редактировались.

Проверка не устанавливает точность σ/переноса, физический смысл всех
систематик SGPS, совместное покрытие будущего, внутрибиновый рост или
оперативную задержку. Эти ограничения остаются в [METHOD.md](METHOD.md)
и [RESULTS.md](RESULTS.md).
