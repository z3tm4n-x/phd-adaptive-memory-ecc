# T67 — рост GOES: измерения отдельно от отклика памяти

Завершённая инженерная разведка по Issue #67, включая уточнение 01.10.2026.
Ветка `t67-goes-growth`, база инструкций/работы
`4ab4ddb4d3e4c84b70957446fb71849db34623ec`; #69 при старте не слит.
Черновой PR открыт в первый день: [#71](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/pull/71).

## Суть для автора

В оригинальных минутных SGPS видны и медленные, и очень быстрые изменения.
Для заданного протонного отклика R0-A минимальный e-fold выше 0,001 с⁻¹
составил 18/149/3/1 минут в четырёх примерах автора соответственно.
Самая быстрая точка — повторный направленный подъём **после пика**, а не
вход из спокойной обстановки; по ней нельзя исключать любой счётчиковый метод.
Минутные измерения существенно меняют требования по сравнению с 5-минутными.
Подготовлены условные параметры T45/T57, но перенос к родителям,
непрерывный рост, совместное покрытие будущего и задержка канала не доказаны.
Следующий выбор автора — передать условные входы теоретику или сначала
закрыть эти договоры; снижения налога контроля работа не обещает.

## Основные результаты

**Числа ниже — описательные оценки бинированной модели**, не физические
верхние границы/95%-интервалы. Объект: 32 data bits × 2¹⁹, CY62167, протоны,
10 мм Al, 4π-эквивалент каждого направления, `main_loglog`, `screened`
(флаг динамической ошибки допускается, [полный контракт](METHOD.md)).

| Пример автора | Пик по минутным бинам, с⁻¹ | Минимальный e-fold выше 0,001 с⁻¹: 1-min / 5-min |
|---|---:|---:|
| 08.06.2024 | 0,0387929 | 18 / 25 мин |
| 21.11.2024 | 0,00426769 | 149 / 195 мин |
| 11.11.2025 | 0,0276912 | 3 / 5 мин |
| 19.01.2026 | 0,426274 | 1 / 5 мин |

Пики и минимальные времена могут принадлежать **разным датчикам**;
UTC/направление/интеграл — [reference_events.csv](outputs/reference_events.csv).
При l=0,001 с⁻¹ максимум ΔH_l/Δt = **0,0235850 с⁻¹** по 1-min и
0,00454976 с⁻¹ по 5-min. Это необходимое значение для согласования с
объявленными бинами как точными данными, **не нижняя граница истинного
физического роста при неизвестной ошибке измерений**.

Охват: инвентарь 7 790 ежедневных файлов разных версий; использованы
1 097 NetCDF (1,623 ГБ), все 46 каталожных записей и специальный месяц
09.2017. Из 46 записей данные есть у 45; 14.07.2017 недоступен в выбранных
L2. Плюс окно полного сентября: всего 47 окон, 46 с данными.
Получены 28 992 строки метрик и 214 завершённых переходов; это не число
независимых реализаций. Неполный фон/нулевой процентиль не заменялся ε.
Обработаны все эпизоды **заранее выбранного каталожного охвата**, не все
слабые возмущения за десятилетие.

## Повтор

Из корня репозитория, Python с версиями из `requirements.txt` и стандартным
NetCDF reader (Python `netCDF4` **или** установленный `libnetcdf`/VTK):

```bash
python -B experiments/t67-goes-growth/reproduce.py --cache ../t67-cache --out ../t67-results
```

Команда проверяет тесты, загружает/проверяет SHA-256, пересчитывает таблицы,
проверки и PNG/SVG. При изменившихся байтах NOAA останавливается; semantic
patch не применяется. Сырые NetCDF и промежуточные ряды вне Git.
Новые зависимости не устанавливались; использован имеющийся NetCDF C API.
Отдельно: `python -B -m unittest discover -s experiments/t67-goes-growth -p test_*.py -v`.
Финальный полный повтор завершён; 24 теста проходят. Условия, независимые
численные проверки и исправленные дефекты — [VERIFICATION.md](VERIFICATION.md).
