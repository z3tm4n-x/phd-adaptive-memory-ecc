# Прототип ABI и обязательства PS–PL — контрольная точка 13.10

**Реализовано:** `rule.h` и исполняемый тестовый ABI AAPCS32, little endian.
Вход32 байта: now_slow:u64@0, generation:u64@8,
source_fast_timestamp:u64@16, flags:u32@24, reserved=0:u32@28.
Состояние56 байт; начальная функция допустима только до миссии.
Драйвер теста не является готовым MMIO-драйвером SRAM/PS7.

`now_slow` — номер обработанного 50-МГц фронта; source_fast_timestamp —
исходный номер 250-МГц фронта ERR. Время обработки не подменяет источник
при проверке пары. Разрядности64 сохраняются. Перед каждым новым входом
история должна быть полной и упорядоченной; на пропуск/перестановку generation
устанавливается sticky fault. Повтор времени/неизвестный reserved также
отклоняется. Это усиление контроля входа вне нормального договора Б,
не разрешение оплачивать вечный fault-FAST прежней средней ценой.

Ядро обновляет три countdown через разность now: математически пропускает
только промежутки **без** событий. Не пропускаются ERR или loss. Нагрузка
временного шага не зависит от продолжительности удержания. Сравнение пары
включает равенство границе. На фронте принятия события LOW не выдаётся.
Слово `low` здесь — только результат правила; оно не обходит local guard,
generation/cache, freeze или неразрывную E.

## Проект интерфейса, ещё не реализованный AXI top

Предполагаемый штатный путь: PS M_AXI_GP0 → AXI interconnect/protocol converter
→ атомарный mailbox/FIFO на50МГц → принятый candidate_link. Сырой FIFO
с130-битными записями — диагностическая отправная точка, не выбранный
окончательный транспорт: budget.py показывает его недостаточную пропускную
способность для разрешённой loss-пачки даже без времени CPU.

Должны быть доказаны до интеграции:

1. Неизменяемый snapshot прочитан целиком; ни два32-битных чтения generation,
   ни запись половины64-битного решения не публикуют смешанный пакет.
2. Конечный commit после payload и DMB/DSB, Device/Strongly-ordered MMIO;
   write response не приравнивается к применению разрешения.
3. Последовательность/CRC, last_processed_generation, frame lease и
   drop-on-expiry; local same-edge veto остаётся без ожидания ARM.
4. При разрыве/дубликате/перестановке нового LOW нет; восстановление не
   очищает миссионный бюджет и не отменяет уже frozen skip/pending write.
5. История и приложение используют разные учтённые очереди. AXI-доставка
   правила не получает бесплатно320/320нс прикладного пути.
6. Ограничение запросов включает выполняемый запрос и удержанный ответ.
   Подключение CPU не наследует старый STA/цену timing-shell.

Выбранное следующее направление — точное пакетирование истории и публикация
заранее вычисленного временного разрешения, с доказательством семантики
summary. Передача только последнего generation без представления всего
префикса запрещена. Блоки должны иметь ограниченную длительность/задержку;
сжатие loss не должно считать переходы отсутствовавшими или заново назначать
бюджет. Программная проверка ассоциации ERR/удержаний должна оставаться
программной; PL оставляет сбор/порядок, срочный veto и готовый календарь.
