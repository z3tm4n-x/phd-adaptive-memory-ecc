# Воспроизведение первого результата T105

Среда поставки: WSL Ubuntu 26.04, Python 3.14.4, native GCC 15.2.0,
ARM GCC 14.2.1, binutils 2.45.50, QEMU 10.2.1.
Из корня репозитория на закреплённом SHA:

```sh
python3 experiments/t105-arm-rule/reproduce.py --bootstrap --ps7 --repeat-binary
```

## Инструменты и входы

Первый вызов получает закреплённые Ubuntu packages и распаковывает их
в игнорируемую `.tools/`, без sudo и изменения системных пакетов.
Точные имена, версии и SHA-256 находятся в outputs/tools.json.
Повторная подготовка проверяет опубликованные хеши; недоступная версия
или несовпадение — ошибка входа, а не основание заменить пакет.
Загружено около 89 МБ; распакованный компилятор требует больше места.
Архивы и инструменты в Git не входят.

При первоначальной подготовке запись зеркала QEMU ubuntu3.1 дала 404;
закреплён доступный release ubuntu3. Это раскрытое изменение инструмента
до результата, не изменение исследовательских входов.

`--ps7` вызывает существующий `/home/z3tm4n/bin/vivado-wsl`
(Vivado 2025.2, build 6299465). Он создаёт пробный IP project и сохраняет
конфигурацию. Синтез, route и STA нового top этой командой не выполняются.
Два предупреждения об открытом адресном пути ожидаемы для неполного BD.
Предупреждение locale относится к wrapper.

После подготовки инструментов, без сетевого доступа и нового probe Vivado:

```sh
python3 experiments/t105-arm-rule/reproduce.py
```

Требуемые версии инструментов проверяются и при таком вызове.
Опция `--repeat-binary` собирает ELF повторно и требует побайтного совпадения.

## Проверки и ожидаемые выходы

Ожидаются 20 165 native и 512 ARM сравнений, обнаруженная мутация границы
пары, четыре теста арифметики бюджета и компиляция Python.
Формальные проверки прежнего Б не выдаются за новые.
Программа загружается QEMU loader напрямую, без FSBL и оборудования.
Semihosting используется тестовой оболочкой, не правилом.

Функциональный повтор занимал около 1,3 с времени хоста; IP probe —
порядка 20 с. Это расходы воспроизведения, не время ARM и не критерий
приёмки. Модельные такты Cortex-A9 и WCET этим запуском не получаются.

Сохранены ELF, дизассемблер и атрибуты ARM, functional.json, budget.json,
tests.txt, конфигурация и журнал PS7, binary-repeat.json и manifest.json.
Из 50 296 байт text теста 49 152 байта — векторы с ожидаемыми состояниями.
Функции правила занимают 808 байт, состояние — 56 байт.
Стек, тестовая оболочка, транспорт и BSP не включены в эту цену;
полная цена CPU/PL пока неизвестна.

## Сверка происхождения

До перезапуска сверить опубликованный manifest: повтор обновляет только
выходы этой задачи. ELF и результаты сравнений должны совпадать при
тех же инструментах, флагах и входах. Время хоста и абсолютные пути
в метаданных могут отличаться. Это не требование побайтного совпадения
всех журналов.

Хеши исходников Б/r4 фиксируют происхождение; их функции обновления
не импортируются. C и Python-эталон разделяют объявленные константы
и семантику, но используют разные представления таймеров.
ARM-тест проверяет бинарник на векторах этого эталона.
