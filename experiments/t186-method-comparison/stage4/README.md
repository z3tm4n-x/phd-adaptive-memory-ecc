В корне checkout, Python 3.12, только стандартная библиотека:

```text
python -B experiments/t186-method-comparison/stage4/reproduce.py
```

Первый повтор использует пустой локальный cache; детерминированные
validation/results/inputs/bounds/table должны совпасть с опубликованными.
Нужны Git-объекты истории и теоретической ветки
`comparison-foundations-20261018` с коммитом
`e49314a9a0fbf97699f9c8b0c62d25bae5e3097d`. При обычном клонировании
перед повтором выполните `git fetch origin comparison-foundations-20261018`.
Текущие изменяемые организационные документы не подменяют снимки паспорта.

Лимит **сравнительного расчёта одного вызова** по умолчанию 180 с;
проверки до него, упаковка и сверка после него оплачиваются отдельно.
При лимите возвращается код 3, `progress.json` сообщает число готовых
строк. Повтор той же команды продолжает их; можно увеличить только
операционный бюджет, например `--budget-seconds 300`. Строка, прерванная
внутри исполнения, рассчитывается заново; завершённые строки и входы
сверяются по хешу. Cache привязан к полному паспорту и каталогу результата.
Новый `--output .cache/another-replay` создаёт независимый повтор.

Для управляемой остановки на границе строки:

```text
python -B experiments/t186-method-comparison/stage4/reproduce.py --output .cache/resume-check --max-new-rows 1
python -B experiments/t186-method-comparison/stage4/reproduce.py --output .cache/resume-check --budget-seconds 300
```

Код 3 первого вызова ожидаем. Частичный набор не получает итоговой таблицы
и не считается завершённым. `--pilot` выполняет две заранее выбранные
строки rise_fall/uniform; его успешный код не означает готовности матрицы.
`--record` предназначен для публикации нового результата после фиксации
кода; обычная проверка не меняет принятые файлы.

Здесь нет оценки полного Q методом Монте-Карло. Ускоренный генератор
и одни и те же отмеченные истории используются для цены; lifetime-границы
присоединяются условно по T196. CPU и энергия сохраняются параметрами,
а требования к физическому транспорту и размещению памяти — условиями.
