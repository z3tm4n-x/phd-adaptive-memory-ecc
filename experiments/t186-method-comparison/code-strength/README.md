# Одна таблица трёх вариантов, #186 / #196 / #206

Основной выход23.10 готов к проверке: [таблица](outputs/table.md),
[результат и полный вектор цены](outputs/results.json),
[12 групповых чувствительностей](outputs/sensitivity.json),
[условия](CONDITIONS.md), [сервис](SERVICE.md), [отчёт/остаток](REPORT.md).

Вход инженерно согласован с картой и оркестратором; конкретная подпись #196
к новому сервису/цене остаётся на рассмотрении. Это условный p1=1 с общей
геометрией и нагрузкой; не физическая квалификация CY62167 и не оптимум класса.

Воспроизведение из корня репозитория, Python3.11+ без внешних пакетов:

```powershell
& '../tmp/goes16-venv/Scripts/python.exe' -B experiments/t186-method-comparison/code-strength/reproduce.py
```

Если данного локального venv нет, использовать установленный CPython (`py -3.13`).
Команда запускает функциональные/арифметические проверки и сравнивает четыре
детерминированных файла с сохранёнными. `--record` перезаписывает только файлы
этого нового пакета. `prepare.py` — совместимый вход к тому же воспроизведению;
старую предварительную таблицу он больше не записывает.

`--require-agreement` возвращает2, пока не получена адресная подпись теоретика.
Это явно отличает готовые авторские числа от согласования; отсутствие подписи
не блокирует обычное воспроизведение. Одного URL общей теории для подписи
новых численных строк недостаточно.

Функциональный кодек — exact T187 H-column mapping, systematic encoding,
плотный syndrome ROM. Это 45364 исправления на заранее заданных payload,
не оценка аппаратного времени. Всего139 направленных проверок:66 прежних
функциональных/ценовых и73 новых риск/календарь/чувствительность. Из них
12 прямых cell-case и2 сертифицированные малые CTMC; MC не применяется.
