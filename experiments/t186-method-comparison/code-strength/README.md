Повтор из корня репозитория, Python 3.10+, только стандартная библиотека:

```sh
python -B experiments/t186-method-comparison/code-strength/prepare.py
```

Команда проверяет хеши закреплённых исходников, сохранность предыдущих этапов,
конструкции кодов, учёт цены и побайтовое совпадение трёх файлов подготовки.
Выход 0 означает воспроизведённую подготовку, **не готовое сравнение**.
`--record` обновляет только новые outputs этой задачи. Ни один прошлый
расчёт или транспортный файл на запись не открывается.

`--require-agreement` возвращает 2, пока не получены оба адресных ответа
по общему входу и новое применимое основание #196. Это проверка фактической
зависимости, а не самостоятельная научная приёмка. `unit-test-only` внутри
теста проверяет логику сверки и никогда не записывается как полученный ответ.
Ветви new-n39 Q, fixed-t2 с приложением и расчёт сравнительных количеств работ
ещё не реализованы: их форму определяет ответ теоретика.

Новые файлы находятся в дочернем PR #211 на базе прежней ветки, чтобы
незавершённая приёмка PR204 не задерживала подготовку и её предмет не менялся.
Транспорт не расширяется. Исторические 20x, 1.761x и 2.8x не переносятся.
