Воспроизведение из корня репозитория, Python3.11+ без внешних пакетов:

```powershell
& '../tmp/goes16-venv/Scripts/python.exe' -B experiments/t186-method-comparison/code-strength/reproduce.py
```

Если данного локального venv нет, использовать установленный CPython (`py -3.13`).
Команда запускает функциональные/арифметические проверки и сравнивает шесть
детерминированных файлов с сохранёнными. `--record` перезаписывает только файлы
этого нового пакета. `prepare.py` — совместимый вход к тому же воспроизведению;
старую предварительную таблицу он больше не записывает.

Для назначенной локальной правки используется короткий повтор:

```powershell
& '../tmp/goes16-venv/Scripts/python.exe' -B experiments/t186-method-comparison/code-strength/reproduce.py --repair-only --require-agreement
```

неизменности источников и AST не допускает иных расчётных изменений в этом
режиме. [Область R1](R1.md), [результаты проверок](outputs/repair-validation.json).
