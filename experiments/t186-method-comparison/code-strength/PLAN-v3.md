Новый сервис ниже — предъявляемая численная область, не измерение аппаратуры.

1. Чистое общее начало, K0=0, pending=0. Инициализация всех W слов кодированием
   и тремя x16 записями оплачивается отдельным префиксом и в амортизированной
   цене; физическая вероятность ошибки инициализации остаётся UNKNOWN.
   В условной модели единый резерв Delta=6e-6 за весь срок, без пополнения
   по проходам. Условное событие среды/чистого начала задаёт область Q;
   физические delta_env/delta_init не равны нулю и не заявляются покрытыми.
2. Основная нагрузка — полный полезный 32-битный write через старое full-word
   read/decode и новый encode/write. Read не ремонтирует. Strict-uniform
   неизменён. Burst и partial-write не блокируют основной выход.
3. Условная сервисная точка: x16 read/write по16 нс, decode39/44 по20/24 нс,
   encode39/44 по20/24 нс, разворот8 нс. Для расчёта bus occupation весь
   decode/encode резервирует шину. Это явная консервативная реализация;
   аппаратный параллелизм можно оценить параметром отдельно. E удаляет
   старые рождения и сохраняет новые; snapshot/lock всех48 позиций и
   no-alias — обязанности исполнителя, а не следствие трёх чтений.
4. Общие потенциальные окна batch8: c=164, g=196, frame1568 нс, app grant
   на1312 нс; ximin=.99999, xiplus=1.00001, endpoint-span=.5 нс.
   Приложение ingress320 + ready80, outbound320 + backpressure100 нс.
   Транспорт и его обработчик не меняются. Каждый word обслуживается в
   первом fast-проходе; затем обязательный проход раз в k циклов.
   При адаптации возможны дополнительные FAST, mandatory-опора неизменна.
5. Fixed-кандидат для каждого кода: наибольшее целое k>=1, для которого
   моментный upper с E-cross <=0.5 epsilon; P=k W g. Это sufficient-выбор
   на объявленной сетке, не оптимум класса. Adaptive выбирается из
   k={3,5,9,27} по тому же тесту, затем сохраняет own ERR two-stage90/180с,
   строгий выход, source PAIR, максимум hold, same-edge veto и NR.
   До новой информационной подписи применяется детерминированная опора
   T196(5); формула(7)/старая full38 q-мажоранта не подставляется.
6. Для постоянного p: Phi(R)=A2 R^2 + A3 R^3. При max cell P и aperture d
   используем U=Delta+D+W[A2 P S2+A3 P^2 S3]
   +W[2 A2 B d S1+3 A3(B d P S2+B^2 d^2 S1)].
   Последний член следует из m(H)<=B d, непересечения J и
   sum m(J)^2<=P S2; не зануляет E-cross. Дополнительные полезные записи
   удовлетворяют E и не сдвигают mandatory-окна; T196§3 позволяет их
   игнорировать в верхе риска. Direct считается один раз из общего p_s.
7. Цена — вектор. Fixed не платит cuts/ERR-transport/adaptive decisions.
   Аппаратный таймер fixed, app/channel, память, кодек и idle power не
   бесплатны: неизвестные коэффициенты явны. Для corrections используется
   parent-count до плохой истории + U*hard work после неё; параллельно
   выдаётся безопасный all-history always-E upper. Для adaptive обычные
   hold-полосы ограничены через 2 publications/parent (между повторными
   app-read одного слова проходит больше mandatory-P), false, outages,
   startup/recovery. Вне этой области остаётся hard upper.
   Дополнительные новые source-veto параметризуются v=E N_v/T,
   kappa_v по T196(11); v=0 — только именованный срез, не физический факт.
8. Обязательные epsilon, deadline3us, peak80%/1ms отдельно от целей карты
   epsilon/2, deadline2.4us, peak64%, прочих0.8*cap. Неизвестные RAM/LUT/

9. Проверки: точная арифметика/направленное интегрирование E-cross,
