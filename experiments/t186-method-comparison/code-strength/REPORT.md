## Достаточность, цели запаса и чувствительность

Все три условные Q проходят жёсткуюepsilon и цельepsilon/2. Ядро SRAM
проходит80% на каждом1мс, но дополнительные controller операции должны
войти в опубликованный остаток, не нарушая окна. App-response≈2.533/2.541мкс
проходит3мкс, однако **не проходит цель2.4мкс**. Пик t2≈65.860157% не
проходит цель64%, хотя меньше80%. Это конкретные недоборы целевого запаса,
а не скрытый PASS или доказанная физическая невозможность.

12 зарегистрированных p2/p3 срезов сохранены с исходными периодами.
Для fixed они используют полные moment/direct/mixed/E оценки; для adaptive
на новой опоре пока только generic mandatory-upper, явно диагностический.
Даже singleton-ячейка этого файла не заменяет основной информационный
сертификат. Перенос lower-channel/сопряжения на p2/p3 пока отдельно открыт.
При p2=1e-7,p3=0 fixed t1 upper≈1.286e-3: достаточность по этой границе
не установлена. T2 upper≈5.00205e-4. Upper>epsilon не исключает весь класс.
При p3=1e-8,p2=0 t2 upper≈5.62156e-4. Physical p_s/interword остаются UNKNOWN.

Цена кодека параметризована с совместным ограничением календаря. При
фиксированных counts получается формальный порог по SRAM, но фактическая
добавочная decode44 latency ограничена≈27.584281нс. На этом сервисном
пределе заново посчитаны Q и цена исправлений. Перенос формального ценового
порога за допустимую сервисную область запрещён. Энергетического/площадного
победителя без цен и caps не назначаем.

## Воспроизводимость и точный остаток

Вход диагностического среза закреплён в PLAN-v3/7fafb69. По решению
оркестратора app-read перестал публиковать ERR/G; источники только
scrub/pre-write. PLAN-v4/7e42ffb закреплён до нового J: новый информационный
календарь, W/ell, сетка, критерий выбора. Геометрия/темпы/fixed-периоды сохранены. Сервис/применимость
проверяются вместе с входом, а не только по названию старого договора.

203 направленные проверки, в том числе45364 исправления функционального
кодека,12 cell-case с явным E-cross и2 малые CTMC с сертифицированным
интервалом, соседний k, ресурсные окна и pending/post-A. Дополнительно788
полных q-клеток,524288 фаз и точное воспроизведение старого T119 u/v/J. Пять файлов
воспроизводятся exact; статистическая ошибка MC отсутствует потому, что
MC не использовался. Это не делает физические/модельные UNKNOWN нулевыми.
