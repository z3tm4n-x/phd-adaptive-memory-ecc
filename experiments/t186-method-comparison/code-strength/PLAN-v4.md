# Адресное завершение информационной строки, 22.10.2026

До вычисления нового J фиксируется решение оркестратора
PR211#6334727215. Предыдущий fa1350a / v3 и его clean replay сохраняются
как диагностическая mandatory-строка, не сравнение информационного метода.

Общий физический/численный закон, полезный объём, приложение, три кода,
сервисные времена, все fixed-периоды/цены и неизвестные caps не меняются.
Обычный app-read теперь явно **не публикует ERR/G**. Контрольный read и
предмодификационный full32 read публикуют один ERR на всю транзакцию.
Обычный read не делает write-back. Цена приложения/кодека сохраняется.

Для основной adaptive-строки используются T196(7), T119(2)–(5):

- nu1=(39/152)*nu_ref; b/B/FS/ell масштабируются одновременно, rho=.048
  сохраняется. p1=1; a=1, zeta=0, phi=1−1/W. Нельзя оставить ell=.001
  после уменьшения array-rate или 4/524288 вместо нового4/W.
- Потенциальный batch8 c164/g196/freeze320 прежний. Adaptive адрес
  k_a^(-1)*j modW; первые W и j mod k_a=0 обязательны. Это точный календарь
  T119, не clumped-per-pass диагностической строки. Fixed-календарь остаётся
  ранее заданным; per-word max period/число обязательных чтений те же.
- Проверяются k={3,5,9,27}, w/h90/180с. Новые tau включают P_l, E,
  observed-write aperture, source→fresh10us и endpoint jitter. Таймеры20нс
  округляются по медленным часам; NR>=h_upper+tau; максимум34бит.
- Направленные Decimal интервалы48digits из неизменного T114. K(q)
  обобщается из T119 лишь явными W, ell и календарём; исходник не меняется.
  phase_cells=8, q_cells=192, refinements=5, u-множители{1,2,4,16}.
  Каждая целая q-клетка проверяется по монотонному K и вогнутому slack,
  не по графику/нескольким точкам. Все клетки/endpoint-slack сохраняются.
- Выбирается наибольший зарегистрированный k с полным U_A<=epsilon/2.
  Если ни один не проходит, записать конкретный остаток; не выдавать
  mandatory-строку за завершённую основную информационную строку.
- Цена использует тот же консервативный all-history договор. Верх
 2 publications/parent оставляется: E может увидеть позднее рождение,
  которое переживёт release и будет устранено следующим E. Он больше
  не обосновывается app-read. Дополнительные G/veto оплачиваются отдельно.
- Для p2/p3 не переносить информационный singleton-сертификат без проверки
  нового нижнего канала/сопряжения. В sensitivity оставить generic
  mandatory-upper на выбранной опоре и явно указать его основание.

Проверить масштабирование конуса q/ell, фазовый коэффициент4/W, целые
таймеры/защищённые окна, все интервальные клетки и прямое сравнение с
более мелкими фазовыми разбиениями для выбранных q. Ценовой lower всего
постоянного класса не заявлять. Конкретная подпись #196/независимая приёмка
остаются отдельными. Транспорт/принятые файлы не менять.
