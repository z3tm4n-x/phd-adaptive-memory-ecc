# Адресная проверка t2 на одних полезных записях

[Результат и область](REPORT.md), [точные числа/полная цена](outputs/result.json),
[проверки](outputs/validation.json), [основание](basis.json).
Новый пакет от main7cb8911; все принятые файлы остаются неизменными.

Из корня репозитория, CPython3.11+ без внешних пакетов:

```powershell
& '../tmp/goes16-venv/Scripts/python.exe' -B experiments/t186-method-comparison/app-only/reproduce.py --require-basis
```

Либо `python -B experiments/t186-method-comparison/app-only/reproduce.py --require-basis`
на установленном CPython. `--record` записывает только два выхода нового
пакета. Обычно повтор занимает меньше секунды на этой машине; это стоимость
программного расчёта, не аппаратный timing. Временная сложность проверки
краёв O(W), без материализации315 млрд запросов каждого типа.

Проверяются SHA256 девяти локальных источников из sources.json (только
CRLF→LF), неизменный v4 и связь с адресным основанием #196. Точные внешние
документ/результат77ca3822 прочитаны и хешированы до расчёта; ссылки/хеши
записаны как provenance. Во время повтора Git/сеть не нужны: риск вычисляется
из закреплённых локальных функций и независимо сверяется с формулой и
точной дробью теоретика. Прежний Git-aware replay code-strength здесь
не запускается и не исправляется ради выборочного main.

Без применимого basis.json новый Q/полная цена не вычисляются;
`--require-basis` возвращает2. Статус применимости соавтора не является
решением приёмки. Выбор F0 с OFF отдельно предложен оркестратору.

Полный результат —27 адресных проверок. Старые широкие кампании/проверки
теоретика не повторяются. [Чистый повтор и отрицательные проверки](outputs/replay.json)
выполнены на81f7f1a60f71d10ad61146bbbe8809c997b5d909:27 проверок,
два совпавших SHA, три отклонённые подмены. В выборке нет .git и не нужна
сеть; все41 blob принятого code-strength в ветке сохранены.
