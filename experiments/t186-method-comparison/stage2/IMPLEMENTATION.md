# Уточнения реализации до тренировочных и тестовых чисел

Эти детали конкретизируют PLAN.md, не подбираются по результатам.

Начальное целевое число Красникова m=1 — собственная инициализация.
Цикл [a,a+P) считает доставленные ERR; доставка ровно в правую границу
попадает в следующий цикл. При нулевом счёте m сохраняется. Пустые циклы
с неизменным состоянием агрегируются, однако каждый логический пересчёт
остаётся в счётчике стоимости. Период Pk=k W 196 нс. Границы циклов
локальны для алгоритма; фаза общего календаря не перезапускается.

Патент: окно (t-w,t], по source-time уже доставленных ERR. Первое решение
на пустой истории в w; затем по доставке/истечению. До w новые ERR могут
удерживать FAST, но не разрешают ранний LOW. Равенства порогам держат режим.

Прогноз: часовые бины определены временем доставки, не source-time.
Закрытый час обрабатывается на первом cut строго после границы часа.
Новая доставка сначала попадает в свой бин и не изменяет закрытые часы.
Вектор признаков содержит последние шесть часов от старшего к младшему.
Обучающих пар — 18 на полный 24-часовой тренировочный эпизод.

Генератор использует u=(getrandbits(53)+1)/(2^53+1), без нулей и единиц.
Однородные кандидаты: t+=-log(u)/B; thinning: u<=lambda(t)/B.
Только принятый кандидат получает независимые word/bit; время ceil(t*1e9).
math.log/exp относятся к библиотеке платформы; проверяются закреплённые
хеши сгенерированных данных. Аналитический NHPP не отождествляется
с округлённой целочисленной историей.

initial_peak: B до initial_hold, затем экспоненциальный спад до b за fall.
rise_fall: b до peak_start, экспоненциальный подъём за rise, hold на B,
экспоненциальный спад за fall, затем b. repeat_rise повторяет этот импульс
с repeat_start. Неперекрытие импульсов проверяется.

При совпадении времени: XOR-инверсии, публикация/доставка ERR, таймер,
старт, snapshot, commit, release. Граница цикла Красникова закрывается
внутри доставки до учёта новой метки. Решение о выполнении слота берётся
на start-320 нс. Копирование скрытого будущего в состояние политики
не допускается. Драйвер симулятора знает будущее только для очереди событий.

Стоимость содержит физические в численной модели импульсы bus, число
доставленных ERR и логических обновлений алгоритмов. Время Python —
инженерная скорость решателя, не стоимость ARM, не WCET и не энергия.
