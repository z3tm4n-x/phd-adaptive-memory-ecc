# Условный вероятностный расчёт и постоянный соперник

OWN RESULT, требуется независимая научная проверка. Это отдельный
непрерывный uniform-singleton NHPP-подслучай, не замена полного R0-A/Θ.
Метки независимы: слово равномерно среди W=524288, бит среди n=38.
Интенсивность λ относится ко всей памяти. Старт чистый; идеальная
ERR-запись удаляет рождения до start, сохраняет рождения от start.
Приложение только читает. Истинный первый вес >1 — событие A_T независимо
от последующего XOR и исправления. Корректирующая запись допустима и
при весе >1 именно в этой условной модели E, а не как свойство SEC-DED.

## Общая опора и парный верх

Все выбранные маски содержат слоты j mod27=0. W взаимно просто с27,
поэтому для каждого слова есть такой слот через P27=27 W 196 нс.
Начальный обязательный проход только сокращает ожидание. Изменение режима
не сбрасывает фазу; freeze не удаляет общий обязательный слот.

Любое ещё живое рождение будет старше следующего такого start и будет
удалено не позже start+132 нс. Достаточная максимальная давность
Lk=k W 196 нс+132 нс применима к опоре k=27, к нашему правилу k=3,
к постоянному k — именно этот k. Рождение ровно на start сохраняется
до следующего прохода; +132 нс поэтому нельзя отбросить.

Первый вес >1 требует двух различных битов одного слова с разницей
времён не более L. Считаем также пары, отменённые XOR или уже исправленные:
это завышение, не равенство событиям отказа. По формуле Кэмпбелла и union
bound, c=(n−1)/n:

    Q(T) <= c/W ∫₀ᵀ λ(t) ∫max(0,t−L)ᵗ λ(s) ds dt
         <= c/W · L · S₂,       S₂=∫₀ᵀ λ(t)² dt.

Второй переход: продолжить λ нулём вне [0,T], заменить t−s на u;
для каждого u∈[0,L] интеграл произведения λ(t)λ(t−u) не превосходит
S₂ по Коши—Буняковскому. Верх ограничивается единицей.
Он общий для адаптивного выбора масок: расписание не подставляется
как независимое от меток, используется только детерминированная опора.

## Более узкий верх постоянного периода

Фиксированный k посещает каждое слово раз за P=k W 196 нс. Для
произвольного времени рождения s следующие W выбранных start дают
следующее посещение каждого слова. Пусть kn — предыдущий выбранный слот.

    start(j)=196j−32(j mod8), 196kn−s <= 224

Поэтому среднее по W словам ожидание до следующего
start не больше P/2+98k+224 нс. С ремонтом:

    mean R_w(s) <= P/2+98k+356 нс,       R_w(s)<=Lk.

При |d log λ/dt|<=ρ имеем λ(s+u)<=λ(s) exp(ρLk). Суммирование
пар по одинаковому слову даёт более узкий достаточный верх:

    Q_fixed <= c/W · S₂ · (P/2+98k+356 нс) · exp(ρLk).

Берётся минимум этого и общего верха. Усреднение по фазам разрешено
здесь из-за равномерной независимой метки слова и фиксированного
расписания; так усреднять адаптивное расписание нельзя. Неполный конец
горизонта и обязательный стартовый проход только уменьшают опасное время.

Для заданных синтетических профилей S₂ интегрируется по постоянным и
экспоненциальным сегментам. `bounds.py` вычисляет рациональные верх/низ
для log разложением atanh с оценённым хвостом; exp — рядом с геометрическим
верхом остатка. Печатные верхние числа округляются вверх до18 знаков.
Это погрешность вычисления достаточного верха, не полная неопределённость.

Для скалярной миссионной оболочки λ=b+f, 0<=f<=B−b, ∫f<=Fs:

    S₂ <= b²T+(B+b)Fs.

Таблица `outputs/bounds.json` отделяет суточные эпизоды от этой
10-летней условной оболочки. Её перенос на direct/MCU, иные пространственные
метки, потери ERR, ошибки времени и неполную коррекцию остаётся UNKNOWN.
Округлённый генератор историй не объявляется точным непрерывным NHPP.

## Что означает постоянный кандидат

Для k=1,3,9,27 предъявлены достаточные верхи. Наибольший k, прошедший
данный сертификат, — лишь кандидат конечного семейства с меньшей базовой
ценой 92/(196k); это не доказанный минимум ожидаемой полной цены и
тем более не оптимум всего постоянного класса. Если верх выше ε,
допустимость неизвестна: нельзя объявить период невозможным или исключить
его из класса. Необходимая граница, цена исправлений/наблюдения и переход
к полному договору остаются в остатке до20.11.
