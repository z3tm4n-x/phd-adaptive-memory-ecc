Рекомендация и область: [основной текст](../../theory/t135-demo-operating-point.md).
Согласование реализации: [HANDOFF.md](HANDOFF.md).
План до подстановок опубликован на d061bc405e6181c641e06238d602014e69b51581.
Принятые источники и SHA перечислены в config.json и report.json.

## Что воспроизводится

Пять конечных подстановок, без поиска нового семейства:

- исходная строка T114 rows[26], с точным совпадением U и цены;
- та же среда с FAST, ka=1;
- чувствительность T114 к более раннему freeze и таймеру 50 МГц;
- отдельный условный совместный cap S2/FS из #135;
- рекомендуемая принятая T119 same_rule_two, freeze320, подготовка до freeze.

Перед новой T119-подстановкой заново рассчитывается принятая same_rule_two;
U, интеграл мажоранты и миссионная цена сравниваются как точные дроби.
Остальные принятые строки T119 читаются для сравнения без объявления
повторной полной кампании. Точка cy_T95_anchor_c1/100 читается из принятой
карты с её исходной областью, не пересаживается в E.

## Команды из корня репозитория

    python -B experiments/t135-demo-operating-point/verify.py

Команда ничего не перезаписывает. Она сверяет 14 принятых файлов с
базой main e63964c2b9ddf6a53fe9c76bd5942f458f167f8e, запускает прежнюю
T114 verify.py (19 тестов состояния + 439 численных/граничных проверок),
11 адресных регрессий T135 и побайтовое воспроизведение report.json.
Нужны стандартная библиотека Python и git, включая указанную базу.
Не запускаются RTL, физические расчёты или общий оптимизатор.

Для отдельной проверки:

    python -B experiments/t135-demo-operating-point/calculate.py
    python -B -m unittest discover -s experiments/t135-demo-operating-point -p test_contract.py

Создание только собственного отчёта при намеренном обновлении:

    python -B experiments/t135-demo-operating-point/calculate.py --write

Принятые calculate.py/joint.py импортируются только для вычислений.
Временная подстановка сервисных констант выполняется в объектах памяти
и восстанавливается в finally; файловой записи в принятый пакет нет.
Принятые Decimal-интервалы для exp/log и Fraction для сравнений сохранены.
JSON содержит точные дроби; десятичные верхние числа в тексте округлены
вверх, запасы вниз. Float используется только для экранной диагностики.
Мажоранта проверяется на целых клетках, не только в точках.

## Резерв 100 МГц

service-100MHz-template.json намеренно не заполнен и не является сертификатом.
Инженер передаёт заполненную копию и точный SHA сервисного договора.

    python -B experiments/t135-demo-operating-point/calculate.py --service PATH_TO_COMPLETED_JSON

Вывод идёт в stdout; прежний report.json не меняется. Неизвестные времена,
неподтверждённые E/lock и неподходящий договор часов отвергаются.
Скрипт округляет c/a/g вверх к сетке, затем пересчитывает T114 для исходной
и условной среды и выводит изменение запаса относительно предъявленных строк.
Нет автоматического подбора более удобной среды или игнорирования отказа
ресурсного неравенства. Одно число частоты не преобразуется в WCET.

## Адресные регрессии

Совместный S2/FS и сохранение D*/квот; недостаточность одного cap S2;
оплата первого неполного такта таймера; граница суммы CDC и +1 нс;
невозможность спрятать путь 1 мкс после прежнего freeze; +1 нс в E;
отказ при null; неполная observed-write; безопасное округление календаря
100 МГц на алгебраическом sentinel; наличие all-ERR маски без ценовой
доступности; оплата округления полного recovery h+tau в цене.
Sentinel использует старые времена на сетке 10 нс только
для теста арифметики: он не является результатом реализации 100 МГц.

## Граница результата

Расчёт проверяет условный договор. Числа схемы/STA, радиационные входы,
реальная нагрузка и эквивалентность двух доменов остаются инженерными
обязанностями. Полная нагрузка в report включает заданную область
приложения; это не измерение. Старые нижние границы постоянного режима
не перенесены в изменённый cap; выигрыша в новой среде не заявлено.
