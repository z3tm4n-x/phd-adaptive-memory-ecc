## Суть для автора

**Рекомендую красную ветвь разведки:** не запускать длительное доказательство
А2 через принятый T57 и локальное улучшение счётчика. Перейти к предусмотренному
двухдневному сравнению LEO/положение и R0-A/звёздный датчик через оркестратора.
Новые работы здесь не запускаются; порог 5× не снижен.

Причина оказалась раньше статистики: чтобы обеспечить 5×, защита должна
стоить не больше **2.13467%** шины в среднем за срок. Но весь принятый
поточечный аффинный слой T57 при ресурсе 25% требует **не меньше 2.65344%**,
даже с идеальной бесплатной информацией. Это доказанная нижняя цена
**названного слоя**, не отказ верхнего риска и не невозможность всех
адаптивных политик. Замена только статистики/порога не исправляет причину.

Вторая проверка дала тот же ответ даже при благоприятном different-bit
коэффициенте вместо токенного: нижняя цена такого поточечного слоя
**2.54597%**. Правомерность его использования в T57 не заявляется.
Для выхода нужны существенно другой совместный бюджет скрытого состояния
и редкости либо другая точка/сервис, а не один небольшой пробел на два дня.

### Наблюдение и причинность

Считается исправление полного внешнего слова: latch → исправляющий fence →
доставка → обработанный счёт. Приход между latch и fence может удалиться
без записи в счётчик. Это учтено точной фазовой экспозицией. До сопряжения
физический счёт совпадает со вспомогательным; физический ERR не объявлен Poisson.

В пике среднее ожидание **родителя** 3.01517 с. Для фиксированного периода
13.81535 с (эквивалент целевой цены) вероятность молчания первого прохода
около 10.12%; 95%-срок первой доступной выдачи около 15.941 с даже при
нулевой доставке. Это одновспышечная диагностика, не гарантия миссии.
Достаточный пример общего union по возможным решениям даёт около 84.103 с;
он не объявлен необходимой задержкой. Повторные входы кандидат T57 оплачивает
своим общим интегралом и блоковым покрытием, не новым ε каждой вспышке.

Календарь не сжимается до Wc. На смене периода сохраняются старые остатки
и ранее объявленное действие. Доставка+решение должны уложиться в
**457.65625 нс** существующего достаточного календаря. Это обязательство,
не доказанный WCET большой целочисленной арифметики.

## Бюджеты и полная цена информации

Основная цена: U_scan + C_observation + C_control + C_extra_recovery.
Штатные U-записи и продолжение на резерве уже включены в U_scan, повторно
не оплачиваются. Дополнительные передачи, восстановление вне этого календаря
и плохие истории канала не могут исчезать из цены.

| Незакрытый член / запас | Максимум, ещё совместимый с выводом | Статус |
|---|---|---|
| Остаток цены предъявленного кандидата L_fixed/5−U_known | −0.2283971662912 доли шины при U_known=0.2497438524591 | Отказ его миссионного cap; сам по себе не доказывает невозможность |
| Дополнительная шина: наблюдение, управление, внеплановое восстановление | **Нет неотрицательного совместного бюджета для 5× в слое:** L_fixed/5−C_layer^- = −0.0051877902399 | Строгое препятствие уже при бесплатных канале/управлении |
| Прежний неоплаченный запас идеального ориентира | +0.0029524095569 доли шины | Только диагностика без пикового ресурса; фактическим резервом не является |
| Сумма ошибок начала, среды, канала, исполнения для предъявленного кандидата | ≤0.000517286138248 **за весь срок совместно** | Каждая по отдельности не больше остатка; нельзя дать его одновременно всем |
| Дополнительная занятость шины в любом 1 мс при a_b=1.2 | ≤156.25 нс по аддитивному тесту | Только до дополнительного пересчёта календаря/ресурса |
| Доставка и вычисление после последнего fence | ≤457.65625 нс совместно | Проектное условие; пропуск сохраняет обещанный резерв, не тихую цену |
| CPU | Время обновлений/блоковой проверки не измерено; тот же deadline | Отдельный ресурс, не нулевая стоимость |
| Полезная нагрузка | Любой одинаковый ненулевой read-only поток в σ+0.5t, атомарность ≤0.1 мкс | Нагрузка не придумана; writes/посторонние коррекции не допускаются |
| Полная шина: постоянный / кандидат за срок | ≤60.791725392% / ≤74.974385246% до дополнительных членов | Добавлено u_p+σ/T; **не** коэффициент основной экономии |

Малая оставшаяся вероятность не делает канал квалифицированным. При ненулевом
недосчёте/потере надо также применить соответствующий ценовой член T57
(lifetime-квота один раз, с отсечением единицей), а не оставить старую тихую цену.
Конечный численный тест кандидата прошёл: 10 членов логарифма, 40-битные
сетки накопления/якоря, запас допуска длинного действия >0.73032717 с.
Это численная разрешимость теста, не аппаратная реализация за 457 нс.

## Условие → основание → проверка → последствие нарушения

| Условие | Основание | Что проверено | Последствие нарушения |
|---|---|---|---|
| Те же W/n/T/ε/B/b/FS у обоих методов | Закреплённая диагностика T58 | 8 входных blob и preflight побайтно | Отношение цен не заявляется |
| Одиночные равномерные независимые XOR-родители; D*=0 | Объявленный диагностический Θ, не физика | Коэффициенты token/different-bit разделены | Нужен иной закон меток; нижний/верхний расчёты нельзя переносить |
| Начальный пик и полностью тихая среда допустимы | T58, T126 А | Один свидетель расходует ровно FS; только снижение | Без этих траекторий пересчитываются lower постоянного и слоя |
| Clean/no-pending, U correct-with-hits | Условный принятый сервис | Начальные/конечные клетки и latch–fence сохранены | Нужна цена/квота подготовки и чувствительного сервиса |
| Полная цена c=39/R включает U и штатное управление | Исследовательский эффективный контракт | Wc, календарь, пик, FIFO проверены раздельно | При сырой скорости линии числа не применимы |

| Применимость роста к кандидату | Явный дополнительный срез ℓ=b, ρ≤4·10⁻⁶ | Доказательство/конечная подстановка T57 | Без него только резерв с начала, тихий upper не действует |
| Обработанный счёт, своевременность, без скрытой потери | Условный контракт внешнего39; не CY ERR | Точные видимые окна, сдвиг доставки, конечный тест | Добавить квоту/цену; пропуск не доказывает долгую экономную работу |
| Единый lifetime-бюджет и ресурс на плохих историях | T57 | H=15/J=1578, no reset, all-history cap | Не складывать новые ε после повторных входов |

## Три варианта и решение

| Вариант | Трудоёмкость / срок | Риск и научное влияние | Рекомендация |
|---|---|---|---|
| Настройки/статистика своего счётчика в T57 | Разведка выполнена; длительное доказательство заняло бы 7–10 дней | Lower цены исключает цель независимо от улучшения информации | **Не продолжать этот маршрут** |
| Другая архитектура информации/сервиса А2 или history-dependent совместный бюджет | 1–2 дня на новый контракт; 7–10+ дней на существенно новое доказательство, срок не подтверждён | Один дополнительный канал при прежнем G не снимает барьер; conditional-write/read cost не известны | Сохранить как отдельный возможный путь, сейчас не запускать |
| Разрешённые резервные примеры: LEO по положению и R0-A со звёздным датчиком | **2 рабочих дня сравнения**, затем выбрать один договор | Другие информационные классы; нижняя чувствительность/цена/доставка могут остаться неизвестными | **Рекомендуемый следующий шаг через оркестратора** |

Для 5× в нынешнем токенном слое даже по наиболее благоприятному числителю
нужен резерв ≤0.732423 с, то есть ≥40.2652% плотности при прежнем сервисе:
25% не хватает. Это объясняет уровень проблемы, не предложение молча
изменить ресурс. Всеобщая невозможность А2 не доказана. Новая совместная
теория скрытого состояния может изменить результат, но не является
одним установленным пробелом для жёлтой двухдневной доработки.

## Повтор и границы поставки

Из корня checkout (Python ≥3.10, Git; внешних данных/пакетов нет):

    python -B experiments/t140-a2-signal/analyze.py
    python -B -m unittest discover -s experiments/t140-a2-signal -p 'test_*.py'
    python -B theory/check_t57_uniform_count.py
    python -B -m unittest discover -s experiments/t58-fixed-baseline-r0b -p 'test_certificate.py'
    python -B -m unittest discover -s experiments/t126-regime-map -p 'test_bounds.py'

Первый вызов ничего не пишет: заново считает и сравнивает report.json.
--write записывает **только новый** отчёт T140. Прежний preflight повторён
побайтно без изменения его результата. Решения на Fraction/целых и направленных
экспонентах; плавающие десятичные числа не участвуют в допуске.

Прошли 16 новых адресных тестов и 54/16/32 принятых теста T57/T58/T126.
Прямой перебор маленьких календарей проверяет только формулу экспозиции;
полный массив считается точной floor_sum, не переносом малой модели.
Полная 2916-строчная репродукция T58 с исходным XLSX не заявлена.
Новой адаптивной кампании, RTL, физического расчёта, запуска агентов или
изменения принятых научных файлов нет. Это поставленная разведка, не
самостоятельное научное принятие или закрытие Issue.
