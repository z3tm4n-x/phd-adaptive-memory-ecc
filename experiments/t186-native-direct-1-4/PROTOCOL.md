# 1.4. Договор до подсчёта

Вход — [назначение 1.4](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/issues/186#issuecomment-6801180415), main `86033c4027067c33799b5d485e37a7fcc7bfd272`. Берём 14 протонных и 14 тяжёлоионных серий CY62167GE30-45ZXI с отключённым ECC из [Zenodo 8314389](https://zenodo.org/records/8314389). Имена и SHA-256 всех членов задаёт [манифест](../RE-CY62167-ADDRESS-MAPPING-01/input_manifest.json). Знаменатель — все обычные исходные кластеры соответствующей серии, включая одноячеечные. Применяем фильтр T68 для служебных записей с единственной уникальной координатой (0,0). Укажем отличие от Д2, где исключались только подтверждённые маркеры. Сохраняем границы исходных записей, повтор координаты внутри записи считаем один раз. Числитель — число кластеров с двумя различными координатами хотя бы в одном предполагаемом слове. Один кластер входит в числитель один раз. Печатаем результаты для протонов и тяжёлых ионов отдельно, а также по файлам. Это условные частоты среди зарегистрированных кластеров на всём испытанном массиве.

**Карта.** Координаты X и Y даны в шагах опубликованной сетки 4096×4096, расстояние между ячейками — максимум абсолютных разностей координат. Сценарии регулярного размещения проверяем вдоль X и вдоль Y. Пусть t — координата по выбранной оси, u — по другой. Запишем t=(32b+j)s+r, где 0≤j<32, 0≤r<s. Одно слово имеет метку (u,b,r), его информационная позиция — j. Для определённости закрепляем все шесть проверочных позиций в отдельной полосе той же оси, на координатах (u,t₀+(6b+h)s+r), h=0…5, t₀=32s·ceil(4096/(32s)). Эти шесть координат находятся вне зарегистрированного массива. Это полная **модельная** карта. При свободном размещении проверочных позиций та же проекция данных допускает их сближение с любым разрядом. Для точных разбиений массива без дополнения края проверяем s=1,2,4,8,16,32,64,128. Для целочисленной диагностической карты с продолжением последнего блока за край проверяем также все s от 1 до наибольшего зарегистрированного диаметра плюс один. Выдаём первый нулевой числитель и начало непрерывного нулевого хвоста, проверяем их раздельно. При больших шагах диаметр ограничивает пересечение. Дополнительная адресная гипотеза — четыре последовательных внешних байта, слово floor(A(X,Y)/4), 32 разных ячейки данных по модели GF(2), шесть проверочных позиций скрыты. **Доверие и перенос.** Идентификатор родителя, пригодная полнота регистрации пространственно разнесённых попаданий, охват проверочных ячеек и совместная представительность испытательных энергий и углов не заданы. Границу на частицу вычисляем только под явно указанным договором. Для иллюстративной доли прямых событий d=10⁻⁴ и частоты инверсий на разряд из главного примера берём S₁=187464, W=32768 или 44529. При среднем m инверсий на непустую частицу N⁺=W S₁/(524288 m), E[N_пр]≤N⁺ f, Q_пр≤min(1,N⁺ f). Для двух инверсий используем опубликованные округлённые вниз цели f*=1,70·10⁻⁸ и 1,25·10⁻⁸. Для иных законов справочно выдаём собственные N⁺ и d/N⁺ при сохранении общей нормировки. При нуле находок минимальное N проверяемых **независимых непустых частиц** с полными масками и покрытием миссионной смеси удовлетворяет (1−f*)^N≤0,05, одностороннее доверие 95%. На нескольких независимых испытательных компонентах для совместного доверия распределяются бюджеты ошибки. При неполном покрытии используем §2.5, (2.15)–(2.16), с остатком от непокрытых компонент. Решение автора о назначении доли остаётся открытым.
