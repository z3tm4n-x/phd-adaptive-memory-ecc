# Расчётные дополнения к примеру CY62167GE30-45

От хода опыта 11.11. Подмена счёта и замедление после повреждения команды воспроизвелись на первом исполнении. После этого добавлены запоминание факта ERR, проверка допустимого значения шага при установке и исполнении, затем — контроль чётности межпроходной паузы по результату отдельной инъекции. Окончательные варианты сравниваются на девяти одинаковых сценариях. Параметры расчёта SEPEM и выборка не менялись.

Основание — решение автора от 11.11.2026. Память 0,125 МиБ, 65 536 адресов ×16, внутренний код 32+6, десять лет. Сравниваются только режимы на одной карте. Квота накопления с учтёнными исключениями исполнения равна 10⁻³. Для прямых попаданий результат выдаётся как функция отдельно назначаемой доли. Пример с 10⁻⁴ показывает масштаб требования.

Для цены одного десятилетия берём окно №462 (SEPEM, 16.12.1996 07:20 — 16.12.2006 19:20 UTC), реконструкцию №459, регистровое управление и исправное исполнение. Сначала подставляем верх экспозиции окна в принятую ведомость математического ожидания для каждой карты. Для оценки среднего на конкретном размещении заранее фиксируем замкнутые соседние пары, 32 768 слов, штатные часы, полный отчёт, нулевые дополнительные сбросы и начальное чистое состояние. Сохраняем закон меток №457, порядок всех посещений и тариф порта. 128 независимых реализаций со стартовым семенем 462, без отбора. Редкие неоднозначные продолжения при первом выходе за принятую семантику учитываем отдельно. Среднее по реализациям иллюстрирует цену и не служит сертификатом.

Уменьшенный цифровой исполнитель содержит восемь адресов, регистры счёта и выбора шага. Синтез для семейства Zynq-7000 и адресные инъекции проверяют наблюдаемые механизмы, включая возможность опасного ложного нуля. Ожидаемые результаты опыта задаются до запуска: при последнем исправлении, распознанном неполном отчёте и неустановленной команде сохраняется частый шаг; повреждённый достоверный на вид ноль и повреждённый регистр команды требуют отдельного учёта. Экспериментальная частота сбоев за срок не выводится из количества цифровых инъекций. Без повторной квалификации принятых результатов и без облучения.

## Исправление 5.1. Фронты до изменения RTL

Исходник рецензии — `348f2a4b093d6966fc6441f6f665895a95aeea61`. Для обеих конфигураций отсчёт начинается с фактического чтения адреса 0 в раунде 1280, после разгона штатной истории. Период часов 10 нс, малый проход 2800 нс.
