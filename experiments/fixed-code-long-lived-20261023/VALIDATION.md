# Проверка и воспроизведение

План опубликован до расчётов: PR249, коммит
`24636b542a2ea746d1de969bd9549d6b7254e7b6`.
Принятые исходники и результаты не изменяются. 12 необходимых входов
зафиксированы в `frozen-inputs.json`; SHA256 проверяются после CRLF→LF.
Код использует Python 3 и стандартную библиотеку.

Из корня репозитория:

```text
python -B -m unittest discover -s experiments/fixed-code-long-lived-20261023 -v
python -B experiments/fixed-code-long-lived-20261023/calculate.py --check
```

Первая команда проверяет новую область сравнения и целостность сертификатов;
вторая точно воспроизводит итоговый JSON из сохранённых k53/k107 и принятого
k27. Она не пересчитывает интегралы. `--assemble` заново собирает итоговый
JSON из этих же сертификатов; `--compute` дополнительно пересчитывает k53/k107
с направленными 48-разрядными интервалами. Полный пересчёт новых интегралов
занимает минуты; прежняя кампания k27 не повторяется.

Проведён полный расчёт k53 и k107, после первого непройденного Q остановка
по плану. Семь тестов прошли: полный бюджет постоянного режима; сохранение
прежней цены k27; фазы и большие периоды в малой геометрии; допустимость
пикового свидетеля; строгая граница исключения; независимость старого
достаточного Q от полезных очисток; сплошное покрытие новых интенсивностей
ячейками и точная проверка их аффинных верхов. Это авторские проверки,
не независимая научная приёмка.

Поле `selected_target=ε/2` в исходных сертификатах оставлено неизменным:
это диагностическая цель импортированной функции. В новом сравнении
приёмочное условие явно `Q_upper≤ε`, одинаковое для обоих методов.
Итог содержит одновременно старый и новый постоянные кандидаты.

Новая нижняя граница охватывает все фазы и весь хвост P≥P0 аналитически;
малый тест не выдаётся за исчерпывающее доказательство. В финальной цене
сохранён дополнительный размах J после исключения на разрешённом ξ⁺.
Для независимого чтения — `THEORY.md`, для научного смысла — `REPORT.md`.

Контрольный чистый снимок и его результат записываются после публикации
первого коммита. Новые формулы и сравнительный вывод до рецензии не приняты.
