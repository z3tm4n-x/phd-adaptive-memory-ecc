# Как проверить оценку для №96

Опорный commit диссертации b2b9871e4e810411d9f078881248d1322f79f388. Замысел и численная подстановка опубликованы в b1571a1266e5a1bd563adb85fffc8fd04090d7dd до новых трасс. Исходный RTL находится в отдельном репозитории adaptive-secdec-scrubber на 689807698880fe7ef4f3ca6c9e7fa3426493a6f8. Новое исправление закрытой эпохи на 03e12c9 там проверяется отдельно. Даже если рабочая копия контроллера обновлена, скрипт извлекает оба модуля именно из объектов Git исходной версии.

Из корня этой поставки достаточно Python ≥3.10 и стандартной библиотеки для повторной проверки 15 наблюдений, распределения всех триггеров, арифметики, разрешений и защитных кодов.

```sh
set -eu
d=experiments/t96-native64k-fault-budget
python3 -B "$d/check.py"
(cd "$d" && sha256sum -c SHA256SUMS)
```

Для пересчёта исходных сигналов нужны Git, Bash, Icarus Verilog и vvp. Воспроизведено на Ubuntu 26.04 с Icarus 12.0. Числа проверены также в Windows на Python 3.12.10. Запуск четырёх симуляторов параллельно определяет только время работы. Случайных входов и seed нет.

```sh
set -eu
d=experiments/t96-native64k-fault-budget
w=$(mktemp -d)
git clone https://github.com/z3tm4n-x/adaptive-secdec-scrubber.git "$w/release"
git -C "$w/release" fetch origin research/t96-native64k
bash "$d/run_traces.sh" "$w/release" "$w/traces"
cmp "$w/traces/observations.txt" "$d/observations.txt"
python3 -B "$d/check.py" --traces "$w/traces/observations.txt"
```

Стенд моделирует память через известные адресные входы DQ/ERR. Величины времени в observations.txt — номинальные нс относительно первого физического старта, −1 означает, что сигнал не наблюдался в данном интервале или поздняя граница не исследовалась. first_start_L=−1 в случаях 0 и 2 означает отсутствие старта на L, а не доказанное отсутствие будущих стартов. Столбец zero показывает принятие на сечении, install_code — код на фронте установки. held_data и data_5ns_before_WE_rise — наблюдения на активном выводе за 10 и за 5 нс до подъёма WE#. В случае 9 наблюдались все границы до 8L при ускорении внутренности неактивных интервалов. В случае 14 вся пауза прошла с тактированием. В остальных строках поздние последствия не достраиваются. Направленный переворот записывает одно поле в середине такта. Случай 10 подавляет комбинированный строб на один фронт и относится к общему пути.

Опись получена чтением уже размещённой контрольной точки Vivado 2025.2, SW Build 6299465. SHA-256 локального файла DCP 1782f067c07b097cbb5ad367d05602253255f3cbb689b967fdf9de9053ccf4c4. При пересоздании DCP важны совпадение используемой версии инструмента, ресурсы и строки размещения. Двоичный файл может содержать служебные метки сеанса. Если имеется исходная контрольная точка, достаточно второй команды Vivado. Следующий блок воспроизводит и исходное размещение. В этой проверке применялась обёртка /home/z3tm4n/bin/vivado-wsl.

```sh
set -eu
d=$(realpath experiments/t96-native64k-fault-budget)
git -C "$w/release" checkout --detach 689807698880fe7ef4f3ca6c9e7fa3426493a6f8
bash "$w/release/experiments/t96-native64k/run_route.sh" "$w/route"
vivado -mode batch -nojournal -nolog -source "$d/inventory.tcl" -tclargs "$w/route/routed.dcp" "$w/registers.tsv"
cmp "$d/registers.tsv" "$w/registers.tsv"
```

Оригинал постера, проверенного 13.11.2026, хранится у издателя. Для сверки контрольной суммы и чтения графиков достаточно следующего вызова. Вся собственная численная информация содержится в пакете.

```sh
curl -fL https://indico.esa.int/event/439/contributions/7941/attachments/5183/8216/SEFUW_v1.1.pdf -o "$w/SEFUW_v1.1.pdf"
echo "1d23d496e206b3f612aac1cfe6695d9fbf67bf05af065d82d7a43f28506038ec  $w/SEFUW_v1.1.pdf" | sha256sum -c -
```

**Граница независимости.** Проверяющий Python использует отдельный список ожидаемых наблюдений и формулы времени. Verilog стенд наблюдает выводы и обращается к внутренним регистрам для задания именно исследуемого дефекта. Обе стороны используют один календарь. Защита проверяется на уровне спецификации. Размещение и физика облучения предлагаемой версии не проверялись. Проверка исходного размещения не воспроизводит облучение.
