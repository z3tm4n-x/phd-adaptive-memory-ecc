**Сделано:** сценарий4, полный W524288/full38,1,2мс, реальный исправленный
startup ELF и firmware, неизменный arm_executor/vendor XPM, условная

эталоном: по6171 операция,48 ответов,149428 E-фронтов,3 собственных ERR.

**Время:** при заданных80мкс на driver visit максимальный полный cut→cut
161940нс; это результат **синтетической сервисной модели**, не A9/WCET.
4669 runtime ISA и81/70 MMIO read/write; CPU и SRAM не суммируются.
PL2476LUT/5516FF/4,5BRAM36 и STA+0,225/+0,044нс переиспользованы по
хешам, новый route не делался. Физическое ARM-время/наличие платы —
не подтверждено. Startup13943ISA,1268B; OCM57344B — прежние ресурсы.

**Независимость:** memory responder SV использует mask/recent; checker
использует рождённые во времени множества, абсолютную формулу календаря,
принятый независимый ETransaction и абсолютный raw-event Oracle В.
Production update/CRC не вызываются эталоном. Общие ABI/константы,
Unicorn/XSim/vendorXPM и прежняя CP15/GIC модель раскрыты. Эта проверка
не является новой независимой проверкой физического PS7 или ECC-карты.

запуск до первого рабочего опыта. Исправлен только тестовый транспорт;
production/семантика/входы сохранены. Ошибок production в этом выходе не
установлено. Мутации не выдаются за найденные производственные дефекты.
