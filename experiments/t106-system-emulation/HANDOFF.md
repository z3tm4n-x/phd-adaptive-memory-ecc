## Проверка и независимость

69 unit tests без пропусков, compileall, отрицательные мутации, полные
пошаговые проверки и отдельная арифметика FAST прошли. Вспышка не заменена
пилотом. Эталон памяти использует birth-labelled множества против
SV-битовых масок; правило — абсолютный Oracle, не копия production C.
Общие зависимости: ABI/E-контракт, Memory/ETransaction, CP15/GIC model,
generic CT2/CT3 codec, Unicorn/XSim/vendor XPM. Точные пустые блоки проверены
против буквального C/ELF/RTL; не заявляется буквальное исполнение триллионов
операций. Новая независимая Scientific Review не запускалась.

PL: 2476 LUT, 5442 slice FF + 74 IOB FF, 4,5 BRAM36, DSP0.
Прежний route по 9 хешам: setup +0,225/hold +0,044 нс.
Adaptive резервирует одно ядро; полезный CPU% неизвестен.
OCM 57344 Б, firmware 4244 Б, startup 1268 Б. Сервис 188160 нс —
модельное условие, не аппаратное ARM-время/WCET. CPU/PL/шина не объединены
в один процент. [CONDITIONS](CONDITIONS.md) сводит условия один раз.
