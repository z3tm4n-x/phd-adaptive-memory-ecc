# Полный сценарий 2: техническая фиксация до запуска

Продолжение 441dbef, 15.10.2026. Актуальные инструкции прочитаны на
main 203575d3da57124d3af46791c65a6895969b2195; область #106 прежняя.
Не изменяем принятую production C/ELF/RTL, частоты и входы BURST.md.
Отдельные run_burst/tb_burst/bridge_burst — производные стенда сценария5,
не новый контроллер. Старый путь и результаты остаются побайтно.

Полный вход: outputs/burst-stimulus.json.gz, ровно 363900 с и 5237
инжекций, adaptive и all-slot FAST. Не новая реализация случайного потока.
Перед полным запуском — явно помеченный технический префикс первых
20 исходных событий, до последнего из них плюс1с (все попавшие туда
соседние события также сохраняются). Его числа не результат сценария2.
Дополнительно новый путь сверяется с сохранёнными short/lowprobe.

Проблема: буквальный сырой журнал длинного профиля может превысить
доступное место. Варианты: хранить целиком (ненужная дисковая цена);
потоково сжимать без потерь (выбрано); сокращать время/слова/инжекции
(изменяет опыт, отвергнуто). FIFO пишет каждый исходный текстовый токен
в прежний независимый от модели CT2-кодек. Развёрнутый SHA проверяется.
Системный счётчик фактически тактируемых slow-фронтов в новом DPI
расширен до64бит; production timestamp/G уже64бит. Functional instruction
guard поднят до2 млрд только как защита от зависания, не WCET.

Сначала измеряем время/размер/память пилота, затем оцениваем полный
путь; при неприемлемой цене меняем хранение/проверку, не научный вход.
Общий эталон check_sparse переиспользуется и явно назван общей зависимостью:
он не вызывает production-переходы/перенос состояния стенда. Проверки
охватывают память, первое превышение, собственные ERR, порядок/cut/G,
разрешение, календарь, корректирующую запись и полный горизонт.

Полная стоимость включает начальный/конечный участок и незавершённую
операцию; ARM-ISA и представленные пустые сервисы разделены. Полный
модельный сервис188160нс не измерение времени Cortex-A9. Плата/WCET
не заявляются; Q(T) за срок эмуляцией не доказывается.
