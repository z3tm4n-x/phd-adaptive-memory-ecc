# Предварительная фиксация selected DREG / CW

Научный вопрос/параметры исходного задания неизменны; calculation_config.json
является активным численным config. Старые config/entry points остаются
историческими и отключёнными. Новые исходники: input_contract.py,
upstream_regression.py, selected_recovery.py, cw_calculate.py,
independent_validation.py. Их commit предшествует любому новому upstream/DREG/I1/I2
расчёту. Transport исполняется по отдельной ранее зафиксированной процедуре.

Последовательность обязательна: пригодный transport → отдельная upstream
regression (288 точек, 1e-6 relative, exact-zero rule) → выбранный DREG → CW →
независимые проверки. Исторические main и любые risk/MC grids не вызываются.
Обычный upstream сравнивается с frozen d10_lambda_central_s-1; DREG получает
истинное mreg/kbar по всем energy nodes, включая high bucket. Никакая колонка
upstream не объявляется DREG. CSV/source/SHA закреплены input_contract/source_manifest.

Полный GOES archive читается для metadata, временной сетки и исторической
популяции median fallback для high-energy gap. Ни rates, ни риски вне выбранных
288 блоков не вычисляются. Проверяются все 59 member SHA, обе направления,
timestamp как начало периода, явная правая граница 2026-01-20 04:00 UTC.
Кусочно-постоянное r задано на полных 300-s блоках; tau=1 s. Для любого
фиксированного phase периодическое продление потенциальных Delta-окон имеет
суммарную длину 300*Delta в блоке. Исключение окон до чистого старта и обрезка
на конце H уменьшают вклад. Pair Cauchy-Schwarz контролирует и неполные
начальные/конечные inter-check интервалы. Это SR-03 duty-основание, не
использование средней загрузки для произвольной r(t).

Арифметическая область: nu_C_bit_DREG в CSV — точная десятичная запись нового
вычисленного численного представления, r=nu/2^24 точно. Fraction выполняет
интегралы/коэффициенты без округления. Печатные upper округляются вверх целой
арифметикой к сетке 1e-40; lower — вниз. Огибающая min(1,a_upper+b_upper*Delta)
и её threshold вычисляются точно из этих upper. Запас подписанный; отрицательный
не обрезается. Равенство допустимо, Delta=1 недопустима, при b=0 деление не
выполняется. Exact rational threshold и его округлённая вниз допустимая запись
сохраняются отдельно. Statistical confidence/physical coverage не вычисляются.

Это строгая арифметическая upper для объявленного численного r, не интервал
ошибки реальной физической интенсивности, не строгий error bound всех libm/BLAS
операций transport и не доказательство тождества недоступной исторической матрице.
Регрессия 1e-6 — критерий воспроизведения представления, не вероятность нарушения
coverage. Неизвестное физическое отклонение не оплачивается этой tolerance.

Независимый checker не импортирует основной вычислитель интегралов. Он использует
Decimal precision=200 с Inexact trap и обратным порядком суммирования; проверяет
точные дроби и направление округления. Дополнительно пересчитывает DREG из
сохранённых энергетических contributions через math.fsum (tolerance 1e-12,
диагностика реализации), вызывает реальный CLI на ошибочной нормировке,
дубликатах/пропусках/NaN/negative/time errors и проверяет zero-series.
Boundary cases: Delta=0, Delta=1 и рядом, a=epsilon, b=0, отрицательный остаток,
равенство coverage, насыщение U=1. Отдельные точные window intersections
проверяют start/end truncation и отрицательную регрессию average duty для
произвольной r. Это не повторение закрытых 4096 executor traces.

Критерий результата: вычислительная достаточность только на выданной области
(Delta,delta_cov_upper); реальное покрытие/чистый старт/WCET/full-device остаются
отдельными предметами. Любой непройденный gate сохраняется и разбирается без
повышения заранее заданных tolerances. Independent checker — работа этой RE-сессии,
он не заменяет назначенного Scientific Reviewer.
