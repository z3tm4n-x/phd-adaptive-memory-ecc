**Время, единицы и предпосылки.** Timestamp означает начало усреднения.
H=[2026-01-19 04:00:00 UTC, 2026-01-20 04:00:00 UTC), последний блок — 03:55.
288 полных блоков по 300 s; нет пропусков, дубликатов, NaN или отрицательных rates.
r=nu_C_bit_DREG_s^-1/2^24 — суммарный накопительный data-bit поток делится один раз.
Direct hazard не подставляется.

N_w=2^19, 32 наблюдаемых data bits/word, W32_seq — объявленное отображение,
не установленное внутреннее W. r имеет единицы s^-1, I1 безразмерен, I2 — s^-1,
a безразмерен, b — s^-1. Общая детерминированная r, независимые простые NHPP
по разрядам внутри слова, равномерность по bits и постоянство rate внутри блока —
предпосылки. Чистый старт, отсутствие pending write, фиксированные фазы проверок,
singleton-only write с latched clean image и завершение до следующей проверки
также предполагаются. Межсловная независимость union upper не нужна.

Duty-условия выполнены в этой численной модели: 300/tau=300, H состоит из полных
постоянных блоков. Для любой фиксированной фазы периодически продолженные
потенциальные Delta-окна занимают 300*Delta в блоке. Исключение pre-start окон
и обрезка на конце H уменьшают экспозицию. Pair Cauchy-Schwarz включает неполные
начальные/конечные inter-check интервалы. Поэтому допустимы
a=N_w*C(32,2)*tau*I2 и b=31*N_w*I1/tau без фазовой квадратуры.
Случайная фактическая задержка допустима при доказанном детерминированном верхнем
пределе Delta; просто past-known random delay вместо этого предела не подставляется.

CSV nu — точное десятичное численное представление модели; r делится точно.
Fraction считает интегралы без округления. Целая арифметика округляет upper вверх
к шагу 1e-40, lower вниз; избыток каждого upper <1e-40. Огибающая использует
полные a_upper/b_upper в начале REPORT.

Это строгий контроль интегралов объявленного численного r. Он не доказывает
строгую погрешность всех libm/BLAS действий относительно идеального вещественного
transport и не поглощает физическую неопределённость отклика. Statistical
confidence interval не строился; central_mean не стал физической upper.
Старый U_reg не использовался ни для rates, ни как целевой ответ.

Достаточная область: 0<=Delta<1 s и 0<=delta_cov_upper<=s(Delta), только при s>=0.
Поскольку epsilon<1, это равносильно
a_upper+b_upper*Delta+delta_cov_upper<=0.001. Равенство допускается.
При нулевом coverage точный threshold:

    Delta_star = 6901842227663796180021608536530559127
                 / 25281037181797039690725000000000000000000000 s

Округлённая **вниз**, гарантированно допустимая запись:
0.0000002730047101324343639986193957750873 s. Здесь threshold<tau и достигается;
в Delta_star остаток ровно 0, поэтому coverage upper должен быть нулевым.

| Delta | U_model_upper (кратко) | Подписанный остаток (кратко) | При coverage=0 |
| --- | ---: | ---: | --- |
| 0 | 0.000309815777234 | +0.000690184222766 | достаточно |
| 10 ns | 0.000335096814415 | +0.000664903185585 | достаточно |
| 100 ns | 0.000562626149052 | +0.000437373850948 | достаточно |
| Delta_star | 0.001 точно | 0 точно | достаточно, равенство |
| 1 microsecond | 0.002837919495413 | -0.001837919495413 | недостаточно по этой upper |
| 0.999999 s | 1 точно | -0.999 точно | недостаточно по этой upper |

Таблица округлена, точные values в JSON. Отрицательный остаток не обрезается.
При b=0 деление не выполняется: если a<=epsilon, вся строгая область Delta<tau
допускается; при a>epsilon область пуста. При a=epsilon,b>0 допускается лишь
Delta=0,coverage=0. Delta=tau исключена; если threshold>=tau, tau была бы только
недостигаемым supremum. Непрохождение upper не доказывает невозможности всех Fixed.

**Физический перенос.** Нужны событие V нарушения покрытия, доказанная связь
физического E_cap с моделью вне V и отдельное P(V)<=delta_cov_upper для того же
H/среды. При предполагаемом WCET<=100 ns требуется
P(V)<=0.0004373738509484092210949108536530559127. Вычитание только задаёт требование.

Приоритетный недостающий контракт: **верхняя вероятность неохваченных
E_cap-релевантных путей полного слова**. Нужно документировать переход от
physical parent events к регистрации и ошибкам полного data+parity ECC-слова,
с верхней вероятностью нарушения этой связи. Его основания — записи до
кластеризации, экспозиция/fluence и режим чтения, parent association и
подтверждённое post-W описание либо доказанная инвариантная огибающая.
При WCET<=100 ns приведённая граница сделала бы достаточность переноса данной
Fixed проверяемой при остальных выполненных предпосылках. Это один контракт
с несколькими основаниями; одно измерение не объявляется устранением всех
пробелов. Аппаратные работы этой поставкой не запускаются.
