## Быстрый повтор

Из корня репозитория; Python3.10+, стандартная библиотека, Git с объектом базы:

```bash
python3 -B experiments/t126-regime-map/verify.py
```

По умолчанию **ничего не записывает**. Проверяет 32 малых регрессии,
17 закреплённых научных файлов, две старые точки T58, исходный lower T95,
три адресных necessary-cap подстановки; сравнивает три T126 output побайтно.
JSON содержит точные дроби; числа Markdown округлены наружу. SVG — статусы
проверенных точек, не интерполяция и не новый научный график-функция.
`--write` создаёт только `starter-map.json`, `starter-map.svg`, `ANCHORS.md`
в **этой** новой папке. Он не перезаписывает принятые outputs.

## Содержимое

| Файл | Роль |
|---|---|
| PLAN.md, grid.json | План/конечные множества до нового инженерного перебора |
| bounds.py, test_bounds.py | Новая допустимость necessary-свидетеля; принятые lower; малые проверки |
| verify.py | Только принятые anchors, адресные necessary-подстановки и сериализация |
| starter-map.json | Исходные дроби, источник, область, цена/риск, пять статусов, неизвестные |
| starter-map.svg, ANCHORS.md | Графическая и читаемая формы той же таблицы |
| HANDOFF.md | Последовательная передача инженеру через оркестратора после #127 |
| SOURCES.md | Четвёртая SRAM и подготовка орбитального пятого примера |

Каждая строка несёт `example_id`: CY/T95, CY/T114 и будущие толщины —
один A3, а не дополнительные примеры. `domain` разделяет несовместимые
Λ/Θ, U/E, приложение и метрику. `null` не участвует в арифметике как нуль.
Новый S₂ нельзя одновременно вставить в upper и сохранить прежний
непроверенный lower. Для бюджетов кроме1% начальная большая R0-B-строка
не объявляет старый1%-lower исключением нового класса.

## Остаток до первой карты

1. Инженер после #127 выполняет конечную сетку по HANDOFF; нужны его точный
   input SHA и согласование воспроизведённых строк, а не новые параметры.
2. Точки CY по защите — по переданным согласованным inputs/unknowns.
   Новый S₂-класс, direct и нижний канал не предполагаются квалифицированными.
3. Четвёртый образец — до получения точной ревизии и переносимой кривой
   остаётся пустым; старый master/RES-002 gain не расширяется до lifetime.
4. Экспорт сопоставимого тихого upper постоянного E из принятого ценового
   договора. Его миссионный scalar в эту ячейку сейчас не копируется.

Принятые T52–T114, RES и паспорт не меняются; T119 пока кандидат.
Ни `verify.py`, ни эта передача не запускают RTL, физические кампании,
агентов, новый оптимизатор или реализацию. Main не сливать, Issue не закрывать.
