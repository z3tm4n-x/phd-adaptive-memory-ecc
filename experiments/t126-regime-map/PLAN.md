## 1. Утверждение и границы

По явно указанным памяти/среде/наблюдениям/сервису/приложению и бюджету
применить **принятые** достаточные условия T52/T58/T80/T95/T114.
Отдельно применить необходимые границы только при допустимом свидетеле
для того же класса. Выдать достаточность постоянного, необходимость и
достаточность адаптации, только достаточность адаптации, исключение всего
объявленного класса управления периодом либо неустановленную область.

Нет новой универсальной теоремы о карте, нового правила или достаточного
сертификата. Новые доказательства допускаются только для необходимых
границ, прежде всего при новом ограничении S2. Отказ достаточного условия
не доказывает невозможности. T119/d0ce4425 до принятия после #122 — только
кандидат, не основание цвета карты. Тонкая оптимизация ERR под R0-A прекращена.

## 2. Координаты и сопоставимость — до таблицы

- Полное n, W, смысл интенсивности (родители/касания/одиночные инверсии),
  T/epsilon, марки/MCU/позиции, начальное состояние; нельзя молча применять
  k=(n−1)/(2nW) к произвольному marked-потоку. T114 использует иной
  коэффициент первого разрыва, включая XOR-скрытие ERR.
- D*: верх ожидаемого числа прямых многобитовых родителей, не нижняя
  вероятность и не синоним прямой ионизации протоном. delta>=1 и
  delta+sigma>=1 не являются необходимыми границами.
- S2 разделить на фон за **весь** срок и солнечный избыток со смешанным
  членом2bs. Точные интегралы, верхние границы и отношение их верхов
  различаются. eta не подменять 1+CV². Нулевые знаменатели — явный статус.
- P_min получить из полного выполнимого календаря, пика, приложения,
  задержки и10%, не из одной занятости Wc. Различить ресурсный минимум,
  минимум объявленного семейства и необходимый нижний предел периода.
- chi оставить вектором параметров принятого канала; отдельные
  безразмерные проекции — только подписи, не достаточная статистика.
- Цена: спокойная основная, средняя за срок рядом; приложение, канал,
  возвраты, плохие истории, остатки и неизменные lifetime-квоты включены.
  Соперники совпадают по Lambda/Theta, U/E, полному слову и потоку приложения.

## 3. Четыре примера и пятый задел

1. Малый R0-B, n39/W262144: принятый постоянный T58, условная диагностика.
2. Большой R0-B/магистерская, n39/W1935832: историческое положительное
   сравнение не переносить на новый класс. Отдельно T58-класс и конечные
   исторические окна RES-002; отсутствие lifetime-моста пометить.
3. CY62167/full38: **один пример**. Все толщины из #127 — одна кривая;
   до передачи инженера остаются прежние условные строки T95/T114.
   Мониторная T95 — контроль большого условного выигрыша, не реальный прибор.
4. Другая SRAM/external39: до расчёта обязательны точный образец/ревизия,
   первичный источник низкоэнергетических протонов, кривая/единицы/диапазон,
   энергия у кристалла, режим и неопределённость. Пока кандидат неизвестен.
5. Во второй итерации ДЗЗ с положением/временем штатной аппаратуры.
   Сейчас только источники и необходимые поля данных; SAC-C/ICARE — кандидат.
   Датчик частиц допустим для наземной проверки, не скрытый вход правила.

## 5. Решение по каждому исходу

Есть постоянный в бюджете → предъявить его, не объявляя оптимальным.
Исключён сопоставимый постоянный класс и есть адаптация → нужная и возможная
адаптация в этом бюджете. Есть адаптация без исключения → необходимость
не установлена. Исключён весь явно названный класс управления → «период
не спасает» только для него. Иначе — «область не установлена» с причиной.
Само отсутствие физического входа — не доказательство невозможности.

Большой выигрыш — нижняя цена **всего** постоянного класса / достаточный
полный адаптивный верх. Новый S2 может удалить прежний начальный пик:
проверить его заново, а не переносить30.81%/33.68%. Если квалифицированного
большого выигрыша пока нет, показать условный контроль и точный пробел.

**Расчёт и предел.** Все 36 узлов `grid.json`, исходный T58 диапазон
M=1…2^64−1, поиск по точным рациональным ветвям, без Монте-Карло. Для каждого
узла независимо от бюджета экспортируется предъявленный допустимый Fixed
с его ценой; тест бюджета применяется затем. Отдельно нижняя Q для всего
T58-класса при данном бюджете. Нижний конец интервала цены получается из
того же допустимого plateau по T126/Б2–Б3, только при проверенном хвосте:
фиксированный split=2 с, сетка инверсии 1 нс, не более 64 шагов. Если этот
свидетель не даёт lower — null, а не новый поиск свидетелей. Это применение
кандидатной необходимой границы, её статус сохраняется до общей рецензии.
Изменение W сохраняет per-bit закон; D*=0 только в singleton-диагностике.
Ресурсный минимум определяется отдельно от бюджета средней цены.

**CY.** Четыре точки #127 × три ε × три бюджета остаются одним примером.
В них считаются только доступные условные координаты: фон, s², 2bs,
singleton k и отдельно β0; никакой D* из прежнего класса не переносится.
Полные Q/нижняя цена/канал остаются null с причиной. Даже положительный
арифметический запас сам по себе не даёт допуска. Прежние T95/U и все
предъявленные T114/E строки (и отказы) экспортируются отдельно при их
исходном ε=.001; смена ε не переименовывает принятые квоты/правила.
Они не заменяют новые физические строки. Минимум адаптивных цен допустим
только внутри одного профиля, роста, приложения и ε.

**Тихая цена постоянного E.** Отдельно экспортируется принятый T110
`constant().cost_upper` для returning-тихих интервалов, с добавкой слабой
E-апертуры T114/Г3, X и наблюдения записей на том же общем envelope.
Миссионный scalar не используется как тихая цена. Все слагаемые и общий
поток сохраняются отдельно; нет новой ценовой теоремы.
