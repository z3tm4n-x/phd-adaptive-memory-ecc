# T126. Первая ограниченная инженерная карта — 08.10.2026

**Решение.** Карта даёт достаточный постоянный режим в **8 из36** узлов R0-B.
В14 узлах он исключён принятой нижней оценкой T58; ещё в3 — только новой
**кандидатной**, пока не принятой границей T126. В остальных11 решение не
установлено. Ни исключение Fixed, ни неуспех верхней оценки не доказывают
невозможность всего класса периодического управления. Адаптивный сертификат
для этих R0-B узлов не предъявлен. Новые физические точки CY пока не допускаются.

бюджеты спокойной защиты={1,10,50}%. Закон на **бит** неизменен.
Полное слово39, независимые равномерные одиночные инверсии и D*=0 —
только диагностическая модель T58. Полный целочисленный диапазон периодов,
календарь, приложение, пик/задержка проверяются вместе; Pmin не заменён Wc.

неуспех фиксированного split2с оставляет `null`. Доработок сетки не было.
