# T126. Повтор первой инженерной карты

Из корня **опубликованного commit этой ветки**, Python3.12 и Git:

```bash
python -X utf8 -B experiments/t126-regime-map/reproduce.py
```

Численные расчёты требуют только стандартную библиотеку. В первый раз
нужен доступ к GitHub: точные файлы #127 читаются по `2695d5a…` с проверкой
Git-blob и SHA-256; при отсутствии магистерских объектов создаётся внешний
bare-cache и загружается только `cf7ab706224f7872fdafcf34febda70e3f6c8dd1`.
Точное имя cache печатается в журнале. Код не сливает ветки и не меняет main.

Для заранее подготовленного/офлайн-повтора:

```bash
python -X utf8 -B experiments/t126-regime-map/reproduce.py --master-repo /absolute/path/to/master.git
```

В master.git должны быть объекты указанного SHA. В научном checkout должны
быть Git-объекты `2695d5ade64a2e13116dce937c7c95aa4dff3a51` и базы
`67bf34b4f06a0410461e728f4217b8c58f704b04`. Подготовить их можно обычным
`git fetch origin <точный-SHA>` до отключения сети. Свежий shallow checkout
без этих объектов не является подготовленным офлайн-входом.

## Что выполняет команда

1. T58: source hashes магистерской,31 тест,54 core и2916 прежних диагностических строк.
2. T95:71 проверка; T114:19 state и439 численных проверок, включая его принятые зависимости.
3. Исходная теория T126:32 регрессии,17 source checks,7 anchors и3 cap-свидетеля.
4. Общий suite T126:32+15=47 тестов; новый независимый `checker.py` отдельно.
5. Новый полный расчёт283 строк и **побайтное** сравнение JSON/CSV.
6. compileall; кэш только в системной временной папке, не в Git.

Ни одна из команд не перезаписывает принятые outputs. Новые outputs тоже
не меняются без отдельного `engineering.py --write`. Такой флаг для старых
пакетов не использовался. `--skip-accepted` предназначен только для разработки
и не называется полным воспроизведением. Не применять Python `-O`: проверки
содержат assertions. `--receipt <новый-путь>` сохраняет необязательную квитанцию
с командами, stdout/stderr, временем, средой, SHA кода и файлов; научные числа
от этой квитанции не зависят. Штатный повтор не меняет опубликованную квитанцию.

## Численная семантика и границы независимости

`map.json` содержит исходные рациональные строки. CSV — человекочитаемый
срез: upper округлены вверх, lower вниз до18 знаков; пустое поле означает
неизвестное/неприменимое, **не нуль**. Полные причины/канал/календарь/цена
по компонентам — в JSON. Все доли загрузки в JSON/CSV от0 до1, кроме
необходимых цен, которые могут превышать1; в отчёте они переведены в проценты.
Q — вероятность первого превышения корректирующей способности полного слова.
Смешанный2bs источника #127 проверяется с допуском1e-8с⁻¹ только из-за его
прежней binary64-сериализации; этот допуск не квалифицирует физический вход.

Вычислитель переиспользует принятые `certificate.py`, T110/T114 и helpers
теории T126. Это воспроизведение, не независимая реализация всей науки.
`checker.py` не импортирует ни один из них: независимо раскладывает caps,
Б2/Б3 и фазовый край, upper R0-B, ценовой экспорт постоянного E и2bs.
Общие зависимости — закреплённые исходные числа, формулы, Python Fraction/
Decimal. Тесты искусственных подмен должны отклонить ошибочные outputs;
согласие двух реализаций не заменяет Scientific Review.

При разработке расширения checker один раз неверно взял10мкс вместо
исходных3мкс из T58 при проверке всей шины. Проверка не прошла; checker
исправлен на прямое чтение закреплённого deadline. Научные параметры и
вычислитель не менялись ради прохождения проверки. Других неразрешённых
вычислительных отказов в поставке не оставлено. Сведения окончательного
повтора и хеши приведены в `outputs/reproduction.json`; при новом повторе
время/пути/версия ОС могут отличаться, JSON/CSV научных чисел — нет.
