**Суть для автора.** При ERR интерфейс заблокирован до завершения исправления:
старый образ не может затереть новую принятую запись, включая другой alias.
Без ERR интерфейс освобождается после проверки и отключения выходов SRAM.
Но E не равен clean-U: ошибка после чистого наблюдения может сохраниться.
Поэтому новые времена передаются для адресного пересчёта сервиса и Q(T).
Редкость ERR не используется для оправдания пика; проверен all-ERR верх.
Нельзя переносить старую цену постоянного full-U соперника на новый E.

Сохранены точные D* обеих строк, Λ/Θ, ε=10⁻³ и квоты, запас 10%, предел 80%
и цель задержки 3 мкс. Нужны подтверждение проектных I/O/clock/CDC границ,
контракт полезного CPU/X трафика и backpressure; неизвестные — `null`.
Это конкретные условия продолжения, не запрос квалификации D* или облучений.
Записи приложения остаются вне Q(T). В/Г и основной RTL не начаты.

```sh
python -B experiments/t104-new-rtl-executor/run_budget.py
```
