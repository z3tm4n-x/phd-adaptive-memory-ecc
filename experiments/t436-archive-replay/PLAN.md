# Ц4. Парная архивная иллюстрация для §4.6

[Задание №436](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/issues/436). База `68ad547faefa19a72d9a99fd4424ac6f55ffd27b`. Рассчитать первым выбранное десятилетие SEPEM, затем два ряда GOES East и West. Сравниваются зарегистрированное правило §2 Ц2 (`8472a0a2`) и допустимый фиксированный период 4L. Единица наблюдения — пара на одной реализации потока частиц.

* Вход SEPEM начинается 16.12.1996 в 07:20 UTC. Вход GOES начинается 01.01.2017 в 00:00 UTC. Длительность каждого — 315 576 000 с. Используем пятиминутные средние Ц1 и реконструкцию №423/426. Измеренные участки, заполнение пропусков и хвост после 09.11.2026 отмечаем отдельно. При смене среды состояние банка и счётчик продолжаются.
* Первая строка — повтор 0. Заранее назначены 16 независимых пар на архив, индексы 0…15. NumPy PCG64, SeedSequence([436, 20261110, i, r]), где i=0/1/2 для SEPEM/East/West и r — индекс повтора. Для реконструированной частоты ν генерируем неоднородный пуассоновский поток с темпом 39Wν/(2D), D=38·524288. Выбор двух разных слов равномерен, в каждом инвертируется один из 39 разрядов. Хеш упорядоченных времён и полных меток одинаков у обеих политик каждой пары.
* Номинальные часы, чистая память, нулевой pending. W=65536, L=12 845 056 нс. Проход 0 обязателен. Постоянный календарь обслуживает раунды 0,4,8,…, правило начинает часто. Номер слова на позиции j равен 3j mod W, смещение в наносекундах равно 1568⌊j/8⌋+164(j mod 8). Логическое чтение имеет согласованный снимок на старте, чтение/декодирование занимает 48/68 нс шины/сервиса. При исправлении прибавляем 56 нс обоим. Исправляем разряд на release, сохраняем XOR всех поздних инверсий. Для сверхрадиусного снимка продолжаем по модельному декодеру (39,32) из `reference-continuation-01/witness.py`. Сигнал неисправимости делает отчёт непригодным. Работа продолжается до T.
* Сечение scan+drain в номинальной модели Dₒ=L−256 нс, монтаж Iₒ=160 нс. Оба срока приняты как условие исполнения. Снимок, release и сечение исполняются на своих тактах. Частица внутри наносекундного интервала приходит после его левой границы. Если отчёт подтверждён, коррекции публикуются один раз на логическую запись. Нуль 730 полных ячеек подряд разрешает один редкий промежуток 32L. Коррекция или непригодность сбрасывает историю. Транспортных потерь в выбранном исполнении нет. Таймер и решения используют только публичный счёт.
* Считаем начатые защитные операции целиком, полные и начатые проходы раздельно. Длительность частого режима определяется промежутками между началами проходов по (6) Ц2. Пик за 1 мс указываем по принятому верху резерва. При сравнении полной цены добавляем неизвестные расходы управления, отдельно сохраняем процессор и энергию. Для парных затрат приводим разброс по повторениям. Для каждого ряда сохраняем наблюдение первого возврата в частый режим внутри измеренного каталожного события, при его отсутствии — первого за срок.
* Вклад в вероятность считаем по парам различных родителей одного слова на заданной функции ν. Учитываем пары по обе стороны календарной границы, включая пропуски. Используем верх по возможной длине между посещениями с апертурой и условие пустой предыстории из §4 Ц2. Эта оценка относится к заданному исполнению. Испытание с пошаговым исполнителем охватывает реальные чтения, состояние, конечную запись, края и выход из тихого режима.
