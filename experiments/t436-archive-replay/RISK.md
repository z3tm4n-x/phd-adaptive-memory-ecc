# Вклад каталожных событий, остального времени и пропусков

Оцениваем вероятность хотя бы одного превышения исправляемого веса 1 за весь срок при заданной реконструкции и номинальном исполнении [плана](PLAN.md). Расчёт детерминированный, общий для всех 16 повторов истории. Он опирается на покрытие первого касания занятого слова из [§4 Ц2](../../theory/t196-long-quiet-rule-20261109.md). Классовые верхи с исполнительными исключениями приведены отдельно в [Ц1](../c1-common-geo-20261109/TABLE.md) и [Ц3](../c3-candidate-price-20261109/README.md).

**Какая пара нужна.** Пусть $c=39/D$ и $\kappa=Wc/2$. Частицы образуют неоднородный пуассоновский поток с интенсивностью $\kappa\nu(t)$. Фиксированное слово выбирается с вероятностью $2/W$, поэтому интенсивность касаний этого слова равна $c\nu(t)$. Разные слова у одной частицы зависимы. Одна такая частица оставляет не более одной инверсии в каждом слове. До первого касания уже занятого слова (включая ожидающий завершения ремонт) превышение невозможно. По полному стартовому и крайним интервалам §4 два разных родителя, достаточных для этого первого касания, попадают в один интервал от начала обслуживания слова до конца следующего. Это даёт верх по среднему числу подходящих пар. В него входят повтор в тот же разряд и совпадения в двух словах.

Обозначим $d=124$ нс, $h_k=kL+d$. Для фиксированного 4L разница времён двух рождений ограничена $h_4$ на всём сроке. Для L/32L все пары с разницей до $h_1$ учитываем безусловно. Для более длинной пары нужен редкий промежуток и пустое окно предыстории. Принадлежность пары к реально выбранному расписанию заранее неизвестна.

**Пустое окно для более длинной пары.** Положим $P=32L$, $N=730$. Пусть $t$ — время поздней частицы в редком промежутке, начинающемся с общего прохода $j$. Тогда $jP\le t\le jP+P+L+d$. На живом префиксе решение о редком промежутке требует нулевого подтверждённого счёта. В $H_j=[(j-N)P+D_o,jP]$ в каждый момент апертура может скрыть не более одного слова, поскольку расстояние между началами слотов не меньше 164 нс. Два разных слова одной частицы одновременно скрыть невозможно. До первого касания занятого слова такая частица обязательно дала бы исправление к общему сечению. Следовательно, в $H_j$ частиц нет.

Для каждого возможного $j$ отрезок $K_t=[t-NP+D_o,t-P-L-d]$ содержится в $H_j$. Его длина $a=NP-D_o-P-L-d$ превышает 299,6 с. Он заканчивается раньше $t-h_{32}$, поэтому его пустота независима от двух рассматриваемых рождений на заранее заданных временах. Вес долгой пары сверху ограничен вероятностью пустоты $\exp[-\kappa\int_{K_t}\nu]$. В расчёте берём $v(t)=\exp[-\kappa a\,m(t)]$, где $m(t)$ — наименьшее значение частоты в текущем и двух предыдущих бинах по 300 с. Эти бины покрывают $K_t$, когда редкое действие возможно. На участках целиком до $NP$ вес равен нулю. Это использует информацию о частоте только при оценке вероятности.

**Что суммируется.** Для каждого упорядоченного по времени сочетания участков $A,B$ вклад равен верхней оценке
$$
 Wc^2\int_{t\in B}\nu(t)\int_{s\in A,\;0\le s<t}\nu(s)\,w(s,t)\,ds\,dt .
$$
Для 4L берём $w={\bf1}_{t-s\le h_4}$. Для правила берём $w={\bf1}_{t-s\le h_1}+v(t){\bf1}_{h_1<t-s\le h_{32}}$. Внутри каждого отрезка линейной реконструкции обе интенсивности сверху заменяются их максимумами. Геометрическая площадь полосы по разности времён интегрируется точно в вещественной арифметике с обрезанием у 0 и $T$. Соседние куски и все короткие части перед подъёмами также проверяются. Поэтому переходы события, пропуска или хвоста сохраняют пары через границу. В реализации уровни для верхних весов округлены с запасом, сумма положительных слагаемых увеличена на $10^{-8}$ относительно. Тест на постоянном фоне воспроизводит общую площадь $Th-h^2/2$ и площадь $h^2/2$ для пары через внутреннюю границу. [Код](risk.py) · [Проверка](verify.py).
