Контроллер использовал подтверждённый счёт двух ремонтов. При принятом Dₒ=L−256 нс и Iₒ=160 нс остаётся 40 нс от самого позднего release до решения и 96 нс от окончания монтажа до следующего частого прохода. Это условия модели исполнения.

В расчёте слово хранится как XOR-маска 39 разрядов относительно корректного начального кодового слова. Линейный код даёт один и тот же синдром для данной маски при любом корректном исходном содержимом. Полезные чтения приложения сохраняют память и не выдают ERR контроллеру. Пока защитная запись ожидает release, старый разряд остаётся в слове, поздние инверсии переносятся в следующий интервал. Доступы и цена продолжаются до T, включая путь после превышения веса 1.

## Воспроизведение

Из корня репозитория выполните три команды на Python 3.12.14 с NumPy 2.3.5, SciPy 1.18.1 и h5py 3.16.0. Путь `../tmp` указывает на родительский каталог кэшей `t141-cache` и `c1-goes`.

```
python experiments/t436-archive-replay/verify.py
python experiments/t436-archive-replay/calculate.py --cache ../tmp --check
python experiments/t436-archive-replay/table.py --check
```

Для первого выхода добавить к команде расчёта `--histories SEPEM`. Архивы хранятся вне Git. У SEPEM проверяются хеши массивов T141, у GOES — все 4 761 записи манифеста и реконструированные интегралы. JSON содержит хеш профиля, seed и SHA-256 всех меток каждой пары. Исходники Ц1 сверяются с зафиксированными коммитами, для чего нужна история Git. [Восстановление SEPEM](../tNN-sepem-profiles/REPRODUCE.md) · [Восстановление GOES](../c1-geo-fixed-20261109/GOES-CONFIG.md).

Шесть направленных проверок сверяют ускоренный ход с пошаговым чтением слов и проверяют геометрию пар. На полном банке при T=L+112 нс оба исполнителя получили 65 537 чтений и две начатые записи у правила, 65 536 и одну у 4L. Первый случай заканчивается в незавершённом ремонте слова 0. Проверены штатный порог 730 на малом банке, разные фазы исправлений, перенос остатка и обслуживание после превышения. Следующее действие по №436 — адресное воспроизведение этих строк рецензентом.
