# Ц4. Цена реакции на собственные исправления

Первой рассчитана пара за 16.12.1996 07:20 — 16.12.2006 19:20 UTC. Объём полезных данных 0,25 МиБ, 65 536 слов (39,32), срок 315 576 000 с. Приведён заранее выбранный повтор 0. Обе политики получили те же 12 174 частицы. У каждой частицы два разных слова и по одному разряду в каждом. Цена — чистая защитная шина на номинальных часах.

Обе последние проверки завершились до конца десятилетия. Одна логическая запись ремонта стоит 56 нс, поэтому в обеих строках записи занимают 0,001363488 с. Остальная указанная шина занята чтениями по 48 нс. На выбранной реализации известная цена 4L выше в 6,5466 раза. Разность составляет 16 369 669,276 с. Условие сохранения преимущества при полной цене — разность дополнительных затрат адаптивного и постоянного управления меньше этой экономии. Пик за любое окно 1 мс ограничен сверху 57,934624% шины с резервами приложения и управления. Это расчётный верх Ц1. Процессор, энергия, сроки подтверждения и фактическая цена управления требуют своих оснований. [Ведомость](../c3-candidate-price-20261109/LEDGER.md).

**Причина возврата.** Частый старт впервые перешёл к редкому шагу через 300,073352960 с. В каталожном событии 04.11.1997 одна и та же модельная частица №435 инвертировала разряд 36 слова 12 575 и разряд 28 слова 54 937 (нумерация с нуля). По фазам общего прохода ремонты завершились через 63,502504 и 70,551904 мс после частицы. В 13:08:25,503162 UTC контроллер закрыл ячейку с подтверждённым счётом 2, обнулил историю и назначил частый шаг. Следующий проход начался через 256 нс после сечения. Для нового редкого шага требуются ещё 730 полных нулевых ячеек. [Метки и моменты решений](sepem.json).

В 16 заранее назначенных парах средняя экономия известной шины равна 16 372 601 с, выборочное стандартное отклонение 4 747 с, диапазон 16 364 064…16 380 978 с. Разброс относится к реализации модельных частиц при одном восстановленном профиле. Для него отдельный расчётный верх пар разных родителей даёт 0,000172661 для L/32L и 0,000302563 для 4L, включая переходы между событиями и остальным временем. ## Воспроизведение

Из корня репозитория на Python 3.12.14, NumPy 2.3.5, SciPy 1.18.1 и h5py 3.16.0, где `../tmp` — родитель каталогов `t141-cache` и `c1-goes`:

```
python experiments/t436-archive-replay/verify.py
python experiments/t436-archive-replay/calculate.py --cache ../tmp --histories SEPEM --check
```

Шесть направленных проверок сверяют ускоренный ход с пошаговым чтением слов и проверяют геометрию пар. Есть короткий тест на полном банке, сжатый банк с штатным порогом 730, попадания в pending, разные фазы двух публикаций, частичный проход у T и продолжение при обнаружении неисправимой ошибки.
