# Задача 1.2. Регистрация до расчёта

База `190149428a41d6a142dee54273374fc6bc6be5a6`. [Назначение автора](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/issues/196#issuecomment-6828229997) · [Четыре исходных закона](../t186-cluster-laws/PROTOCOL.md) · [Общий календарь](../t186-native-ge30-x16/calendar.json) · [Действующая лестница](../../theory/t196-native-err-20261110.md)

**Объект и карта.** 0,125 МиБ долгоживущих данных CY62167GE30-45, 32+6, 65 536 адресов ×16, один или два адреса каждой из $W=32768,\ldots,44529$ охваченных внутренних групп. Карта и циклический порядок этих $W$ слов произвольны, фиксированы на десять лет и одинаковы у соперников. Равномерное начало на кольце охваченных слов — расчётная гипотеза 1.1 для основного объёма. На изделии положение соседей, в том числе у края области, требует отдельного обоснования. Внутри слова инвертируется одна равномерная позиция из 38. Позиции различных слов метки и метки различных частиц независимы при заданном профиле. Закон числа и размещения затронутых слов задаётся до внутренней коррекции.

| Закон | Множество слов одной частицы | Среднее число $m$ |
|---|---|---:|
| Одиночный | Одно равномерное | 1 |
| Контроль №457 | Два разных равномерных без возвращения | 2 |
| Смесь соседей | Одно с вероятностью 4/5, иначе два последовательных | 6/5 |
| Пять соседей | Пять последовательных | 5 |

На эталоне $D=38\cdot524288$ позиций интенсивность инверсий равна $\nu(t)$ с⁻¹. Для каждой позиции сохраняется $\nu(t)/D$, для банка интенсивность пуассоновских родителей $W\nu(t)/(524288m)$. На накопление с одной квотой исполнения $\delta=6\cdot10^{-6}$ выделено $\varepsilon=10^{-3}$. $T=315576000$ с. Прямые внутрисловные метки вынесены в 1.4.

**Наблюдения и критерий.** Календарь №456–457 со всеми фазами, допусками часов, обеими половинами и полным обслуживанием. $L=22{,}9376$ мс, общая ячейка $256L$, пороги 5, 10, 19, 38, 75, 149, 298, 596. Контроллер получает свои команды, локальное время, счёт завершённых исправлений и признак полного своевременного отчёта. Для каждого разрешения сравним интенсивность различных родителей, пересекающих гарантированно видимые слова, с интенсивностью касаний этих же слов, делённой на максимальную кратность. Проверим включение события допуска на живом префиксе в событие отсутствия видимых родителей. Сохраняем конечную запись, остаток, непригодные и поздние отчёты. Отдельно проверим частичный обзор и полную историю, заканчивающуюся обязательным общим проходом.

**Цена.** Один постоянный физически реализуемый период на ту же карту, все внутрипроходные посещения №457. Первый свидетель — начальное высокое плато №457 из $\mathcal A_U$, второй — перенесённое десятилетие SEPEM 1996–2006 из набора всех реконструкций №459, по №462. На каждом предъявим нижнюю вероятность физического превышения для *всего* хвоста периодов. Основной свидетель — ровно две частицы в общем свободном интервале, точное пересечение их слов и независимые позиции. Для контроля вычислим вероятность одновременного попадания в пару разных слов и поправку за повторный счёт успеха. Используем одну полосу ширины $\xi_+ L+d_E$ на все адреса и консервативные потери краёв и изменения профиля №462. Для порога $P_0=K/W$ фиксируем алгоритм до подстановки. Старт с $K=\lceil2W_{\max}(\xi_+ L+d_E)\rceil$ слово·с, удвоение до первой строгой границы либо исчерпания положительного множителя «ровно две частицы», затем целочисленное деление отрезка пополам с проверкой выданного верхнего конца. Соперник не ограничен сеткой $K$ или кратными $L$. Выход — нижние секунды и процент защиты за десять лет на каждом конце диапазона и формула на каждой карте. Цены включают как минимум обязательные чтения. Отношение цен не служит критерием 1.2.

**Проверка частных случаев.** Карта разведки на 16 словах с половинами $(w,w+16)$, 32 адреса и её номинальные фазы. Перечислить все метки и пересечения двух меток, сравнить четыре последовательных слова, дополнение одного слова и равные средние у двух соседних и двух равномерных. Для каждого из четырёх основных законов выполнить 65 536 независимых испытаний, генератор Python `random.Random`, зерно $1961200+j$ по порядку таблицы с $j=0,1,2,3$. Проверяются три вероятности: исправление при одиночном родителе между посещениями адресов 27 и 28 к концу полного прохода, пересечение множества без одного обслуживаемого слова при приходе после выборки перед общим проходом и физическое превышение от двух родителей без обслуживания из чистого состояния. Для 12 долей — одновременная 95%-я полоса Хёффдинга с поправкой объединения. Остановиться при указанном размере выборки. По событиям сервиса отдельно проверить партнёра, проверочный разряд, позднюю инверсию в апертуре, потерянный и поздний отчёт, незавершённую запись и сброс. Числа испытаний не определяют границы для основного объёма.
