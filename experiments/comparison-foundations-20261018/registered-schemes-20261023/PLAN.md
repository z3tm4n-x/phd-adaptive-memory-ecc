## Проверяемый выход

Для патента w30/60/120, Красникова Ms.001/.01 zero=longest и Chen-analog
F.025/.1/.4 дать применимую гарантию, нарушающий вероятностный свидетель
либо точный остаток. zero=hold ссылкой на принятый PR234.
Отдельная история без отказа не доказывает гарантию, один плохой параметр
не исключает семейство. Полную цену обработки сохранить параметрически.

До вычислений закреплён один кандидат среды: исходный фон до21600с,
экспоненциальный подъём200с, плато B115000с, симметричный спад200с,
далее фон. Проверить пик/массу/рост исходного класса точно. Это допустимый
синтетический свидетель, не физически измеренная вспышка.

1. Повторно использовать принятые парные/апертурные основания для общей
   обязательной опоры27; вывести численный upper и остаток до epsilon.
2. Для Красникова longest проверить короткий причинный путь возврата27
   после отсутствия новых родителей. Свидетель — две разные позиции
   одного слова между E, с оплаченной вероятностью окружающей тишины;
   app-E и незавершённые операции исключаются явно. При недостаточном
   lower дать зазор и остаток, без автоматического расширения поиска.
3. Для Chen F.1/.4 проверить, удерживает ли верх370 доставленных ERR/час
   k27 после первых шести часов. Разложить счёт на основные родители и
   повторы слабой E: пороги350 и20 соответственно. Вероятность нарушения
   оплатить; история счётчика не фиксируется бесплатно. F.025 проверять
   отдельно, не переносить на него результат других бюджетов.
4. Для патента сначала использовать имеющиеся основания и точные пороги;
   если общий upper не закрывается, назвать недостающий функционал
   собственной истории/вероятностный остаток. Новую общую теорию не строить.
