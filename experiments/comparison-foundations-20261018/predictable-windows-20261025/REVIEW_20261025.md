## Что проверено по существу

1. **Общий класс.** Покрытие солнечной добавки окнами — новое явное
   ограничение, одинаковое для соперников. Вне окон остаётся фон.
   Прежний резерв 6e-6 и новый 1e-6 оплачены один раз внутри epsilon=.001.
   Вывод не требует пуассоновского закона после условливания на хороший
   прогноз: используются включение события и исходные моменты при
   фиксированной экзогенной интенсивности. Физическое происхождение
   нового временного класса и квот не заявлено.
2. **Гарантированные окна.** Проходы p mod k_H=0 и p mod k_L=0 вложены
   при k_L=89*k_H; умножение адреса на 3 переставляет слова. Нечётность
   k из прежнего ERR-календаря здесь не требуется. Последняя готовая
   проверка гарантирует частую опору вокруг опасного интервала; H=1 с
   превышает P_H^++d_E. Правое расширение покрывает последнюю опасную
   ячейку; без него гарантия теряется. Начало, незавершённая операция,
   возврат и хвост не получают нового чистого состояния. Внешний календарь
   и его окна сохраняют предпосылки принятого сервиса.
3. **Верх Q.** На ячейках с солнечной добавкой действует короткая граница
   длины, на остальных — длинная. Неравенство nu²≤b²+(B+b)s и Коши дают
   два основных члена (3); непересекающиеся предшествующие ячейки и
   ограниченная E-апертура дают смешанный член. Это применение T196(5)
   к фиксированной обязательной опоре, без предположения монотонности
   XOR-процесса при добавлении исправлений.
4. **Постоянный класс.** Старое непрерывное плато действительно недопустимо.
   Новый свидетель помещается даже в номинальные окна, соблюдает рост,
   пик и массу. Для каждого из 256 плато удалены все возможные E-окна;
   оценка свободных длин равномерна по фазам и всему хвосту P≥P0.
   Условная оценка первого превышения применяется из любого исправимого
   состояния, без очистки между плато. Выбранный исправный канал допустим
   в общем классе; постоянному режиму не списана неиспользуемая delta_p.
5. **Цена.** В (7) верх фактической работы отделён от гарантированной опоры.
   Полосы планового FAST, loss/recovery, ложные тревоги, начало и хвост
   оплачены вместе с возможным перекрытием. Оценка количества полных
   начатых операций покрывает незавершённые при T. Селектор времени и
   здоровья продолжает то же правило после отказа данных; ремонт на
   плохой истории оплачивается через U_A*N_max. Без этого свойства
   селектора верх чтений также требует добавки U_A*N_max. Общий ECC
   полезных чтений и инициализация включены в отношение. Управление,
   CPU, энергия, память канала и совместный WCET остаются параметрами.
