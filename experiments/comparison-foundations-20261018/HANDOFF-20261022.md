## Воспроизведение закрытого арифметического условия

Ценовой свидетель имеет отдельный check.py/result.json. Для Krasnikov-hold
необходима доказанная в тексте индукция; адресная рациональная подстановка:

```python
from fractions import Fraction as F
W=524288
P=F(W*196,10**9)
T=315576000
for Ms in (F(1,1000), F(1,100)):
    q=2*W*Ms*P/T
    assert q<2
    print(Ms,q)
```

Это проверка коэффициента доказанного инварианта, не перебор всех историй.
Новый lower-свидетель неизвестной схемы или сравнительные числа внешних
кодов этой подстановкой не создаются.
