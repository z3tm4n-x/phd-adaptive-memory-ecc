# Адресное AC-заключение для PR223

22.10.2026. From #206 to #186/#196/оркестратор. Область — соответствие
источнику и условия платы, без повторного вычисления сервиса/Q/общей таблицы.

Проверен [PR223](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/pull/223)
на head `3af399bf04f11028cc57113e17510a595a4016a8`, вычислительный снимок
`88b467c3eb12f46cccd17a4ddb0e2462f71a6b82`. Прочитаны SERVICE, вход и REPORT.
Git blobs: SERVICE `de3f8ac7e4b60cccfeb7bcd9b4afccef6f180494`,
service-input `d82bd52716f91ed1b0fd429d56e819373bf61010`,
REPORT `a6698f1ad0ed348ec47883068f35038e396e81f3`.
Вход SHA256 из поставки: `7c225013bde6c6afaca38029c20f31e3aec01acf14ec420e3469b4660684cec6`.

**Вывод:** применимость указанного AC-источника и условная форма чтения/
OE-HIGH записи подтверждаются. Конкретного противоречия datasheet в этом
договоре не найдено; изменение 64-нс формы по источнику не требуется.
Это разрешает продолжить проверку сервиса, но не подтверждает параметры платы.

Источник — [Infineon 38-05446 Rev.*Q](https://www.infineon.com/assets/row/public/documents/10/49/infineon-cy62167ev30-mobl-16-mbit-1m-x-16-2m-x-8-static-ram-datasheet-en.pdf),
02.08.2018, SHA `3af6dadb2fa2ca75edfc92532f0dbab6a39e6d6dc7d9fac1c05648c5e49b8f8d`.
Повторно адресно прочитаны стр.4/5/7/8/9, визуально сопоставлены таблица7 и
формы8/9 с последовательностью SERVICE. Полный технический паспорт не
пересмотрен заново; предыдущая точная идентификация part number сохранена.

- tRC/tWC=45 min, tAA/tACE/tDBE=45 max, tDOE=22 max и tHZOE=18 max
  соответствуют read64/capture56/release32. Для первого чтения адрес должен
  опередить либо совпасть с CE1/CE2/BE по прим.26. Предложенные 8 нс из c
  обеспечивают только бюджет; фактические скосы обязаны сохранить порядок.
  После захвата до смены адреса/снятия OE сохраняется отдельный hold.
- WE LOW8..48, address/data/CE/BE до64 и OE HIGH соответствуют Figure7.
  tPWE=35 min, tAW/tSCE/tBW=35 min, tSD=25 min; tSA/tHA/tHD=0 min.
  Начало/конец внутренней записи определяются **пересечением** активных
  WE/CE/BE, прим.22/27. Все ограничения SERVICE обязаны относиться к этим
  выводным фронтам, включая возможную более раннюю деактивацию CE/BE.
- OE должен быть HIGH до включения внешнего драйвера, с оплаченной паузой
  освобождения SRAM. После write внешний драйвер должен отключиться до
  следующего чтения. Figure7/прим.28/30 не разрешают конфликт драйверов.
  Условие tSD+tHZWE из прим.23 относится к запрещённому здесь OE-LOW режиму.
- Суммарные потери read capture, pulse, release, setup и hold в SERVICE
  явно раздельны и должны соблюдаться **одновременно**. Параметры clock,
  endpoint jitter, IO delays, capture setup/hold, нагрузки и фронты остаются
  проектными условиями. Запас времени контроллера не заменяет AC-неравенства.
- Стр.4/прим.7 требует ramp100 мкс и wait200 мкс после стабилизации.
  Выбранный post-stable wait256 мкс допустим условно; неподтверждённый ramp
  и boot не дают верхней границы от power-on. Они правильно оставлены UNKNOWN.
  Уровни и рабочий диапазон берутся из Operating Range, не Maximum Ratings;
  для TSOP динамический VIL не выше0,7 В (прим.9). Нагрузка/фронты/опорные
  уровни Figure3 и прим.18 обязательны для переноса AC, включая отличие
  определения tristate-параметров по прим.20/21.

AN13842/AN66311 снимают две прежние AC-оговорки для правильно установленного
1843 согласно [основному отчёту](REPORT.md). Это не полная идентификация die
или радиационная эквивалентность. Остаются физические свидетельства E,
clean/init, моментов/меток и полная цена фактической аппаратуры.
Теоретическую подпись E/arrival→deadline выполняет #196; научное принятие
и слияние PR223 — оркестратор. OFF в основной класс автору не приписывается.

Новое радиационное препятствие передаётся отдельно: HEP Fig.5 не привязан
явно к1843, а нейтронные данные REDW1843 / Cecchetto default1731 требуют
run/device ID. Эти ограничения не останавливают условный AC-сервис и не
разрешают объявить его физическим Q.
