## Выполнено

Из `git archive` вычислительного снимка создан отдельный каталог без `.git`.
Скрипт исполнен Python3.12.14 с пятью предварительно экспортированными blobs
и шестью локальными PDF. Сеть и вероятностный/сервисный движок в повторе не
использовались. Итоговый SHA256 `thresholds.json`:

    1b9b2183123a45211ac3d2d02004bb6252a4db1b38c9e0b387df17e0b9dddca5

Проверены SHA256 и Git-blob SHA1 каждого из пяти принятых источников,
SHA256 каждого PDF, совпадение общего входа/готовой оценки/моментов между
#186/#196. Для всех шести порогов рациональная арифметика подтверждает,
что округлённая вниз граница ещё достаточна, а соседняя сверху пересекает
именно границу достаточного сертификата. Физическая невозможность из этого
не выводится. Даты AN проверяются только в отношении двух AC-исправлений.

Пять намеренных подмен обнаружены с ожидаемой причиной:

1. Изменённый принятый `app_result` — source drift.
2. Изменённые байты datasheet — PDF drift.
3. Самовольное снятие конфликта date code — явный запрет без нового источника.
4. Неподтверждённое численное physical c — отсутствие физического сертификата.
5. Изменённый ожидаемый выход — output drift.

После восстановления файлов последний повтор совпал с первым побайтно.
Протокол/время/версия — [replay.json](replay.json). Первый запуск вспомогательной
обвязки остановился на декодировании Windows traceback; режим UTF-8 исправил
обвязку. Научные файлы и вычисления из-за этого не менялись, временная подмена
источника восстановлена в `finally`. Время повтора не является аппаратным WCET.

Diff от базы затрагивает только новый подкаталог этой поставки; принятые
файлы неизменны. `git diff --check` пройден. Последующее дополнение отчёта,
AC_REVIEW и протокола не меняет вычислительный вход/код/выход.

## Команды

Скачать шесть PDF по URL из `sources.json`, сохранив имена ключей `pdfs`.
При несовпадении хеша не заменять ожидаемый хеш молча: проверить новую редакцию.
В Git-репозитории с указанной базой:

    python -B experiments/regime-map-methodology-20261019/revision-evidence-20261022/thresholds.py --pdf-dir /path/to/pdfs --check

Для переноса без Git добавить `--export-sources /new/dir`; каталог должен
ещё не существовать. Затем в чистой выборке этого подкаталога:

    python -B experiments/regime-map-methodology-20261019/revision-evidence-20261022/thresholds.py --source-dir /new/dir --pdf-dir /path/to/pdfs --check

Python stdlib достаточно. PDF в Git не копируются; URL, точные хеши и
локаторы обеспечивают проверку источника. Повтор расчёта требует их локальных
копий. Таблицы/формулы #186/#196 импортируются только как закреплённые входы.
