# Повтор ε-среза

Python3.12+ stdlib для чисел/тестов. Для статического графика — Matplotlib
(проверено3.11.2). Из корня репозитория:

```text
python -B experiments/regime-map-methodology-20261019/epsilon-slice-20261027/numerical/run.py --check
python -B -m unittest discover -s experiments/regime-map-methodology-20261019/epsilon-slice-20261027/numerical -p test_slice.py -v
python -B experiments/regime-map-methodology-20261019/epsilon-slice-20261027/numerical/plot.py
```

run.py --write сохраняет результат той же зарегистрированной конфигурации.
prepare.py — сохранённый одноразовый шаг регистрации; при существующем
manifest повторно не работает, чтобы не перезаморозить источники молча.
Все текущие источники — из репозитория; для запуска после git archive
.git и исторические ветки не нужны. Пути разрешаются относительно __file__.
Input/manifest проверяются, разрешено только отличие fixed.epsilon.
В exp/ln научных сравнений используются направленные48-разрядные интервалы;
float применяется только для подписей таблицы/графика.

Выбор N — конечная настройка решения, ограниченная риском и T, без
новой физической оси или MC. Числа являются условными границами/кандидатами.
При добавлении нового основания #196 нужно явно обновить настройки и
происхождение; удалять проверки старой точки .001 нельзя.

Статус/результат — REPORT.md, таблица — TABLE.md, перенос — DERIVATION.md,
проверки и чистый снимок — VALIDATION.md. А не закрывается этим пакетом.
