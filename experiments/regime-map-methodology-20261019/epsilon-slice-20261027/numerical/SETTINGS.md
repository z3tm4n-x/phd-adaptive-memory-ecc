# Инженерный кандидат настройки, до расчёта

27.10.2026. Это предложение #186 по общему конечному продолжению A11,
для согласования #196; научная подпись ещё не получена. Прежний single-pilot
и его параметры не переписываются. Для трёх обязательных ε применяется
одно следующее семейство; неуспех его достаточных тестов не исключает А.

Постоянный кандидат: startup и период k полных fast-циклов Wg без
статистического drain; максимум целого k, для которого
δ₀+[(k+1)Wg ξ⁺+2J]S₂/W≤ε. Это лучший период по данному достаточному
сертификату, не доказанный optimum постоянного класса. Верх сильного
детерминированного класса пока даётся этим допустимым членом класса;
нижняя граница относится ко всем расписаниям. Оптимальное непостоянное
расписание не подменяется этой частной строкой.

Адаптация: фиксированное дополнительное требование δ_C≤5e-5 во всех
строках (не измеренная квота, не её подгонка к ε). e=ε−δ₀−5e-5.
Из e резерв базы e/2, α*=e/10, ζ*=e/10, β*=3e/10.
База k_b≥2 блока scan+drain: максимальное целое по A6–A8 и резерву e/2.
u=R/2, η=1. M=ceil(2u/(g a_b⁻)): одна группа покрывает два времени u/g;
q,w и μ вычисляются по A4–A5 с фактическими ξ/J, без старого округления.

Конечное число N попыток назначается до миссии; каждая имеет α*/N, ζ*/N,
β*/N. K — минимальный целый, для которого факториальный хвост
(BP_obs)^(K+1)/(K+1)!≤ζ*/N. Длинный период k_e кратен k_b,
максимален по A10, не меньше2k_b. Порог C — максимальный целый,
строго удовлетворяющий направленному A3. Используются лишь настройки с
непустой группой, неотрицательным порогом и N группами, помещающимися до T.

Выбор N — одномерная настройка решения: максимизировать потенциальное
сокращение N(k_e/k_b−1) основных проходов, при равенстве выбрать меньше N.
Поиск ограничен исходным T и необходимым расходом β на минимальное
удлинение. Это не распределение вероятностей и не предсказание средней
экономии. Научные параметры не варьируются; новые физические сетки/MC нет.

Эпоха попытки имеет M k_b+k_e блоков независимо от исхода. При отказе
она заполняется базовыми действиями; при успехе — одним длинным. Эпохи
сцеплены после единственного startup, фаза и начало следующей одинаковы
на всех ветвях. После N попыток база продолжается до T. Invalid не возвращает
α/ζ/β и не даёт новой попытки; состояние памяти не очищается.
Условный перенос A4–A5 к относительному началу каждой группы должен
подтвердить #196: это не сброс физического clock/epoch или бюджета.

Полная цена сохраняет все дополнительные guard по общему hard cap.
Для фиксированного календаря отдельный all-history gate допускает только
его назначенные старты (пропуски лишь уменьшают верх); для адаптации
сохраняются все потенциальные слоты. Эта обязанность исполнения явно
отделена от вероятности корректного ремонта. Неизвестное управление
соперника и адаптации сохраняется разными параметрами.

Оптимистический read-низ адаптивного семейства: все N допусков успешны,
нет дополнительной работы, но обучение и оставшаяся база оплачены;
на good execution все эти обязательные посещения сохраняются. Умножение
на1−δ₀−δ_C и краевые вычеты переводят его в необходимую ожидаемую цену.
Это нижняя оценка цены конкретного семейства, не средняя цена спокойной
истории и не нижняя граница всех адаптивных методов.
