# Уточнение плана: фильтр оценки цены до дорогих Q

24.10.2026, после запуска первой пробы 256 КиБ. Прямой интервальный
пересчёт по всем фазам растёт с k; для меньшего объёма k_fixed быстро
растёт. До следующих интегралов добавляется проверяемый фильтр цены.
Это минимальное изменение порядка вычислений, не изменение модели или
выбор более удобной физики. Базовый PLAN.md сохраняется.

Обозначения — T196 hold-price и PR250: F=bT+Fs, w=90, h=180 секунд;
S(l) — неизменённый счёт потенциальных решений, N_H — прежний жёсткий
верх всех FAST-чтений. Для любого допустимого календаря этого правила
tau>=0, w_upper>=w, h_upper>=h, recovery_upper>=h, U>=delta.
Поэтому обе используемые оценки числа чтений (старое 2F-удержание и
новый union/hold-price), до общего cap, не меньше

    N_floor = S(w)bT + S(h)Fs + S(h)r_F T
              + (recoveries+1)S(h) + B_loss + delta*N_H.

В старой оценке 2F*S(hold), где hold>=h>=w, покрывает первые два члена;
ложные флаги, recovery, loss и bad оплачены отдельно. В новой оценке
соответствующие длины V,H,L не меньше w,h,h; удалены только неотрицательные
пары, смешанные члены, weak-E повторы и обязательная опора. Верх исходного
риска включает delta. Следовательно вычисляемый верх цены чистой шины

    A_upper(k) >= R_bus_plus * min(N_H,N_floor) / T = A_floor_certificate.

**Это нижняя граница вычисляемого верхнего сертификата**, не нижняя
граница реальной ожидаемой цены и не утверждение об исчерпании квот.
Если F_lower<=A_floor_certificate, выбранный способ сравнения
F_lower/A_upper не докажет преимущество ни при одном k. Более точный
верх цены или более сильный низ постоянного класса может изменить вывод.

Если фильтр сработает, дорогие информационные сертификаты для этого
объёма пропускаются. Для строки таблицы остаётся допустимая адаптивная
политика: наибольший нечётный k<=k_fixed. Её риск сертифицируется уже
принятым mandatory-only верхом T196(5): дополнительные правильные E
не увеличивают риск первого превышения. Календарь, наблюдение и полный
hold-price пересчитываются. Никакой оптимальности этой строки не заявляется.
Первую уже запущенную пробу 256 КиБ довести до результата; если фильтр
не сработает, сохранить исходные не более трёх информационных проб.

Для сопоставления с допустимым постоянным свидетелем его неизвестная
добавочная цена управления также остаётся параметром. Необходимый предел
`u_A < F_witness_upper - A_support_lower + u_fixed_upper` имеет конечное
значение только после задания u_fixed_upper. При неизвестном коэффициенте
это не красная область невозможности на карте. Основная зелёная область
использует достаточный предел u_A_upper < F_class_lower - A_upper и
не требует бесплатно обнулять управление постоянного режима.

Новый фильтр и его применение требуют независимой проверки вместе
с поставкой. Научная приёмка PR250 этим не пересматривается.
