# #166 — последовательный обход 4–8 слов

**Пакет готов 15.10.2026, ожидает одной адресной рецензии.**
[REPORT](REPORT.md) · [точная модель/условия](METHOD.md) ·
[входы до расчёта](inputs.json) · [источники](sources.json) ·
[машинные числа](outputs/results.json) · [проверки](outputs/validation.json).

Восемь синтетических точек: W=4/8, full39 SEC-DED, const/piece λ,
read–fence0/.05 с, T=3,4 с. L — T45, U — T52; дополнительно T57/T36.
Эталон имеет поглощающий первый отказ, рационально ограниченный остаток;
MC использует явные битовые XOR и отдельный календарь.

Проверенное окружение: Python 3.12.14, Git; зависимости в
[requirements.txt](requirements.txt). Из корня одна команда повтора:

```text
python -B experiments/sequential-small-validation-20261014/reproduce.py
```

Требуется история Git с коммитами sources.json; shallow-архива без
объектов недостаточно. Команда переписывает только outputs/ и локальный
игнорируемый .cache/. Полный запуск занимает секунды на текущем окружении.
Все 9 источников проверяются по закреплённым объектам Git; 7 научных
входов также обязаны совпасть с checkout. MAP и RESEARCH_PLAN — исторический
контекст принятия: их последующие административные изменения допустимы.
30 адресных проверок,8 точных строк,8 полных перечислений и 1,6 млн MC.
Общий результат/статусы — [validation.json](outputs/validation.json);
локальный побайтный повтор — [repeat.json](outputs/repeat.json).
Основной код: exact.py (рациональные интервалы), enumerated.py
(полная цепь), mc.py (независимые биты), checks.py, reproduce.py.

[PLAN](PLAN.md) и seed/N неизменны с 1627981. Научная база
d135c665039a30014f12e2946a676da7ee64e2aa. Ветка
`sequential-small-validation-20261014`.
Результат не является физической квалификацией или доказательством
общей теоремы; принятые артефакты и главы не менялись.
