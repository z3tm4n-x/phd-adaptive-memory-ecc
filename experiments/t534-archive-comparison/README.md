# 256 КиБ. Сколько порта занимает лестница при той же гарантии, что и у постоянного периода

На SEPEM 1996–2006 лестница заняла в среднем **1 274 365,16 с, или 0,403822%** десятилетия. Стандартная ошибка по 128 реализациям — **461,52 с**, номинальный 95%-й интервал среднего — **1 273 451,90–1 275 278,43 с**. На восьми отдельных реконструкциях GOES средние составили **1 002 347,77–1 041 538,65 с (0,317625–0,330044%)**. Во всех строках объём 256 КиБ, 65 536 внутренних слов, все 131 072 адреса ×16 одной замкнутой карты $(w,w+65\,536)$. На штатном исполнении $I=X=0$. [Назначение и регистрация до прогонов](PROTOCOL.md) · [Данные SEPEM](sepem-256.json) · [Данные GOES](goes-256.json)

**Гарантия для всего класса ГСО.** До предъявления истории назначены принятая лестница и достаточный постоянный кандидат **86,429 мс**. Верх вероятности первого превышения при накоплении за десять лет равен соответственно 0,000677662949 и 0,000999990641 при допуске 0,001. На всём классе лестнице достаточно **1 973 781,020 с (0,625454%)**, кандидату — **48 405 502,012 с (15,338778%)**. Любой допустимый постоянный период, включая промежуточные значения, требует в ожидании **не менее 28 156 816,664 с (8,922356%)** обязательных чтений. Поэтому строго гарантировано **≥14,265420 раза** на классе. На конкретном десятилетии SEPEM получаем **22,095** при делении этого низа на выборочное среднее лестницы и **≥15,811476** при делении на аналитический верх для этой истории. [Гарантия и две фазы №528](../../theory/t525-two-phases-256k.md) · [Период и необходимый низ класса](../t504-large-bank/result.json)

**Гарантия для всех принятых реконструкций.** Один период **165,5542 мс** проходит для всего архивного множества с $Q^+\le0,000999993788$. Проверка использует общие ограничения пика $B\le0,525$ с⁻¹, экспозиции $S_1\le164\,372$, суммарного подъёма $U\le24$ с⁻¹ и второго момента $S_2\le60\,045,248$ с⁻¹. Они покрывают произвольное начало полного десятилетия в SEPEM и зафиксированные заполнения GOES. Внешнее округление $S_2$ здесь только для чтения, в расчёте использована исходная дробь. Для лестницы та же двухфазная оценка даёт $Q^+\le0,000414082744$, верх цены **1 785 490,791 с (0,565788%)**. Необходимый низ архивного постоянного класса **5 784 051,126 с (1,832855%)**, достаточный верх цены указанного кандидата **25 265 869,317 с (8,006271%)**. Это даёт **≥3,239474 раза** на всём архивном множестве. На замкнутых 64 КиБ соответствующий низ отношения **≥1,24654** оставляет двукратную экономию на архивном множестве открытой. ## Почему нижняя цена действует на каждой истории

На плато ГСО для полных слов и отдельно на допустимом десятилетии SEPEM для архива два попадания в свободном интервале исключают слишком длинные постоянные периоды. При $W=65\,536$ исключение начинается на физических часах свидетеля с $p_0=9531/W$ с для ГСО и с $p_0=46397/W$ с для архива. Для 64 КиБ эти числа равны $4767/16384$ и $40586/16384$ с. Период фиксируется для всего своего класса. Раз он выдерживает и историю-свидетель при самых медленных штатных часах, на любом штатном исполнении любого входящего в класс профиля между началами проходов проходит не больше $p_0+2J$, где $J=0,5$ нс. За вычетом двух граничных проходов нужно хотя бы $A[T/(p_0+2J)-2]$ чтений по ≥98,999 нс, где $A=2W$. Множитель $1-0,000006$ учитывает возможное нарушение исполнения на данной истории. Нижняя граница относится к ожиданию. Конкретная траектория с нарушением может занять меньше. Верх цены лестницы, напротив, включает возможную предельную работу после остановки вплоть до $T$. [Свидетель двух родителей](../../theory/t196-visible-parents-20261112.md) · [Независимая проверка четырёх границ](check.py)

Свидетель SEPEM и общие ограничения дают сертификат на ранее объявленное множество реконструкций. Имитация выполнена на **девяти** представителях. В GOES непокрытые интервалы заполнены по №459 фоном и предусмотренным подъёмом перед следующим измеренным бином, оба края включены. Хеши всех девяти профилей и значения интегралов совпали с №495. Выбор специального периода после предъявления одной истории относится к прежнему, третьему сравнению. [Измеренная часть, заполнение и даты каждого источника](../t186-volume-archive/README.md)

## Разброс и границы применения

На каждом объёме исполнено по 128 независимых реализаций меток на каждой истории. Начальные семена, порядок историй, закон смеси, перенос и заполнение совпадают с №495. Ожидаемое число родителей для 256 КиБ получено из интенсивности $W\nu/(524288\cdot1,2)$, правило пересчитано для прохода 45,8752 мс и восьми ступеней от $L$ до $128L$. Наблюдение происходит при физическом чтении, начатый доступ обрезается концом срока. Для 64 КиБ совпали хеши всех девяти потоков меток и результатов двух прежних политик.

На 256 КиБ неоднозначные попадания в апертуру потребовали ветвления в **8** реализациях лестницы, **20** реализациях постоянного режима ГСО и **15** реализациях архивного кандидата. Для каждого исполнения и каждой истории все ветви закрылись до конца срока. В алгоритме оставлен верх расходов на остаток срока при сложном наложении или первой неисправимой ошибке. Когда период фиксирован, все будущие чтения учитываются точно. Стандартная ошибка и интервал Стьюдента характеризуют выборку при данных профиле, карте, часах и законе частиц. Ноль неразрешённых исходов из 128 даёт односторонний 95%-й биномиальный верх 2,3133% на их частоту при фиксированной истории. Физическая полнота ERR, реальная раскладка ячеек, прямые поражения, ошибки заполнения и расходы CPU и энергии требуют собственных оснований. [Модель обслуживания](../t186-native-ge30-x16/README.md)

~~~
