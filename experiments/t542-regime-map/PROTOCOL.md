# Критерии сборки карты для главы 4

Пункт 2 [№542](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/issues/542). Исходная версия `a5df64aab07ef149f3547479c6a5f96f5a3468e1`. Единица наблюдения основной таблицы — одна из двенадцати строк ГСО для смеси 4/5 одиночных и 1/5 соседних пар на проектной карте `(w,w+W)`. В каждой строке сохраняем банк, закон, разрядную нормировку, сервис и правило из [регистрации исходной карты](../t186-native-cost-map/PROTOCOL.md). Координаты — исходные доля допуска при непрерывном обходе и среднее число слов на частицу. Для пяти проверенных законов на 128 КиБ сохраняем область проверки видимости отдельно.

Сопоставляем вероятность накопления и ожидаемые секунды защитного порта до конца десяти лет. При базовом регистровом исполнении сначала проверяем допуск обеих политик. Для допустимых политик верх одной цены ниже необходимого низа другой доказывает строгий выбор. Пересечение оценок, отсутствие достаточного верха и превышение допуска нижним свидетелем получают разные обозначения. Пустой постоянный класс не имеет конечной цены лучшего режима. Отдельно указываем цену достаточного постоянного кандидата.

Для [двух фаз](../t525-two-phases/result.json) проверим, какие величины зависят от допуска, и проверим сравнения во всех четырёх исходных строках данного банка. Переносим только границы для тождественных карты, закона, расписания, квоты исполнения и множества профилей. Учитываем также ранее принятые границы на том же объекте, если они строго уточняют результат. До подстановки критерий изменения исхода — смена одной из пяти категорий решения. Уменьшение границы цены внутри прежней категории показываем отдельно.

На основном допуске покажем также [варианты охвата 64 и 128 КиБ](../t186-pair-service-table/README.md), [перестановки и внешний свидетель на 256 КиБ](../../theory/t534-address-phase-256k.md). При неизвестной карте используем доказанное покартовое отношение либо границы, одновременно верные для каждой карты. Четверть допуска проверяем по непрерывному обходу. Для фиксированного класса ГСО и единого периода на всех принятых реконструкциях сравнение строится по отдельности. Выборки отдельных историй подписываем как имитацию. Объёмы сверх сетки указываем только в области опубликованного нижнего свидетеля. Выход — одна таблица, один рисунок и команда их сборки из сохранённых ведомостей.
