## Воспроизведение без перезаписи

Python3.10+ и git; стандартная библиотека. Сначала должны быть доступны
git-объекты закреплённых входов (их получение не меняет рабочую ветку):

    git fetch origin 519ac5e0c858ce5f71ba71c0f344d2a79edf60f2 e8b1225fe71ceb34bb3684a6b8890c8f1f3adb67 ea789fc4b4d69699696d66a41b2738099d4154bb
    python -B experiments/next-route-20261013/verify.py

Отдельные команды:

    python -B experiments/next-route-20261013/arm_check.py
    python -B experiments/next-route-20261013/route_check.py
    python -B experiments/t95-method-regime-map/verify.py
    python -B -m unittest discover -s experiments/t88-dstar-sensitivity -p 'test_*.py'
    python -B experiments/t90-monitor-physical/run.py --check

По умолчанию два новых отчёта пересчитываются и побайтно сравниваются.
--write существует только для собственной поставки T146; принятые
результаты скрипты не генерируют. Общая verify.py проверяет также
неизменность всех tracked принятых входов текущего коммита.
В reproduction.json сохранён результат последнего нового --record,
который пишет только этот собственный файл T146.
