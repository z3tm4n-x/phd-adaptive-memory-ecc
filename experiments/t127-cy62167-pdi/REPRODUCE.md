# Воспроизведение T127

Из корня checkout. CPython3.12.14; numpy2.3.5, scipy1.18.1, psutil7.2.2.
Для65 регрессионных тестов также pandas3.0.1, matplotlib3.11.2; весь набор
закреплён в `experiments/tNN-sepem-profiles/requirements.txt`.

```powershell
python -m pip install -r experiments/tNN-sepem-profiles/requirements.txt
python -X utf8 -B experiments/t127-cy62167-pdi/reproduce.py
```

Команда пересчитывает только outputs своего пакета, запускает10 новых и65
старых тестов, независимый checker, compileall и второе вычисление во временном
каталоге с побайтовым сравнением пяти существенных выходов. Сырые SEPEM и их
кэш не нужны: популяция проверяется по принятой events.csv, это не новый
полный разбор471МБ H-reference. Никакой транспорт RADAR не запускается.
Полный исходный пересчёт RDS остаётся отдельной командой из T123/REPRODUCE.md.

Для повторения также двух адресных внешних проверок:

```powershell
python -X utf8 -B experiments/t127-cy62167-pdi/reproduce.py --silso 'путь/SN_ms_tot_V2.0.txt' --zenodo 'путь/8314389.zip'
```

Точный SILSOsnapshot — URL/hash в DATA_PASSPORT. Без него используются
включённые42 годовые суммы498 окончательных месяцев, полученные из того
snapshot; это воспроизведение суммы, не независимая проверка monthlysource.
С Zenodo повторно сверяются14 известных протонных членов; без ZIP сохранённый
исторический receipt не выдаётся за новую raw-проверку (`checks.json` помечает
`external_raw_rechecked=false`). Локальный ZIP пользователя имеет28 членов.

Чтобы проверить без перезаписи поставленных outputs, добавьте `--out` с внешним
временным каталогом. Пять детерминированных таблиц/JSON сравниваются побайтно;
receipt/log имеют время, пути, HEAD и runtime, поэтому не ожидаются идентичными.
`outputs/output_hashes.json` фиксирует байты поставки, исключая сам себя.
Хэши входов — байты checkout (на Windows возможен CRLF), не обещание равенства
текстовых хэшей между Git line-ending конфигурациями. Git SHA закрепляет содержание.

Потребности: несколько секунд, около110МБ пикового RSS/WSet для отдельного
calculate; весь запуск включает отдельные процессы тестов. Итоговые измерения
есть в reproduction.json/checks.json. Интернет после получения зависимостей
для стандартного запуска не нужен. Все исходные пакеты читаются без изменения.

Независимость: checker не импортирует calculate/transport/gost/service,
сам реализует скалярный log-log/CSDA, ветви ГОСТ и Decimal-арифметику календаря
и апертуры. Общие данные — исходные таблицы, одинаковая заявленная модель;
QUADPACK/NumPy не являются экспериментальным подтверждением источников.
Прежние65 тестов — регрессия, а не отдельный Scientific Review.
