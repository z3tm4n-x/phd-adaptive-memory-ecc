# ГСО и архивные истории. Цена лестницы, чувствительность и три решения

**На всём классе ГСО**, при 0,125 МиБ и допуске на накопление $10^{-3}$, основной смеси нужна лестница. Её верх — 782 798,885 с защитного порта за десять лет (0,248054%). Для любого допустимого постоянного периода низ составляет 11 527 603,947 с, выигрыш не менее 14,72 раза. При $34{,}016758 I+X\le4\,981\,003{,}088$ с сохраняется выигрыш 2×. Здесь $I$ ограничивает ожидаемое число дополнительных общих интервалов со сбросом истории, $X$ — прочую защитную занятость порта до конца срока. В цену входят исправляющие записи и обслуживание после доказательной остановки. [Принятая карта №481](../t186-native-cost-map/README.md).

**На множестве всех принятых реконструкций** при той же смеси и карте верх лестницы составляет 717 259,503 с, низ постоянного режима — 1 585 505,253 с. Это не менее 2,21 раза при $I=X=0$. Для гарантии 2× достаточно $34{,}016758 I+X\le75\,493{,}123$ с, при $X=0$ допустимы до 2 219 дополнительных интервалов в ожидании. Здесь один период должен удовлетворить всем реконструкциям, в том числе сдвигам SEPEM и принятым заполнениям GOES. У отдельной истории своё среднее и свой верх. [Два множества профилей №473](../../theory/t196-cluster-main-20261112.md).

## Чувствительность главной точки

В таблице $Q^+$ относится к риску накопления с единой квотой исполнения. В двух последних строках добавлен прямой вклад. Обе цены — секунды защитного порта за десять лет при $I=X=0$. Для постоянного приведён необходимый низ **всего класса допустимых периодов**. Запас для 2× равен половине этого низа за вычетом верха лестницы. Если достаточный верх риска превышает допуск, положительное арифметическое значение запаса не подтверждает экономию.

**Что изменено в табличной конфигурации.** У COSRAD исходные $b,B,S_1,S_2,g,U$ заданы №457. Максимальный интеграл частоты $S_1=187464$, верх интеграла её квадрата $S_2=134874{,}446808$ с⁻¹. У ОСТ $b_1=0{,}000159224571\ldots$, $B_1=0{,}814275880\ldots$ с⁻¹. У каждой из двух конфигураций архивный протонный сигнал дополняется синхронной непротонной составляющей с собственным отношением $\beta$ солнечного ЛПЭ к H. Переход $\nu_1=b_1+k(\nu_0-b_0)$ имеет $k=(1+\beta_1)/(1+\beta_0)=0{,}829373837968\ldots$. У табличного проектного класса $B=\max\{B_1,b_1+k(B_0-b_0)\}$, $g=k g_0$ и $U=kU_0=23{,}931582095\ldots$ с⁻¹ в координатах **своего** фона. Квота экспозиции берёт максимум аффинного верха 164 215,232919 и верха №459 при произвольном сдвиге начала SEPEM 164 371,897837. Отсюда $S_2^+=b_1^2T+(B+b_1)(S_1^+-b_1T)=92954{,}9546541\ldots$ с⁻¹. Это проектное множество с указанными квотами включает все девять опубликованных реконструкций. Из четырёх спектральных таблиц сама форма во времени не следует. Новый нижний свидетель начинает при собственном $B$ на 140 181,93085 с и затем остаётся на $b_1$. Он расходует $B-b_1\le U$ и даёт $S_2^-\ge92954$ с⁻¹. Строгий двухродительский тест №472 на этом свидетеле исключает периоды от $7849/32768$ физических секунд. Весь допустимый постоянный класс заключён по цене между 8 547 669,135 и 10 685 487,142 с. Верх даёт исполнимый период 0,1957186 с. При COSRAD собственное высокое плато и порог $5820/32768$ дают принятую строку №481. [Свёртка и перенос №459](../t186-ost-geo-3g/README.md) · [Свидетель и подстановки](sensitivity.json).

**Что изменяет решение.** При росте только $U$ исходное плато остаётся допустимым. Постоянный кандидат 0,138453 с удовлетворяет сроковому требованию в обоих срезах. Его верх 15 105 096,076 с использует ограничение хвоста числом запланированных чтений плюс квота нарушений исполнения. Число чтений и сырой верх вспомогательной остановки следует различать. При прежней видимости физический допуск лестницы перестаёт подтверждаться предъявленным сертификатом между $2{,}909182560U$ и $2{,}909182561U$. Верх (1) №473 при остальных неизменных входах аффинен по $U$. В исходной смеси доказано $\eta=13653/16384$. Снижение только доказанного минимума до 6013/16384 ещё допускает выбор лестницы на ГСО. При 6012/16384 значение сертификата уже **не меньше 0,001000094833**. Для реконструкций свой достаточный порог равен 2435/8192. Эти коэффициенты измеряются в разных своевременно видимых частицах на инверсию. Указанный перенос цены предполагает прежние касания, ремонт, истинные исправления и сбросы. Выбывшие полноценные отчёты оплачиваются в $I$, ложное подтверждение нулевого отчёта входит в сроковую квоту. Открытые данные для реальных ионов такого низа не устанавливают. [Условия выделения видимой части №479](../../theory/t196-small-ion-visibility-20261113.md).

**Что означает отдельный прямой бюджет.** $d=10^{-4}$ — иллюстративный верх вероятности прямого поражения за весь срок. Он задаёт величину для условной чувствительности, физического верха для изделия в нём нет. Предполагаются прежние частоты остаточных одноразрядных касаний до первой прямой метки и сохранение условий наблюдения на этом префиксе. По объединению событий $Q^+_{\rm общ}\le Q^+_{\rm нак}+d$ без требования независимости. К цене каждой политики консервативно прибавляем $d(c_R+c_W)N_h\le18\,213{,}606$ с. Это оплачивает возможную полную работу на пути с прямой меткой по всем оставшимся слотам порта. Если за этими слотами есть другие операции, их цена входит в $X$. Исполнимый постоянный кандидат даёт верх 15 123 309,682 с в отдельном бюджете, в общем бюджете берётся период 0,125678 с с верхом 16 656 904,365 с. Для необходимой цены **любого** соперника, ограниченного общим допуском, в класс включён разрешённый случай нулевого прямого вклада. Нижний свидетель проверяется на **общем** допуске 0,0011 либо 0,001. Если каждому сопернику дополнительно предъявляется покомпонентное ограничение накопления, соответствующие более сильные низы равны 11 527 603,947 и 12 500 587,842 с. Такая разница не возникает у достаточного кандидата, для которого требование к накоплению проверено явно. [Ведомость обоих договоров](sensitivity.json).

Верх риска внешнего слова 0,000017533768, ожидаемая известная цена пуска 0,0156629467–0,015794436 с. По сравнению с тем же пуском L/32L требует ещё не менее 3 366 956,689933 с защитных чтений. При $X_{\rm OFF}-X_{\rm L/32L}\le3\,366\,956{,}689933$ с OFF остаётся не дороже. Если после редкого нарушения до $T$ насыщается порт, известный дополнительный верх этого восстановления составляет 5 533,236359 с, включаемых в $X_{\rm OFF}$. Обычное управление и энергия сохраняют свои коэффициенты. Условие физического переноса при принятых остаточных одноразрядных частотах требует $d_{38}\le0{,}000982466232039$ на весь кристалл за срок, а также того же нейтронного и корпусного альфа-фона. Этот внешний сервис читает полное слово за 240 нс и добавляет 260 нс на запись. [Принятый наземный пример и контракт №446](../t446-terrestrial-retention/README.md).

## Воспроизведение

Из корня репозитория передать каталог с тремя кэшами из поручения. Нужны Python 3.11+, NumPy, Numba, SciPy и зависимости штатного читателя GOES. Первая команда повторяет все девять историй. Для первой строки достаточно `--part sepem`. Без `--check` команды расчёта сохраняют ведомости. Результат проверен на Python 3.13.5, NumPy 2.2.4, Numba 0.61.2, SciPy 1.15.2. [Пути к исходным файлам и назначение](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/issues/186#issuecomment-6847527710).

~~~text
python experiments/t186-native-archive/archive.py --cache PATH_TO_TMP --check
python experiments/t186-native-archive/check.py
python experiments/t186-native-archive/sensitivity.py --check
python experiments/t446-terrestrial-retention/reproduce.py --check
~~~

На коротких искусственных историях отдельная реализация перебирает календарные проходы без ускоренного пропуска пустых интервалов и проверяет оба адреса, фронт +60 нс, три исхода наложения, край срока, число исправлений и полную цену. Фиксированные семена, контрольные суммы профилей, меток и результатов, обе границы выборочного среднего и неопределённые продолжения сохранены в [SEPEM](sepem.json) и [GOES](goes.json).
