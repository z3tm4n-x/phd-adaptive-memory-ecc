# Условная граница битовых меток полного слова

23.10.2026. **OWN RESULT — элементарная счётная граница, для рецензии.**
Численных сечений нет; физический пробел этой формулой не закрыт.
Назначение — проверить, обязательно ли требовать полный журнал масок.
Это не Q(T), не временной закон событий и не новая теория адаптации t=2.

## Определения и доказательство

При фиксированных частице `s`, энергии `E` и направлении `Omega` пусть
`mu(dM)` — неотрицательная мера сечения **одного родительского события**
по меткам M перевёрнутых хранимых битов двух установленных чипов.
Один и тот же внешний флюенс и геометрия используются во всех сечениях.
Переключения/многократные попадания разных родителей не сливаются в метку.
Механизмы отказа без такой битовой метки учитываются отдельно.

У принятого размещения `address=3*w+floor(p/16)`,
`chip=floor((p%16)/8)`, `DQ=p%8` множества активных позиций разных слов
не пересекаются. Для каждого кода берём его активные позиции A_w:
0..38 для n=39, 0..43 для n=44. Обозначим:

- `b_w(M) = |M intersect A_w|` — число перевёрнутых активных битов слова;
- `D_r(M) = sum_w 1[b_w(M)>=r]` — число слов с меткой веса не меньше r;
- `B_active(M) = sum_w b_w(M)`, `B_all(M) = |M|` — соответственно
  активные биты и все биты двух установленных чипов, включая padding/остаток.

Для любого M и целого r>=1 непосредственно:

`r*D_r(M) <= B_active(M) <= B_all(M)`.

Интегрирование по одной и той же неотрицательной мере даёт:

`sum_w sigma_mark(>=r,w) <= sigma_B_active/r <= sigma_B_all/r`,

где `sigma_mark(>=r,w) = integral 1[b_w(M)>=r] mu(dM)`,
а `sigma_B_all = integral B_all(M) mu(dM)`. Последнее — взвешенное
числом перевёрнутых битов **сечение всей установленной памяти** в cm²,
не сечение события и не сечение в пересчёте на один бит. Сечение события
«хотя бы одно такое слово» не больше левой суммы. Для одного слова тот же
верх допустим; делить его на W без дополнительного основания нельзя.

Если получен обеспеченный верх `sigma_B_all <= U_B`, то для r=2 имеем
`U_B/2`, для r=3 — `U_B/3`. Эти пороги относятся к меткам, которые из
чистого слова могут превысить t=1 или t=2. Они не учитывают накопление
от разных родителей и не заменяют расчёт состояния слова. Нижняя граница
по одной sigma_B в общем случае равна нулю: все метки могут быть одиночными.

## Что позволяет и чего требует граница

Не нужны равномерность по адресам, знание scrambling, независимость слов
или чипов. Межчиповые события разрешены: они просто входят в M целиком.
Сумма двух **совместимых с этой геометрией** верхов битового отклика чипов
даёт верх `U_B` по линейности; независимость здесь не требуется.
Отношение активной ёмкости к установленной не является допустимым
коэффициентом уменьшения верха без пространственного основания.

Требуются охват всех битов/механизмов заявленной битовой меры, тот же
part/revision и режим, энергии/частицы/углы, нормировка и основание верхней
границы. Измеренная средняя или подогнанная кривая сама таким верхом не
становится. Отказы SEFI/контроллера без битовой метки не покрываются.
Применение этих маргинальных верхов к высшим/смешанным моментам t=2
и закону родителей отдельно согласуется с #196; здесь оно не выполнено.

Защита: либо сечение к потоку **у памяти** плюс уже рассчитанный спектр
после 4 г/см² Al, либо эффективное `U_B` к внешнему потоку, уже содержащее
эту защиту. Без одного из этих совместимых входов свернуть границу нельзя.
Верх по углу может убрать неизвестную направленность отклика, только если
он обоснован на всех нужных углах и есть обеспеченный всенаправленный поток.
SREM L1, восстановленный при изотропии, сам такого верха потока не даёт.

**Результат для получения данных:** полные маски — достаточный, но не
единственный путь; совместимый численный `U_B` позволил бы получить грубый
консервативный верх групп полного слова. Сейчас отсутствует именно этот
физический численный верх, а не доказательство счётного неравенства.
