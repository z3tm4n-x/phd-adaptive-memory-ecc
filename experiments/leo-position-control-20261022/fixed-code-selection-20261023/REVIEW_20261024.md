# Приёмка отбора PR252 — 24.10.2026

**Решение:** принять ограниченный отбор двух архитектур и описание недостающих
входов. Подтверждённая физическая рабочая точка, миссионный Q(T), выигрыш,
временная реализуемость всего контроллера и его полная цена не установлены.
Это завершённый этап #206, а не завершение карты или доказательство
невозможности адаптации. Обязательных исправлений поставки нет.

Проверен исходный head `dd4ff33dea1613afb937d56500a5b9fb5f6249c4`.
Оркестратор прочитал REPORT, исходные параметры и проверяющую программу,
сопоставил выводы с первоисточниками и отдельно повторил расчёт.

## Что принято и чем проверено

- Для 0,5 МиБ полезных данных одна RT4G150 недостаточна при штатном ECC:
  даже идеальная упаковка всех LSRAM и µSRAM даёт
  `(209·1024 + 210·64)·18/8 = 511776` байт. Конструкция на двух приборах
  использует 262144 полных слова (24,18), по 128 LSRAM на прибор;
  полезные разряды, заполнение и ECC учтены раздельно.
- XQRKU060 в режиме (72,64) размещает тот же банк в 65536 полных словах,
  128 блоках BRAM36. Это предпочтительная архитектурная иллюстрация из
  двух проверенных кандидатов; запас ёмкости не является запасом времени.
- В обоих случаях исправленный выход ECC не исправляет массив. Для
  выбранного обслуживания нужна завершённая запись исправленного полного
  слова по связанному с наблюдением адресу. Режим с обнаруженной двойной
  ошибкой не разрешает считать выход исправленными данными.
- RTG4: нормировка `1599/(5.10158e11·20·1024·18)` воспроизводит протонное
  сечение на обследованный бит. Это не отклик всех 24 позиций слова.
  NASA испытывала LSRAM как 65536×8 без EDAC; её многобитовые результаты
  не позволяют положить прямые неисправимые события равными нулю.
- DS882 даёт типичную модельную частоту BRAM, отдельно указывая условия
  CREME96, экранирование и доверительный интервал. Она не задаёт временной
  верх для десятилетней миссии. Число для SEFI конфигурационной памяти
  не перенесено на неисправимые состояния слова BRAM.

Адресная проверка первоисточников: RT-UG, таблицы 2.1–2.2 и §2.1.7;

## Научное следствие и решение о продолжении

Причина остановки — отсутствие в проверенных источниках совместимого
полного отклика и временного класса среды для заявленного Q(T).
Это содержательное требование выбранной модели, а не требование лётной
квалификации. Неизвестность отдельного лота сама по себе не запрещает
расчётный пример. Числа PR250 для (39,32) на (24,18)/(72,64) не перенесены.

Рассмотрены три пути: локально восстановить недостающие границы (нужных
данных сейчас нет); выбрать третью архитектуру (нет конкретного источника,
который заранее закрывает найденный разрыв); изменить область главного
примера (сохраняет результат метода, ослабляет физический практический вывод).
Новый поиск приборов и запросы файлов Ивану не назначаются.

**Решение Ивана 24.10:** основной численный пример и карту
строить в явно заданной расчётной модели; XQRKU060 оставить отдельной
архитектурной иллюстрацией. Не заявлять для неё физический миссионный Q
или перенос выигрыша PR250. Иван прямо подтвердил вариант «расчётный
пример и отдельная архитектурная иллюстрация». Требование получить
подтверждённый физический миссионный Q для основного численного примера
снято; цель содержательного выигрыша и смысл Q в модели не изменены.
