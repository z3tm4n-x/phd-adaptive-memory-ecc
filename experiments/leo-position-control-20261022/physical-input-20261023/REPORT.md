## Что изменилось после прежней поставки

[Публичная форма PSI](https://srem.psi.ch/cgibin/srem_data_sec.pl) и её
страницы формата/покрытия действительно читаются веб-инструментом.
Интерактивный браузер на этом хосте отвечает ERR_CONNECTION_CLOSED;
стандартный curl/Schannel — ошибкой TLS-handshake, HTTP 000, 0 полученных
байтов. Запрос выбранных суток через форму успешно не отправлен; CDF,
его имя L1 и хэш отсутствуют. Это разные уровни доступности, не всеобщий
отказ архива. Сертификаты/авторизация не обходились.

[Каталог PROBA-1](https://srem.psi.ch/static/proba1_datacoverage.shtml)
позволил сделать запрос конкретнее: 28.09.2002 — 1 мин, 27.09 — 1399 мин,
26.09 — 1440 мин. Для проверки одного резервного ряда выбраны **26.09.2002,
L1**, с исходными эфемеридами, потоками, энергиями и quality. Наличие 1440 мин
в каталоге не подтверждает непрерывность или качество L1. Поля/единицы
[описания V0](https://srem.psi.ch/static/proba1_dataformat.shtml) записаны
только как ожидаемые метаданные, не как уже проверенное содержимое L1.
Дата основного SAC-C-кандидата не менялась.

Для SAC-C/KM найден адресный новый маршрут:
[диссертация Petit (2006)](https://depozit.isae.fr/theses/2006/2006_Petit_Sophie.pdf).
Индекс указывает таблицу состава SAC-C с суффиксами/date code. Полный PDF
не получен (web 502, urllib TLS EOF); параметры по фрагменту индекса не
приняты. Три прежних PDF не переаудировались. Адресный поиск не дал
численного совместимого SAC-C-пакета; это не доказательство его отсутствия
у держателей. Контакты с держателями не запускались.

Дополнительный маршрут ESA ODI вернул HTML вместо архива; он не обозначен
ни данными, ни выполненной установкой/выгрузкой. Повторять сетевые отказы
циклически не рекомендую. Все наблюдения доступа и значения UNKNOWN
записаны в [input-status.json](input-status.json).

## Что ещё нужно для вычисления

Два ближайших препятствия независимы:

1. **Сам численный орбитальный ряд:** SAC-C с экспозицией/качеством либо
   выбранный PROBA-файл. Открытая форма, каталог и график не заменяют ряд.
2. **Отклик конкретной памяти и перенос к полному слову:** таблицы событий
   одной KM684000 по частице/энергии/углу/кратности, с привязкой к ревизии
   и размещению; либо обеспеченные консервативные границы на полном слове
   длины 39/44 бит.
   Сечение суммарного числа перевёрнутых битов не восстанавливает закон
   групп. Один PROBA-файл этот пробел не закрывает.

[CHAIN.md](CHAIN.md) показывает всю связку, единицы и минимальные способы
получения каждого звена. Дополнительно нужны согласованная однократная
защита 4 г/см², остаточные компоненты и совместный 10-летний класс/моменты.
Требовать обязательно полный сырой журнал излишне, если уже есть нужные
обоснованные границы; требовать новую транспортную кампанию вне задания.
Ни один отсутствующий вклад не заменён нулём.

Рассмотрены три уровня действия:

- **Локальное получение данных:** один экспорт из работающей сессии PSI и
  существующие таблицы отклика. Это самый узкий следующий шаг; новых моделей
  не требует. Риск — даже корректный L1-файл не закрывает отклик и весь срок.
  Срок получения извне неизвестен; ближайший выход — проверка самого файла.
- **Другая архитектура управления:** t2/OFF или заранее рассчитанное
  расписание. Принятый операционный счёт сохраняется, но численная
  достаточность всё равно зависит от той же физической цепочки. Пересчёт
  без неё не уменьшит неопределённость, поэтому сейчас не запускается.
- **Другая рабочая точка:** разрешённый PROBA-1 вместо SAC-C меняет источник
  орбитального ряда, но не создаёт отклик KM. Проверяется только один день;
  окончательная замена примера пока не рекомендована. Изменение W, T или ε
  не устраняет неизвестную нормировку и потребовало бы изменения постановки.

**Рекомендация:** сначала получить один указанный файл через существующий
рабочий доступ и полный первоисточник/таблицы отклика; оба физических
кандидата пока сохранить условными. Обещать дату физического расчёта до
получения этих данных нельзя.

Поскольку вход ещё недостаточен, Q_OFF44, Q позиционного правила и
выигрыш не рассчитывались. После получения достаточного входа порядок
остаётся: сильный код/OFF и обязательная цена приложения → постоянные
режимы/расписание → позиционная адаптация. Коэффициенты старого v4,
1.066372×/1.196370× и профиль нового применения #186 не перенесены.

## Запрос, проверка и следующая передача

Готов [конкретный запрос Ивану](REQUEST_TO_IVAN.md): одна миссия, один
уровень, одни сутки, оригинальный файл/архив и ссылка выдачи. Иван подтвердил
23.10, что сохранённых SREM-файла и PDF Petit у него нет. Поэтому следующий
шаг требует получения файла, а не поиска уже названного локального пути.
Токен/пароль запрашивать не нужно. Необязательный второй файл — полный
Petit (2006) для проверки привязки испытаний к памяти. Готовый совместимый
SAC-C-пакет, если появится, имеет приоритет.

После получения файла: SHA256/размер/уровень; CDF-тип времени и UTC;
монотонность/дубликаты/пропуски; ECI и единицы позиции; размерности
каналов, энергия/поток/угловая нормировка; quality/fill и экспозиция.
Маски не заполнять, фон не занулять. Перекалибровку L2 и связь с SEPEM
указывать явно. Затем адресный вход #196, без повторного допуска окон.
Численная проверка файла **ещё не выполнена**; парсер неизвестного файла
и искусственные тестовые данные не выдаются за её замену.

Проверки этой документальной поставки: JSON разобран, ссылки на локальные
артефакты существуют, сохранённые W/T/epsilon/код/нагрузка сверены с принятым
входом, diff не затрагивает принятые файлы. Нового численного прогона нет.
Повторить синтаксическую проверку статуса можно из корня репозитория:

```text
python -m json.tool experiments/leo-position-control-20261022/physical-input-20261023/input-status.json
```

Команда воспроизводит только чтение зафиксированного статуса, не физику
и не сетевую доступность в другой момент. Исходный файл, если будет получен,
должен получить отдельный хэш и проверяемый разбор в этой ветке.
Срез 30.10 и вывод 06.11 сохраняются как контрольные точки; наличие физического
примера к ним не объявляется доказанным. Научная приёмка отдельно.
