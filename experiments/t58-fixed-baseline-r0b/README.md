## Суть для автора

- Реализованы исходный U/C-сертификат, до 42 ветвей и весь заданный диапазон тактов.
- Корни и вероятности ограничены направленно; пограничные такты дополнительно решаются точной рациональной арифметикой.
- Проверены подготовка, конечные окна, налог, пик, FIFO и применимые нижние границы.
- Восстановлены 43824 часа старого ряда; единицы — ожидаемые инверсии массива за час. 148 интерполированных часов не скрыты.
- Исходная сетка MAP пересекает **радиационно-ресурсную** границу в объявленной условной модели, не только предел длительности блока.
- Для W=262144, 64 Мбит/с, налога 1% предъявлен U-период 20.18037184 с диагностического Λ.
- Для W=1935832 даже при 256 Мбит/с и налоге 1% lower ≥0.0113836583418>0.01 исключает **только заявленный постоянный U-класс диагностического Λ**.
- Физическое покрытие Λ/Θ, полный закон меток и исполнитель не квалифицированы. Преимущество адаптации и исключение C не заявляются.
