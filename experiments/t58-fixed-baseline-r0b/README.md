# T58 — постоянный сертификат и входы R0-B

Issue #58; база `7f42f356c89b09d69e5c9d13ded0ffdd6bd0ddb1`. Ветка `t58-fixed-baseline-r0b`.
Спецификация T52: `f7180c5b99da0a16db7195ddf407e1fea5029488`, рецензия #56 пока не опубликована.
Это начальная фиксация области и точек **до численных расчётов**.

## Суть для автора

Реализуется достаточный сертификат постоянного U/C и отдельные необходимые тесты.
Исходная сетка MAP не меняется. Максимальный сертифицированный период не будет
назван истинным оптимумом. Исторический ряд не становится будущей границей Λ.
Интенсивность масштабируется вместе с числом полных 39-битных слов.
Отказ upper и достаточного FIFO-теста не исключает класс.
Числа остаются условными по явно заданным входам; итоговый допуск зависит от #56.

## Протокол до расчёта

Конфигурация фиксирует 54 сочетания W/R/налога и все 1458 сочетаний исходной
ресурсной сетки. Основной U: полный сервис c=39/R_eff, расходы до конца T,
включая время после скрытого превышения; конечные окно/проход учитываются.
Сначала восстанавливаются календарь, I1/I2 и происхождение старого ряда.
Исторические 5 с / ~9.07 с и 1+CV² не становятся робастным соперником.

Для небольшой таблицы берутся крайние пороги I2 и ближайшие пороги с обеих
сторон исторического I2 и диагностического S2 класса редкости; дубликаты
убираются, равенства разрешаются порядком W/R/налога. Пик 5%, h=1 мс,
задержка 3 мкс для этой проекции; полная исходная сетка сохраняется в результатах.
Ни одно правило выбора не использует результаты адаптации.

Диагностический класс: B равен максимуму модельного ряда, bbar — максимуму
восстановленного фонового компонента, FS — экспозиции положительного превышения
над bbar. Это условный исторически привязанный класс, **не физическое покрытие**.
Чистое начало, сервис без уязвимости и договор приложения из config — отдельные
исследовательские допущения, не свойства изделия. Параметры физического класса null.
Рост будущего класса не назначается по скачкам часовых средних.

Верхний тест с ресурсом → предъявлен допустимый постоянный в объявленной модели;
нижний выше полного допуска → исключён только её доказанный постоянный класс;
иначе → неразрешённо. При отсутствии физических оснований выдаются критические
диапазоны параметров и точный вопрос автору. Новая кампания/RTL/MC/T2,
адаптивное сравнение и изменения MAP/STATUS/RES не входят в работу.

Будут поставлены код, проверки, воспроизводимая команда и таблицы в этой папке.
