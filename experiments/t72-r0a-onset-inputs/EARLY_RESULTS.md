## Суть для автора

Есть исполняемый причинный long/short кандидат с параметрическим монитором
и дополнительными проходами по первым ERR. Для согласованной условной Θ
подстановки дают риск ниже10^-3 и тихую цену ниже1% для обеих защит.
Положительная точка требует именно полного38 direct upper10^-4, чистого
U≤90 нс, указанного монитора и проверяемого #73 сопряжения расписания.
Эти предпосылки **не установлены** имеющимися физическими upper T68.

| Защита | Риск upper, условный | Тихой налог upper, H=5 с | H=10 с — не проходит | Постоянный ≤1%: риск lower |
|---|---:|---:|---:|---:|
| 2,5 г/см² | 0,000952531 | 0,989391% | 1,078755% | 0,00758767 |
| 3 г/см² | 0,000583699 | 0,946956% | 1,030877% | 0,00378854 |

Длинный/короткий периоды6 с/50 мс, h=10^-4 с^-1 солнечного полного38,
L=2 с, H=5 с. В налог включены ложные тревоги1/сутки, ERR фоновых инверсий,
остаток прошлой вспышки, цена монитора0,01% и максимальная работа после
скрытого отказа с вероятностью≤R. Полный короткий проход занимает49,80732 мс
с окнами приложения. Средний налог пика94,37184%; peak bound на1 мс94,827%.
Для **предлагаемого** arrival envelope из contracts.md delay≤2,85 мкс;
реальный envelope и предел пика ещё должны быть заданы автором.

Переход10→5 с — явное изменение метода после выявленного дефекта цены,
не замена данных. Сетка содержит оба варианта. Без монитора гарантия этой
точки не утверждается; отсутствие ожидаемого счёта не объявляется
невозможностью всех счётчиковых методов.

## Что решает исход

- При H=5 с максимальный c по тихому бюджету:91,0800 /95,4337 нс;
  общая сетка10 нс оставляет90 нс. Известный upper старого исполнителя
  240,512 нс сюда не подходит. Номинальные45+45 нс сами по себе WCET не дают.
- При L=2 с ростовой ceiling на длинных интервалах v=0,0002008 с^-1;
  допустимый по риску ceiling≤0,000415005 /0,002862294 с^-1. Это граница
  условного теста, не оценка физического внутриминутного роста.
- T68 data32 верхние прямые экспозиции A0=0,0153663/0,0122996, R=0,00346309/
  0,00277254 не доказывают требуемый full38 upper10^-4. Точечные L1≈3·10^-5
  не превращаются в upper. Запрос full38/ERR/U/канала — contracts.md§5.
- Условный мониторный поток должен быть экзогенен к родителям памяти для
  выбранной усиленной формулы. Это отдельный предмет проверки #73.
