# T72 — адресное подтверждение T73, приложение Ж.3

## Суть для автора

Проверен **новый научный SHA `3ad0462eac34d47176a6e1b36052855114a508df`**
PR #78. Численная синхронизация подтверждена: четыре набора нового JSON,
восемь строк по двум защитам, исправленная область фазового края и сильный
постоянный соперник согласованы с повторным расчётом. Непредусмотренных
численных расхождений не обнаружено. Изменены только два описательных поля
`mandatory_slots`: 129→85; исполняемый календарь уже использовал 85.

34 теста прошли. Положительный протокол для **7ed0f6c** на инженерном
**426704a12cffddf01463ef11a21c1eaa20baee05**, `RESULTS.md`, прежние
входы/таблицы и код расчёта сохранены без изменения. Это новое инженерное
подтверждение, не замена SHA в старом отчёте и не научная рецензия #74.
Инженерный SHA этого дополнения фиксируется вместе с научным в PR #77:
протокол внутри коммита не содержит самоссылочного SHA.

## Объект, метрики и воспроизведение

CY62167 full38, W=524288, ГСО, T=315576000 с, ε=10⁻³, защиты 2,5/3 г/см².
Все четыре области параметров сохранены раздельно; каждое сравнение
адаптивного и постоянного U использует одинаковую среду, полный код,
начальное состояние и договор обслуживания. Цена — ожидаемая занятость
за объявленное окно, включая работу после скрытого отказа. Возвращения
требуют дополнительного T_Q≥0,9T, K_Q≤1000, не следующего из флюенса.

```bash
python -X utf8 -B experiments/t72-r0a-onset-inputs/confirm_t73_sync.py --out ../t72-sync-3ad0462
```

Для публикации той же командой задан `--out experiments/t72-r0a-onset-inputs/outputs/sync_3ad0462`.
Python 3.12.14, NumPy 2.3.5; новых зависимостей нет. Режим UTF-8 явно задан
для Linux/Windows. Команда не обращается к сети и не открывает исходные
GOES. Временный повтор старых таблиц нужен лишь для сравнения; сохраняются
новые таблицы и лог. Контроль хешей трёх научных файлов выполняется до
расчёта; копии побайтово совпадают с Git-объектами закреплённого SHA.

Интервалы `lower/upper` — направленное десятичное представление значения
формулы, **не** двусторонний доверительный интервал физического риска.
Решения принимаются рационально до округления. Перенесённый `risk_upper`
остаётся верхней оценкой; `fixed_cost_lower` — нижней ценой предъявленного
расписания, не всего класса. Уровни ошибок покрытия не переназначены:
в T73 шесть квот по 10⁻⁶; расширение T72 сохраняет четыре квоты по 10⁻⁵
и явные дополнительные δ_exec=α_M=10⁻⁶, D_*=10⁻⁴.

## Фазовые края и постоянный соперник

Произвольные фазы: повторён контрпример **16 против 24** для ошибочного
переноса 2c/T. Безопасный край — 2Wc⁺/T; необходимый период вычислен именно
по `E3_arbitrary_phase_tau_min_s`. Старые `E3_tau_min_s` и
`T58_class_risk_lower` оставлены историческими полями, но не используются
здесь для обоснования произвольных фаз. Дополнительно проверены 23062
однословных окна; суммирование по W не усиливает край до 2c/T.

| U | Направленный интервал τ_min_any, с | Требуется J | Использовано J₀ |
|---|---:|---:|---:|
| 91 такт | [4,77097294553110; 4,77097294553111] | 24268 | 24540 |
| 90 тактов | [4,71854467297224; 4,71854467297225] | 24538 | 24540 |

N_cell=25732055040. Нижние риски свидетеля после δ_exec по-прежнему не
меньше 0,0075866738 / 0,0037875439 для двух защит. Это исключение
объявленного детерминированного постоянного полного U при налоге ≤1%,
не произвольных расписаний/рандомизированных смесей и не физическая оценка.

Парное размещение: для N=W/2, начал floor(iM/N), занятых блоков длины 2c
точно перечислены экстремумы D(t)=A([0,t])−(2Nc/M)t за период. Проверены
неперекрытие и усиленный межкадровый зазор с ξ⁻/ξ⁺. Размах D≤2c;
его периодичность и кусочная линейность дают край на любом вещественном
окне, а не только на перебранной сетке. Независимая прямая интеграция
17168 окон в 82 малых календарях согласовалась с формулой остатков.
**Полная занятость блока** — условие нижней цены; upper WCET сам по себе
этого не даёт. Полный перебор не является новой физической квалификацией.

M заново найден по точному S₂ и проверен независимой целой частью
отношения бюджета к наклону. M/M+1, пик, FIFO, направления цены проходят
в восьми строках. Наибольший M — край достаточного сертификата, не
истинный оптимум. Кадры 279/560 сохранены как исторические кандидаты T73;
на более широкие бюджеты автоматически не переносятся.

## Канал, LOW, задержки и сохранённые отказы

Повторены прежние 27 тестов: 1024 геометрии / 6714112 пар, 2400 масок,
66 конечных FIFO-трасс, полосы цены, пропуски, плохие окна, overflow/NaN,
необратимость решения и миссионный счётчик окон. Новые семь тестов
включают все Y=0…18500 и Y=0…840000 (858502 принятия, два отказа k+1),
φ-сертификаты, последний допустимый такт задержки и следующий недопустимый
для обоих разных мониторов. Конечные FIFO-трассы не заменяют гарантии (11).

Ревизии требуют a_M=10¹¹, A_M/a_M=1,001, фактическую доставку **вместе
с вычислением ≤9 мс** и совместный U-WCET≤89,9991 нс. При физическом
90 нс запас отрицателен: −0,0009 нс. Поэтому совместный договор не
объявляется выполненным по номинальным 45+45 нс. LOW-запас 5,46134554179;
d_safe≥0,01260606509439 с; все требования остаются условными.

|---|---|
| Расширенный T72, 2,5 г/см² | Риск 0,0010755139903965535>ε; даже без двух добавленных квот остаётся отказ |
| Ревизия 1, удержание 5 с | Верх цены возвращений 1,055678% / 1,019004%>1% |

Ревизия 2 не меняет риск ревизии 1; изменены только заранее объявленные
удержание и полоса цены. Усиленный монитор, full38/ERR, совместное покрытие
Θ и U остаются неквалифицированными входами; запрос из `contracts.md`
сохраняется. Новых отказов при синхронизации не найдено. GOES не повторялся;
принятые пакеты, теория, RTL и main не изменялись. Следующий шаг — закрепление
пары версий оркестратором и независимая рецензия #74, не самостоятельное принятие.
