## Суть для автора

T67 и T68 переиспользуются без изменения. Разделены диагностический ряд
32 data bits/10 мм Al и условная гарантия полного38/2,5–3 г/см². Первый
пакет задаёт воспроизводимые определения спокойного начала и повторных
подъёмов, ненулевой прямой SMU-бюджет и интерфейс для причинного long/short
метода с дополнительным монитором. Полной гарантии и выигрыша пока нет:
они требуют проверки #73 и принятия условных full38/ERR/U/monitor входов.

Этот PR — канал ранних материалов для оркестратора/#73. Новых агентов не
запускал; запросы изготовителю/NOAA/COSRAD самостоятельно не отправлял.
Далее сюда поступят таблицы, код, тесты и единая команда повтора. Принятые
пакеты, MAP, STATUS, паспорт и main не изменяются.
