# T37: черновик рецепта класса интенсивностей Λ

Задача [#37](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/issues/37).
База: `2869b02439ea015ab61fdf64fa173a9dce9b97bd`. Начало: 26.09.2026.
Уровень — разведочный черновик входов для R0/R2/R1 и R4/R5.

## Итог для автора

Подготовлен прослеживаемый [рецепт Λ₀](recipe.md): спокойный уровень,
расчётный пик по проверенной копии ОСТ, рост, запасы, наблюдение и переход
к памяти. [Таблица источников и недостающих входов](inputs.md) отделяет
исторические оценки от проектных границ. [Уточнение запроса COSRAD](cosrad_request_draft.md)
подготовлено для Ивана, не отправлено.

Прочитана первичная копия ОСТ 134-1044-2007 — переиздание по изменению №2
с изменением 1; точные пункты, страницы и SHA-256 приведены в таблице источников.
В Б.2 ψ относится к превышению за календарный срок; пик и флюенс различаются.
Секундную границу роста и общий бюджет покрытия среды из этих положений не получаем.

Ограниченная обработка воспроизвела следующие **описательные максимумы
сохранённого модельного отклика**, не верхние границы физических событий:

| Ряд, центральная оценка, исходная допустимость | Шаг, с | Допустимых пар | max положительной разности / шаг, инверсий/(бит·с²) |
|---|---:|---:|---:|
| GOES-16, 08–12.10.2024, 3 мм Al | 300 | 1 439 | 2,9736771·10⁻¹¹ |
| Тот же ряд, полные часы | 3 600 | 119 | 9,9296638·10⁻¹³ |
| GOES-19, январь–февраль 2026, 1 мм Al | 300 | 16 963 | 4,4573472·10⁻⁹ |
| Тот же ряд, полные часы | 3 600 | 1 404 | 3,9472803·10⁻¹⁰ |

Фильтрация и временное усреднение меняют выборку и её экстремумы.
Параметры проектного класса B/G, запасы, ошибка покрытия среды и событийные
метки оставлены символическими. Гарантия пока условна на принадлежность
обоснованному классу; численного сертификата R0 и оценки экономии нет.
Первый момент битовых инверсий не переименовывается интенсивностью родительских
событий. Принятые данные/RES, MAP, STATUS и старые сценарии сохранены.

## Повтор и проверки

Из корня репозитория, Python 3.11+ и Git, без установки зависимостей:

```bash
python -B experiments/t37-lambda-recipe/reproduce.py
```

Команда выполняет минимальные тесты, проверяет четыре исходных SHA-256,
читает неизменяемые Git blobs заданной базы, вычисляет диагностику E/W/central
и сравнивает её с [summary.json](summary.json). Нормализация CRLF в локальном
checkout не меняет вход расчёта. Нужна история с указанным base SHA;
подмодули/первичные NetCDF/COSRAD для этой команды не требуются.
Проверена среда CPython 3.12.14. `requirements.txt` фиксирует отсутствие
сторонних пакетов. `--write` пересоздаёт только `summary.json` этой задачи.

14 тестов проверяют разности, версии, пропуски, пустые значения, отсутствие
подстановки нуля, полные часы, UTC, нормировку и отклонение неверного хеша.
Два главных пятиминутных максимума отдельно пересчитаны рациональной арифметикой
по сериализованным значениям с проверкой времён достижения. Независимой научной рецензии
пока нет. Для нормативных выводов нужна исходная копия PDF, указанная в inputs.md;
она не включена в команду обработки GOES и не дублируется в Git.

## Объём обработки, зафиксированный до расчёта

Переиспользуются сохранённые ряды GOES-16/GOES-19 и запрос COSRAD.
Большая загрузка данных, транспорт, COSRAD, моделирование отказов, оптимизатор,
T2 и RTL не выполняются. Принятые файлы, MAP и STATUS не изменяются.
Сравнения алгоритмов и метрики их стоимости здесь нет; ресурс будущего метода —
общая шина, определения R0 остаются решениями автора.

Диагностика: число доступных/допустимых записей, пропуски, версии и флаги;
минимум, медиана, максимум и максимальные положительные разности соседних
значений на исходном временном шаге; повтор после неперекрывающегося усреднения
по полным часам. Разности не строятся через пропуски и смену версии обработки.
Результаты относятся к сохранённым модельным первым моментам битовых инверсий,
а не к измеренным непосредственно интенсивностям физических событий памяти.
Флаги и ретроспективные подстановки рассматриваются отдельно.
Случайной выборки, доверительного интервала и гарантированной границы роста
из этого расчёта не создаётся. Seed не требуется.

Готово: инвентаризация и таблица входов, параметрический рецепт Λ₀,
одна команда повторения фактической обработки, тесты, недостающие входы,
уточнение запроса COSRAD для автора. Если обоснования границы нет, она остаётся
символической и гарантия условна на принадлежность исходному классу.
Наблюдаемый максимум сам по себе не принимается проектным пределом.

пример, но не символическую работу. Решение и слияние — PI. PR остаётся черновым.
