# ГСО, сфера Al 3 г/см². Свёртка приложения Л ОСТ и экспорта COSRAD

База `34a6875ee0803e46a47e520d6f4bd5e2008ecb80`. Сверяем [постановку №458](../../thesis/GEO_NATIVE_DESIGN_CASE.md) для той же области 0,125 МиБ и того же порта №456–457. Регистрация относится к дополнительной проверке среды. Состав четырёх таблиц, условия экрана и отклик закреплены до численного сравнения.

- ОСТ 134-1044-2007, изм. 2, таблицы Л.3.1.2, Л.3.1.4, Л.3.2.2, Л.3.2.4. Столбец 3,0, значения максимальной дифференциальной плотности в секунду. Копия PDF SHA-256 `232c84bf7fb6c2d3aec11c44827bcf01a6b6964366a8d0059ff36cd5b143a9e1`.
- COSRAD — сохранённые `sp_x, sl_x, gp_x, gl_x` для той же защиты. Для обоих источников используются функции отклика и интерполяция T141, геометрический множитель 1, полное эталонное число разрядов 19 922 944, солнечная отсечка ЛПЭ 32,6 МэВ·см²/мг. Раздельно считаются собственная табличная область, пересечение диапазонов и вклад за его пределами.
- Спектры задают фон и солнечную добавку. При проверке истории сохраняем архивный протонный ряд, явно указываем допущение о синхронной тяжёлой составляющей и об обращении с пропусками. Сопоставляем с прежними квотами экспозиции, роста и суммарного подъёма. Вклад отсутствующего спектра и совместную вероятность не назначаем по четырём максимумам.
