Ограниченная инженерная проверка завершена 02.10.2026; физическая

## Суть для автора

T68 воспроизведён: его нулевые наблюдения относятся к data32, а не всему 38.
Флюенс восстановлен из числа инверсий и модели чувствительности, не измерен
независимой дозиметрией. При выборе группировки по данным требуется
совместное покрытие. Для full38 неизвестны шесть check-разрядов и заводская группировка;
для внешнего 39 — совместные DQ/ERR после внутренней ECC, а не raw-SMU.
Увеличение флюенса уменьшает статистический верх только в покрытой области;
пробелы углов, скрытых разрядов и закона регистрации этим не закрываются.
Точный запрос и количественные условные требования подготовлены, никому
внешнему не отправлены. #80/#82 получают неизвестное полное D*, не ноль.

|---|---|---:|---|
| Внутренний 32+6;2,5 | 0 в 45/55 групп;3 однострочные, actualW/check неизвестны | 0,00346309 /0,0101278 | неизвестен; недостаточно данных |

| Внешний 39;2,5 | Логическое 16+16+7, H_low/H_pin; нет ECC-on DQ-выборки | неприменимо как оценка внешнего 39 | неизвестен; недостаточно данных |
| Внешний 39;3 | То же; все семь check учтены, межчиповая независимость не принята | неприменимо как оценка внешнего 39 | неизвестен; недостаточно данных |

¹ θ_F=0,3; семья 55×6 узлов, только при перечисленных модельных/статистических
условиях. Не совместное 95%-е покрытие физической Θ. Полная таблица σ,
экспозиций, покрытия и применимости — `outputs/architectures.csv`.
Сечение data32 при LET=57: условная точечная 95% upper 4,76858815·10⁻⁴ см²/массив;
F57=8974,60086 см⁻², F_eff=6282,22060 см⁻²; наблюдение не покрывает все 38/39 позиций.

Для прежней data32-оболочки и будущего нулевого счёта, θ_F=0,3,
совместных 55×6 границ, D₀≤5e−5 потребовал бы **добавочный** F≥7362094,684 /

квалификация full-word. Для неё нужны коэффициенты и непокрытый остаток
из [запроса](request_for_author.md); неизвестные оставлены null.

## Повтор

Из корня репозитория, Python 3.12, версии в `requirements.txt`:

```bash
python experiments/t81-direct-architecture/run.py
```

Без сети/больших архивов: принятые таблицы и малый `calc_v18.zip` уже в Git.
Результат: `outputs/*.csv`, `handoff.json`, `protocol.json`, `tests.txt`.
Все 24 теста проходят: регрессии UR/UA0, независимые интегралы/Poisson-инверсия,
единицы, группировки, pinmap, корни, бюджеты и сохранение неизвестных.
Условия/выводы формул — [METHOD](METHOD.md). Карта и RES не меняются;
к приёму предлагается инженерный пакет, не новый физический RES.
