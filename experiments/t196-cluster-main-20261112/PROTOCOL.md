# Задача 1.3. Входы и критерии до численного расчёта

[Назначение автора, №196](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/issues/196#issuecomment-6829839547) · [Программа на исходном main 2fad665](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/blob/2fad665727c00ebf7f1943bbc560682623b13a96/thesis/WORK_PROGRAM_20261111.md#visibility) · [Основание 1.2, b7d6cf9](https://github.com/z3tm4n-x/phd-adaptive-memory-ecc/blob/b7d6cf91d5bd33df6c313536748be7dda87ed0f8/theory/t196-visible-parents-20261112.md).

**Один главный пример.** Берём принятую замкнутую карту 0,125 МиБ, $W=32768$ полных внутренних слов CY62167GE30-45 по 32+6 позиций. Для определённости половины слова $w$ имеют адреса ×16 $w,w+W$, слова $w=0,\ldots,W-1$ образуют кольцо. Этот выбор задаёт одну расчётную геометрию до результата. В обоих режимах обходятся все $A=65536$ адресов. Память чиста при старте, данные долгоживущие, приложение не записывает ни одну половину. $T=315576000$ с, $\varepsilon=10^{-3}$ для первого превышения в слове за срок от накопления, включая один раз $\delta=6\cdot10^{-6}$ на исключения исполнения. Прямой вклад относится к 1.4.

**Закон и наблюдения.** Интенсивность инверсий эталона $\nu(t)$ с⁻¹, на разряд $\nu/(38\cdot524288)$, на банк $R=Wc\nu$, $c=1/524288$. Независимые пуассоновские родители с интенсивностью $R/m$ при данном профиле, $m$ — среднее число разных затронутых слов. В каждом затронутом слове одна из 38 равномерных позиций, позиции независимы при заданной метке. Сначала смесь (одно слово с вероятностью 4/5, иначе два соседних) и пять соседних. Затем контроль №457 (равномерная пара разных слов), четыре и восемь соседних. У блока начало равномерно на кольце. Нормируем частоту родителей, гарантирующих достоверный ERR на пригодном префиксе, как $\lambda_{\rm вид}\ge\eta R$. Из 1.2 для смеси $\eta=(5W-4)/(6W)$, для блока длины $k\ge2$ и равномерной пары $\eta=1/k$. Историческая контрольная граница №457 использует $(W-1)/(2W)$. Множественные ERR одного родителя учитываются отдельно при оплате реальных записей.

**Общее исполнение.** Действуют №456–457, регистровое управление №460, первый полный проход, фазы обеих половин, слабая конечная запись, завершение в конце срока. $L=22{,}9376$ мс, уровни $2^i L$, $i=0,\ldots,8$, общая ячейка $256L$, нулевые пороги 5, 10, 19, 38, 75, 149, 298, 596. Для разрешения нужны полные отчёты к сечению. Потеря, неполнота и просрочка сбрасывают историю с частым шагом на первом возможном решении. Для физического переноса нужны свойства всех 38 позиций и записи, граница исполнительских исключений и основания для карты и меток. Достоверный ноль, остаток и смысл остановки берём из 1.2.

**Два множества профилей.** На той же карте в первом сравнении один постоянный период выдерживает весь $\mathcal A_U$ ГСО по №457, во втором — все принятые реконструкции SEPEM и GOES №459 с их заполнениями. Для архива сохраняем нижний фон $b$ исходного класса. Общие для всего множества верхние границы: $S_1=164372$, максимум опубликованных пиков с округлением вверх до $10^{-3}$ с⁻¹ и максимум опубликованных квот подъёмов с округлением вверх до целой с⁻¹ по всем строкам №459. Для $S_2$ берём минимум принятого общего верха и $b^2T+(B+b)(S_1-bT)$. Десятилетие SEPEM из №462 — нижний свидетель цены. Для всего класса свидетель — принятое начальное плато. Для смеси, пяти и контроля используем принятые нижние цены 1.2. Для четырёх и восьми повторяем именно критерий (3)–(6) и поиск целого $K$ из протокола 1.2 с новым распределением пересечения двух независимых равномерных блоков.

**Риск и достаточная видимость.** Подставляем $s=\eta Wc$ в (2) №457. Для каждого множества — свои общие $B,U,S_1,S_2$, прежняя сетка скалярного неравенства №449 (32 части каждого удвоения), та же рациональная мажоранта экспоненты. Требуем $q\le\varepsilon$ до округления. На $0<\eta\le1$ локализуем переход предъявленного вычислимого верха делением пополам до ширины $2^{-14}$, сохраняя значения с обеих сторон. Ветвь $\eta=0$ — предел этого сертификата. Сравниваем с максимальной доступной долей $1/m$ и отдельно показываем достаточную долю наблюдаемых родителей $\eta m$. Физическая вероятность может быть меньше верхней границы.

**Цена и решение.** Мера — худшее по одному и тому же множеству профилей математическое ожидание секунд защитного порта до $T$. Берём ведомость (4) №462 со своим верхом остановки. Истинные записи до остановки $H=(W+1)cS_1$; в цене сохраняем повторный ERR и хвост даже при провале достаточного теста. Для числа испорченных исправлениями общих ячеек проверим также верх по родителям: вне конечной полосы одного обязательного общего прохода исправления одного родителя относятся к одной ячейке, внутри — максимум к двум. Берём минимум доказанных верхов. Полосы с учётом допуска часов мажорируем заранее фиксированной периодической маской и квотой вариации. Если переход для двух ячеек не обоснован, остаётся $H$. $I\ge0$ — прочие испорченные ячейки до остановки в ожидании за срок, $X\ge0$ с — вся дополнительная занятость порта; базовая строка $I=X=0$ в регистровом исполнении. Публикуем секунды и процент срока, нижний множитель $F^-/C_\pi^+$ и запас $F^-/2-C_\pi^+$ с допустимыми $I,X$. Для непрошедших сравнений ограничим отношение с другой стороны через один допустимый постоянный период 93,4444 мс и обязательные общие проходы лестницы до $T$ на пути без остановки. Двукратный вывод требует одновременно допустимости и неотрицательного запаса для этого соперника.

Численный этап следует за приёмкой 1.2 на точной версии. Инженеру после 1.4 передаются для самостоятельной сверки те же входы, порог по обе стороны, значения двух свидетелей и обе ведомости на одной карте. Поставка — одна таблица, вывод и воспроизводимый расчёт в одном PR.
